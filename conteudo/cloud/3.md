**Infraestrutura como código** (IaC) é descrever servidores, redes, bases de dados e permissões em ficheiros versionados, em vez de clicar numa consola. Assim a infraestrutura é revista em pull requests, reproduzível e documentada.

## Terraform (declarativo)

```hcl
provider "aws" { region = "eu-west-1" }

resource "aws_s3_bucket" "fotos" {
  bucket = "minha-app-fotos"
}

resource "aws_instance" "web" {
  ami           = "ami-0abc123"
  instance_type = "t3.small"
  count         = 2
  tags = { Nome = "web" }
}
```

```bash
terraform plan     # mostra o que vai mudar, sem mudar
terraform apply    # aplica
```

O Terraform guarda um **estado** (o que criou) e calcula a diferença entre o código e esse estado: criar, alterar ou destruir.

## Ansible (configuração)

Terraform cria máquinas; **Ansible** configura o que está dentro delas, por SSH, com tarefas **idempotentes** (correr duas vezes dá o mesmo resultado):

```yaml
- hosts: web
  become: true
  tasks:
    - name: instalar nginx
      apt: { name: nginx, state: present }
    - name: nginx a correr
      service: { name: nginx, state: started, enabled: true }
```

## O plano

```python run
def plano(codigo, estado):
    acoes = []
    for nome, cfg in codigo.items():
        if nome not in estado:
            acoes.append(f"+ criar {nome}")
        elif estado[nome] != cfg:
            mud = [k for k in cfg if cfg[k] != estado[nome].get(k)]
            acoes.append(f"~ alterar {nome}: {', '.join(mud)}")
    for nome in estado:
        if nome not in codigo:
            acoes.append(f"- destruir {nome}")
    return acoes or ["sem alterações"]

estado = {"web": {"tipo": "t3.small", "n": 2}, "cache": {"tipo": "redis"}}
codigo = {"web": {"tipo": "t3.medium", "n": 2}, "fotos": {"tipo": "s3"}}
for linha in plano(codigo, estado):
    print(linha)
print(plano(estado, estado))
```
