Com dezenas de serviços em centenas de máquinas, ninguém arranca contentores à mão. O **Kubernetes** é um **orquestrador**: declaras o estado desejado («quero 3 réplicas desta imagem») e ele trabalha continuamente para que o estado real coincida.

## Objetos principais

- **Pod**: um ou mais contentores que partilham rede; a unidade mínima.
- **Deployment**: mantém N réplicas de um pod e faz atualizações graduais.
- **Service**: um endereço estável que distribui pedidos pelos pods.
- **ConfigMap / Secret**: configuração e segredos.
- **Ingress**: entrada HTTP do exterior.

```yaml
apiVersion: apps/v1
kind: Deployment
metadata: { name: web }
spec:
  replicas: 3
  selector: { matchLabels: { app: web } }
  template:
    metadata: { labels: { app: web } }
    spec:
      containers:
        - name: web
          image: minha-app:1.4
          resources: { limits: { cpu: "500m", memory: "256Mi" } }
          readinessProbe: { httpGet: { path: /saude, port: 8000 } }
```

```bash
kubectl apply -f web.yaml
kubectl get pods
kubectl rollout undo deployment/web     # voltar à versão anterior
```

## O ciclo de reconciliação

Cada controlador do Kubernetes é um ciclo: observa o estado real, compara com o desejado, age para reduzir a diferença. Se um nó morre, os seus pods desaparecem do estado real e o controlador cria outros noutros nós.

```python run
def reconcilia(desejado, real, nos):
    acoes = []
    vivos = [p for p in real if p["no"] in nos]
    for p in real:
        if p["no"] not in nos:
            acoes.append(f"perdido {p['nome']} (nó {p['no']} morreu)")
    n = len(vivos)
    while n < desejado:
        no = min(nos, key=lambda x: sum(1 for p in vivos if p["no"] == x))   # o nó menos ocupado
        novo = {"nome": f"web-{len(vivos) + len(acoes)}", "no": no}
        vivos.append(novo); acoes.append(f"criar {novo['nome']} em {no}"); n += 1
    while n > desejado:
        p = vivos.pop(); acoes.append(f"apagar {p['nome']}"); n -= 1
    return vivos, acoes

real = [{"nome": "web-0", "no": "A"}, {"nome": "web-1", "no": "B"}, {"nome": "web-2", "no": "B"}]
real, acoes = reconcilia(3, real, nos=["A", "C"])        # o nó B morreu
print(acoes)
real, acoes = reconcilia(2, real, nos=["A", "C"])        # reduzir para 2
print(acoes)
```
