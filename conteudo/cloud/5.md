Escalar é aguentar mais carga. **Vertical**: uma máquina maior (simples, mas tem limite e é um ponto único de falha). **Horizontal**: mais máquinas iguais atrás de um **balanceador de carga** (exige que os servidores não guardem estado local, como sessões em memória).

## Algoritmos de balanceamento

- **Round-robin**: um de cada vez, em ciclo.
- **Menos ligações**: para o servidor com menos pedidos ativos.
- **Hash consistente**: o mesmo cliente (ou chave) vai sempre para o mesmo servidor; ao adicionar um servidor, só uma pequena parte das chaves muda de sítio. Usado em caches e bases de dados distribuídas.

```python run
import hashlib, bisect

def h(s):
    return int(hashlib.md5(s.encode()).hexdigest(), 16)

def modulo(chave, servidores):
    return servidores[h(chave) % len(servidores)]

class Anel:
    def __init__(self, servidores, virtuais=100):
        self.pontos = sorted((h(f"{s}#{i}"), s) for s in servidores for i in range(virtuais))
        self.chaves = [p for p, _ in self.pontos]
    def __call__(self, chave):
        i = bisect.bisect(self.chaves, h(chave)) % len(self.pontos)
        return self.pontos[i][1]

chaves = [f"utilizador{i}" for i in range(1000)]
antes, depois = ["A", "B", "C"], ["A", "B", "C", "D"]
m = sum(modulo(k, antes) != modulo(k, depois) for k in chaves)
a1, a2 = Anel(antes), Anel(depois)
c = sum(a1(k) != a2(k) for k in chaves)
print(f"módulo: {m / 10:.0f}% das chaves mudam de servidor")
print(f"anel:   {c / 10:.0f}% das chaves mudam de servidor")
```

Com módulo, acrescentar um servidor baralha quase tudo (numa cache, é como apagá-la). Com o anel, só cerca de 1/4 muda: as que passam a pertencer ao novo servidor.

## Autoescala

Regra típica: se a CPU média passa 70% durante 3 minutos, acrescenta instâncias; se fica abaixo de 30%, remove. Também importam: **cache** (CDN, Redis) para não chegar sequer aos servidores, **filas** para absorver picos, e **réplicas de leitura** da base de dados.
