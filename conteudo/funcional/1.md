Na programação funcional, um programa é uma **expressão** que se avalia, e não uma sequência de ordens que alteram variáveis. A linguagem do curso é o Haskell (a mesma do LI1 da UMinho e do curso de Oxford). Instala o GHC com o [GHCup](https://www.haskell.org/ghcup/) e abre o interpretador com `ghci`.

## Expressões e avaliação

Em Haskell, tudo é uma expressão com um valor:

```haskell
ghci> 2 + 3 * 4
14
ghci> if 10 > 3 then "sim" else "não"
"sim"
ghci> let x = 5 in x * x
25
```

Não há `if` sem `else`: uma expressão tem sempre de ter valor. Avaliar é **substituir** até não haver mais nada a fazer:

```haskell
quadrado x = x * x

-- quadrado (2 + 1)
-- = (2 + 1) * (2 + 1)
-- = 3 * 3
-- = 9
```

Esta forma de raciocinar, substituir iguais por iguais, é o que vais usar para ler qualquer programa funcional.

## Funções

Uma função define-se com equações. A aplicação escreve-se sem parênteses nem vírgulas:

```haskell
-- media.hs
media :: Double -> Double -> Double
media a b = (a + b) / 2

maior :: Int -> Int -> Int
maior a b
  | a >= b    = a
  | otherwise = b

main :: IO ()
main = do
  print (media 4 7)        -- 5.5
  print (maior 3 9)        -- 9
  print (maior 3 (9 - 8))  -- 3
```

Corre com `runghc media.hs`, ou carrega no `ghci` com `:load media.hs`.

- `media 4 7` aplica `media` a `4` e depois a `7`. A aplicação tem a prioridade mais alta: `maior 3 9 - 8` é `(maior 3 9) - 8`.
- As linhas com `|` são **guardas**: a primeira condição verdadeira escolhe o resultado.

## Funções puras

Uma função é **pura** quando:

1. o resultado depende **só** dos argumentos;
2. não tem efeitos secundários: não escreve no ecrã, não altera variáveis globais, não lê ficheiros.

Em Haskell, todas as funções são puras. As variáveis não mudam de valor: `x = 5` diz que `x` **é** 5, para sempre. Isto dá uma propriedade forte, a **transparência referencial**: podes trocar `quadrado 3` por `9` em qualquer sítio do programa sem mudar o resultado.

Compara com Python, onde a mesma chamada pode dar resultados diferentes:

```python run
total = 0
def soma_ao_total(x):
    global total
    total += x
    return total

print(soma_ao_total(5))
print(soma_ao_total(5))
```

Esta função não é pura: depende de `total`, que muda entre chamadas. Prevê o resultado antes de correr.

## Erros comuns

- Escrever `media(4, 7)`: em Haskell isto é aplicar `media` a um **par**, e dá erro de tipos. Escreve `media 4 7`.
- Esquecer os parênteses em argumentos negativos: `abs -3` lê-se como `abs - 3`. Escreve `abs (-3)`.
- Tentar "mudar" uma variável com `x = x + 1`: em Haskell, isto é uma definição recursiva infinita.
