Haskell é uma linguagem **funcional**: não há variáveis que mudam nem ciclos `for`. Tudo são funções que recebem valores e devolvem valores. Parece estranho ao início, mas muda a forma como pensas em programas, e várias ideias suas (map, filter, imutabilidade) já estão em Python, JavaScript, Java e Kotlin.

## Um programa para ler: a média dos números positivos de uma lista

```haskell
mediaPositivos :: [Double] -> Double
mediaPositivos numeros
  | null positivos = 0
  | otherwise      = sum positivos / fromIntegral (length positivos)
  where
    positivos = filter (> 0) numeros

main :: IO ()
main = print (mediaPositivos [4, -2, 10, 0, 7])
```

Para experimentar sem instalar, há interpretadores online (procura "Haskell playground"). Com o GHC instalado: `runghc media.hs`.

## Como se lê

- `mediaPositivos :: [Double] -> Double` é a **assinatura**: recebe uma lista de `Double` e devolve um `Double`. Lê-se a seta como "para".
- As linhas com `|` são **guardas**: como um `if/elif/else`. `otherwise` é o "senão".
- `where` define nomes auxiliares, aqui `positivos`.
- `filter (> 0) numeros`: filtra os maiores que zero. `(> 0)` é uma função "está acima de zero?".
- Não há `return`: o valor da expressão **é** o resultado.
- `fromIntegral` converte o comprimento (inteiro) para decimal, porque Haskell não mistura tipos sozinho.

## Recursão em vez de ciclos

```haskell
somaLista :: [Int] -> Int
somaLista []     = 0
somaLista (x:xs) = x + somaLista xs
```

Lê-se: "a soma de uma lista vazia é 0; a soma de uma lista com primeiro elemento `x` e resto `xs` é `x` mais a soma do resto". Cada caso é uma linha. Este estilo (*pattern matching*) também existe em Python 3.10+ (`match`) e em Kotlin.

## Armadilhas

- Os erros de tipos do compilador são compridos: lê a primeira linha e a parte "Expected type / Actual type".
- A indentação conta, como em Python.
- Tudo é imutável: não "mudas" uma lista, crias uma nova.

## Exercício

O que devolve `misterio [3, 1, 4, 1, 5]`?

```haskell
misterio :: [Int] -> Int
misterio []     = 0
misterio (x:xs)
  | even x    = 1 + misterio xs
  | otherwise = misterio xs
```

??? Solução
Conta quantos números pares há na lista (`even x` é "x é par"). Só o 4 é par: devolve `1`.
