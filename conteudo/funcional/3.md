Em Haskell não há ciclos `for` nem `while`. Para percorrer uma lista usa-se **recursão estrutural**: dizes o que fazer com a lista vazia e o que fazer com uma lista que tem uma cabeça e uma cauda. A forma da função segue a forma dos dados.

## Como é feita uma lista

Uma lista ou é vazia `[]`, ou é um elemento seguido de outra lista: `x : xs`.

```haskell
[1, 2, 3]  ==  1 : (2 : (3 : []))
```

O operador `:` ("cons") junta um elemento à frente. É barato: não copia a lista.

## O padrão de recursão

```haskell
soma :: [Int] -> Int
soma []     = 0              -- caso base: lista vazia
soma (x:xs) = x + soma xs    -- caso recursivo: cabeça + soma da cauda
```

Avaliação, passo a passo:

```
soma [3, 5, 2]
= 3 + soma [5, 2]
= 3 + (5 + soma [2])
= 3 + (5 + (2 + soma []))
= 3 + (5 + (2 + 0))
= 10
```

Para escrever uma função destas, pergunta: **qual é a resposta para a lista vazia?** E, **se eu já tiver a resposta para a cauda, como obtenho a resposta para a lista inteira?**

## Mais exemplos

```haskell
-- listas.hs
dobros :: [Int] -> [Int]
dobros []     = []
dobros (x:xs) = 2 * x : dobros xs

pares :: [Int] -> [Int]
pares [] = []
pares (x:xs)
  | even x    = x : pares xs
  | otherwise = pares xs

pertence :: Eq a => a -> [a] -> Bool
pertence _ []     = False
pertence y (x:xs) = y == x || pertence y xs

inverte :: [a] -> [a]
inverte []     = []
inverte (x:xs) = inverte xs ++ [x]

main :: IO ()
main = do
  print (dobros [1, 2, 3])        -- [2,4,6]
  print (pares [1 .. 10])         -- [2,4,6,8,10]
  print (pertence 'x' "haskell")  -- False
  print (inverte "abc")           -- "cba"
```

## Recursão com acumulador

`inverte` acima é lenta: `++` percorre a lista da esquerda, e isso dá O(n²). Com um acumulador, fica O(n):

```haskell
inverte' :: [a] -> [a]
inverte' xs = aux xs []
  where
    aux []     acc = acc
    aux (y:ys) acc = aux ys (y : acc)
```

## A mesma ideia em Python

A recursão estrutural não é exclusiva do Haskell. Prevê o resultado e depois corre:

```python run
def soma(xs):
    if not xs:
        return 0
    return xs[0] + soma(xs[1:])

def maximo(xs):
    if len(xs) == 1:
        return xs[0]
    m = maximo(xs[1:])
    return xs[0] if xs[0] > m else m

print(soma([3, 5, 2]), maximo([4, 9, 1, 7]))
```

## Erros comuns

- Esquecer o caso base: a função entra em recursão infinita ou dá "Non-exhaustive patterns".
- Usar `head` e `tail` em vez de pattern matching: `head []` rebenta em tempo de execução.
- Confundir `x : xs` (elemento e lista) com `xs ++ ys` (lista e lista).
