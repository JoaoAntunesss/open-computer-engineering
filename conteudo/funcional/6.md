Algumas funções funcionam para **qualquer** tipo (`length`), outras só para tipos que tenham certas operações: `sort` precisa de saber comparar, `sum` precisa de saber somar. As **classes de tipos** dizem que operações um tipo suporta. São parecidas com as interfaces de Java, mas podem ser acrescentadas a tipos que já existem.

## Ler uma restrição de classe

```haskell
ghci> :type sort
sort :: Ord a => [a] -> [a]
ghci> :type elem
elem :: (Foldable t, Eq a) => a -> t a -> Bool
```

`Ord a =>` lê-se "para qualquer tipo `a` que seja ordenável". As classes mais comuns:

| Classe | Operações | Exemplos de tipos |
|---|---|---|
| `Eq` | `==`, `/=` | quase todos |
| `Ord` | `<`, `<=`, `compare`, `max` | números, `Char`, `String` |
| `Show` | `show` (converter para texto) | quase todos |
| `Num` | `+`, `-`, `*`, `abs` | `Int`, `Integer`, `Double` |
| `Fractional` | `/` | `Double`, `Float` |

## Derivar instâncias

Para tipos simples, o compilador escreve as instâncias por ti:

```haskell
data Naipe = Paus | Ouros | Copas | Espadas
  deriving (Show, Eq, Ord, Enum, Bounded)

-- Paus < Espadas                    == True  (pela ordem da declaração)
-- [minBound .. maxBound] :: [Naipe] == [Paus,Ouros,Copas,Espadas]
```

## Escrever uma instância à mão

```haskell
data Moeda = Euros Int   -- em cêntimos

instance Show Moeda where
  show (Euros c) = show (c `div` 100) ++ "," ++ pad (c `mod` 100) ++ " €"
    where pad n = if n < 10 then '0' : show n else show n

-- show (Euros 1205)  ==  "12,05 €"
```

## Criar uma classe

```haskell
class Forma a where
  area      :: a -> Double
  perimetro :: a -> Double

data Quadrado = Quadrado Double
data Circulo  = Circulo Double

instance Forma Quadrado where
  area (Quadrado l)      = l * l
  perimetro (Quadrado l) = 4 * l

instance Forma Circulo where
  area (Circulo r)      = pi * r * r
  perimetro (Circulo r) = 2 * pi * r

relacao :: Forma a => a -> Double
relacao f = area f / perimetro f
```

`relacao` funciona com qualquer tipo que seja instância de `Forma`.

## Classes vs. interfaces de Java

- Em Java, uma classe declara as interfaces que implementa quando é escrita. Em Haskell, podes tornar o tipo `Int` (que não escreveste) instância de uma classe tua.
- O compilador escolhe a instância pelo **tipo**, em tempo de compilação. Não há objetos nem métodos virtuais.
- Uma classe pode impor outra: `class Eq a => Ord a` quer dizer que só pode ser ordenável quem já é comparável por igualdade.

## Ler e prever

Sem correr, que tipo o GHC infere para cada função?

```haskell
f x y = x == y
g xs  = maximum xs + 1
h x   = show (x * 2)
```

1: `f :: Eq a => a -> a -> Bool`; `g :: (Ord a, Num a) => [a] -> a`; `h :: (Num a, Show a) => a -> String`.

2:

```haskell
instance Eq Moeda where
  Euros a == Euros b = a == b

instance Ord Moeda where
  compare (Euros a) (Euros b) = compare a b
```

3:

```haskell
class Descreve a where
  descreve :: a -> String

instance Descreve Bool where
  descreve True  = "verdadeiro"
  descreve False = "falso"

instance Descreve Naipe where
  descreve n = "naipe " ++ show n
```
