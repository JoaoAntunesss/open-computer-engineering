Muitas funções recursivas sobre listas têm sempre a mesma forma. As **funções de ordem superior** captam essas formas uma vez: recebem outra função como argumento. As três mais importantes são `map`, `filter` e `fold`, e aparecem hoje em quase todas as linguagens (Python, JavaScript, Java com streams, C#).

## map: transformar cada elemento

```haskell
map :: (a -> b) -> [a] -> [b]
map _ []     = []
map f (x:xs) = f x : map f xs
```

```haskell
ghci> map (* 2) [1, 2, 3]
[2,4,6]
ghci> map length ["ana", "rui", "inês"]
[3,3,4]
```

## filter: ficar com os que passam o teste

```haskell
filter :: (a -> Bool) -> [a] -> [a]
filter _ [] = []
filter p (x:xs)
  | p x       = x : filter p xs
  | otherwise = filter p xs
```

```haskell
ghci> filter even [1 .. 10]
[2,4,6,8,10]
ghci> filter (\s -> length s > 3) ["ana", "inês", "rui"]
["inês"]
```

`\s -> length s > 3` é uma **função anónima** (lambda).

## foldr: reduzir a lista a um valor

`foldr` substitui cada `:` por uma função e o `[]` final por um valor inicial:

```haskell
foldr :: (a -> b -> b) -> b -> [a] -> b
foldr _ z []     = z
foldr f z (x:xs) = f x (foldr f z xs)
```

```
foldr (+) 0 [1, 2, 3]
= 1 + (2 + (3 + 0))
= 6
```

Quase tudo se escreve com `foldr`:

```haskell
soma        = foldr (+) 0
produto     = foldr (*) 1
comprimento = foldr (\_ n -> 1 + n) 0
map' f      = foldr (\x acc -> f x : acc) []
```

`foldl` faz o mesmo da esquerda para a direita: `foldl (-) 0 [1, 2, 3]` = `((0 - 1) - 2) - 3` = `-6`, enquanto `foldr (-) 0 [1, 2, 3]` = `1 - (2 - (3 - 0))` = `2`. Para somas grandes usa `foldl'` (de `Data.List`), que não acumula trabalho por fazer.

## Composição de funções

O operador `.` liga funções: `(f . g) x = f (g x)`. Permite escrever pipelines curtos:

```haskell
somaQuadradosImpares :: [Int] -> Int
somaQuadradosImpares = sum . map (^ 2) . filter odd

-- somaQuadradosImpares [1 .. 5]  ==  1 + 9 + 25  ==  35
```

Lê-se da direita para a esquerda: filtra os ímpares, eleva ao quadrado, soma.

## O mesmo em Python e JavaScript

```python run
nums = [1, 2, 3, 4, 5]
from functools import reduce
print(list(map(lambda x: x * 2, nums)))
print(list(filter(lambda x: x % 2 == 1, nums)))
print(reduce(lambda acc, x: acc + x * x, filter(lambda x: x % 2, nums), 0))
print(sum(x * x for x in nums if x % 2))
```

```js run
const nums = [1, 2, 3, 4, 5];
console.log(nums.filter(x => x % 2).map(x => x * x).reduce((a, b) => a + b, 0));
```

## Exercícios

1. Com `map`, transforma `["ana", "rui"]` em `["ANA", "RUI"]` (usa `toUpper` de `Data.Char`).
2. Com `filter` e `length`, conta quantas palavras de uma lista começam por vogal.
3. Escreve `filter` com `foldr`.
4. Quanto dá `foldr (\x acc -> acc ++ [x]) [] [1, 2, 3]`? E o que faz esta função?
5. Escreve `todos :: (a -> Bool) -> [a] -> Bool` com `foldr`.

??? Soluções
1: `map (map toUpper) ["ana", "rui"]`: cada nome é uma lista de `Char`, por isso aplica-se `map toUpper` a cada um.

2: `length (filter (\p -> not (null p) && head p `elem` "aeiouAEIOU") palavras)`.

3: `filter' p = foldr (\x acc -> if p x then x : acc else acc) []`.

4: `[3, 2, 1]`: inverte a lista (em tempo quadrático).

5: `todos p = foldr (\x acc -> p x && acc) True`.
