Interfaces são feitas com código (HTML, CSS, JavaScript), e muitos problemas de usabilidade e acessibilidade veem-se logo a ler esse código, sem abrir o browser. Esta lição treina esse olhar.

## Ler e prever: o que ouve um leitor de ecrã?

```html
<div class="botao" onclick="enviar()">Enviar</div>
<img src="grafico-vendas.png">
<input type="text" placeholder="Email">
<span style="color:#bbb">Campo obrigatório</span>
```

Antes de continuar: imagina que usas só o teclado e um leitor de ecrã. Consegues chegar ao "botão"? Sabes o que mostra a imagem? Sabes o nome do campo depois de começares a escrever? Consegues ler o aviso cinzento?

## Encontra o erro: um formulário que não diz o que correu mal

```js run
function valida(email, idade) {
  const erros = [];
  if (!email.includes("@")) erros.push("Erro");
  if (idade < 18) erros.push("Erro");
  return erros.length ? "Dados inválidos." : "Enviado!";
}
console.log(valida("ana.exemplo.pt", 17));
console.log(valida("ana@exemplo.pt", 30));
```

O código funciona, mas a mensagem é inútil para quem a lê. O que deve dizer uma boa mensagem de erro?

**Ler e prever:** o `div` não recebe foco com o teclado nem é anunciado como botão; a imagem não tem `alt`; o placeholder desaparece ao escrever e nem sempre é lido como nome do campo; o cinzento claro sobre branco tem contraste muito baixo.

```html
<button type="submit">Enviar</button>
<img src="grafico-vendas.png" alt="Vendas a subir de 120 em janeiro para 310 em junho">
<label for="email">Email</label>
<input id="email" type="email" autocomplete="email" required aria-describedby="email-ajuda">
<p id="email-ajuda">Obrigatório. Vamos usá-lo só para confirmar a inscrição.</p>
```

**Encontra o erro:** "Dados inválidos." não diz que campo nem como corrigir. Boas mensagens dizem o problema e a solução, junto do campo.

```js
function valida(email, idade) {
  const erros = {};
  if (!email.includes("@")) erros.email = "O email tem de ter @, por exemplo nome@exemplo.pt.";
  if (idade < 18) erros.idade = "A inscrição é só para maiores de 18 anos.";
  return erros;
}
```
