**Refatorar** é mudar a estrutura do código **sem mudar o que ele faz**: nomes melhores, funções mais pequenas, duplicação eliminada. É o que mantém um projeto vivo durante anos. A regra que torna isto seguro: **testes antes, passos pequenos, testes depois de cada passo**.

## Porquê refatorar

Código difícil de ler é código onde os bugs se escondem e onde cada alteração demora o triplo. Sinais de que precisa (os chamados *code smells*):

- Funções muito compridas.
- Código copiado e colado em vários sítios.
- Nomes que não dizem nada (`dados2`, `tmp`, `processa`).
- Muitos parâmetros, ou `if` encadeados a decidir pelo tipo de coisa.
- Comentários a explicar o que um bocado de código confuso faz (o código podia ser claro).

## O método

1. **Garante testes** que cubram o comportamento atual. Se não houver, escreve testes que capturem o que o código faz **hoje** (mesmo que tenha bugs: primeiro preserva, depois corrige).
2. Faz **uma** alteração pequena (renomear, extrair uma função).
3. Corre os testes. Verde? Commit. Vermelho? Desfaz e tenta mais pequeno.
4. Repete.

Nunca mistures refatoração com funcionalidades novas no mesmo commit: se algo partir, não sabes qual das duas foi.

## Refatorações básicas

- **Renomear** (F2 no VS Code renomeia em todo o projeto).
- **Extrair função**: um bloco com um propósito passa a função com nome.
- **Extrair variável**: uma expressão comprida ganha um nome explicativo.
- **Substituir números mágicos** por constantes (`23` → `TAXA_IVA = 0.23`).
- **Trocar `if` por tipo por polimorfismo** (a técnica da Programação por Objetos).

```python
# antes
def p(c):
    if c["t"] == "vip" and c["v"] > 50:
        return c["v"] * 0.85
    return c["v"] * (0.95 if c["t"] == "vip" else 1)

# depois
DESCONTO_VIP = 0.05
DESCONTO_VIP_GRANDE = 0.15
LIMITE_COMPRA_GRANDE = 50

def preco_com_desconto(cliente):
    valor = cliente["valor"]
    if cliente["tipo"] != "vip":
        return valor
    desconto = DESCONTO_VIP_GRANDE if valor > LIMITE_COMPRA_GRANDE else DESCONTO_VIP
    return valor * (1 - desconto)
```

## Refatorar com IA

A IA é boa a propor refatorações, e é aqui que os testes mais importam: pede a mudança à IA, corre os testes, lê o diff. Pede passos pequenos ("só extrai esta função"), não "melhora este ficheiro".
