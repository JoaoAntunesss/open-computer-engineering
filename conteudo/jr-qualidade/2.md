Um teste unitário verifica uma unidade pequena (uma função, um método) sem depender de bases de dados, internet ou ficheiros. Com o **pytest**, escrever um é tão simples como escrever uma função que começa por `test_`.

## A estrutura: preparar, agir, verificar

```python
# precos.py
def preco_final(preco, quantidade, cupao=None):
    total = preco * quantidade
    if cupao == "MENOS10":
        total *= 0.9
    if total > 100:
        total -= 5
    return round(total, 2)
```

```python
# test_precos.py
from precos import preco_final

def test_sem_cupao_abaixo_de_100():
    # preparar / agir / verificar
    assert preco_final(10, 3) == 30

def test_cupao_menos10_aplica_desconto():
    assert preco_final(10, 3, "MENOS10") == 27

def test_acima_de_100_desconta_5():
    assert preco_final(60, 2) == 115

def test_exatamente_100_nao_desconta():
    assert preco_final(50, 2) == 100

def test_cupao_desconhecido_e_ignorado():
    assert preco_final(10, 1, "FALSO") == 10
```

Corre com `pytest` no terminal. Repara nos nomes: lidos em sequência, documentam as regras.

## Muitos casos de uma vez

```python
import pytest
from precos import preco_final

@pytest.mark.parametrize("preco, qtd, cupao, esperado", [
    (10, 3, None, 30),
    (10, 3, "MENOS10", 27),
    (60, 2, None, 115),
    (50, 2, None, 100),
    (0, 5, None, 0),
])
def test_preco_final(preco, qtd, cupao, esperado):
    assert preco_final(preco, qtd, cupao) == esperado
```

## Testar erros

```python
def test_quantidade_negativa_da_erro():
    with pytest.raises(ValueError):
        preco_final(10, -1)
```

Este teste falha com o código de cima: não há validação. Testes assim mostram decisões que ninguém tomou.

## Testar coisas que mudam: datas

Uma função que usa `date.today()` dá resultados diferentes conforme o dia. Solução: recebe a data como parâmetro (com valor por defeito), e o teste passa uma data fixa.

```python
from datetime import date

def faltam_dias(evento, hoje=None):
    hoje = hoje or date.today()
    return (evento - hoje).days

def test_faltam_dias():
    assert faltam_dias(date(2027, 1, 10), hoje=date(2027, 1, 1)) == 9
```

## Erros comuns

- Testar com os mesmos valores do exemplo e nunca os limites.
- Um teste com 15 `assert` sobre coisas diferentes: quando falha, não sabes qual.
- Testes que só passam porque copiaste o resultado do código (se o código está errado, o teste "confirma" o erro).
