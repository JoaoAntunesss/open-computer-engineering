Métodos formais servem para provar que o código faz o que deve. Antes de usares ferramentas como Dafny ou TLA+, o mesmo raciocínio pode ser treinado a ler código comum: encontrar a **invariante** de um ciclo e verificar se ela se mantém.

## Ler e prever: uma invariante

```python run
def maximo(xs):
    assert len(xs) > 0                      # pré-condição
    m = xs[0]
    for i in range(1, len(xs)):
        # invariante: m é o maior de xs[0..i-1]
        assert m == max(xs[:i])
        if xs[i] > m:
            m = xs[i]
    assert m == max(xs)                     # pós-condição
    return m

print(maximo([3, 9, 2, 9, 4]))
```

Antes de correr: a invariante é verdadeira antes da primeira volta? Se for verdadeira no início de uma volta, continua verdadeira no início da seguinte? Isso, mais a condição de saída, prova a pós-condição.

## Encontra o erro: a invariante que falha

```python run
def soma_ate(n):
    s, i = 0, 0
    while i < n:
        # invariante pretendida: s == 0 + 1 + ... + i
        assert s == i * (i + 1) // 2, (i, s)
        i += 1
        s += i - 1
    return s

print(soma_ate(5))   # esperado: 15
```

O `assert` falha. A leitura linha a linha (com a tabela de rastreio) mostra porquê, antes de qualquer prova.
