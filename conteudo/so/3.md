Um processo pode ter várias **threads**: linhas de execução que correm em paralelo e partilham a mesma memória. São mais leves do que processos e comunicam diretamente pela memória partilhada, o que é ao mesmo tempo a vantagem e o perigo. Quem decide que thread corre em cada núcleo, e durante quanto tempo, é o **escalonador**.

## Processos e threads

| | processo | thread |
|---|---|---|
| memória | própria | partilhada com as outras threads do processo |
| pilha e registos | próprios | próprios |
| ficheiros abertos | próprios | partilhados |
| criar e trocar | mais caro | mais barato |
| uma falha | só esse processo morre | o processo inteiro morre |

Usos típicos: um servidor com uma thread por pedido, uma interface gráfica com uma thread de interface e outras para trabalho pesado, um cálculo dividido pelos núcleos.

## POSIX threads em C

```c
// threads.c
#include <stdio.h>
#include <pthread.h>

#define N 4
long somas[N];

typedef struct { int id; long inicio, fim; } Tarefa;

void *trabalha(void *arg) {
    Tarefa *t = arg;
    long s = 0;
    for (long i = t->inicio; i < t->fim; i++) s += i;
    somas[t->id] = s;                    // cada thread escreve na sua posição
    return NULL;
}

int main(void) {
    pthread_t th[N];
    Tarefa t[N];
    long total_n = 100000000, parte = total_n / N;
    for (int i = 0; i < N; i++) {
        t[i] = (Tarefa){i, i * parte, (i + 1) * parte};
        pthread_create(&th[i], NULL, trabalha, &t[i]);
    }
    long total = 0;
    for (int i = 0; i < N; i++) {
        pthread_join(th[i], NULL);       // espera que a thread acabe
        total += somas[i];
    }
    printf("%ld\n", total);
    return 0;
}
```

Compila com `gcc -O2 -pthread threads.c`. Cada thread soma uma parte; o `main` espera por todas com `pthread_join` e junta os resultados. Como cada thread escreve numa posição diferente, não há conflito. (Na lição seguinte vês o que acontece quando escrevem na mesma variável.)

## Escalonamento

Há mais threads prontas do que núcleos. O escalonador escolhe qual corre, e o **temporizador** interrompe-a ao fim de um **quantum** (alguns milissegundos) para dar a vez a outra. Trocar de thread é uma **mudança de contexto**: guardar registos de uma, carregar os da outra.

Objetivos que entram em conflito:

- **Débito:** fazer o máximo de trabalho por segundo.
- **Tempo de resposta:** reagir depressa a quem está à espera (o rato, o teclado).
- **Justiça:** ninguém fica sem processador para sempre (*starvation*).

## Algoritmos clássicos

- **FCFS** (por ordem de chegada): simples; uma tarefa longa atrasa todas as curtas.
- **SJF** (a mais curta primeiro): minimiza o tempo médio de espera, mas exige saber a duração.
- **Round-robin:** cada uma corre um quantum e volta para o fim da fila. Justo e com boa resposta; o quantum certo é um compromisso entre resposta e custo das mudanças de contexto.
- **Prioridades** com **envelhecimento** (a prioridade sobe com a espera, para evitar a fome).
- **Filas multinível com retroação:** tarefas que gastam o quantum todo (de cálculo) descem de prioridade; as interativas (que bloqueiam cedo) ficam em cima.
- **CFS** (o escalonador do Linux até 2023): dá a vez à thread que usou menos tempo de processador, com uma árvore rubro-negra ordenada por esse tempo. Foi substituído pelo **EEVDF**, que segue a mesma ideia.

## Simular e comparar

Prevê qual dá menor tempo médio de espera para estas tarefas, que chegam todas ao mesmo tempo:

```python run
tarefas = {"A": 8, "B": 1, "C": 3, "D": 2}     # duração (ms)

def fcfs(t):
    tempo, espera = 0, {}
    for nome, d in t.items():
        espera[nome] = tempo
        tempo += d
    return espera

def sjf(t):
    return fcfs(dict(sorted(t.items(), key=lambda x: x[1])))

def round_robin(t, quantum=2):
    resta = dict(t)
    fila = list(t)
    tempo, fim = 0, {}
    while fila:
        n = fila.pop(0)
        corre = min(quantum, resta[n])
        tempo += corre
        resta[n] -= corre
        if resta[n]:
            fila.append(n)
        else:
            fim[n] = tempo
    return {n: fim[n] - t[n] for n in t}        # espera = fim - duração

for nome, f in (("FCFS", fcfs), ("SJF", sjf), ("RR q=2", round_robin)):
    e = f(tarefas)
    print(f"{nome:7} espera média = {sum(e.values()) / len(e):.2f}  {e}")
```
