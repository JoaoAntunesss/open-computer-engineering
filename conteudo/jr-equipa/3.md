Code review é quando outra pessoa lê o teu código antes de ele entrar no projeto, e tu lês o dos outros. É uma das formas mais rápidas de aprender, e é onde se vê a diferença entre um júnior e um sénior.

## Pedir revisão

- Revê o teu próprio diff **antes** de pedires. Metade dos comentários que receberias, apanhas tu.
- Explica o contexto na descrição do PR (o quê, porquê, como testar).
- Assinala o que te deixa inseguro: "não tenho a certeza se esta query é eficiente com muitos dados". Ajuda o revisor a focar-se.

## Receber comentários

- Os comentários são sobre o código, não sobre ti.
- Se não percebes um comentário, pergunta. Se discordas, explica porquê, com argumentos ("assim evita uma query por cliente"), e aceita a decisão da equipa.
- Responde a todos: "feito", "boa, mudei" ou "prefiro manter porque…". Não deixes comentários sem resposta.
- Agradece. Alguém gastou tempo a melhorar o teu trabalho.

## Dar revisão

O que procurar, por ordem de importância:

1. **Está certo?** Faz o que o PR diz? Casos-limite? Erros?
2. **É seguro?** Dados do utilizador tratados, permissões, segredos.
3. **Está testado?** Os testes cobrem o que mudou?
4. **Percebe-se?** Nomes, estrutura, comentários onde fazem falta.
5. **Estilo**: se a equipa tiver linter, deixa isso para a máquina.

Como escrever:

- Pergunta em vez de mandar: "O que acontece se a lista vier vazia?" em vez de "Isto está mal".
- Diz porquê: "Usa parâmetros na query, senão fica vulnerável a injeção de SQL."
- Distingue o obrigatório do opcional: prefixos como **"nit:"** (pormenor) ou **"opcional:"** ajudam.
- Elogia o que está bem feito. Também é feedback.

## Code review com IA

Há ferramentas que comentam PRs automaticamente. São úteis para apanhar erros óbvios, mas não percebem o objetivo do negócio nem o histórico do projeto. A revisão humana continua a ser obrigatória na maioria das equipas.

## Exercício

Abre um PR antigo (e já fechado) de um projeto open source que conheças. Lê o diff sem ler os comentários, escreve a tua revisão e depois compara com os comentários que a equipa deixou.
