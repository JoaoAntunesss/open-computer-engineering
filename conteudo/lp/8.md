Linguagens de programação estudam-se melhor a ler código pequeno e "estranho": âmbito, closures, avaliação preguiçosa. São exatamente os comportamentos que surpreendem quem lê código em produção. Prever o resultado antes de correr mostra se percebeste a semântica da linguagem, e não só a sintaxe.

## Ler e prever: closures num ciclo

```python run
funcoes = []
for i in range(3):
    funcoes.append(lambda: i)
print([f() for f in funcoes])

funcoes2 = []
for i in range(3):
    funcoes2.append(lambda i=i: i)
print([f() for f in funcoes2])
```

Antes de correr: o que esperas em cada linha? O que é capturado pela `lambda`, o valor de `i` ou a variável `i`?

O mesmo em JavaScript, com `var` e com `let`:

```js run
const a = [], b = [];
for (var i = 0; i < 3; i++) a.push(() => i);
for (let j = 0; j < 3; j++) b.push(() => j);
console.log(a.map(f => f()), b.map(f => f()));
```

## Encontra o erro: um valor por omissão partilhado

```python run
def acrescenta(item, lista=[]):
    lista.append(item)
    return lista

print(acrescenta("a"))
print(acrescenta("b"))
print(acrescenta("c", []))
print(acrescenta("d"))
```

A intenção era cada chamada sem lista começar com uma lista vazia. O que acontece, e quando é que o `[]` é avaliado?

## Escreve tu

Escreve um gerador preguiçoso `primos()` que produz números primos para sempre, e usa-o para mostrar os 10 primeiros sem criar nenhuma lista infinita. Explica em que momento cada primo é calculado.

??? Soluções
**Ler e prever:** a primeira linha dá `[2, 2, 2]`: as três lambdas capturam a **mesma** variável `i`, que no fim vale 2. A segunda dá `[0, 1, 2]`, porque `i=i` guarda o valor no momento da definição. Em JavaScript, `var` tem âmbito de função (`[3,3,3]`) e `let` cria uma variável nova em cada volta (`[0,1,2]`).

**Encontra o erro:** o valor por omissão é avaliado **uma vez**, quando a função é definida, e a mesma lista é reaproveitada: `['a']`, `['a', 'b']`, `['c']`, `['a', 'b', 'd']`. Corrige com `lista=None` e `if lista is None: lista = []`.

**Escreve tu:**
```python
from itertools import count, islice
def primos():
    encontrados = []
    for n in count(2):
        if all(n % p for p in encontrados if p * p <= n):
            encontrados.append(n)
            yield n
print(list(islice(primos(), 10)))
```
Cada primo só é calculado quando o `islice` pede o seguinte.
