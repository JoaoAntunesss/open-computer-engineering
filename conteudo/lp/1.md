A melhor forma de perceber uma linguagem de programação é **implementá-la**. Começa-se pela **sintaxe abstrata** (a estrutura do programa, sem pormenores de escrita) e por um **interpretador** que a avalia. Com umas dezenas de linhas, tens uma linguagem com variáveis, funções e recursão, e percebes de onde vêm conceitos como âmbito, ambientes e closures. É a abordagem dos livros *Crafting Interpreters* e *PLAI* (Brown) e das cadeiras de linguagens do MIT e de Berkeley.

## Sintaxe concreta e abstrata

- **Concreta:** como se escreve: `(2 + 3) * x`, `2 3 + x *`, `(* (+ 2 3) x)`.
- **Abstrata:** a árvore, que é a mesma nas três: Mul(Add(Num 2, Num 3), Var x).

O analisador sintático (Compiladores, lição 3) passa de uma para a outra. Para estudar a semântica, ignora-se a sintaxe concreta: usam-se diretamente as árvores, ou uma sintaxe trivial de analisar, como as **expressões S** do Lisp e do Racket.

## Uma linguagem pequena

Expressões: números, variáveis, operações, `let` (dar nome a um valor), `if`, funções anónimas (`lambda`) e aplicação.

```
(let ((x 5)) (* x x))                         → 25
((lambda (n) (+ n 1)) 41)                     → 42
(let ((dobro (lambda (f) (lambda (x) (f (f x))))))
  ((dobro (lambda (y) (* y 3))) 2))            → 18
```

## Ambientes e closures

O **ambiente** associa nomes a valores. Avaliar uma `lambda` produz uma **closure**: a função **mais o ambiente onde foi criada**. É por isso que uma função "se lembra" das variáveis de fora: o âmbito é **léxico** (decidido pelo sítio onde o código está escrito), não dinâmico (decidido por quem chama).

```python run
import re

def analisa(texto):                          # expressões S → listas de Python
    tokens = re.findall(r"\(|\)|[^\s()]+", texto)
    def ler(i):
        if tokens[i] == "(":
            lista, i = [], i + 1
            while tokens[i] != ")":
                elem, i = ler(i); lista.append(elem)
            return lista, i + 1
        t = tokens[i]
        return (int(t) if re.fullmatch(r"-?\d+", t) else t), i + 1
    return ler(0)[0]

class Closure:
    def __init__(self, params, corpo, amb):
        self.params, self.corpo, self.amb = params, corpo, amb

PRIMITIVAS = {"+": lambda a, b: a + b, "-": lambda a, b: a - b, "*": lambda a, b: a * b,
              "<": lambda a, b: a < b, "=": lambda a, b: a == b}

def avalia(e, amb):
    if isinstance(e, int):
        return e
    if isinstance(e, str):
        if e in amb: return amb[e]
        if e in PRIMITIVAS: return PRIMITIVAS[e]
        raise NameError(f"variável não definida: {e}")
    cabeca = e[0]
    if cabeca == "let":                              # (let ((nome valor)) corpo)
        (nome, valor), = e[1]
        return avalia(e[2], {**amb, nome: avalia(valor, amb)})
    if cabeca == "if":
        return avalia(e[2] if avalia(e[1], amb) else e[3], amb)
    if cabeca == "lambda":                           # captura o ambiente atual
        return Closure(e[1], e[2], amb)
    f = avalia(cabeca, amb)
    args = [avalia(a, amb) for a in e[1:]]
    if isinstance(f, Closure):
        return avalia(f.corpo, {**f.amb, **dict(zip(f.params, args))})
    return f(*args)

programas = [
    "(let ((x 5)) (* x x))",
    "((lambda (n) (+ n 1)) 41)",
    "(let ((dobro (lambda (f) (lambda (x) (f (f x)))))) ((dobro (lambda (y) (* y 3))) 2))",
    "(let ((x 10)) (let ((f (lambda (y) (+ x y)))) (let ((x 1000)) (f 1))))",
]
for p in programas:
    print(p, "→", avalia(analisa(p), {}))
```

Prevê os quatro resultados. O último é o teste do âmbito léxico: dentro de `f`, `x` é o 10 do sítio onde `f` foi criada, não o 1000 de onde é chamada.

## Recursão

Com só `let` e `lambda`, uma função não se pode chamar a si própria (o nome ainda não existe quando a `lambda` é avaliada). As linguagens resolvem isto com `letrec` / `define` (o ambiente da closure passa a incluir o próprio nome), ou, teoricamente, com o **combinador Y** (próxima lição).
