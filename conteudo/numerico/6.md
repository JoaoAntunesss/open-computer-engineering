Uma **equação diferencial** descreve como uma coisa muda: a velocidade de queda depende da velocidade atual (resistência do ar), o número de infetados depende de quantos estão infetados e quantos estão suscetíveis, a carga de uma bateria depende da corrente. Quase nenhuma tem solução em fórmula, por isso resolvem-se numericamente, passo a passo. É o coração de qualquer simulação: física de jogos, meteorologia, epidemiologia, circuitos.

## O problema

Uma **equação diferencial ordinária** (EDO) com condição inicial:

y'(t) = f(t, y),    y(t₀) = y₀

Quer-se y em instantes futuros. Sistemas de várias equações (posição e velocidade; suscetíveis, infetados e recuperados) tratam-se da mesma forma, com y como vetor.

## Método de Euler

Segue a derivada durante um passo h:

yₙ₊₁ = yₙ + h · f(tₙ, yₙ)

É o que usaste em Física. Simples, mas pouco exato: erro global proporcional a h (para metade do erro, o dobro dos passos). E pode ser **instável**: com h grande, a solução numérica explode mesmo quando a verdadeira não explode.

## Runge-Kutta de ordem 4 (RK4)

Avalia a derivada em quatro pontos dentro do passo e faz uma média pesada:

```
k1 = f(t, y)
k2 = f(t + h/2, y + h/2 · k1)
k3 = f(t + h/2, y + h/2 · k2)
k4 = f(t + h,   y + h · k3)
y_seguinte = y + h/6 · (k1 + 2k2 + 2k3 + k4)
```

Erro global proporcional a **h⁴**: quatro vezes mais trabalho por passo, mas passos muito maiores para a mesma precisão. É o "cavalo de batalha" das EDO.

## Comparar com uma solução conhecida

y' = −2y, y(0) = 1 tem solução exata y = e⁻²ᵗ. Prevê como o erro em t = 2 muda quando h passa para metade, em cada método, e o que acontece a Euler com h = 1,1:

```python run
import math

def euler(f, y, t, h, passos):
    for _ in range(passos):
        y = y + h * f(t, y); t += h
    return y

def rk4(f, y, t, h, passos):
    for _ in range(passos):
        k1 = f(t, y)
        k2 = f(t + h / 2, y + h / 2 * k1)
        k3 = f(t + h / 2, y + h / 2 * k2)
        k4 = f(t + h, y + h * k3)
        y = y + h / 6 * (k1 + 2 * k2 + 2 * k3 + k4); t += h
    return y

f = lambda t, y: -2 * y
exato = math.exp(-4)
for h in (0.2, 0.1, 0.05):
    n = round(2 / h)
    print(f"h = {h:4}: Euler erro {abs(euler(f, 1, 0, h, n) - exato):.1e}   RK4 erro {abs(rk4(f, 1, 0, h, n) - exato):.1e}")
print("Euler com h = 1.1, 10 passos:", euler(f, 1, 0, 1.1, 10))
```

Para esta equação, Euler é estável só se h < 1 (porque |1 − 2h| tem de ser menor do que 1).

## Um modelo de epidemia (SIR)

Três grupos: suscetíveis S, infetados I e recuperados R, numa população de N pessoas.

- S' = −β·S·I/N (contágios)
- I' = β·S·I/N − γ·I
- R' = γ·I (recuperações)

```python run
def sir(beta, gama, N=10_000, I0=10, dias=160, h=0.1):
    S, I, R = N - I0, I0, 0.0
    pico, dia_pico = I, 0
    for passo in range(int(dias / h)):
        def deriv(S, I, R):
            nova = beta * S * I / N
            return -nova, nova - gama * I, gama * I
        # RK4 para o sistema
        k1 = deriv(S, I, R)
        k2 = deriv(*(v + h / 2 * k for v, k in zip((S, I, R), k1)))
        k3 = deriv(*(v + h / 2 * k for v, k in zip((S, I, R), k2)))
        k4 = deriv(*(v + h * k for v, k in zip((S, I, R), k3)))
        S, I, R = (v + h / 6 * (a + 2 * b + 2 * c + d) for v, a, b, c, d in zip((S, I, R), k1, k2, k3, k4))
        if I > pico:
            pico, dia_pico = I, passo * h
    return round(pico), round(dia_pico), round(R)

for beta in (0.3, 0.2, 0.15):
    pico, dia, total = sir(beta, gama=0.1)
    print(f"R0 = {beta / 0.1:.1f}: pico de {pico} infetados ao dia {dia}; no fim, {total} recuperados")
```

Prevê o efeito de baixar β (menos contactos): o pico baixa, mas chega mais tarde. Foi esta a ideia por trás do "achatar a curva".

## Na prática

- `scipy.integrate.solve_ivp`: métodos de passo **adaptativo** (RK45 por omissão), que escolhem h sozinhos para cumprir uma tolerância.
- Problemas **rígidos** (*stiff*), com escalas de tempo muito diferentes (reações químicas, circuitos): métodos implícitos (`method="BDF"` ou `"Radau"`).
- Em simulação física de jogos, o **Euler semi-implícito** ou o **Verlet**, que conservam a energia (Física, lição 2).
