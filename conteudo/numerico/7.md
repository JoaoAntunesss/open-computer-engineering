Em Algoritmos viste a programação linear do ponto de vista geométrico: o ótimo está num vértice da região admissível. O **método simplex** é a forma de chegar lá sem enumerar todos os vértices: começa num vértice e vai saltando para vizinhos melhores, até nenhum vizinho ser melhor. Nesta lição vês o algoritmo por dentro, na forma de **quadro** (*tableau*), e como se usa na prática.

## Forma padrão

Maximizar cᵀx sujeito a Ax ≤ b, x ≥ 0 (com b ≥ 0). Cada desigualdade ganha uma **variável de folga** que a transforma em igualdade:

4x + 2y ≤ 100   →   4x + 2y + s₁ = 100,  s₁ ≥ 0

A folga mede quanto do recurso sobra.

## O algoritmo

1. **Solução inicial:** todas as variáveis originais a 0, as folgas iguais a b (o vértice na origem).
2. **Variável a entrar:** a que tem o coeficiente mais negativo na linha do objetivo (a que mais aumenta o lucro por unidade). Se nenhum for negativo, a solução é ótima.
3. **Variável a sair (teste da razão):** para cada linha com coeficiente positivo na coluna que entra, divide-se o lado direito por esse coeficiente; a menor razão diz que restrição bloqueia primeiro.
4. **Pivotagem:** operações de linha (como na eliminação de Gauss) para pôr a coluna que entra com 1 na linha do pivô e 0 nas outras. Volta ao passo 2.

## O exemplo das mesas e cadeiras

Maximizar 30x + 20y com 4x + 2y ≤ 100 (carpintaria) e x + y ≤ 40 (pintura):

```python run
from fractions import Fraction as F

def simplex(c, A, b, nomes):
    m, n = len(A), len(c)
    # quadro: m linhas de restrições + linha do objetivo; colunas: n originais + m folgas + lado direito
    T = [[F(v) for v in A[i]] + [F(int(i == j)) for j in range(m)] + [F(b[i])] for i in range(m)]
    T.append([F(-v) for v in c] + [F(0)] * m + [F(0)])
    base = list(range(n, n + m))
    todos = nomes + [f"folga{i + 1}" for i in range(m)]
    while True:
        col = min(range(n + m), key=lambda j: T[-1][j])
        if T[-1][col] >= 0:
            break                                            # ótimo
        razoes = [(T[i][-1] / T[i][col], i) for i in range(m) if T[i][col] > 0]
        if not razoes:
            return "ilimitado"
        _, lin = min(razoes)
        print(f"entra {todos[col]}, sai {todos[base[lin]]}")
        p = T[lin][col]
        T[lin] = [v / p for v in T[lin]]
        for i in range(m + 1):
            if i != lin and T[i][col] != 0:
                f = T[i][col]
                T[i] = [a - f * b_ for a, b_ in zip(T[i], T[lin])]
        base[lin] = col
    sol = {todos[base[i]]: T[i][-1] for i in range(m)}
    return {k: str(sol.get(k, 0)) for k in todos}, "objetivo =", str(T[-1][-1]), \
           "preços-sombra:", [str(T[-1][n + i]) for i in range(m)]

print(simplex([30, 20], [[4, 2], [1, 1]], [100, 40], ["x", "y"]))
```

Prevê as duas pivotagens: primeiro entra x (lucro 30 por unidade, o maior); qual restrição bloqueia? Usam-se frações para não haver erros de arredondamento. No fim, a linha do objetivo dá também os **preços-sombra**: quanto aumentaria o lucro com mais uma hora de cada recurso.

## Casos especiais

- **Ilimitado:** a variável que entra não tem nenhum coeficiente positivo na coluna: o lucro pode crescer sem limite (normalmente, falta uma restrição no modelo).
- **Impossível:** as restrições contradizem-se. Com restrições ≥ ou =, o vértice na origem não é admissível; usa-se o método das **duas fases** (primeiro encontra um vértice admissível) ou o "grande M".
- **Degenerescência:** uma razão igual a zero; pode haver ciclos, evitados com a **regra de Bland** (escolher sempre o menor índice).
- **Soluções múltiplas:** um coeficiente zero na linha do objetivo de uma variável fora da base.

## Na prática

Ninguém escreve o simplex para usar a sério: usa-se `scipy.optimize.linprog` (HiGHS), PuLP, OR-Tools, ou o **Solver do Excel**, que resolve exatamente estes problemas a partir de uma folha de cálculo. O trabalho é **modelar**. Em média, o simplex faz poucas pivotagens (proporcional ao número de restrições), mesmo sendo exponencial no pior caso.
