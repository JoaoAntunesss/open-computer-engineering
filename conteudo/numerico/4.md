Muitas vezes tens dados em pontos soltos (medições, uma tabela) e queres valores entre eles, ou uma função que os descreva. Há duas ideias diferentes: a **interpolação** passa **exatamente** por todos os pontos; o **ajuste por mínimos quadrados** passa **perto** deles, aceitando que os dados têm ruído. Escolher mal entre as duas é um erro clássico.

## Interpolação linear

Entre dois pontos, a reta. É o que faz um gráfico de linhas, uma tabela de impostos por escalões com valores intermédios, ou uma animação entre duas posições. Simples e robusta.

## Interpolação polinomial

Por n + 1 pontos passa **um único** polinómio de grau n. Calcula-se com a forma de **Lagrange** ou, de forma mais eficiente, com as **diferenças divididas de Newton**.

O problema: com muitos pontos igualmente espaçados, o polinómio oscila violentamente perto das pontas (**fenómeno de Runge**).

```python run
def lagrange(xs, ys, x):
    total = 0.0
    for i, (xi, yi) in enumerate(zip(xs, ys)):
        termo = yi
        for j, xj in enumerate(xs):
            if j != i:
                termo *= (x - xj) / (xi - xj)
        total += termo
    return total

runge = lambda x: 1 / (1 + 25 * x * x)
for n in (5, 10, 15):
    xs = [-1 + 2 * i / n for i in range(n + 1)]               # pontos igualmente espaçados
    ys = [runge(x) for x in xs]
    erro = max(abs(lagrange(xs, ys, t / 500 - 1) - runge(t / 500 - 1)) for t in range(1001))
    print(f"grau {n:2}: erro máximo {erro:.3f}")

import math
for n in (10, 15):
    xs = [math.cos((2 * i + 1) * math.pi / (2 * n + 2)) for i in range(n + 1)]   # pontos de Chebyshev
    ys = [runge(x) for x in xs]
    erro = max(abs(lagrange(xs, ys, t / 500 - 1) - runge(t / 500 - 1)) for t in range(1001))
    print(f"grau {n:2} com pontos de Chebyshev: erro máximo {erro:.3f}")
```

Prevê: aumentar o grau melhora ou piora? Os **pontos de Chebyshev** (mais juntos nas pontas) resolvem o problema.

## Splines

Em vez de um polinómio de grau alto, usam-se **muitos polinómios de grau baixo** (normalmente cúbicos), um entre cada par de pontos, colados de forma suave (mesmo valor, mesma primeira e segunda derivadas nos pontos de junção). As **splines cúbicas** são a escolha habitual para interpolar: suaves, sem oscilações. São também a base das curvas em desenho vetorial e em CAD (Computação Gráfica, lição 8). Em Python: `scipy.interpolate.CubicSpline`.

## Mínimos quadrados

Quando os dados têm ruído, passar exatamente por todos os pontos é ajustar o ruído. Procura-se, numa família de funções (retas, parábolas, exponenciais), a que minimiza a soma dos quadrados dos erros. Para modelos lineares nos parâmetros, isto dá um sistema linear (as **equações normais** AᵀAc = Aᵀy, ou, mais estável, a fatorização QR).

```python run
import numpy as np
rng = np.random.default_rng(0)

x = np.linspace(0, 10, 25)
y = 3 + 2 * x - 0.15 * x ** 2 + rng.normal(0, 1, x.size)     # parábola com ruído

for grau in (1, 2, 10):
    coef = np.polyfit(x, y, grau)                            # mínimos quadrados
    residuos = y - np.polyval(coef, x)
    x_novo = 12                                               # fora dos dados
    print(f"grau {grau:2}: erro quadrático médio {np.mean(residuos ** 2):.2f}  "
          f"previsão em x=12: {np.polyval(coef, x_novo):8.2f}")
print("valor verdadeiro em x=12 (sem ruído):", 3 + 2 * 12 - 0.15 * 144)
```

O grau 10 tem o menor erro nos dados, mas a pior previsão fora deles: ajustou o ruído (**sobreajustamento**, *overfitting*). É exatamente o problema central de Aprendizagem Automática.
