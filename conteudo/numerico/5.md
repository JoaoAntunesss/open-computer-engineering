Integrar e derivar são operações do Cálculo que, em computação, se fazem quase sempre **numericamente**: muitas funções não têm primitiva conhecida, e muitas vezes só se tem uma tabela de valores (medições de um sensor de 10 em 10 segundos). A ideia é aproximar a função por polinómios simples, onde integrar e derivar é fácil.

## Derivação numérica

Da definição de derivada:

- **Diferença para a frente:** f'(x) ≈ (f(x + h) − f(x)) / h. Erro proporcional a h.
- **Diferença central:** f'(x) ≈ (f(x + h) − f(x − h)) / (2h). Erro proporcional a h²: muito melhor, pelo mesmo custo.

O dilema do h: h grande dá erro de **truncatura** (a fórmula é só uma aproximação); h muito pequeno dá erro de **arredondamento** (subtrair dois números quase iguais: o cancelamento da lição 1). Há um h ótimo:

```python run
import math
f, df_exata, x = math.sin, math.cos(1.0), 1.0
print(f"{'h':>8} {'frente':>12} {'central':>12}")
for k in range(1, 15, 2):
    h = 10 ** -k
    frente = (f(x + h) - f(x)) / h
    central = (f(x + h) - f(x - h)) / (2 * h)
    print(f"{h:8.0e} {abs(frente - df_exata):12.2e} {abs(central - df_exata):12.2e}")
```

Prevê em que h o erro é mínimo para cada fórmula. Para derivadas exatas em código, usa-se **diferenciação automática** (o que o PyTorch e o JAX fazem para treinar redes neuronais): aplica a regra da cadeia às operações do programa, sem aproximação nenhuma.

## Integração numérica (quadratura)

Divide-se [a, b] em n intervalos de largura h e aproxima-se a função em cada um:

- **Retângulos** (ponto médio): erro proporcional a h².
- **Trapézios:** une os pontos por retas. h · (f₀/2 + f₁ + … + fₙ₋₁ + fₙ/2). Erro proporcional a h².
- **Simpson:** une os pontos três a três por parábolas. (h/3) · (f₀ + 4f₁ + 2f₂ + 4f₃ + … + fₙ), n par. Erro proporcional a **h⁴**: duplicar n divide o erro por 16.

```python run
import math

def trapezios(f, a, b, n):
    h = (b - a) / n
    return h * (f(a) / 2 + sum(f(a + i * h) for i in range(1, n)) + f(b) / 2)

def simpson(f, a, b, n):                    # n tem de ser par
    h = (b - a) / n
    s = f(a) + f(b)
    s += 4 * sum(f(a + i * h) for i in range(1, n, 2))
    s += 2 * sum(f(a + i * h) for i in range(2, n, 2))
    return h / 3 * s

# a área debaixo da curva normal entre -1 e 1 (não tem primitiva elementar): ≈ 0.682689
f = lambda x: math.exp(-x * x / 2) / math.sqrt(2 * math.pi)
exato = math.erf(1 / math.sqrt(2))
for n in (4, 8, 16, 32):
    print(f"n = {n:2}: trapézios erro {abs(trapezios(f, -1, 1, n) - exato):.1e}   "
          f"Simpson erro {abs(simpson(f, -1, 1, n) - exato):.1e}")
```

Prevê como o erro de cada método diminui quando n duplica.

## Na prática

- **Quadratura adaptativa:** usa intervalos pequenos onde a função muda depressa e grandes onde é suave. `scipy.integrate.quad` faz isto e devolve uma estimativa do erro.
- **Gauss-Legendre:** escolhe os pontos de forma ótima; com n pontos integra exatamente polinómios de grau 2n − 1.
- **Monte Carlo** (Probabilidades, lição 6): para integrais em muitas dimensões, onde as grelhas são impossíveis (com 10 dimensões e 10 pontos por eixo, 10¹⁰ pontos). O erro diminui com 1/√n, seja qual for a dimensão.

## Dados medidos

Com uma tabela de medições (por exemplo, a velocidade de um carro a cada segundo), integra-se com os trapézios para obter a distância, sem precisar de nenhuma fórmula para a função.
