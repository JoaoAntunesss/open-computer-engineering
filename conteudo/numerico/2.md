Encontrar x tal que f(x) = 0 é um dos problemas mais comuns em computação numérica: a taxa de juro que iguala uma prestação, o instante em que dois objetos colidem, o preço que equilibra oferta e procura. Quase nunca há fórmula, por isso usam-se métodos **iterativos**: começam numa aproximação e melhoram-na até ser suficientemente boa.

## Bisseção

Se f é contínua e f(a) e f(b) têm sinais opostos, há um zero entre a e b (teorema de Bolzano). Divide-se o intervalo ao meio e fica-se com a metade onde o sinal muda.

- **Sempre converge** (com as condições acima).
- Lenta: cada passo ganha 1 bit de precisão (o erro passa para metade). Para 10⁻¹⁰ a partir de um intervalo de largura 1, cerca de 34 passos.

## Newton-Raphson

Usa a tangente: a partir de xₙ, segue a reta tangente até ao eixo dos x.

xₙ₊₁ = xₙ − f(xₙ) / f'(xₙ)

- **Convergência quadrática** perto do zero: o número de algarismos certos **duplica** a cada passo.
- Precisa da derivada.
- Pode falhar: se f'(x) ≈ 0 (tangente quase horizontal), salta para longe; se começar mal, pode oscilar ou divergir.

## Secante

Como Newton, mas aproxima a derivada com os dois últimos pontos. Não precisa de f'. Convergência um pouco mais lenta (ordem ≈ 1,618, a razão de ouro).

## Comparar

```python run
import math

def bissecao(f, a, b, tol=1e-12):
    passos = 0
    while b - a > tol:
        m = (a + b) / 2
        if f(a) * f(m) <= 0: b = m
        else: a = m
        passos += 1
    return (a + b) / 2, passos

def newton(f, df, x, tol=1e-12, maximo=50):
    for passos in range(1, maximo + 1):
        novo = x - f(x) / df(x)
        if abs(novo - x) < tol:
            return novo, passos
        x = novo
    return x, maximo

def secante(f, x0, x1, tol=1e-12, maximo=50):
    for passos in range(1, maximo + 1):
        x2 = x1 - f(x1) * (x1 - x0) / (f(x1) - f(x0))
        if abs(x2 - x1) < tol:
            return x2, passos
        x0, x1 = x1, x2
    return x1, maximo

f = lambda x: x ** 3 - 2 * x - 5          # o exemplo histórico de Newton
df = lambda x: 3 * x ** 2 - 2
print("bisseção:", bissecao(f, 2, 3))
print("Newton:  ", newton(f, df, 2))
print("secante: ", secante(f, 2, 3))

# os algarismos certos duplicam em cada passo de Newton
raiz = newton(f, df, 2)[0]
x = 2.0
for k in range(5):
    x = x - f(x) / df(x)
    print(f"passo {k + 1}: erro {abs(x - raiz):.1e}")
```

## Quando Newton falha

```python run
f = lambda x: x ** (1 / 3) if x >= 0 else -(-x) ** (1 / 3)     # raiz cúbica: zero em 0
df = lambda x: (1 / 3) * abs(x) ** (-2 / 3)
x = 1.0
for k in range(6):
    x = x - f(x) / df(x)
    print(f"passo {k + 1}: x = {x}")
```

Prevê o que acontece. Aqui, cada passo de Newton dá exatamente −2x: afasta-se do zero e oscila cada vez mais. Na prática, combinam-se métodos: o **método de Brent** (o `scipy.optimize.brentq`) usa a bisseção para garantir a convergência e a secante ou interpolação para a velocidade.

## Critérios de paragem

- |xₙ₊₁ − xₙ| < tolerância (o passo é pequeno);
- |f(xₙ)| < tolerância (o valor está perto de zero);
- um número máximo de iterações, **sempre**, para não ficar em ciclo infinito;
- para números grandes, uma tolerância **relativa** (|xₙ₊₁ − xₙ| < tol · |xₙ|), como viste na lição de leitura de código.
