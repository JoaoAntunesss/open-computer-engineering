Resolver sistemas de equações lineares Ax = b é provavelmente a operação mais usada em computação científica: simulações de estruturas e de fluidos, circuitos elétricos, gráficos, regressão, redes neuronais. Em Álgebra Linear aprendeste a eliminação de Gauss à mão; aqui interessa fazê-la bem num computador: depressa, sem amplificar erros, e para sistemas com milhões de incógnitas.

## Eliminação de Gauss e fatorização LU

A eliminação de Gauss transforma A numa matriz triangular superior U; os multiplicadores usados formam uma matriz triangular inferior L. Fica **A = LU** (com trocas de linhas: PA = LU). Depois, resolver Ax = b é resolver dois sistemas triangulares, muito fáceis:

1. Ly = Pb (substituição para a frente)
2. Ux = y (substituição para trás)

Custo: fatorizar é O(n³); cada resolução depois é só O(n²). Se tiveres de resolver com a mesma A e muitos b diferentes, fatoriza-se uma vez.

## Escolha de pivô

Dividir por um pivô pequeno amplifica os erros de arredondamento. Com **pivotagem parcial**, troca-se a linha atual pela que tem o maior valor absoluto naquela coluna. Prevê o que acontece sem pivô:

```python run
def gauss(A, b, pivotagem=True):
    n = len(A)
    M = [row[:] + [bi] for row, bi in zip(A, b)]
    for k in range(n):
        if pivotagem:
            p = max(range(k, n), key=lambda i: abs(M[i][k]))
            M[k], M[p] = M[p], M[k]
        for i in range(k + 1, n):
            f = M[i][k] / M[k][k]
            for j in range(k, n + 1):
                M[i][j] -= f * M[k][j]
    x = [0.0] * n
    for i in reversed(range(n)):
        x[i] = (M[i][n] - sum(M[i][j] * x[j] for j in range(i + 1, n))) / M[i][i]
    return x

A = [[1e-17, 1.0], [1.0, 1.0]]       # solução exata: x ≈ 1, y ≈ 1
b = [1.0, 2.0]
print("sem pivotagem:", gauss(A, b, pivotagem=False))
print("com pivotagem:", gauss(A, b, pivotagem=True))
```

Sem pivotagem, o multiplicador é 10¹⁷ e o resultado fica destruído. Todas as bibliotecas sérias pivotam.

## Na prática: NumPy e SciPy

```python run
import numpy as np

A = np.array([[4.0, -1, 0], [-1, 4, -1], [0, -1, 4]])
b = np.array([2.0, 4, 10])
x = np.linalg.solve(A, b)                  # LU com pivotagem (LAPACK)
print("x =", x, " verificação:", np.allclose(A @ x, b))

# NUNCA calcular a inversa para resolver um sistema: mais lento e menos exato
print("com inversa:", np.linalg.inv(A) @ b)

# condicionamento: quanto o problema amplifica erros nos dados
H = np.array([[1 / (i + j + 1) for j in range(8)] for i in range(8)])   # matriz de Hilbert
print(f"número de condição de A: {np.linalg.cond(A):.1f}   de Hilbert 8×8: {np.linalg.cond(H):.1e}")
xh = np.linalg.solve(H, H @ np.ones(8))    # a solução exata é tudo 1
print("Hilbert, erro máximo:", np.abs(xh - 1).max())
```

Prevê o erro com a matriz de Hilbert. Um número de condição de 10¹⁰ quer dizer que se podem perder cerca de 10 algarismos dos 16 disponíveis. Não é culpa do algoritmo: é o problema que é sensível.

## Métodos iterativos

Para sistemas **enormes e esparsos** (milhões de incógnitas, mas cada equação só envolve algumas, como numa malha de elementos finitos), O(n³) é impossível e a matriz nem cabe em memória como densa. Usam-se métodos que só precisam de multiplicar A por um vetor:

- **Jacobi:** cada incógnita é recalculada a partir dos valores anteriores das outras.
- **Gauss-Seidel:** igual, mas usa logo os valores acabados de calcular. Converge mais depressa.
- **Gradiente conjugado** (para matrizes simétricas definidas positivas) e **GMRES**: os usados na prática, com **pré-condicionadores**.

Jacobi e Gauss-Seidel convergem quando a matriz é **diagonalmente dominante** (em cada linha, o elemento da diagonal é maior do que a soma dos outros em valor absoluto), como a matriz A do exemplo.

```python run
A = [[4.0, -1, 0], [-1, 4, -1], [0, -1, 4]]
b = [2.0, 4, 10]
x = [0.0, 0.0, 0.0]
for it in range(1, 30):
    antigo = x[:]
    for i in range(3):                       # Gauss-Seidel: usa logo os x[j] novos
        x[i] = (b[i] - sum(A[i][j] * x[j] for j in range(3) if j != i)) / A[i][i]
    if max(abs(x[i] - antigo[i]) for i in range(3)) < 1e-10:
        break
print("iterações:", it, " x =", [round(v, 6) for v in x])
```
