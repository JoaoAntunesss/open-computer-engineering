O **servidor** (back-end) é onde ficam os dados, as regras que não podem ser contornadas e os segredos (chaves de APIs, palavras-passe da base de dados). O browser é de quem o usa: tudo o que lá corre pode ser visto e alterado. Por isso, validações, preços, permissões e pagamentos decidem-se sempre no servidor. As tecnologias mais comuns: **Node.js** (JavaScript), **PHP/Laravel**, **Python/Django ou FastAPI**, **Java/Spring**.

## O que um servidor web faz

1. Recebe um pedido HTTP.
2. **Encaminha-o** (routing) para a função certa, conforme o método e o caminho.
3. Passa por **middleware**: autenticação, registo (logs), limites de pedidos, análise do JSON.
4. Valida os dados, aplica as regras, fala com a base de dados.
5. Devolve uma resposta (JSON, HTML, um ficheiro).

## Node.js com Express

```js
// servidor.js — npm install express
import express from "express";
const app = express();
app.use(express.json());                                   // middleware: lê JSON

const marcacoes = [];                                      // num projeto real: base de dados

app.get("/api/marcacoes", (req, res) => {
  const { dia } = req.query;
  res.json(dia ? marcacoes.filter(m => m.inicio.startsWith(dia)) : marcacoes);
});

app.post("/api/marcacoes", (req, res) => {
  const { cliente, telefone, inicio } = req.body ?? {};
  if (!cliente || !/^9\d{8}$/.test(telefone ?? "") || isNaN(Date.parse(inicio)))
    return res.status(422).json({ erro: "dados_invalidos" });
  if (marcacoes.some(m => m.inicio === inicio))
    return res.status(409).json({ erro: "hora_ocupada" });
  const nova = { id: marcacoes.length + 1, cliente, telefone, inicio };
  marcacoes.push(nova);
  res.status(201).json(nova);
});

app.listen(3000, () => console.log("http://localhost:3000"));
```

## Python com FastAPI

```python
# main.py — pip install fastapi uvicorn; uvicorn main:app --reload
from datetime import datetime
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

app = FastAPI()
marcacoes: list[dict] = []

class NovaMarcacao(BaseModel):            # a validação vem dos tipos
    cliente: str = Field(min_length=1)
    telefone: str = Field(pattern=r"^9\d{8}$")
    inicio: datetime

@app.post("/api/marcacoes", status_code=201)
def criar(m: NovaMarcacao):
    if any(x["inicio"] == m.inicio for x in marcacoes):
        raise HTTPException(409, "hora_ocupada")
    nova = {"id": len(marcacoes) + 1, **m.model_dump()}
    marcacoes.append(nova)
    return nova
```

O FastAPI gera documentação interativa automaticamente em `/docs`. No Laravel e no Django há o mesmo padrão: rotas, controladores, validação, modelos (ORM) e migrações da base de dados.

## Validar no servidor, sempre

A validação no browser é para dar feedback rápido; a do servidor é a que conta, porque qualquer pessoa pode enviar pedidos diretamente (com `curl`, ou mudando o JavaScript da página). Prevê o que o validador abaixo aceita:

```python run
import re
from datetime import datetime, timedelta

AGORA = datetime(2026, 11, 9, 12, 0)
HORARIO = (9, 19)                                   # abre às 9h, fecha às 19h
PRECOS = {"corte": 1500, "cor": 4500}               # cêntimos; o preço vem do servidor

def valida(pedido):
    erros = []
    if not re.fullmatch(r"9[1236]\d{7}", pedido.get("telefone", "")):
        erros.append("telefone inválido")
    try:
        inicio = datetime.fromisoformat(pedido.get("inicio", ""))
        if inicio < AGORA + timedelta(hours=2):
            erros.append("é preciso marcar com 2 horas de antecedência")
        if not HORARIO[0] <= inicio.hour < HORARIO[1]:
            erros.append("fora do horário")
    except ValueError:
        erros.append("data inválida")
    if pedido.get("servico") not in PRECOS:
        erros.append("serviço desconhecido")
    preco = PRECOS.get(pedido.get("servico"))        # o "preco" enviado pelo cliente é ignorado
    return erros or f"ok, a pagar {preco / 100:.2f} €"

pedidos = [
    {"telefone": "912345678", "inicio": "2026-11-10T10:00", "servico": "corte", "preco": 0},
    {"telefone": "812345678", "inicio": "2026-11-09T13:00", "servico": "corte"},
    {"telefone": "961234567", "inicio": "2026-11-10T20:30", "servico": "unhas"},
    {"telefone": "931234567", "inicio": "amanhã às 10", "servico": "cor"},
]
for p in pedidos:
    print(valida(p))
```

Repara no primeiro pedido: o cliente tentou pôr `"preco": 0`. O servidor ignora-o e usa o seu preço.

## Variáveis de ambiente e segredos

Configuração e segredos (a ligação à base de dados, a chave da API de SMS) vêm de **variáveis de ambiente**, nunca escritos no código: `process.env.SMS_KEY` (Node), `os.environ["SMS_KEY"]` (Python). Em desenvolvimento, um ficheiro `.env` **no `.gitignore`**.
