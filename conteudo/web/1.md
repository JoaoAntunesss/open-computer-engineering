O HTML diz **o que cada coisa é**: um título, uma lista, um botão, um formulário, o conteúdo principal. O browser, os leitores de ecrã, os motores de pesquisa e as ferramentas de tradução usam essa informação. Escrever HTML semântico é a coisa mais barata que podes fazer pela acessibilidade e pelo SEO de um site, e dá menos trabalho do que o contrário.

## A estrutura de uma página

```html
<!doctype html>
<html lang="pt-PT">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Salão Aurora — Marcações online</title>
  <meta name="description" content="Marque o seu corte ou coloração em 1 minuto.">
  <link rel="stylesheet" href="estilo.css">
</head>
<body>
  <header>
    <a href="/" aria-label="Salão Aurora, página inicial"><img src="logo.svg" alt=""></a>
    <nav aria-label="Principal">
      <ul>
        <li><a href="/servicos">Serviços</a></li>
        <li><a href="/marcar" aria-current="page">Marcar</a></li>
      </ul>
    </nav>
  </header>
  <main>
    <h1>Marcar um serviço</h1>
    <section aria-labelledby="t-servicos">
      <h2 id="t-servicos">Escolha o serviço</h2>
      …
    </section>
  </main>
  <footer>
    <address>Rua das Flores, 12, Porto · <a href="tel:+351912345678">912 345 678</a></address>
  </footer>
</body>
</html>
```

- `lang`: os leitores de ecrã escolhem a pronúncia; o browser oferece tradução.
- `viewport`: sem ele, o telemóvel mostra a página como num ecrã de computador, minúscula.
- `title` e `description`: o que aparece no separador e no Google.

## Elementos de estrutura

| Elemento | Significado |
|---|---|
| `header`, `footer` | cabeçalho e rodapé (da página ou de uma secção) |
| `nav` | navegação principal |
| `main` | o conteúdo principal (um por página) |
| `section` | uma secção temática, com título |
| `article` | conteúdo que faz sentido sozinho (uma publicação, um cartão de produto) |
| `aside` | conteúdo relacionado, à parte |
| `h1`…`h6` | títulos, por ordem, sem saltar níveis |

Um `div` não significa nada: usa-se só para agrupar por razões de estilo.

## Elementos interativos

- **Ligações** (`<a href>`) levam a outro sítio; **botões** (`<button>`) fazem uma ação. Não troques: um "botão" que é um `div` com `onclick` não funciona com teclado nem é anunciado como botão.
- **Formulários:** cada campo com o seu `label`, o `type` certo e `autocomplete`.

```html
<form action="/marcar" method="post">
  <fieldset>
    <legend>Os seus dados</legend>
    <label for="nome">Nome</label>
    <input id="nome" name="nome" autocomplete="name" required>

    <label for="tel">Telemóvel</label>
    <input id="tel" name="tel" type="tel" autocomplete="tel" inputmode="numeric"
           pattern="9[1236][0-9]{7}" required aria-describedby="tel-dica">
    <small id="tel-dica">9 dígitos, para o lembrete por SMS.</small>

    <label for="dia">Dia</label>
    <input id="dia" name="dia" type="date" min="2026-11-10" required>
  </fieldset>
  <button type="submit">Confirmar marcação</button>
</form>
```

`type="tel"` abre o teclado numérico no telemóvel; `type="date"`, o calendário; `required` e `pattern` validam antes de enviar (mas o servidor tem de validar outra vez: o browser não é de confiança).

## Verificar uma página

A estrutura dos títulos é o índice da página para quem usa um leitor de ecrã. Este pequeno verificador encontra problemas comuns num excerto de HTML:

```js run
const html = `
<h1>Salão Aurora</h1>
<h3>Serviços</h3>
<img src="corte.jpg">
<div onclick="marcar()">Marcar</div>
<input id="email" type="email">
<h2>Contactos</h2>
<a href="#">clique aqui</a>`;

const problemas = [];
let nivel = 0;
for (const m of html.matchAll(/<h([1-6])>/g)) {
  const n = Number(m[1]);
  if (n > nivel + 1) problemas.push(`salto de h${nivel} para h${n}`);
  nivel = n;
}
for (const m of html.matchAll(/<img(?![^>]*\balt=)[^>]*>/g)) problemas.push(`imagem sem alt: ${m[0]}`);
if (/<div[^>]*onclick/.test(html)) problemas.push("div com onclick (devia ser <button>)");
for (const m of html.matchAll(/<input[^>]*id="([^"]+)"/g))
  if (!html.includes(`for="${m[1]}"`)) problemas.push(`campo #${m[1]} sem label`);
if (/>\s*(clique aqui|aqui|ver mais)\s*</i.test(html)) problemas.push("texto de ligação sem significado");
console.log(problemas.join("\n"));
```

Prevê os problemas que encontra. Na prática, usa o **Lighthouse** ou o **axe** nas ferramentas de programador: verificam isto e muito mais.
