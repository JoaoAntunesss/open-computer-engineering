O CSS decide o aspeto da página: cores, letras, espaços e, sobretudo, a **disposição** dos elementos. Durante anos isso fazia-se com truques (`float`, tabelas). Hoje há duas ferramentas feitas de propósito: o **flexbox**, para alinhar coisas numa direção, e a **grelha** (*grid*), para disposições em duas dimensões. Com elas e com **media queries**, a mesma página funciona num telemóvel e num ecrã grande.

## O modelo de caixa

Cada elemento é uma caixa: conteúdo, `padding` (espaço interior), `border`, `margin` (espaço exterior). Põe isto no início de todas as folhas de estilo:

```css
*, *::before, *::after { box-sizing: border-box; }
```

Assim, `width: 300px` inclui o padding e a borda, o que torna as contas previsíveis.

## Flexbox: uma dimensão

```css
.barra {
  display: flex;
  justify-content: space-between;   /* eixo principal: distribuição */
  align-items: center;              /* eixo cruzado: alinhamento */
  gap: 1rem;                        /* espaço entre os filhos */
}
.servicos {
  display: flex;
  flex-wrap: wrap;                  /* passa para a linha seguinte se não couber */
  gap: 1rem;
}
.servicos > .cartao { flex: 1 1 220px; }   /* cresce, encolhe, base de 220px */
```

Serve para barras de navegação, centrar coisas, filas de botões, listas de cartões que se adaptam.

## Grid: duas dimensões

```css
.pagina {
  display: grid;
  grid-template-columns: 240px 1fr;          /* barra lateral fixa + resto */
  grid-template-areas:
    "topo  topo"
    "lado  conteudo"
    "rodape rodape";
  gap: 1.5rem;
  min-height: 100vh;
}
header { grid-area: topo; }
aside  { grid-area: lado; }
main   { grid-area: conteudo; }
footer { grid-area: rodape; }

/* uma grelha de cartões sem media queries */
.galeria {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  gap: 1rem;
}
```

`fr` é uma fração do espaço que sobra. `repeat(auto-fill, minmax(200px, 1fr))` cria tantas colunas quantas couberem, cada uma com pelo menos 200px.

Regra prática: **grid** para a disposição da página e de grelhas; **flex** para alinhar coisas dentro de um componente.

## Responsivo

**Mobile first:** escreve primeiro o estilo para ecrãs pequenos e acrescenta regras para ecrãs maiores.

```css
.pagina { display: grid; grid-template-columns: 1fr; }      /* telemóvel: uma coluna */

@media (min-width: 768px) {
  .pagina { grid-template-columns: 240px 1fr; }             /* a partir de 768px: duas */
}
```

Outras ferramentas:

- Unidades relativas: `rem` (relativa ao tamanho de letra da raiz; respeita a preferência do utilizador), `%`, `vw`/`vh`.
- `clamp(1.5rem, 4vw, 3rem)`: tamanho que cresce com o ecrã, entre um mínimo e um máximo.
- Imagens: `max-width: 100%; height: auto;` e `srcset` para servir imagens mais pequenas aos telemóveis.
- Alvos de toque com pelo menos 44 × 44 px.

## Simular o auto-fill

Prevê quantas colunas cabem em cada largura de ecrã com `repeat(auto-fill, minmax(200px, 1fr))` e `gap: 16px`:

```js run
function colunas(largura, minimo = 200, gap = 16) {
  // n colunas cabem se n * minimo + (n - 1) * gap <= largura
  const n = Math.max(1, Math.floor((largura + gap) / (minimo + gap)));
  const larguraColuna = (largura - (n - 1) * gap) / n;
  return { n, larguraColuna: Math.round(larguraColuna) };
}
for (const w of [360, 430, 768, 1024, 1440]) {
  const { n, larguraColuna } = colunas(w);
  console.log(`${String(w).padStart(4)}px → ${n} coluna(s) de ${larguraColuna}px`);
}
```

## Variáveis e cascata

```css
:root {
  --cor-principal: #6b2d5c;
  --espaco: 1rem;
}
@media (prefers-color-scheme: dark) {
  :root { --cor-principal: #e2a4cf; }
}
.botao { background: var(--cor-principal); padding: var(--espaco); }
```

A **cascata** decide que regra ganha quando várias se aplicam: importância (`!important`), depois **especificidade** (id > classe > elemento), depois a ordem (a última ganha). Mantém a especificidade baixa (sobretudo classes) e evita `!important`: é a forma de o CSS não se tornar uma guerra.
