Em produção não tens o depurador, nem prints no terminal, nem o utilizador ao lado a dizer o que clicou. Tens **logs** e **alertas de erros**. Se não os preparares antes, quando algo partir vais estar às escuras.

## Logs em vez de prints

```python
import logging

logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(name)s %(message)s")
log = logging.getLogger("marcacoes")

def criar_marcacao(dados, utilizador_id):
    log.info("criar marcacao utilizador=%s inicio=%s", utilizador_id, dados.inicio)
    try:
        ...
    except HoraOcupada:
        log.warning("hora ocupada utilizador=%s inicio=%s", utilizador_id, dados.inicio)
        raise
```

Os níveis dizem a importância:

| Nível | Para |
|---|---|
| `DEBUG` | Pormenores para depurar (desligado em produção) |
| `INFO` | Acontecimentos normais (marcação criada) |
| `WARNING` | Algo estranho mas tratado (hora ocupada, pedido inválido) |
| `ERROR` | Falhou e o utilizador sentiu |
| `CRITICAL` | O sistema não consegue funcionar |

## Bons logs

- Dizem **o quê**, **quem** e **com que dados** (identificadores, não dados pessoais).
- **Nunca** contêm passwords, tokens, números de cartão ou dados de saúde.
- São estruturados (campos `chave=valor` ou JSON), para se poderem pesquisar e filtrar.
- Têm um identificador do pedido, para seguires um pedido do início ao fim.

## Apanhar erros com o Sentry

Um serviço como o Sentry (plano gratuito) recebe automaticamente cada erro não tratado, com o traceback, o pedido que o causou e quantos utilizadores afetou, e envia-te um alerta:

```python
import os
import sentry_sdk

sentry_sdk.init(dsn=os.environ.get("SENTRY_DSN"), traces_sample_rate=0.1)
```

Em vez de saberes do erro por um cliente zangado, sabes por um email, com o traceback já lá.

## Ler logs quando algo corre mal

1. Começa pela hora em que o problema aconteceu.
2. Procura os `ERROR` à volta dessa hora.
3. Usa o identificador do pedido para ver tudo o que esse pedido fez.
4. Tenta reproduzir localmente com os mesmos dados (vê a cadeira Depurar).
