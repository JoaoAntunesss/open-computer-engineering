O **FastAPI** é uma das formas mais simples e modernas de fazer uma API em Python. Valida os dados automaticamente, gera documentação interativa e é rápido. Nesta lição constróis a base de uma API de marcações.

## Instalar e correr

```text
python -m venv .venv
source .venv/bin/activate      # no Windows: .venv\Scripts\activate
pip install "fastapi[standard]"
fastapi dev main.py
```

Abre `http://127.0.0.1:8000/docs`: tens uma página onde podes experimentar todos os endpoints.

## A primeira API

```python
# main.py
from datetime import datetime
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

app = FastAPI(title="Marcações")

class NovaMarcacao(BaseModel):
    cliente: str = Field(min_length=2, max_length=80)
    servico: str
    inicio: datetime

class Marcacao(NovaMarcacao):
    id: int

marcacoes: dict[int, Marcacao] = {}
proximo_id = 1

@app.get("/marcacoes")
def listar() -> list[Marcacao]:
    return list(marcacoes.values())

@app.get("/marcacoes/{mid}")
def obter(mid: int) -> Marcacao:
    if mid not in marcacoes:
        raise HTTPException(status_code=404, detail="Marcação não existe")
    return marcacoes[mid]

@app.post("/marcacoes", status_code=201)
def criar(dados: NovaMarcacao) -> Marcacao:
    global proximo_id
    if any(m.inicio == dados.inicio for m in marcacoes.values()):
        raise HTTPException(status_code=409, detail="Hora já ocupada")
    m = Marcacao(id=proximo_id, **dados.model_dump())
    marcacoes[proximo_id] = m
    proximo_id += 1
    return m
```

## Como se lê

- `@app.get("/marcacoes")` liga a função ao pedido `GET /marcacoes`.
- `{mid}` no caminho passa a parâmetro da função, já convertido para `int`.
- `NovaMarcacao` é um modelo **Pydantic**: descreve o JSON esperado. Se o pedido vier com um campo em falta ou um `inicio` que não é data, o FastAPI responde 422 sozinho, com uma explicação.
- `HTTPException` devolve o código de erro certo.
- As anotações de tipo (`-> Marcacao`) servem para validar a resposta e gerar a documentação.

## Testar a API

```python
# test_main.py
from fastapi.testclient import TestClient
from main import app

c = TestClient(app)

def test_criar_e_obter():
    r = c.post("/marcacoes", json={"cliente": "Ana", "servico": "corte", "inicio": "2027-01-10T15:00"})
    assert r.status_code == 201
    mid = r.json()["id"]
    assert c.get(f"/marcacoes/{mid}").json()["cliente"] == "Ana"

def test_hora_ocupada_da_409():
    corpo = {"cliente": "Rui", "servico": "barba", "inicio": "2027-01-11T10:00"}
    c.post("/marcacoes", json=corpo)
    assert c.post("/marcacoes", json=corpo).status_code == 409
```
