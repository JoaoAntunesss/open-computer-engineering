O SQL é a linguagem para consultar e alterar bases de dados relacionais. Nesta lição treinas as consultas do dia a dia: filtrar, juntar tabelas, agrupar e usar subconsultas. Os exemplos correm aqui no browser, com SQLite (a base de dados do Android, do iOS e de muitas aplicações), através do Python.

## A base de dados de exemplo

```python run
import sqlite3
db = sqlite3.connect(":memory:")
db.executescript("""
CREATE TABLE cliente (id INTEGER PRIMARY KEY, nome TEXT, cidade TEXT);
CREATE TABLE servico (id INTEGER PRIMARY KEY, nome TEXT, preco REAL);
CREATE TABLE marcacao (id INTEGER PRIMARY KEY, cliente_id INTEGER REFERENCES cliente,
                       servico_id INTEGER REFERENCES servico, dia TEXT);
INSERT INTO cliente VALUES (1, 'Ana', 'Porto'), (2, 'Rui', 'Braga'), (3, 'Eva', 'Porto'), (4, 'Tó', 'Aveiro');
INSERT INTO servico VALUES (1, 'Corte', 15), (2, 'Coloração', 45), (3, 'Manicure', 20);
INSERT INTO marcacao VALUES (1, 1, 1, '2026-11-02'), (2, 1, 2, '2026-11-09'), (3, 3, 1, '2026-11-03'),
                            (4, 2, 3, '2026-11-03'), (5, 3, 2, '2026-11-10'), (6, 1, 1, '2026-11-16');
""")

def mostra(sql):
    cur = db.execute(sql)
    print(" | ".join(c[0] for c in cur.description))
    for linha in cur.fetchall():
        print(" | ".join(str(x) for x in linha))
    print()

mostra("SELECT nome, preco FROM servico WHERE preco > 18 ORDER BY preco DESC")

mostra("""
SELECT c.nome, s.nome AS servico, m.dia
FROM marcacao m
JOIN cliente c ON c.id = m.cliente_id
JOIN servico s ON s.id = m.servico_id
WHERE c.cidade = 'Porto'
ORDER BY m.dia
""")

mostra("""
SELECT c.nome, COUNT(m.id) AS marcacoes, COALESCE(SUM(s.preco), 0) AS gasto
FROM cliente c
LEFT JOIN marcacao m ON m.cliente_id = c.id
LEFT JOIN servico s ON s.id = m.servico_id
GROUP BY c.id
ORDER BY gasto DESC
""")

mostra("""
SELECT nome FROM cliente
WHERE id IN (SELECT cliente_id FROM marcacao WHERE servico_id = 2)
""")
```

Antes de correr, prevê o resultado de cada consulta. Repara no Tó na terceira: com `LEFT JOIN`, aparece com 0 marcações; com `JOIN`, desapareceria.

## Filtrar: WHERE

- Comparações: `=`, `<>`, `<`, `>=`, `BETWEEN 10 AND 20`, `IN ('Porto', 'Braga')`.
- Texto: `LIKE 'Ma%'` (começa por "Ma"), `LIKE '%ção'`.
- Nulos: `IS NULL`, `IS NOT NULL` (nunca `= NULL`, que dá sempre "desconhecido").
- `AND`, `OR`, `NOT`, com parênteses quando se misturam.

## Agregar: GROUP BY e HAVING

Funções de agregação: `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`.

- Sem `GROUP BY`, a agregação resume a tabela toda numa linha.
- Com `GROUP BY`, uma linha por grupo. No `SELECT` só podem aparecer as colunas do `GROUP BY` e agregações.
- `WHERE` filtra **linhas** antes de agrupar; `HAVING` filtra **grupos** depois.
- `COUNT(*)` conta linhas; `COUNT(coluna)` conta valores não nulos. Com `LEFT JOIN`, usa `COUNT(m.id)` para dar 0 a quem não tem marcações.

## Subconsultas

- **Em `WHERE ... IN`** (como a 4.ª consulta).
- **Escalares:** devolvem um só valor: `WHERE preco > (SELECT AVG(preco) FROM servico)`.
- **Correlacionadas:** referem a linha de fora; correm uma vez por linha: `WHERE EXISTS (SELECT 1 FROM marcacao m WHERE m.cliente_id = c.id)`.
- **No `FROM`** (tabela derivada) ou, de forma mais legível, com `WITH`:

```sql
WITH gasto AS (
  SELECT cliente_id, SUM(s.preco) AS total
  FROM marcacao m JOIN servico s ON s.id = m.servico_id
  GROUP BY cliente_id
)
SELECT c.nome, g.total FROM cliente c JOIN gasto g ON g.cliente_id = c.id
WHERE g.total > (SELECT AVG(total) FROM gasto);
```

## Alterar dados

```sql
INSERT INTO servico (nome, preco) VALUES ('Brushing', 12);
UPDATE servico SET preco = preco * 1.05 WHERE nome = 'Corte';
DELETE FROM marcacao WHERE dia < '2026-01-01';
```

Antes de um `UPDATE` ou `DELETE`, corre o mesmo `WHERE` num `SELECT` para veres que linhas vão ser afetadas. Um `DELETE` sem `WHERE` apaga a tabela inteira.
