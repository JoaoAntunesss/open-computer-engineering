Até agora, os programas faziam sempre a mesma coisa, linha após linha. Com **condições** o programa escolhe o que fazer; com **ciclos** repete trabalho. Com estas duas ideias, mais variáveis, consegues escrever qualquer algoritmo.

## if, elif, else

```python
nota = int(input("Nota (0-20): "))

if nota < 0 or nota > 20:
    print("Nota inválida")
elif nota >= 18:
    print("Excelente")
elif nota >= 10:
    print("Aprovado")
else:
    print("Reprovado")
```

- A **indentação** (4 espaços) é que define o que está dentro de cada bloco. Não é decoração: é a sintaxe do Python.
- As condições são testadas por ordem e só o primeiro bloco verdadeiro corre. Por isso o `elif nota >= 10` não precisa de dizer `and nota < 18`.

### O que conta como verdadeiro

Numa condição, o Python aceita qualquer valor. São **falsos** o `False`, o `0`, o `0.0`, a string vazia `""`, a lista vazia `[]` e o `None`. Tudo o resto é verdadeiro. Isto permite escrever:

```python
nome = input("Nome: ")
if not nome:
    print("Não escreveste nada")
```

## O ciclo while

Repete enquanto a condição for verdadeira:

```python
n = 1
while n <= 5:
    print(n)
    n += 1
```

O `while` serve quando **não sabes à partida** quantas vezes vais repetir. Por exemplo, pedir um valor até ser válido:

```python
idade = int(input("Idade: "))
while idade < 0 or idade > 130:
    print("Idade impossível, tenta outra vez.")
    idade = int(input("Idade: "))
```

Se a condição nunca ficar falsa, o ciclo nunca acaba. Se o teu programa parecer congelado, carrega em `Ctrl+C` e verifica se a variável da condição muda dentro do ciclo.

## O ciclo for

Percorre os elementos de uma sequência:

```python
for letra in "Porto":
    print(letra)

for i in range(5):          # 0, 1, 2, 3, 4
    print(i)

for i in range(2, 11, 2):   # 2, 4, 6, 8, 10 (início, fim exclusivo, passo)
    print(i)
```

O `range(a, b)` vai de `a` até `b - 1`. O fim fica de fora para que `range(n)` tenha exatamente `n` elementos.

Usa `for` quando sabes o que vais percorrer, e `while` quando a paragem depende de algo que vais descobrindo.

## Padrões que se repetem

Quase todos os ciclos são variações de quatro padrões. Reconhecê-los poupa-te de reinventar cada vez.

**Acumular**: começa num valor neutro e vai juntando.

```python
soma = 0
for x in range(1, 101):
    soma += x
print(soma)      # 5050
```

**Contar**:

```python
texto = "programação em python"
vogais = 0
for c in texto:
    if c in "aeiouáàãâéêíóõôú":
        vogais += 1
```

**Procurar o melhor**: guarda o melhor até agora e compara cada novo elemento.

```python
valores = [12, 7, 19, 3, 15]
maior = valores[0]
for v in valores[1:]:
    if v > maior:
        maior = v
```

**Procurar e parar**: o `break` sai do ciclo assim que encontras o que procuras.

```python
n = 91
primo = n > 1
for d in range(2, int(n ** 0.5) + 1):
    if n % d == 0:
        primo = False
        break
print(n, "é primo" if primo else "não é primo")    # 91 = 7 × 13
```

Repara que só testamos divisores até `√n`: se `n = a × b` com `a ≤ b`, então `a ≤ √n`. Este tipo de raciocínio é o que separa um programa que demora um segundo de um que demora uma hora.

O `continue` salta para a próxima volta do ciclo sem executar o resto do bloco.

## Ciclos dentro de ciclos

```python
for linha in range(1, 6):
    for coluna in range(1, 6):
        print(f"{linha * coluna:4}", end="")
    print()          # muda de linha no fim de cada linha da tabuada
```

O ciclo de dentro corre inteiro em cada volta do de fora: aqui são 5 × 5 = 25 multiplicações. Com dois ciclos de `n` voltas cada, o trabalho cresce com `n²`. Vais voltar a isto quando falarmos de complexidade.

## Erros comuns

- Indentação misturada (tabs e espaços). Configura o editor para inserir 4 espaços.
- `while` cuja variável nunca muda: ciclo infinito.
- Erros de um a mais ou a menos com `range` (*off-by-one*): `range(1, 10)` não inclui o 10.
- Modificar uma lista enquanto a percorres com `for`.
- Usar `=` dentro de um `if` em vez de `==` (em Python dá erro de sintaxe, em C compila e faz asneira).
