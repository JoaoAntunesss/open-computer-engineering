Os programas reais trabalham com coleções de dados: as notas de uma turma, os contactos de uma agenda, as palavras de um texto. O Python tem quatro estruturas embutidas, cada uma com um propósito. Escolher a certa torna o código mais simples e, muitas vezes, muito mais rápido.

## Listas: sequências que mudam

Uma **lista** guarda elementos por ordem, e pode crescer, encolher e ser alterada.

```python
notas = [14, 9, 17, 12]
notas[0]          # 14  (o primeiro elemento tem índice 0)
notas[-1]         # 12  (índices negativos contam do fim)
notas[1:3]        # [9, 17]  (fatia: do índice 1 até ao 3, exclusive)
len(notas)        # 4

notas.append(15)          # acrescenta no fim
notas.insert(0, 10)       # insere na posição 0
notas.remove(9)           # remove o primeiro 9
ultimo = notas.pop()      # tira e devolve o último
notas.sort()              # ordena a própria lista
ordenadas = sorted(notas, reverse=True)   # devolve uma lista nova
12 in notas               # True
```

### Compreensões de listas

Uma forma compacta de construir listas a partir de outras:

```python
quadrados = [x * x for x in range(1, 6)]           # [1, 4, 9, 16, 25]
aprovados = [n for n in notas if n >= 10]
nomes_maiusculas = [n.upper() for n in ["ana", "rui"]]
```

Lê-se como em matemática: "o conjunto de `x²` para `x` de 1 a 5".

### Atenção: variáveis apontam para objetos

```python
a = [1, 2, 3]
b = a           # b aponta para a MESMA lista
b.append(4)
print(a)        # [1, 2, 3, 4]  — a também mudou
c = a.copy()    # c é uma lista nova com os mesmos elementos
```

Isto é das fontes de erros mais comuns em Python. O `=` nunca copia: dá mais um nome ao mesmo objeto. O mesmo acontece quando passas uma lista a uma função: se a função a alterar, alteras a original.

## Tuplos: sequências fixas

Um **tuplo** é como uma lista que não pode ser alterada:

```python
ponto = (3, 4)
x, y = ponto              # desempacotar
data = (2026, 11, 2)
data[0] = 2027            # TypeError: tuplos não se alteram
```

Usa tuplos para grupos fixos de valores com significado por posição (coordenadas, datas, um registo), e para devolver vários valores de uma função:

```python
def min_max(valores):
    return min(valores), max(valores)

menor, maior = min_max([4, 1, 9])
```

## Dicionários: procurar por chave

Um **dicionário** associa **chaves** a **valores**. Em vez de procurares pela posição, procuras pelo nome:

```python
idades = {"Ana": 21, "Rui": 19}
idades["Ana"]               # 21
idades["Bea"] = 22          # acrescenta
idades["Rui"] += 1          # altera
"Ana" in idades             # True (procura nas chaves)
idades.get("Zé", 0)         # 0 se a chave não existir, em vez de erro
del idades["Bea"]

for nome, idade in idades.items():
    print(f"{nome} tem {idade} anos")
```

O dicionário é a estrutura mais útil do Python. Um exemplo clássico, contar palavras:

```python
texto = "o rato roeu a rolha o rato fugiu"
contagem = {}
for palavra in texto.split():
    contagem[palavra] = contagem.get(palavra, 0) + 1
# {'o': 2, 'rato': 2, 'roeu': 1, 'a': 1, 'rolha': 1, 'fugiu': 1}
```

Procurar uma chave num dicionário é **quase instantâneo**, mesmo com milhões de entradas, porque usa uma tabela de dispersão (*hash table*). Procurar um valor numa lista obriga a percorrê-la. Vais perceber porquê em Algoritmos e Estruturas de Dados.

As chaves têm de ser imutáveis (números, strings, tuplos). Os valores podem ser qualquer coisa, incluindo listas e outros dicionários:

```python
aluno = {
    "nome": "Ana",
    "numero": 2500123,
    "notas": {"Programação": 17, "Cálculo": 14},
}
aluno["notas"]["Cálculo"]     # 14
```

## Conjuntos: elementos únicos

Um **conjunto** guarda elementos sem ordem e sem repetições:

```python
inscritos_prog = {"Ana", "Rui", "Bea"}
inscritos_calc = {"Rui", "Zé"}

inscritos_prog & inscritos_calc     # {'Rui'}  interseção
inscritos_prog | inscritos_calc     # todos     união
inscritos_prog - inscritos_calc     # {'Ana', 'Bea'}  diferença
set([3, 1, 3, 2, 1])                # {1, 2, 3}  tirar repetidos
```

Como nos dicionários, testar `x in conjunto` é praticamente instantâneo.

## Qual escolher

| Precisas de… | Usa |
|---|---|
| uma sequência ordenada que muda | lista |
| um grupo fixo de valores | tuplo |
| procurar algo pelo nome ou identificador | dicionário |
| saber se algo existe, sem repetições | conjunto |

## Erros comuns

- Achar que `b = a` copia uma lista.
- Usar uma lista para perguntar "isto existe?" milhares de vezes, quando um conjunto o faz sem custo.
- `KeyError` ao aceder a uma chave que não existe: usa `in` ou `.get()`.
- Confundir `lista.sort()` (altera a lista e devolve `None`) com `sorted(lista)` (devolve uma nova).
- Alterar uma lista enquanto a percorres com `for`. Constrói uma lista nova com uma compreensão.

## Ler e prever: coleções

Nos dados reais aparecem quase sempre listas de dicionários. Lê de fora para dentro: a lista, cada elemento, cada campo.

```python run
encomendas = [
    {"cliente": "Ana", "total": 25.0, "paga": True},
    {"cliente": "Rui", "total": 40.5, "paga": False},
    {"cliente": "Sofia", "total": 12.0, "paga": True},
]
recebido = 0
for e in encomendas:
    if e["paga"]:
        recebido = recebido + e["total"]
print(recebido)
```

Uma armadilha que só se vê a ler com atenção: duas variáveis podem apontar para a **mesma** lista.

```python run
a = [1, 2, 3]
b = a
b.append(4)
print(a)
```

`b = a` não copia; mudar `b` muda "as duas". Para copiar: `b = a.copy()`.

Prevê antes de correr:

nums = [5, 3, 8, 1]
nums.append(nums[0] + nums[-1])

## Prática com correção automática

Escreve a solução no editor e carrega em **Testar**: o teu código é corrido contra vários casos e vês logo quais passam. Tenta primeiro sem ajuda; a dica e a solução estão lá para quando precisares.

```exercicio
id: ip4-maior-lista
titulo: O maior da lista
enunciado: Escreve `maior_da_lista(numeros)`, que devolve o maior número da lista, sem usar `max` nem ordenar. Se a lista estiver vazia, devolve `None`.
dica: Trata primeiro a lista vazia. Depois começa com o primeiro elemento e percorre os outros com um `for`.
proibido: max, sorted, sort
inicio:
def maior_da_lista(numeros):
    return None
testes:
maior_da_lista([3, 9, 2]) == 9
maior_da_lista([5]) == 5
maior_da_lista([-3, -1, -7]) == -1
maior_da_lista([]) == None
maior_da_lista([4, 4, 4]) == 4
solucao:
def maior_da_lista(numeros):
    if not numeros:
        return None
    m = numeros[0]
    for x in numeros[1:]:
        if x > m:
            m = x
    return m
```

```exercicio
id: ip4-pares
titulo: Só os pares
enunciado: Escreve `so_pares(numeros)`, que devolve uma **nova** lista só com os números pares, pela mesma ordem. A lista original não deve mudar.
dica: Cria uma lista vazia e vai acrescentando com `append` os que têm `x % 2 == 0`. Também dá com uma compreensão de lista.
inicio:
def so_pares(numeros):
    return []
testes:
so_pares([1, 2, 3, 4, 5, 6]) == [2, 4, 6]
so_pares([1, 3, 5]) == []
so_pares([]) == []
so_pares([0, -2, 7]) == [0, -2]
(lambda xs: (so_pares(xs), xs)[1])([1, 2]) == [1, 2]
solucao:
def so_pares(numeros):
    return [x for x in numeros if x % 2 == 0]
```

```exercicio
id: ip4-contar
titulo: Contar palavras
enunciado: Escreve `contar(palavras)`, que recebe uma lista de palavras e devolve um dicionário com quantas vezes aparece cada uma. Por exemplo, `["a", "b", "a"]` dá `{"a": 2, "b": 1}`.
dica: Para cada palavra: se ainda não está no dicionário, começa em 0; depois soma 1. `d.get(p, 0) + 1` faz as duas coisas.
proibido: Counter
inicio:
def contar(palavras):
    return {}
testes:
contar(["a", "b", "a"]) == {"a": 2, "b": 1}
contar([]) == {}
contar(["sol", "sol", "sol"]) == {"sol": 3}
contar(["Ana", "ana"]) == {"Ana": 1, "ana": 1}
solucao:
def contar(palavras):
    d = {}
    for p in palavras:
        d[p] = d.get(p, 0) + 1
    return d
```
