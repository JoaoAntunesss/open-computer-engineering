Vamos usar **Python 3**: lê-se quase como português técnico e é a linguagem de entrada no MIT, em Berkeley e no IST.

## Expressões e valores

Uma **expressão** é algo que o Python avalia e que dá um **valor**:

```python
>>> 2 + 3 * 4
14
>>> (2 + 3) * 4
20
>>> 7 / 2        # divisão real: dá sempre um float
3.5
>>> 7 // 2       # divisão inteira: arredonda para baixo
3
>>> 7 % 2        # resto da divisão
1
>>> 2 ** 10      # potência
1024
```

A precedência é a da matemática: `**` primeiro, depois `*`, `/`, `//`, `%`, e por fim `+` e `-`. Na dúvida, usa parênteses: tornam o código mais claro mesmo quando não são precisos.

## Tipos

Cada valor tem um **tipo**, que define o que se pode fazer com ele. A função `type` diz-te qual é:

```python
>>> type(42)
<class 'int'>          # inteiro, de tamanho ilimitado
>>> type(3.14)
<class 'float'>        # número real (vírgula flutuante)
>>> type("Lisboa")
<class 'str'>          # texto (string)
>>> type(True)
<class 'bool'>         # verdadeiro ou falso
```

Os inteiros em Python não têm limite: `2 ** 200` funciona. Os `float` têm precisão limitada, e isso tem consequências:

```python
>>> 0.1 + 0.2
0.30000000000000004
>>> 0.1 + 0.2 == 0.3
False
```

Não é um erro do Python: `0,1` não tem representação exata em binário, tal como `1/3` não tem em decimal. Para comparar floats, usa uma tolerância: `abs(a - b) < 1e-9`, ou `math.isclose(a, b)`.

O mesmo operador faz coisas diferentes consoante o tipo:

```python
>>> 3 + 4
7
>>> "3" + "4"
'34'          # juntar texto
>>> "ab" * 3
'ababab'
>>> "3" + 4
TypeError: can only concatenate str (not "int") to str
```

O Python não converte tipos às escondidas. Se queres converter, dizes explicitamente:

```python
>>> int("42") + 1
43
>>> str(42) + "!"
'42!'
>>> float("3.5")
3.5
>>> int(3.9)      # corta a parte decimal, não arredonda
3
```

## Variáveis

Uma **variável** é um nome que aponta para um valor. A atribuição usa `=`:

```python
preco = 12.5
quantidade = 3
total = preco * quantidade
print(total)       # 37.5
```

O `=` não é a igualdade da matemática: é uma ordem. "Avalia o lado direito e põe o nome do lado esquerdo a apontar para o resultado." Por isso isto faz sentido:

```python
contador = 0
contador = contador + 1     # agora vale 1
contador += 1               # forma abreviada: agora vale 2
```

Regras para nomes: letras, números e `_`, sem começar por número. Em Python usa-se `minusculas_com_underscores`. Escolhe nomes que digam o que o valor significa: `idade_media` em vez de `x2`. Daqui a um mês, és tu quem vai ler o código.

## Ler dados do utilizador

```python
nome = input("Como te chamas? ")
idade = int(input("Que idade tens? "))     # input devolve sempre texto
print(f"Olá, {nome}! Daqui a 10 anos terás {idade + 10} anos.")
```

O `f"..."` (*f-string*) substitui o que está entre `{}` pelo valor da expressão. Também formata números: `f"{3.14159:.2f}"` dá `'3.14'`.

## Valores lógicos

As comparações dão `True` ou `False`:

```python
>>> 5 > 3
True
>>> 5 == 5.0      # == compara; = atribui
True
>>> "abc" < "abd" # ordem alfabética (do código dos caracteres)
True
>>> 3 < 5 < 10    # Python permite encadear comparações
True
```

E combinam-se com `and`, `or` e `not`:

```python
idade = 20
tem_bilhete = True
pode_entrar = idade >= 18 and tem_bilhete
```

## Erros comuns

- Confundir `=` (atribuição) com `==` (comparação).
- Esquecer que `input` devolve texto: `input() + 1` dá `TypeError`.
- Comparar floats com `==`.
- Achar que `int(3.9)` arredonda. Para arredondar, usa `round(3.9)`.
- Nomes como `l`, `O` ou `x1`, `x2`, `x3`, que não dizem nada.

## Ler e prever: a tabela de rastreio

Ler código é uma competência à parte de o escrever, e treina-se. A ferramenta base é a **tabela de rastreio**: uma linha por instrução, uma coluna por variável, e o valor de cada uma depois dessa linha. Faz a tabela **antes** de correr e escreve o que esperas ver; só depois carrega em **Correr**.

```python run
pontos = 10
pontos = pontos + 5
pontos = pontos * 2
print(pontos)
```

| Linha | pontos |
|---|---|
| 1 | 10 |
| 2 | 15 |
| 3 | 30 |

O `=` lê-se "fica com": primeiro calcula-se o lado direito com o valor **antigo**, depois guarda-se. Agora um caso que engana quase toda a gente:

```python run
a = 1
b = 2
a = b
b = a
print(a, b)
```

Faz a tabela. Dá `2 2`, não `2 1`: na linha 3 o valor original de `a` perdeu-se. Para trocar a sério: `a, b = b, a`.

Prevê o resultado de cada programa antes de correr:

```python run
x = 4
y = x * 2
x = y - 1
y = x + y
print(x, y)
```

```python run
texto = "ab"
texto = texto + texto
texto = texto * 2
print(texto, len(texto), "7" + "1", 7 + 1)
```

??? Soluções (ler e prever)
1: x=4, y=8, x=7, y=15. Mostra `7 15`.

2: "ab" → "abab" → "abababab" (8 carateres). `"7" + "1"` junta textos: `71`; `7 + 1` soma: `8`. Mostra `abababab 8 71 8`.

## Exercícios

1. Escreve um programa que peça uma temperatura em graus Celsius e mostre o valor em Fahrenheit (`F = C × 9/5 + 32`), com uma casa decimal.
2. Pede um número de segundos e mostra-o no formato `h:mm:ss`. Por exemplo, `3725` dá `1:02:05`.
3. Sem correr, diz o valor e o tipo de cada expressão: `7 // 2 * 2`, `7 / 2 * 2`, `"7" * 2`, `10 % 3 == 1`, `int("7") + float("0.5")`.

??? Soluções
```python
# 1
c = float(input("Temperatura em °C: "))
f = c * 9 / 5 + 32
print(f"{c:.1f} °C = {f:.1f} °F")

# 2
total = int(input("Segundos: "))
horas = total // 3600
minutos = (total % 3600) // 60
segundos = total % 60
print(f"{horas}:{minutos:02d}:{segundos:02d}")
```
O `:02d` escreve o inteiro com dois dígitos, completando com zeros à esquerda.

3: `7 // 2 * 2` é `6` (`int`), porque `7 // 2` é 3. `7 / 2 * 2` é `7.0` (`float`). `"7" * 2` é `'77'` (`str`). `10 % 3 == 1` é `True` (`bool`). `int("7") + float("0.5")` é `7.5` (`float`): somar um `int` com um `float` dá um `float`.

## Prática com correção automática

Cada exercício já traz a função começada (`def ...`): escreve o corpo e devolve o resultado com `return`. Vais aprender funções a fundo na lição 3; por agora, pensa nelas como uma caixa que recebe valores e devolve uma resposta. Carrega em **Testar** e o teu código é corrido contra vários casos.

```exercicio
id: ip1-segundos
titulo: Quantos segundos?
enunciado: Escreve `para_segundos(horas, minutos, segundos)`, que devolve o total de segundos. Por exemplo, 1 h 1 min 1 s são 3661 segundos.
dica: Uma hora tem 60 × 60 segundos e um minuto tem 60.
inicio:
def para_segundos(horas, minutos, segundos):
    # escreve aqui o cálculo
    return 0
testes:
para_segundos(0, 0, 0) == 0
para_segundos(1, 1, 1) == 3661
para_segundos(0, 2, 30) == 150
para_segundos(2, 0, 0) == 7200
para_segundos(10, 59, 59) == 39599
solucao:
def para_segundos(horas, minutos, segundos):
    return horas * 3600 + minutos * 60 + segundos
```

```exercicio
id: ip1-media
titulo: Média de três notas
enunciado: Escreve `media(a, b, c)`, que devolve a média aritmética das três notas (um número decimal).
dica: Soma as três e divide por 3. Em Python, `/` dá sempre um resultado decimal.
inicio:
def media(a, b, c):
    return 0
testes:
media(10, 12, 14) == 12.0
media(0, 0, 0) == 0.0
media(20, 19, 18) == 19.0
media(9, 10, 10) == 29 / 3
solucao:
def media(a, b, c):
    return (a + b + c) / 3
```

```exercicio
id: ip1-fahrenheit
titulo: Celsius para Fahrenheit
enunciado: Escreve `fahrenheit(c)`, que converte graus Celsius em Fahrenheit com a fórmula F = C × 9 / 5 + 32.
inicio:
def fahrenheit(c):
    return 0
testes:
fahrenheit(0) == 32.0
fahrenheit(100) == 212.0
fahrenheit(-40) == -40.0
fahrenheit(37) == 98.6
solucao:

```
