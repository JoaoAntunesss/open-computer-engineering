Quase todos os dados com que vais trabalhar chegam como texto: ficheiros CSV, registos de servidores, páginas web, respostas de utilizadores. Saber partir, limpar e transformar texto, e ler e escrever ficheiros, é das competências mais usadas na prática.

## Strings

Uma string é uma sequência de caracteres. Funciona como um tuplo: tem índices e fatias, e **não pode ser alterada**.

```python
s = "Engenharia"
s[0]          # 'E'
s[-3:]        # 'ria'
len(s)        # 10
s[0] = "e"    # TypeError: as strings não se alteram
s = "e" + s[1:]   # cria uma string nova
```

### Métodos que vais usar sempre

Todos devolvem uma string **nova**; a original fica igual.

```python
"  olá  ".strip()                 # 'olá'      tira espaços nas pontas
"Porto".upper(), "Porto".lower()  # 'PORTO', 'porto'
"a,b,,c".split(",")               # ['a', 'b', '', 'c']
"um  dois\ttrês".split()          # ['um', 'dois', 'três']  (qualquer espaço)
"-".join(["2026", "11", "02"])    # '2026-11-02'
"banana".replace("a", "o")        # 'bonono'
"banana".count("a")               # 3
"banana".find("na")               # 2  (-1 se não encontrar)
"relatorio.pdf".endswith(".pdf")  # True
"123".isdigit()                   # True
```

O `split` e o `join` são o par mais importante: um parte texto em pedaços, o outro junta pedaços em texto.

### Percorrer e construir

```python
def inverte_palavras(frase):
    return " ".join(reversed(frase.split()))

inverte_palavras("o rato roeu a rolha")   # 'rolha a roeu rato o'
```

Construir uma string longa com `+=` dentro de um ciclo é lento, porque cada `+=` cria uma string nova. Junta os pedaços numa lista e faz `"".join(lista)` no fim.

### Caracteres, Unicode e codificações

Cada carácter tem um número (o seu *code point* Unicode): `ord("A")` é 65, `chr(233)` é `'é'`. No disco, o texto é guardado como bytes segundo uma **codificação**. Usa sempre **UTF-8**: representa qualquer língua, incluindo o português e emojis.

Se vires caracteres estranhos como `Ã§` no lugar de `ç`, o ficheiro foi escrito numa codificação e lido noutra.

## Ler ficheiros

```python
with open("notas.txt", encoding="utf-8") as f:
    for linha in f:
        print(linha.strip())
```

- O `with` garante que o ficheiro é fechado no fim, mesmo que haja um erro.
- Percorrer `f` dá uma linha de cada vez, com o `\n` no fim (por isso o `strip`). Funciona com ficheiros de qualquer tamanho, porque não carrega tudo para a memória.
- `f.read()` lê o ficheiro inteiro para uma string; `f.read().splitlines()` dá uma lista de linhas sem `\n`.

## Escrever ficheiros

```python
with open("relatorio.txt", "w", encoding="utf-8") as f:
    f.write("Relatório de notas\n")
    for nome, nota in [("Ana", 17), ("Rui", 12)]:
        f.write(f"{nome}: {nota}\n")
```

O modo `"w"` apaga o que lá estava; `"a"` acrescenta no fim. O `write` não muda de linha sozinho: tens de pôr `\n`.

## CSV

Um CSV é uma tabela em texto, uma linha por registo e vírgulas a separar os campos:

```text
nome,numero,nota
Ana Silva,2500123,17
"Costa, Rui",2500456,12
```

Repara na terceira linha: o nome tem uma vírgula, por isso vem entre aspas. Fazer `linha.split(",")` à mão falha aqui. Usa o módulo `csv`, que trata destes casos:

```python
import csv

with open("pauta.csv", encoding="utf-8", newline="") as f:
    alunos = list(csv.DictReader(f))

# alunos[1] == {'nome': 'Costa, Rui', 'numero': '2500456', 'nota': '12'}
media = sum(int(a["nota"]) for a in alunos) / len(alunos)

with open("aprovados.csv", "w", encoding="utf-8", newline="") as f:
    w = csv.DictWriter(f, fieldnames=["nome", "nota"])
    w.writeheader()
    for a in alunos:
        if int(a["nota"]) >= 10:
            w.writerow({"nome": a["nome"], "nota": a["nota"]})
```

Os valores lidos de um CSV são sempre texto: converte-os com `int` ou `float`.

## JSON

O JSON é o formato de troca de dados da web. Mapeia diretamente para dicionários e listas:

```python
import json

config = {"tema": "escuro", "idiomas": ["pt", "en"], "versao": 3}
with open("config.json", "w", encoding="utf-8") as f:
    json.dump(config, f, ensure_ascii=False, indent=2)

with open("config.json", encoding="utf-8") as f:
    config = json.load(f)
```

## Quando os ficheiros falham

Ficheiros que não existem, sem permissões ou com dados mal formatados são normais. Trata o que sabes resolver:

```python
try:
    with open(caminho, encoding="utf-8") as f:
        dados = f.read()
except FileNotFoundError:
    print(f"Não encontrei {caminho}. Confirma o nome e a pasta.")
```

Apanha só os erros que esperas. Um `except:` sozinho esconde também os erros do teu próprio código.

## Erros comuns

- Esquecer o `encoding="utf-8"` e os acentos saírem estragados no Windows.
- Fazer `split(",")` em CSVs com aspas.
- Esquecer o `\n` no `write`.
- Abrir um ficheiro com `"w"` quando querias acrescentar: perdes o conteúdo.
- Esquecer que tudo o que vem de um ficheiro de texto é `str`.

## Prática com correção automática

Escreve a solução no editor e carrega em **Testar**: o teu código é corrido contra vários casos e vês logo quais passam. Tenta primeiro sem ajuda; a dica e a solução estão lá para quando precisares.

```exercicio
id: ip5-iniciais
titulo: Iniciais de um nome
enunciado: Escreve `iniciais(nome)`, que devolve as iniciais em maiúsculas, sem espaços. `"ana maria silva"` dá `"AMS"`. Ignora espaços a mais entre os nomes.
dica: `nome.split()` parte o nome em palavras (e ignora espaços repetidos). De cada palavra queres a posição 0.
inicio:
def iniciais(nome):
    return ""
testes:
iniciais("ana maria silva") == "AMS"
iniciais("João Antunes") == "JA"
iniciais("  rui   costa ") == "RC"
iniciais("eva") == "E"
iniciais("") == ""
solucao:
def iniciais(nome):
    return "".join(p[0].upper() for p in nome.split())
```

```exercicio
id: ip5-palindromo
titulo: Palíndromo
enunciado: Escreve `e_palindromo(texto)`, que devolve `True` se o texto se lê igual de trás para a frente, ignorando espaços e maiúsculas. `"Ame a ema"` é palíndromo.
dica: Primeiro "limpa" o texto: minúsculas (`lower`) e sem espaços (`replace(" ", "")`). Depois compara com o texto ao contrário: `s[::-1]`.
inicio:
def e_palindromo(texto):
    return False
testes:
e_palindromo("ovo") == True
e_palindromo("Ame a ema") == True
e_palindromo("python") == False
e_palindromo("") == True
e_palindromo("A base do teto desaba") == True
e_palindromo("ab") == False
solucao:
def e_palindromo(texto):
    s = texto.lower().replace(" ", "")
    return s == s[::-1]
```

```exercicio
id: ip5-csv
titulo: Somar uma coluna de um CSV
enunciado: Escreve `total_coluna(linhas, coluna)`. `linhas` é uma lista de strings no formato CSV com `;` (a primeira é o cabeçalho) e `coluna` é o nome de uma coluna com números. Devolve a soma dessa coluna.
dica: `linhas[0].split(";")` dá os nomes das colunas; `.index(coluna)` diz-te a posição. Depois percorre `linhas[1:]`, parte cada uma com `split(";")` e soma `float(...)` dessa posição.
inicio:
def total_coluna(linhas, coluna):
    return 0
testes:
total_coluna(["nome;valor", "a;10", "b;5.5"], "valor") == 15.5
total_coluna(["x;y;z", "1;2;3", "4;5;6"], "z") == 9.0
total_coluna(["x;y;z", "1;2;3", "4;5;6"], "x") == 5.0
total_coluna(["produto;preco"], "preco") == 0
solucao:
def total_coluna(linhas, coluna):
    i = linhas[0].split(";").index(coluna)
    total = 0
    for linha in linhas[1:]:
        total += float(linha.split(";")[i])
    return total
```
