O maior erro de quem começa é escrever 50 linhas de uma vez e só depois correr. Quando dá erro, não sabes qual das 50 linhas o causou. Quem programa com experiência faz o contrário: escreve **2 ou 3 linhas, corre, confirma**, e só depois avança.

## O ciclo curto

1. Escreve o mínimo que faça **alguma coisa** visível.
2. Corre.
3. Confirma que o resultado é o que esperavas.
4. Acrescenta o próximo bocadinho. Volta ao 2.

Se algo partir, só pode ter sido a última coisa que acrescentaste. A depuração fica trivial.

## Exemplo: um jogo do galo, passo a passo

**Passo 1: mostrar um tabuleiro vazio.** Nada mais.

```python run
tabuleiro = [" "] * 9

def mostra(t):
    for i in range(0, 9, 3):
        print(" | ".join(t[i:i + 3]))

mostra(tabuleiro)
```

Corre. Funciona? Avança.

**Passo 2: fazer uma jogada.**

```python run
tabuleiro = [" "] * 9

def mostra(t):
    for i in range(0, 9, 3):
        print(" | ".join(t[i:i + 3]))

def joga(t, posicao, simbolo):
    if t[posicao] != " ":
        return False
    t[posicao] = simbolo
    return True

print(joga(tabuleiro, 4, "X"))
print(joga(tabuleiro, 4, "O"))   # já ocupada
mostra(tabuleiro)
```

Corre. A segunda jogada devolveu `False`? Ótimo.

**Passo 3: saber se alguém ganhou.**

```python run
LINHAS = [(0,1,2), (3,4,5), (6,7,8), (0,3,6), (1,4,7), (2,5,8), (0,4,8), (2,4,6)]

def vencedor(t):
    for a, b, c in LINHAS:
        if t[a] != " " and t[a] == t[b] == t[c]:
            return t[a]
    return None

print(vencedor(["X","X","X"," "," "," "," "," "," "]))
print(vencedor(["X","O","X"," "," "," "," "," "," "]))
print(vencedor(["O"," "," ","O"," "," ","O"," "," "]))
```

Testámos a função **sozinha**, com tabuleiros feitos à mão, antes de a ligar ao resto. Esperado: `X`, `None`, `O`.

**Passo 4: juntar tudo** num ciclo de jogo. Como cada peça já foi testada, se algo falhar agora, o problema está na forma como as juntaste.

## Commits pequenos

O mesmo princípio aplica-se ao Git: um commit por passo que funciona. Se o passo 5 estragar tudo, voltas ao passo 4 com `git checkout` ou `git restore` em vez de tentares desfazer à mão.

## Com um assistente de código, o mesmo ritmo

Se usares um assistente de código, pede **um passo de cada vez** ("agora só a função que verifica o vencedor") e corre e confirma cada um antes de pedir o seguinte. Assim percebes cada peça e apanhas os erros enquanto ainda são pequenos.
