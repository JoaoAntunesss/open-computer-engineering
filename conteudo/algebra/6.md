Quase todas as transformações mudam a direção dos vetores. Mas algumas direções especiais só são esticadas ou encolhidas: são os **vetores próprios**, e o fator de escala é o **valor próprio**. Encontrá-los é encontrar o "esqueleto" de uma matriz — e está por trás do PageRank da Google, da análise de componentes principais, da estabilidade de sistemas e da mecânica quântica.

## Definição

Seja A uma matriz quadrada. Um vetor v ≠ 0 é **vetor próprio** de A, com **valor próprio** λ, se

**A v = λ v**

Aplicar A a v dá um múltiplo de v: a direção mantém-se (ou inverte, se λ < 0).

Exemplos geométricos em ℝ²:

- escala diag(2, 3): os eixos são direções próprias, com λ = 2 e λ = 3;
- projeção no eixo x: (1, 0) com λ = 1 e (0, 1) com λ = 0;
- reflexão na reta y = x: (1, 1) com λ = 1 e (1, −1) com λ = −1;
- rotação de 90°: nenhum vetor real mantém a direção — os valores próprios são complexos (±i).

## Como calcular

A v = λ v ⇔ (A − λI) v = 0. Para haver v ≠ 0, a matriz A − λI tem de ser singular:

**det(A − λI) = 0**

Esta é a **equação característica**; o lado esquerdo é um polinómio de grau n em λ. Para cada raiz λ, os vetores próprios são o núcleo de A − λI.

Exemplo: A = [[4, 1], [2, 3]].

1. det(A − λI) = (4 − λ)(3 − λ) − 2 = λ² − 7λ + 10 = (λ − 5)(λ − 2).
2. λ = 5: (A − 5I) v = 0 → [[−1, 1], [2, −2]] v = 0 → v = (1, 1).
3. λ = 2: [[2, 1], [2, 1]] v = 0 → v = (1, −2).

Dois atalhos para verificar: a **soma** dos valores próprios é o **traço** (soma da diagonal: 4 + 3 = 7 = 5 + 2) e o **produto** é o **determinante** (12 − 2 = 10 = 5·2).

```python
import numpy as np

A = np.array([[4, 1], [2, 3]])
vals, vecs = np.linalg.eig(A)
print(vals)        # [5. 2.]
print(vecs)        # colunas: vetores próprios normalizados
v = vecs[:, 0]
print(A @ v, vals[0] * v)   # iguais
```

Para n grande, ninguém resolve o polinómio característico (não há fórmula para grau ≥ 5). As bibliotecas usam o **algoritmo QR**, iterativo e estável.

## Diagonalização

Se A (n × n) tem n vetores próprios independentes, junta-os nas colunas de P e os valores próprios na diagonal de D:

**A = P D P⁻¹**

Na base de vetores próprios, A é só uma escala em cada eixo. Isto torna fáceis as potências:

**Aᵏ = P Dᵏ P⁻¹**, e Dᵏ é só elevar a diagonal a k.

Aplicação: a sucessão de Fibonacci. (Fₙ₊₁, Fₙ) = [[1, 1], [1, 0]]·(Fₙ, Fₙ₋₁). Os valores próprios desta matriz são φ = (1 + √5)/2 ≈ 1.618 e 1 − φ ≈ −0.618, o que dá a fórmula de Binet: Fₙ = (φⁿ − (1 − φ)ⁿ)/√5. Para n grande, Fₙ cresce como φⁿ.

## Matrizes simétricas

Se A é **simétrica** (A = Aᵀ), tudo corre bem (Teorema Espectral):

- os valores próprios são todos reais;
- os vetores próprios de valores próprios diferentes são ortogonais;
- A diagonaliza-se como A = Q D Qᵀ, com Q ortogonal (Qᵀ = Q⁻¹).

Matrizes de covariância, Hessianas e matrizes de grafos não dirigidos são simétricas, por isso este caso aparece em todo o lado.

## Método da potência e PageRank

Se aplicares A repetidamente a quase qualquer vetor, a componente na direção do valor próprio de maior módulo cresce mais depressa que as outras e acaba por dominar. É o **método da potência**:

```python
def potencia(A, iters=100):
    v = np.ones(A.shape[0])
    for _ in range(iters):
        v = A @ v
        v = v / np.linalg.norm(v)
    return v @ A @ v, v          # quociente de Rayleigh e vetor

print(potencia(np.array([[4.0, 1], [2, 3]])))   # (≈5.0, ≈[0.707, 0.707])
```

O **PageRank** original da Google é isto: as páginas são estados de uma cadeia de Markov (um navegador que segue links ao acaso), e a importância de cada página é a componente correspondente do vetor próprio de valor próprio 1 da matriz de transição.

```python
# 4 páginas; coluna j = para onde se vai a partir da página j (probabilidades)
L = np.array([[0,   0,   1, 0.5],
              [1/3, 0,   0, 0  ],
              [1/3, 0.5, 0, 0.5],
              [1/3, 0.5, 0, 0  ]])
d = 0.85
G = d * L + (1 - d) / 4          # "teletransporte" para garantir convergência
r = np.ones(4) / 4
for _ in range(100):
    r = G @ r
print(r.round(3))                # a página 0 é a mais importante
```

## Erros comuns

- Aceitar v = 0 como vetor próprio (por definição, não é).
- Esquecer que nem todas as matrizes são diagonalizáveis (ex.: [[1, 1], [0, 1]] só tem uma direção própria).
- Achar que os valores próprios de A + B são as somas dos de A e de B.
- Ler os vetores próprios nas linhas da saída de `np.linalg.eig`: estão nas **colunas**.
