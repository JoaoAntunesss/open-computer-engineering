A decomposição em valores singulares (SVD) é muitas vezes chamada o "ponto alto" da Álgebra Linear: funciona para **qualquer** matriz, quadrada ou não, e diz exatamente quais são as direções mais importantes dos dados. Comprime imagens, reduz dimensões (PCA), faz recomendações e calcula soluções de mínimos quadrados de forma estável.

## A ideia

Toda a matriz A (m × n) se escreve como

**A = U Σ Vᵀ**

- V (n × n) é ortogonal: as colunas v₁, …, vₙ são uma base ortonormada do espaço de partida;
- U (m × m) é ortogonal: as colunas u₁, …, uₘ são uma base ortonormada do espaço de chegada;
- Σ (m × n) é "diagonal", com os **valores singulares** σ₁ ≥ σ₂ ≥ … ≥ 0.

Geometricamente: **toda a transformação linear é uma rotação, seguida de uma escala ao longo dos eixos, seguida de outra rotação**. A leva a esfera unitária a um elipsoide; os σᵢ são os comprimentos dos semieixos, os uᵢ as suas direções, e A vᵢ = σᵢ uᵢ.

## De onde vem

AᵀA é simétrica e com valores próprios ≥ 0. Os vetores próprios de AᵀA são os vᵢ, e os seus valores próprios são σᵢ². Do mesmo modo, os vetores próprios de AAᵀ são os uᵢ. A SVD é o Teorema Espectral da lição 6 aplicado a AᵀA e AAᵀ — e por isso existe sempre.

O número de valores singulares não nulos é a **característica** de A.

```python
import numpy as np

A = np.array([[3, 2, 2], [2, 3, -2]])
U, s, Vt = np.linalg.svd(A)
print(s)                                    # [5. 3.]
S = np.zeros(A.shape); S[:2, :2] = np.diag(s)
print(np.allclose(U @ S @ Vt, A))           # True
```

## Soma de matrizes de característica 1

Multiplicando por blocos, a SVD diz que A é uma soma de "camadas" simples:

**A = σ₁ u₁v₁ᵀ + σ₂ u₂v₂ᵀ + … + σᵣ uᵣvᵣᵀ**

Cada uᵢvᵢᵀ é uma matriz de característica 1 (todas as linhas são múltiplas umas das outras), e as camadas vêm por ordem de importância.

**Teorema de Eckart–Young**: a melhor aproximação de A com característica k (no sentido de menor erro) é ficar só com as k primeiras camadas:

Aₖ = σ₁ u₁v₁ᵀ + … + σₖ uₖvₖᵀ

## Comprimir uma imagem

Uma imagem em tons de cinzento é uma matriz de píxeis. Guardar Aₖ exige k·(m + n + 1) números em vez de m·n.

```python
# imagem sintética 200 × 300: gradientes e um círculo
y, x = np.mgrid[0:200, 0:300]
img = 0.5 + 0.3*np.sin(x/30) * np.cos(y/25) + 0.4*((x-150)**2 + (y-100)**2 < 60**2)

U, s, Vt = np.linalg.svd(img, full_matrices=False)
for k in [1, 5, 20, 50]:
    Ak = (U[:, :k] * s[:k]) @ Vt[:k]
    erro = np.linalg.norm(img - Ak) / np.linalg.norm(img)
    guarda = k * (200 + 300 + 1) / (200 * 300)
    print(f"k = {k:2d}: erro relativo {erro:.3f}, guarda {guarda:.1%} dos números")
```

Com uma fotografia real (por exemplo lida com `matplotlib.pyplot.imread`), k = 50 já é praticamente indistinguível do original. Os valores singulares das imagens naturais caem depressa, e é isso que permite comprimir.

## Análise de componentes principais (PCA)

Tens n pontos com d características (as linhas de uma matriz X). Subtrai a média de cada coluna e calcula a SVD. Então:

- v₁ é a direção em que os dados variam mais (a **primeira componente principal**), v₂ a seguinte, ortogonal à primeira, etc.;
- σᵢ²/(n − 1) é a variância dos dados na direção vᵢ;
- projetar os dados nas primeiras k direções (X·Vₖ) reduz a dimensão perdendo o mínimo de informação.

```python
rng = np.random.default_rng(0)
# 500 pontos em 3D que vivem quase num plano
base = rng.normal(size=(500, 2)) @ np.array([[3, 1, 0], [0, 1, 2]])
X = base + rng.normal(0, 0.1, (500, 3))
Xc = X - X.mean(axis=0)
U, s, Vt = np.linalg.svd(Xc, full_matrices=False)
print((s**2 / (s**2).sum()).round(4))   # a 3.ª componente explica quase nada
Z = Xc @ Vt[:2].T                       # os mesmos dados em 2D
```

A PCA usa-se para visualizar dados com muitas dimensões, remover ruído e acelerar outros algoritmos.

## Mais aplicações

- **Sistemas de recomendação**: a matriz utilizadores × filmes é aproximada por poucas camadas; cada camada é um "gosto" escondido (ação, romance…). Foi a ideia central do prémio Netflix.
- **Pseudoinversa**: A⁺ = V Σ⁺ Uᵀ (inverte os σᵢ não nulos) dá a solução de mínimos quadrados de norma mínima, mesmo quando as colunas são dependentes. É o que `np.linalg.lstsq` e `np.linalg.pinv` usam.
- **Número de condição**: σ₁/σᵣ mede quanto os erros nos dados podem ser amplificados ao resolver A x = b.
- **Pesquisa semântica** (LSA): a SVD da matriz termos × documentos encontra temas.

## Erros comuns

- Confundir valores singulares com valores próprios: só coincidem (a menos do sinal) para matrizes simétricas.
- Esquecer de centrar os dados antes da PCA.
- Usar `full_matrices=True` (o padrão) com matrizes grandes e ficar sem memória: U fica m × m.
- Ler as componentes principais nas colunas de Vt: estão nas **linhas** de Vt (colunas de V).
