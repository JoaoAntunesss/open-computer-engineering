Um vetor é uma lista de números com significado geométrico: uma posição, uma velocidade, uma cor RGB, as características de um utilizador num sistema de recomendação. A Álgebra Linear começa por aprender a somá-los, esticá-los e medir distâncias e ângulos entre eles.

## Vetores

Um vetor de ℝⁿ é uma lista ordenada de n números reais: v = (v₁, v₂, …, vₙ). Em ℝ² e ℝ³ desenha-se como uma seta a partir da origem.

Duas operações básicas:

- **Soma**: (1, 2) + (3, −1) = (4, 1). Geometricamente, pões uma seta a seguir à outra.
- **Multiplicação por escalar**: 3 · (1, 2) = (3, 6). Estica (ou encolhe, ou inverte, se o escalar for negativo).

Uma **combinação linear** de v e w é qualquer vetor a·v + b·w. Quase toda a Álgebra Linear é sobre que vetores se conseguem obter com combinações lineares de outros.

```python
import numpy as np

v = np.array([1, 2])
w = np.array([3, -1])
print(v + w)        # [4 1]
print(3 * v)        # [3 6]
print(2*v - w)      # [-1  5]
```

Repara que `v + w` em NumPy soma elemento a elemento; numa lista Python, `+` concatenava.

## Produto interno

O **produto interno** (ou produto escalar) de dois vetores do mesmo tamanho é

**v · w = v₁w₁ + v₂w₂ + … + vₙwₙ**

e dá um número. Exemplo: (1, 2, 3) · (4, −5, 6) = 4 − 10 + 18 = 12.

Propriedades: é simétrico (v · w = w · v), linear em cada argumento, e v · v ≥ 0, com igualdade só para o vetor nulo.

## Norma e distância

A **norma** (comprimento) de v é

**‖v‖ = √(v · v) = √(v₁² + … + vₙ²)**

que é o Teorema de Pitágoras em n dimensões. A **distância** entre dois pontos é ‖v − w‖.

Um vetor com norma 1 é **unitário**. Para normalizar um vetor, divide-se pela norma: u = v / ‖v‖. Exemplo: v = (3, 4), ‖v‖ = 5, u = (0.6, 0.8).

## Ângulo entre vetores

O produto interno tem uma interpretação geométrica:

**v · w = ‖v‖ ‖w‖ cos θ**

onde θ é o ângulo entre os vetores. Daqui:

- v · w > 0: ângulo agudo (apontam "para o mesmo lado");
- v · w = 0: **ortogonais** (perpendiculares);
- v · w < 0: ângulo obtuso.

A **desigualdade de Cauchy–Schwarz**, |v · w| ≤ ‖v‖ ‖w‖, garante que o cosseno fica entre −1 e 1. A **desigualdade triangular**, ‖v + w‖ ≤ ‖v‖ + ‖w‖, diz que o caminho direto é o mais curto.

## Semelhança do cosseno

Em informática, o cosseno do ângulo é muito usado para medir semelhança entre textos, imagens ou utilizadores representados como vetores:

```python
def cos_sim(a, b):
    return a @ b / (np.linalg.norm(a) * np.linalg.norm(b))

# contagens das palavras ["gato", "cão", "rato", "bolsa"] em três frases
d1 = np.array([2, 1, 1, 0])
d2 = np.array([1, 1, 0, 0])
d3 = np.array([0, 0, 0, 3])
print(cos_sim(d1, d2))   # ≈ 0.866: falam do mesmo
print(cos_sim(d1, d3))   # 0.0: nada em comum
```

O operador `@` faz o produto interno (e, mais à frente, o produto de matrizes). Os motores de pesquisa e os sistemas de recomendação com *embeddings* comparam vetores de centenas de dimensões exatamente assim.

## Projeção

A **projeção** de v sobre a direção de w é a "sombra" de v nessa direção:

**proj_w(v) = (v · w / w · w) · w**

O resto, v − proj_w(v), é ortogonal a w. Exemplo: v = (2, 3), w = (1, 0): proj = (2, 0) e o resto (0, 3) é perpendicular ao eixo x. Esta ideia volta na lição 7, nos mínimos quadrados.

## Erros comuns

- Somar vetores de tamanhos diferentes. Não está definido (o NumPy às vezes faz *broadcasting* e esconde o erro).
- Confundir o produto interno (um número) com o produto elemento a elemento `v * w` (um vetor).
- Esquecer a raiz quadrada na norma.
- Usar a semelhança do cosseno com o vetor nulo (divisão por zero).
