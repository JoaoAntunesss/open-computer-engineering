Os dados reais têm ruído: se mediste 100 pontos que deviam estar numa reta, o sistema "reta passa por todos os pontos" não tem solução. Os **mínimos quadrados** encontram a reta que erra o menos possível, e a resposta é uma projeção ortogonal. É a base da regressão linear, o primeiro modelo de machine learning que se aprende.

## Vetores e bases ortogonais

Vetores são **ortogonais** quando o produto interno é zero. Uma base **ortonormada** tem vetores ortogonais dois a dois e todos de norma 1.

Com uma base ortonormada q₁, …, qₙ, as coordenadas de um vetor são só produtos internos:

**v = (v · q₁) q₁ + … + (v · qₙ) qₙ**

sem resolver nenhum sistema. Por isso as bases ortonormadas são as preferidas em cálculo numérico.

## Matrizes ortogonais

Uma matriz quadrada Q com colunas ortonormadas é **ortogonal**: QᵀQ = I, ou seja **Q⁻¹ = Qᵀ**. Rotações e reflexões são ortogonais. Preservam comprimentos e ângulos: ‖Qx‖ = ‖x‖. Os erros de arredondamento não crescem quando se multiplica por Q, o que as torna muito estáveis.

## Gram–Schmidt

O processo de **Gram–Schmidt** transforma vetores independentes a₁, a₂, … numa base ortonormada do mesmo espaço: a cada passo, tira-se ao vetor a sua projeção sobre os anteriores e normaliza-se.

```python
import numpy as np

def gram_schmidt(A):
    Q = []
    for a in A.T:                       # cada coluna
        v = a.astype(float)
        for q in Q:
            v = v - (q @ a) * q         # retira a componente na direção de q
        Q.append(v / np.linalg.norm(v))
    return np.array(Q).T

A = np.array([[1, 1, 0], [1, 0, 1], [0, 1, 1]]).T
Q = gram_schmidt(A)
print(np.round(Q.T @ Q, 10))            # identidade: colunas ortonormadas
```

Escrevendo cada aⱼ na base dos qᵢ obtém-se a **decomposição QR**: A = QR, com R triangular superior. É usada pelas bibliotecas para resolver mínimos quadrados e calcular valores próprios. (Na prática usa-se uma versão mais estável, com reflexões de Householder: `np.linalg.qr`.)

## Projeção num subespaço

Na lição 1 projetámos sobre uma direção. Para projetar b sobre o espaço das colunas de A, procuramos o ponto p = A x̂ desse espaço mais próximo de b. A condição é que o erro e = b − A x̂ seja **ortogonal a todas as colunas** de A:

Aᵀ(b − A x̂) = 0  ⇒  **AᵀA x̂ = Aᵀb**

Estas são as **equações normais**. Se as colunas de A são independentes, AᵀA é invertível e há uma única solução.

## Mínimos quadrados

Quando A x = b não tem solução (mais equações do que incógnitas, com ruído), a solução de **mínimos quadrados** é o x̂ que minimiza

‖A x − b‖² = soma dos quadrados dos erros

e é exatamente a solução das equações normais. Geometricamente: não conseguimos chegar a b, por isso vamos ao ponto mais próximo que conseguimos alcançar, a sua projeção.

Exemplo: ajustar uma reta y = c + m·t aos pontos (0, 6), (1, 0), (2, 0).

O sistema "a reta passa pelos três pontos" é A x = b com

A = [[1, 0], [1, 1], [1, 2]], x = (c, m), b = (6, 0, 0)

AᵀA = [[3, 3], [3, 5]], Aᵀb = (6, 0). Resolvendo: **c = 5, m = −3**. A reta é y = 5 − 3t, e os erros (1, −2, 1) somam zero e são ortogonais às colunas de A.

```python
t = np.array([0, 1, 2]); y = np.array([6, 0, 0])
A = np.column_stack([np.ones_like(t), t])
print(np.linalg.solve(A.T @ A, A.T @ y))          # [ 5. -3.]
print(np.linalg.lstsq(A, y, rcond=None)[0])       # o mesmo, de forma mais estável
```

## Regressão com mais variáveis e com curvas

A mesma ideia serve para tudo o que seja **linear nos parâmetros**:

- várias variáveis: preço ≈ c + m₁·área + m₂·quartos — uma coluna de A por variável;
- polinómios: y ≈ c₀ + c₁t + c₂t² — colunas 1, t, t²;
- qualquer conjunto de funções: colunas sin t, cos t, eᵗ…

```python
rng = np.random.default_rng(0)
t = np.linspace(0, 4, 200)
y = 1 + 2*t - 0.5*t**2 + rng.normal(0, 0.2, t.size)   # parábola com ruído
A = np.column_stack([np.ones_like(t), t, t**2])
coef, *_ = np.linalg.lstsq(A, y, rcond=None)
print(coef.round(2))                                    # perto de [1, 2, -0.5]
```

## Cuidado com as equações normais

Formar AᵀA eleva ao quadrado o **número de condição** da matriz: se A já é mal condicionada (colunas quase dependentes), AᵀA perde metade dos algarismos significativos. Por isso as bibliotecas usam QR ou SVD (próxima lição) em vez de resolver as equações normais diretamente.

## Erros comuns

- Tentar resolver um sistema sobredeterminado com `np.linalg.solve` (só aceita matrizes quadradas).
- Esquecer a coluna de uns e forçar a reta a passar pela origem.
- Achar que "linear" na regressão significa que o modelo tem de ser uma reta: só tem de ser linear nos coeficientes.
- Ajustar um polinómio de grau muito alto: passa por todos os pontos, mas não generaliza (*overfitting*).
