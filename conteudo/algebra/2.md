Resolver sistemas de equações lineares é das tarefas mais comuns em computação científica: circuitos elétricos, estruturas, redes de fluxo, gráficos, ajuste de modelos. O algoritmo de base, a eliminação de Gauss, ensina-se no secundário com duas equações e funciona exatamente igual com um milhão.

## Sistemas lineares

Um **sistema linear** é um conjunto de equações em que as incógnitas só aparecem multiplicadas por constantes e somadas:

```text
 2x + y −  z =   8
−3x − y + 2z = −11
−2x + y + 2z =  −3
```

Escreve-se em forma matricial **A x = b**, com A a matriz dos coeficientes, x o vetor das incógnitas e b o vetor dos termos independentes. Para trabalhar à mão, junta-se tudo na **matriz aumentada** [A ∣ b].

## Três casos possíveis

Geometricamente, em ℝ² cada equação é uma reta; em ℝ³ é um plano. Um sistema pode ter:

- **uma única solução** (as retas cruzam-se num ponto) — sistema *possível e determinado*;
- **infinitas soluções** (as retas coincidem) — *possível e indeterminado*;
- **nenhuma solução** (retas paralelas distintas) — *impossível*.

Nunca há exatamente duas soluções: se x e y são soluções, todos os pontos do segmento entre elas também são.

## Operações elementares

Estas três operações sobre as linhas não mudam as soluções:

1. trocar duas linhas;
2. multiplicar uma linha por um número diferente de zero;
3. somar a uma linha um múltiplo de outra.

## Eliminação de Gauss

O objetivo é chegar à **forma em escada**: abaixo de cada pivô (o primeiro elemento não nulo da linha) só há zeros. Depois resolve-se de baixo para cima (**substituição para trás**).

Para o sistema acima:

1. Pivô 2 na linha 1. L2 ← L2 + 1.5·L1 e L3 ← L3 + L1: a linha 2 fica (0, 0.5, 0.5 ∣ 1) e a linha 3 fica (0, 2, 1 ∣ 5).
2. Pivô 0.5 na linha 2. L3 ← L3 − 4·L2: linha 3 fica (0, 0, −1 ∣ 1).
3. De baixo para cima: z = −1; 0.5y + 0.5(−1) = 1 → y = 3; 2x + 3 − (−1) = 8 → x = 2.

Solução: **(x, y, z) = (2, 3, −1)**.

## Em Python, sem bibliotecas

```python
def gauss(A, b):
    n = len(A)
    M = [list(map(float, A[i])) + [float(b[i])] for i in range(n)]   # matriz aumentada
    for k in range(n):
        # pivotagem parcial: escolhe a linha com o maior pivô em valor absoluto
        p = max(range(k, n), key=lambda i: abs(M[i][k]))
        if abs(M[p][k]) < 1e-12:
            raise ValueError("matriz singular: não há solução única")
        M[k], M[p] = M[p], M[k]
        for i in range(k + 1, n):
            f = M[i][k] / M[k][k]
            for j in range(k, n + 1):
                M[i][j] -= f * M[k][j]
    x = [0.0] * n
    for i in reversed(range(n)):
        s = sum(M[i][j] * x[j] for j in range(i + 1, n))
        x[i] = (M[i][n] - s) / M[i][i]
    return x

A = [[2, 1, -1], [-3, -1, 2], [-2, 1, 2]]
b = [8, -11, -3]
print(gauss(A, b))    # [2.0, 3.0, -1.0] (a menos de erros de arredondamento)
```

A **pivotagem parcial** (trocar para cima a linha com o maior pivô) não é necessária em aritmética exata, mas em vírgula flutuante evita dividir por números muito pequenos, que amplificam os erros de arredondamento.

Na prática usa-se `np.linalg.solve(A, b)`, que faz o mesmo (via decomposição LU) em código otimizado.

## Custo

Para n equações, a eliminação faz cerca de **2n³/3** operações. Duplicar o tamanho do sistema multiplica o tempo por 8. Para sistemas enormes e esparsos (quase todos os coeficientes nulos, como em simulações físicas) usam-se métodos iterativos, que só tocam nos elementos não nulos.

## Sistemas indeterminados e impossíveis

Se no fim aparece uma linha (0, 0, 0 ∣ c) com c ≠ 0, a equação diz 0 = c: o sistema é **impossível**.

Se aparece (0, 0, 0 ∣ 0) e há menos pivôs do que incógnitas, as incógnitas sem pivô são **livres** e há infinitas soluções. Exemplo: x + y + z = 3 e y − z = 1. Com z = t livre: y = 1 + t, x = 2 − 2t. A solução é uma reta: (2, 1, 0) + t·(−2, 1, 1).

O número de pivôs chama-se **característica** (ou posto, *rank*) da matriz.

## Erros comuns

- Aplicar uma operação a uma linha e esquecer a coluna de b.
- Somar um múltiplo de uma linha a si própria em vez de a outra.
- Dividir por um pivô nulo (falta trocar linhas).
- Concluir "sem solução" quando aparece uma linha só de zeros (0 = 0 é sempre verdade).
