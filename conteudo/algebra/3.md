Uma matriz é uma tabela de números, mas o mais útil é vê-la como uma **função** que transforma vetores. Multiplicar matrizes é compor essas funções; a inversa desfaz a transformação; o determinante mede quanto ela estica ou encolhe o espaço.

## Matrizes e operações

Uma matriz m × n tem m linhas e n colunas; aᵢⱼ é o elemento da linha i, coluna j. Soma-se elemento a elemento e multiplica-se por escalares da forma óbvia.

A **transposta** Aᵀ troca linhas com colunas: (Aᵀ)ᵢⱼ = aⱼᵢ. Uma matriz com Aᵀ = A é **simétrica**.

A **identidade** I tem 1 na diagonal e 0 fora: I·x = x para todo o x.

## Matriz vezes vetor

A·x pode ler-se de duas maneiras, e ambas são importantes:

- **por linhas**: cada componente do resultado é o produto interno de uma linha de A com x;
- **por colunas**: A·x é uma combinação linear das colunas de A, com os coeficientes dados por x.

Exemplo: [[1, 2], [3, 4]] · (5, 6) = (1·5 + 2·6, 3·5 + 4·6) = (17, 39) = 5·(1, 3) + 6·(2, 4).

A segunda leitura explica o sistema A x = b: tem solução exatamente quando b é combinação linear das colunas de A.

## Produto de matrizes

Se A é m × n e B é n × p, o produto AB é m × p e

**(AB)ᵢⱼ = (linha i de A) · (coluna j de B)**

O número de colunas de A tem de ser igual ao número de linhas de B.

Propriedades que deves saber:

- **não é comutativo**: em geral AB ≠ BA;
- é associativo: (AB)C = A(BC);
- (AB)ᵀ = BᵀAᵀ (repara na troca de ordem).

Aplicar B e depois A a um vetor é o mesmo que aplicar AB: A(Bx) = (AB)x. Por isso a ordem importa — calçar as meias e depois os sapatos não é o mesmo que o contrário.

```python
import numpy as np

A = np.array([[1, 2], [3, 4]])
B = np.array([[0, 1], [1, 0]])
print(A @ B)     # troca as colunas de A
print(B @ A)     # troca as linhas de A
print(np.array_equal(A @ B, B @ A))   # False
```

O produto ingénuo de duas matrizes n × n custa n³ multiplicações. Bibliotecas como o BLAS, usadas pelo NumPy e pelas GPUs, fazem o mesmo cálculo dezenas de vezes mais depressa por aproveitarem a cache e o paralelismo — é a operação mais otimizada da computação.

## A inversa

A matriz quadrada A é **invertível** se existe A⁻¹ com A·A⁻¹ = A⁻¹·A = I. Então A x = b tem a solução única x = A⁻¹ b.

Para 2 × 2 há uma fórmula:

**[[a, b], [c, d]]⁻¹ = 1/(ad − bc) · [[d, −b], [−c, a]]**

Em geral, calcula-se com a eliminação de Gauss–Jordan sobre [A ∣ I]: quando o lado esquerdo vira I, o lado direito é A⁻¹.

Na prática **raramente se calcula a inversa**: para resolver A x = b, `np.linalg.solve(A, b)` é mais rápido e mais preciso do que `np.linalg.inv(A) @ b`.

Propriedades: (AB)⁻¹ = B⁻¹A⁻¹ e (Aᵀ)⁻¹ = (A⁻¹)ᵀ.

## O determinante

O **determinante** de uma matriz quadrada é um número que diz por quanto a transformação multiplica áreas (em 2D) ou volumes (em 3D):

- 2 × 2: det [[a, b], [c, d]] = **ad − bc**;
- 3 × 3: pela regra de Sarrus ou por expansão de Laplace ao longo de uma linha.

O sinal diz se a orientação se mantém (positivo) ou se o espaço é "espelhado" (negativo).

Propriedades fundamentais:

- **A é invertível ⇔ det A ≠ 0** (se o volume colapsa para zero, a transformação perde informação e não pode ser desfeita);
- det(AB) = det A · det B;
- det(Aᵀ) = det A;
- trocar duas linhas muda o sinal; somar a uma linha um múltiplo de outra não muda nada;
- o determinante de uma matriz triangular é o produto da diagonal.

A última propriedade dá a forma eficiente de o calcular: elimina até à forma em escada (custo n³) e multiplica os pivôs. A expansão de Laplace custa n! operações — para n = 20 já são 2.4·10¹⁸.

```python
M = np.array([[2, 1, -1], [-3, -1, 2], [-2, 1, 2]])
print(np.linalg.det(M))          # -1.0 (a menos de arredondamentos)
print(np.linalg.inv(M) @ M)      # identidade
```

## Erros comuns

- Multiplicar matrizes elemento a elemento (`A * B` em NumPy) quando se queria o produto (`A @ B`).
- Assumir que AB = BA.
- Escrever (AB)⁻¹ = A⁻¹B⁻¹ sem trocar a ordem.
- Calcular a inversa para resolver um sistema.
- Achar que det(A + B) = det A + det B (é falso).
