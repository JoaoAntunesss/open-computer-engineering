Em gráficos, pesquisa e machine learning, a álgebra linear chega-te como código com matrizes. Ler esse código obriga a saber **as dimensões** de cada coisa em cada linha. É aí que a maioria dos erros se esconde.

## Ler e prever: produto de matrizes à mão

```python run
def produto(A, B):
    linhas, comum, colunas = len(A), len(B), len(B[0])
    return [[sum(A[i][k] * B[k][j] for k in range(comum)) for j in range(colunas)] for i in range(linhas)]

A = [[1, 2],
     [3, 4]]
B = [[0, 1],
     [1, 0]]
print(produto(A, B))
print(produto(B, A))
```

Antes de correr: o que faz multiplicar por B à direita? E à esquerda? Os dois resultados são iguais?

## Encontra o erro: rodar um ponto

Este código devia rodar o ponto (1, 0) 90° no sentido contrário aos ponteiros do relógio, dando (0, 1).

```python run
import math

def roda(ponto, graus):
    t = math.radians(graus)
    R = [[math.cos(t), math.sin(t)],
         [-math.sin(t), math.cos(t)]]
    x, y = ponto
    return (round(R[0][0] * x + R[0][1] * y, 6), round(R[1][0] * x + R[1][1] * y, 6))

print(roda((1, 0), 90))
```
