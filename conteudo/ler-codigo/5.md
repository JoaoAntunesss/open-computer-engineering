Uma **função** é um bocado de código com nome, que podes usar quantas vezes quiseres. Para a ler, só precisas de responder a três perguntas: **o que entra** (parâmetros), **o que acontece** (o corpo) e **o que sai** (o `return`).

## Definir e chamar

```python run
def dobro(x):
    return x * 2

print(dobro(5))
print(dobro(21))
```

- `def dobro(x):` **define** a função. Nada corre ainda: é só a receita.
- `dobro(5)` **chama** a função: `x` passa a valer 5, corre o corpo, e o `return` devolve 10.
- O valor devolvido substitui a chamada: `print(dobro(5))` passa a ser `print(10)`.

Ao ler código, quando encontras uma chamada, **salta mentalmente** para dentro da função com os valores concretos e depois volta.

## Vários parâmetros

```python run
def preco_final(preco, desconto):
    return preco - preco * desconto / 100

print(preco_final(50, 10))
print(preco_final(80, 25))
```

Os valores entram **pela ordem**: o primeiro vai para `preco`, o segundo para `desconto`.

## return não é print

```python run
def soma_com_print(a, b):
    print(a + b)

def soma_com_return(a, b):
    return a + b

x = soma_com_print(2, 3)
y = soma_com_return(2, 3)
print("x =", x)
print("y =", y)
```

Este é um dos enganos mais comuns. `print` **mostra** no ecrã, mas não devolve nada (`x` fica `None`). `return` **devolve** o valor para quem chamou, que o pode guardar e usar. Quase sempre queres `return`.

## O return termina a função

```python run
def classifica(n):
    if n < 0:
        return "negativo"
    if n == 0:
        return "zero"
    return "positivo"

print(classifica(-3), classifica(0), classifica(7))
```

Assim que um `return` corre, a função acaba. As linhas a seguir já não são lidas naquela chamada.

## Variáveis locais

```python run
def calcula():
    resultado = 42
    return resultado

calcula()
print(resultado)
```

Dá erro: `resultado` só existe **dentro** da função. Cada chamada tem as suas próprias variáveis, que desaparecem quando a função acaba. Para usar o valor fora, guarda o que a função devolve: `resultado = calcula()`.

## Funções que chamam funções

```python run
def quadrado(x):
    return x * x

def soma_quadrados(a, b):
    return quadrado(a) + quadrado(b)

print(soma_quadrados(3, 4))
```

Lê de dentro para fora: `soma_quadrados(3, 4)` chama `quadrado(3)` → 9 e `quadrado(4)` → 16, e devolve 25.

## Como ler uma função que a IA escreveu

1. Lê o nome e os parâmetros: dizem o que a função **promete** fazer.
2. Escolhe valores de entrada simples e segue o corpo com eles.
3. Procura todos os `return`: são todas as formas de sair.
4. Pergunta: o que acontece com uma lista vazia, um zero, um texto vazio? É aí que a IA costuma falhar.

## Exercícios

```python run
def misterio(a, b):
    if a > b:
        return a - b
    return b - a

print(misterio(10, 3), misterio(3, 10), misterio(5, 5))
```

```python run
def conta_pares(numeros):
    c = 0
    for n in numeros:
        if n % 2 == 0:
            c = c + 1
    return c

print(conta_pares([1, 2, 3, 4, 6]))
print(conta_pares([]))
```

```python run
def f(x):
    x = x + 1
    return x * 2

x = 5
y = f(x)
print(x, y)
```
