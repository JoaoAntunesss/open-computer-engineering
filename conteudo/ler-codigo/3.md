Até agora os programas corriam todas as linhas. Com `if`, o programa **escolhe** que linhas correr, conforme uma condição seja verdadeira ou falsa.

## Comparações

Uma comparação dá sempre `True` ou `False`:

```python run
idade = 17
print(idade >= 18)
print(idade == 17)
print(idade != 17)
print("Porto" == "porto")
```

| Operador | Quer dizer |
|---|---|
| `==` | igual a |
| `!=` | diferente de |
| `<`, `>` | menor, maior |
| `<=`, `>=` | menor ou igual, maior ou igual |

Atenção ao último exemplo: `"Porto"` e `"porto"` são diferentes, porque as maiúsculas contam.

## if e else

```python run
idade = 17
if idade >= 18:
    print("Pode entrar")
else:
    print("Não pode entrar")
print("Fim")
```

Como se lê:

1. Avalia `idade >= 18`. Com 17, dá `False`.
2. Como é falso, salta o bloco do `if` e corre o bloco do `else`.
3. Depois do `if/else`, continua normalmente: `Fim` aparece sempre.

O que pertence a cada bloco é o que está **indentado** (com espaços à esquerda). Em Python a indentação não é decoração: muda o significado.

## elif: várias hipóteses

```python run
nota = 14
if nota >= 18:
    print("Excelente")
elif nota >= 14:
    print("Bom")
elif nota >= 10:
    print("Suficiente")
else:
    print("Reprovado")
```

As condições são testadas **por ordem** e só corre o **primeiro** bloco verdadeiro. Com 14, a primeira é falsa, a segunda é verdadeira: aparece `Bom` e o resto é ignorado, mesmo que `nota >= 10` também seja verdade.

## and, or, not

```python run
idade = 20
tem_bilhete = False
if idade >= 18 and tem_bilhete:
    print("Entra")
else:
    print("Fica à porta")
print(idade >= 18 or tem_bilhete)
print(not tem_bilhete)
```

- `and`: as duas têm de ser verdadeiras.
- `or`: basta uma.
- `not`: troca verdadeiro por falso.

## Ler um if que a IA escreveu

A IA adora condições compridas. Quando aparecer uma, parte-a em bocados e avalia cada um com os valores concretos:

```python run
stock = 0
encomenda_urgente = True
cliente_vip = False
if stock > 0 or encomenda_urgente and cliente_vip:
    print("Envia hoje")
else:
    print("Envia amanhã")
```

Aqui há uma armadilha: o `and` é avaliado antes do `or`. Lê-se `stock > 0 or (encomenda_urgente and cliente_vip)`: `False or (True and False)`, que dá `False or False`, ou seja `False`. Quando houver dúvida, os parênteses tornam a intenção clara, e se a IA não os pôs, pergunta-te se o resultado é mesmo o que querias.

## Erros comuns

- Usar `=` em vez de `==` numa condição (`if idade = 18:` dá erro de sintaxe).
- Ordem errada nos `elif`: se testares `nota >= 10` antes de `nota >= 18`, um 19 cai em "Suficiente".
- Indentação errada: uma linha a mais ou a menos de espaços muda o bloco a que pertence.

## Exercícios

Prevê o resultado de cada um e só depois corre.

```python run
x = 7
if x > 5:
    print("grande")
if x > 6:
    print("muito grande")
else:
    print("pequeno")
```

```python run
temperatura = 30
if temperatura > 25:
    print("calor")
elif temperatura > 15:
    print("ameno")
print("ok")
```

```python run
a = 3
b = 3
if a == b and a > 5:
    print("sim")
elif a == b or a > 5:
    print("talvez")
else:
    print("não")
```

??? Soluções
1: Aparece `grande` e depois `muito grande`. São dois `if` independentes, por isso os dois são testados. O `else` pertence só ao segundo `if`.

2: Aparece `calor` e depois `ok`. A primeira condição é verdadeira, por isso o `elif` nem é testado.

3: `a == b and a > 5` é `True and False`, ou seja falso. `a == b or a > 5` é `True or False`, verdadeiro. Aparece `talvez`.
