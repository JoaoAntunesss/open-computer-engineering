Uma **variável** é um nome com um valor guardado. O valor pode mudar ao longo do programa, e é exatamente aí que a maioria das pessoas se perde a ler código. A ferramenta para não te perderes chama-se **tabela de rastreio** (*trace table*): uma tabela onde escreves, linha a linha, o valor de cada variável.

## Tipos de valores

Cada valor tem um tipo. Os quatro que vais ver em todo o lado:

| Tipo | Exemplos | O que é |
|---|---|---|
| `int` | `3`, `-7`, `2026` | número inteiro |
| `float` | `3.5`, `0.1` | número com casas decimais |
| `str` | `"Porto"`, `'a'` | texto |
| `bool` | `True`, `False` | verdadeiro ou falso |

```python run
preco = 12.5
quantidade = 3
nome = "caneta"
em_stock = True
print(type(preco), type(quantidade), type(nome), type(em_stock))
```

O tipo decide o que acontece. `+` entre números soma, entre textos junta:

```python run
print(2 + 3)
print("2" + "3")
print("ha" * 3)
```

## Uma variável pode mudar

```python run
pontos = 10
pontos = pontos + 5
pontos = pontos * 2
print(pontos)
```

A segunda linha assusta muita gente: como é que `pontos` é igual a `pontos + 5`? Lembra-te: `=` quer dizer "fica com". Primeiro calcula-se o lado direito com o valor **antigo** (10 + 5 = 15) e só depois esse resultado substitui o valor guardado.

## A tabela de rastreio

Para o programa de cima:

| Linha | pontos |
|---|---|
| 1 | 10 |
| 2 | 15 |
| 3 | 30 |

No fim, `print` mostra `30`. Parece demasiado simples para valer a pena, mas é com esta tabela que vais conseguir ler programas de 50 linhas com ciclos e funções sem te perderes. Os programadores com experiência fazem-na de cabeça; tu vais fazê-la no papel até deixares de precisar.

## Duas variáveis a trocar

```python run
a = 1
b = 2
a = b
b = a
print(a, b)
```

Faz a tabela antes de correr. A maioria das pessoas acha que dá `2 1`.

| Linha | a | b |
|---|---|---|
| 1 | 1 | — |
| 2 | 1 | 2 |
| 3 | 2 | 2 |
| 4 | 2 | 2 |

Dá `2 2`. Na linha 3, o valor original de `a` perdeu-se. Para trocar a sério precisas de guardar um deles antes (`tmp = a`) ou usar a forma do Python `a, b = b, a`.

## Converter tipos

```python run
idade_texto = "25"
idade = int(idade_texto)
print(idade + 1)
print(idade_texto + "1")
```

`int(...)` transforma texto em número, `str(...)` faz o contrário. Muitos bugs de principiante (e de IA) vêm de misturar `"25"` com `25`.

## Erros comuns

- Pensar que `=` compara. Para comparar usa-se `==` (vais ver na próxima lição).
- Esquecer que uma variável mudou umas linhas antes. É para isso que serve a tabela.
- Misturar texto e números: `"Tens " + 3 + " anos"` dá erro. Usa `"Tens " + str(3) + " anos"` ou `f"Tens {3} anos"`.

## Exercícios

Para cada programa, faz a tabela de rastreio no papel, escreve o que vai aparecer e só depois corre.

```python run
x = 4
y = x * 2
x = y - 1
y = x + y
print(x, y)
```

```python run
total = 0
total = total + 5
total = total + 5
media = total / 2
print(total, media)
```

```python run
texto = "ab"
texto = texto + texto
texto = texto * 2
print(texto, len(texto))
```

3: "ab" → "abab" → "abababab". `len` conta os carateres: 8. Mostra `abababab 8`.
