Se usas IA para escrever código, provavelmente já te aconteceu: o programa funciona, mas não sabes porquê. E quando deixa de funcionar, não sabes por onde começar. Esta fase existe para isso. Não precisas de saber nada. Vais aprender a **ler** antes de aprender a escrever, tal como aprendeste a ler livros antes de os escrever.

## O que é um programa

Um programa é uma **lista de instruções** que o computador segue **por ordem**, de cima para baixo, uma de cada vez. O computador não "percebe" o que queres. Faz exatamente o que está escrito, nem mais nem menos.

```python run
print("Olá!")
print("Isto é a segunda linha.")
print(2 + 3)
```

Carrega em **Correr**. Antes de carregares, tenta adivinhar o que vai aparecer. Este hábito, **prever antes de correr**, é a coisa mais importante desta fase inteira. Cada vez que acertas, percebeste. Cada vez que falhas, aprendeste onde estava o teu engano.

Repara em três coisas:

- `print(...)` mostra o que estiver dentro dos parênteses.
- O que está entre aspas (`"Olá!"`) é **texto** e aparece tal e qual.
- O que não está entre aspas é **calculado**: `2 + 3` aparece como `5`.

## Como ler uma linha

Lê sempre uma linha de dentro para fora e da direita para a esquerda quando há um `=`:

```python run
idade = 20 + 5
print(idade)
```

1. O computador calcula o lado direito: `20 + 5` dá `25`.
2. Guarda esse valor num nome, `idade`.
3. Na linha seguinte, `print(idade)` vai buscar o valor guardado e mostra-o.

O `=` em programação **não é** "igual a" como na matemática. Lê-se "fica com" ou "guarda". `idade = 25` quer dizer "o nome idade fica com o valor 25".

## A ordem importa

O computador só sabe o que já leu. Este programa falha:

```python run
print(nome)
nome = "Ana"
```

Lê a mensagem de erro com calma: `NameError: name 'nome' is not defined`. Quer dizer "não conheço nenhum `nome`". Na linha 1 ainda não existia, porque só é criado na linha 2. Troca a ordem das linhas na caixa e corre outra vez.

## Comentários

Tudo o que vem depois de `#` é um **comentário**: o computador ignora, serve para pessoas.

```python run
# Isto não faz nada
print("Isto faz")  # e isto também é ignorado
```

Quando lês código gerado por IA, os comentários ajudam, mas **podem mentir**. A IA às vezes escreve um comentário a dizer uma coisa e código a fazer outra. Confia no código, não no comentário.

## Porque é que isto importa quando usas IA

Quando aceitas código que não sabes ler, ficas dependente: não sabes se está certo, não sabes corrigi-lo e não sabes explicá-lo numa entrevista ou num exame. Ler código é como ler um contrato antes de o assinar. Não precisas de o saber escrever de raiz para perceberes se está a dizer o que devia.

> Regra desta fase: nunca carregues em Correr sem antes escreveres (num papel ou na cabeça) o que achas que vai aparecer.
