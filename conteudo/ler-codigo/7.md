Até aqui leste programas pequenos feitos para aprender. Agora vais aprender a abrir um ficheiro de código real, de outra pessoa ou gerado por IA, com 200 linhas, e conseguir perceber o que faz sem ler tudo de uma ponta à outra.

## Ninguém lê código como um livro

Programadores com experiência **não** começam na linha 1 e leem até ao fim. Saltam, procuram, fazem perguntas. A estratégia:

1. **Para que serve?** Lê o nome do ficheiro, o README e o comentário do topo. Escreve numa frase o que achas que o ficheiro faz.
2. **Mapa.** Lista todas as funções (e classes) só pelo nome e parâmetros. Não leias o corpo ainda.
3. **Ponto de entrada.** Encontra onde o programa começa a correr. Em Python costuma estar no fim: `if __name__ == "__main__":`.
4. **Seguir um caminho.** A partir do ponto de entrada, segue **um** caso concreto (uma entrada real) e salta para dentro de cada função que é chamada.
5. **Confirmar.** Corre o programa, ou um bocado dele, e vê se bate certo com o que previste.

## Um exemplo completo

Lê este ficheiro com a estratégia, antes de correr.

```python run
"""Gestão simples de reservas de mesas de um restaurante."""

MESAS = {1: 2, 2: 4, 3: 4, 4: 6}   # número da mesa: lugares

def mesas_livres(reservas):
    ocupadas = {r["mesa"] for r in reservas}
    return [m for m in MESAS if m not in ocupadas]

def melhor_mesa(pessoas, reservas):
    candidatas = [m for m in mesas_livres(reservas) if MESAS[m] >= pessoas]
    if not candidatas:
        return None
    return min(candidatas, key=lambda m: MESAS[m])

def reservar(nome, pessoas, reservas):
    mesa = melhor_mesa(pessoas, reservas)
    if mesa is None:
        return f"Lamentamos, {nome}: não há mesa para {pessoas}."
    reservas.append({"nome": nome, "mesa": mesa})
    return f"{nome}: mesa {mesa} ({MESAS[mesa]} lugares)."

if __name__ == "__main__":
    reservas = []
    for nome, pessoas in [("Ana", 3), ("Rui", 2), ("Sofia", 4), ("Tiago", 5), ("Inês", 4)]:
        print(reservar(nome, pessoas, reservas))
```

**1. Para que serve?** A docstring diz: reservas de mesas.

**2. Mapa.** `MESAS` (dados), `mesas_livres(reservas)`, `melhor_mesa(pessoas, reservas)`, `reservar(nome, pessoas, reservas)`. Só pelos nomes já se adivinha a história: ver que mesas estão livres, escolher a melhor, reservar.

**3. Ponto de entrada.** O bloco `if __name__ == "__main__":` faz 5 reservas por ordem.

**4. Seguir um caminho.** Ana, 3 pessoas, sem reservas:
- `reservar` chama `melhor_mesa(3, [])`.
- `mesas_livres([])` devolve todas: `[1, 2, 3, 4]`.
- Candidatas com pelo menos 3 lugares: `[2, 3, 4]`.
- `min(..., key=lambda m: MESAS[m])` escolhe a com **menos lugares**: 4 lugares empatam entre 2 e 3, e o `min` fica com a primeira, a mesa 2.
- A Ana fica na mesa 2.

Agora faz tu o resto no papel: Rui (2), Sofia (4), Tiago (5) e Inês (4). Depois corre e compara.

**5. Confirmar.** Se acertaste, percebeste o ficheiro inteiro sem teres lido cada linha com o mesmo cuidado.

## Coisas novas que apareceram

- `{r["mesa"] for r in reservas}`: como uma *list comprehension*, mas cria um **conjunto** (sem repetidos).
- `lambda m: MESAS[m]`: uma função pequena sem nome. Aqui diz ao `min` "compara as mesas pelo número de lugares".
- `None`: "nada". A função devolve `None` quando não encontra mesa, e quem a chama tem de verificar (`if mesa is None`).
- `f"...{nome}..."`: texto com valores lá dentro.

Quando encontrares algo que não conheces, é aqui que a IA é ótima: pergunta "o que faz `lambda m: MESAS[m]` nesta linha?", e não "explica-me o ficheiro".
