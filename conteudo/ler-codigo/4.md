Os ciclos (*loops*) repetem um bloco de código. São a parte onde mais se erra a ler, porque o mesmo pedaço corre várias vezes com valores diferentes. A tabela de rastreio passa a ter uma linha **por volta** do ciclo.

## for: uma volta por cada elemento

```python run
for fruta in ["maçã", "pera", "uva"]:
    print("Gosto de", fruta)
print("Acabou")
```

Lê-se: "para cada `fruta` da lista, corre o bloco indentado". Na 1.ª volta `fruta` vale `"maçã"`, na 2.ª `"pera"`, na 3.ª `"uva"`. Quando a lista acaba, o programa segue para a linha seguinte ao bloco.

## range: contar

```python run
for i in range(5):
    print(i)
```

`range(5)` dá `0, 1, 2, 3, 4`: começa em 0 e **não inclui** o 5. É das coisas que mais confunde. `range(1, 5)` dá `1, 2, 3, 4`, e `range(0, 10, 2)` dá `0, 2, 4, 6, 8`.

## Acumular: o padrão mais comum

```python run
total = 0
for n in [4, 8, 15]:
    total = total + n
print(total)
```

| Volta | n | total depois |
|---|---|---|
| antes | — | 0 |
| 1 | 4 | 4 |
| 2 | 8 | 12 |
| 3 | 15 | 27 |

Vais encontrar este padrão (começar a 0 e ir somando) em quase todos os programas: totais, contagens, médias.

## while: repetir enquanto for verdade

```python run
saldo = 100
meses = 0
while saldo > 0:
    saldo = saldo - 30
    meses = meses + 1
print(meses, saldo)
```

O `while` testa a condição **antes** de cada volta. Faz a tabela: 100 → 70 → 40 → 10 → -20. Depois da 4.ª volta, `saldo > 0` é falso e o ciclo para. Mostra `4 -20`.

Se a condição nunca ficar falsa, o ciclo nunca acaba: é um **ciclo infinito** e o programa fica pendurado. Ao ler um `while`, pergunta sempre: "o que é que, lá dentro, faz a condição ficar falsa?"

## break e continue

```python run
for n in [3, 8, -1, 5]:
    if n < 0:
        break
    print(n)
```

`break` sai do ciclo de imediato: mostra `3` e `8` e para no `-1`. `continue` salta só o resto daquela volta e passa à seguinte. Troca `break` por `continue` na caixa e vê a diferença.

## Ciclos dentro de ciclos

```python run
for linha in range(1, 4):
    texto = ""
    for coluna in range(1, 4):
        texto = texto + str(linha * coluna) + " "
    print(texto)
```

O ciclo de dentro corre **todo** em cada volta do ciclo de fora. Aqui são 3 × 3 = 9 voltas no total.

## Erros comuns (teus e da IA)

- **Falhar por um** (*off-by-one*): `range(1, 10)` não inclui o 10. A IA erra isto muitas vezes.
- Pôr o acumulador (`total = 0`) dentro do ciclo: volta a zero em cada volta.
- Indentar o `print` para dentro do ciclo quando só se queria no fim.

## Exercícios

Faz a tabela de rastreio e prevê o resultado.

```python run
conta = 0
for letra in "banana":
    if letra == "a":
        conta = conta + 1
print(conta)
```

```python run
n = 1
while n < 50:
    n = n * 3
print(n)
```

```python run
total = 0
for i in range(1, 5):
    total = 0
    total = total + i
print(total)
```

??? Soluções
1: Um `for` sobre um texto percorre as letras. Há três `a` em "banana": mostra `3`.

2: 1 → 3 → 9 → 27 → 81. Quando `n` é 81, `n < 50` é falso e para. Mostra `81`. Repara que o resultado é maior do que 50: o teste só acontece no início de cada volta.

3: Este tem um bug de propósito: `total = 0` está dentro do ciclo, por isso volta a zero em cada volta. Na última volta fica 0 + 4. Mostra `4` e não `10`. Para somar 1+2+3+4, a linha `total = 0` tem de estar antes do `for`.
