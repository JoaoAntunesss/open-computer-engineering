Quase todos os programas reais trabalham com **coleções** de dados: uma lista de clientes, um carrinho de compras, as definições de uma app. Em Python, as duas que vais ler a toda a hora são as **listas** e os **dicionários**.

## Listas: coisas por ordem

```python run
notas = [12, 15, 9, 18]
print(notas[0])
print(notas[-1])
print(len(notas))
notas.append(14)
print(notas)
```

- Os elementos estão por ordem e cada um tem uma **posição** (índice) que começa em **0**. `notas[0]` é o primeiro, `notas[3]` é o quarto.
- `notas[-1]` é o último.
- `len(...)` diz quantos elementos há.
- `.append(x)` acrescenta no fim.

Pedir uma posição que não existe dá `IndexError`: com 4 elementos, `notas[4]` não existe, porque as posições vão de 0 a 3.

## Percorrer e filtrar

```python run
notas = [12, 15, 9, 18, 7]
aprovados = []
for n in notas:
    if n >= 10:
        aprovados.append(n)
print(aprovados)
print(sum(aprovados) / len(aprovados))
```

Este padrão (lista vazia, ciclo, `if`, `append`) aparece em todo o lado. A IA costuma escrevê-lo numa só linha, chamada *list comprehension*:

```python run
notas = [12, 15, 9, 18, 7]
aprovados = [n for n in notas if n >= 10]
print(aprovados)
```

Lê-se da mesma maneira: "`n`, para cada `n` em `notas`, se `n >= 10`". Quando vires uma destas e te perderes, reescreve-a como ciclo normal no papel.

## Dicionários: coisas com nome

```python run
cliente = {"nome": "Rita", "idade": 31, "cidade": "Porto"}
print(cliente["nome"])
cliente["idade"] = 32
cliente["email"] = "rita@exemplo.pt"
print(cliente)
```

Num dicionário não há posições, há **chaves**. Cada chave tem um valor. `cliente["nome"]` vai buscar o valor da chave `"nome"`. Atribuir a uma chave que não existe cria-a; a uma que existe, substitui o valor.

Pedir uma chave que não existe dá `KeyError`. Para não rebentar, usa-se `.get`:

```python run
cliente = {"nome": "Rita"}
print(cliente.get("telefone"))
print(cliente.get("telefone", "sem telefone"))
```

## Percorrer um dicionário

```python run
stock = {"canetas": 40, "cadernos": 0, "lápis": 12}
for produto, quantidade in stock.items():
    if quantidade == 0:
        print("Esgotado:", produto)
```

`.items()` dá pares (chave, valor). Em cada volta, `produto` fica com a chave e `quantidade` com o valor.

## Listas de dicionários: os dados reais

É assim que chega quase tudo de uma API ou de uma base de dados:

```python run
encomendas = [
    {"cliente": "Ana", "total": 25.0, "paga": True},
    {"cliente": "Rui", "total": 40.5, "paga": False},
    {"cliente": "Sofia", "total": 12.0, "paga": True},
]
recebido = 0
for e in encomendas:
    if e["paga"]:
        recebido = recebido + e["total"]
print(recebido)
```

Lê de fora para dentro: `encomendas` é uma lista; cada `e` é um dicionário; `e["total"]` é um número.

## Cuidado: duas variáveis, a mesma lista

```python run
a = [1, 2, 3]
b = a
b.append(4)
print(a)
```

`b = a` não copia a lista: as duas variáveis passam a apontar para a **mesma** lista. Mudar uma muda "as duas". Para copiar a sério: `b = a.copy()` ou `b = list(a)`.
