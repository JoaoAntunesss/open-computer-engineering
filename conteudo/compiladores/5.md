Um programa pode estar bem escrito sintaticamente e não fazer sentido: usar uma variável que não existe, somar um texto a um número, chamar uma função com argumentos a menos. A **análise semântica** verifica estas regras, que uma gramática não consegue exprimir. As duas tarefas centrais são **resolver nomes** (a que declaração se refere cada uso) e **verificar tipos**.

## Tabela de símbolos e âmbitos

A **tabela de símbolos** guarda, para cada nome, o que se sabe dele: o tipo, onde foi declarado, se é variável ou função. Como os blocos criam âmbitos encaixados, usa-se uma **pilha de tabelas**: procurar um nome começa no âmbito mais interior e sobe.

```
global: { total: int, media: função(int, int) → float }
  └ função media: { a: int, b: int }
      └ bloco do if: { diferenca: int }
```

Erros detetados aqui: variável não declarada, declarada duas vezes no mesmo âmbito, usada fora do seu âmbito.

## Verificação de tipos

Cada expressão recebe um tipo, calculado a partir dos tipos das partes, segundo **regras**:

```
se e1 : int  e  e2 : int    então  e1 + e2 : int
se e1 : int  e  e2 : float  então  e1 + e2 : float   (conversão implícita)
se e1 : str  e  e2 : str    então  e1 + e2 : str
se c : bool                 então  "se (c)" está bem formado
```

- **Estática** (C, Java, Rust, TypeScript): no compilador, antes de correr.
- **Dinâmica** (Python, JavaScript): durante a execução, quando a operação acontece.
- **Forte / fraca:** se as conversões implícitas são raras (Python: `"3" + 4` dá erro) ou frequentes (JavaScript: `"3" + 4` dá `"34"`, `"3" * 4` dá `12`).

## Um verificador para Mini com tipos

Uma versão de Mini com declarações (`int x = 3;`, `str nome = "Ana";`). Prevê que erros encontra:

```python run
programa = [
    ("decl", "int", "total", ("num", 0), 1),
    ("decl", "str", "nome", ("txt", "Ana"), 2),
    ("decl", "int", "idade", ("bin", "+", ("var", "total"), ("num", 30)), 3),
    ("atribui", "total", ("bin", "*", ("var", "idade"), ("var", "nome")), 4),
    ("bloco", [
        ("decl", "bool", "adulto", ("bin", ">=", ("var", "idade"), ("num", 18)), 6),
        ("se", ("var", "idade"), [], 7),
        ("decl", "int", "total", ("num", 1), 8),
    ], 5),
    ("atribui", "adulto", ("bool", True), 10),
    ("decl", "int", "idade", ("num", 5), 11),
]

REGRAS = {("+", "int", "int"): "int", ("*", "int", "int"): "int", ("+", "str", "str"): "str",
          (">=", "int", "int"): "bool", ("==", "int", "int"): "bool"}
erros, ambitos = [], [{}]

def procura(nome):
    for a in reversed(ambitos):
        if nome in a:
            return a[nome]
    return None

def tipo(e, linha):
    match e:
        case ("num", _): return "int"
        case ("txt", _): return "str"
        case ("bool", _): return "bool"
        case ("var", n):
            t = procura(n)
            if t is None:
                erros.append(f"linha {linha}: '{n}' não está declarada"); return "?"
            return t
        case ("bin", op, a, b):
            ta, tb = tipo(a, linha), tipo(b, linha)
            if "?" in (ta, tb): return "?"
            r = REGRAS.get((op, ta, tb))
            if r is None:
                erros.append(f"linha {linha}: '{op}' não se aplica a {ta} e {tb}"); return "?"
            return r

def verifica(instrucoes):
    for i in instrucoes:
        match i:
            case ("decl", t, n, e, linha):
                if n in ambitos[-1]:
                    erros.append(f"linha {linha}: '{n}' já foi declarada neste âmbito")
                te = tipo(e, linha)
                if te not in (t, "?"):
                    erros.append(f"linha {linha}: não se pode guardar {te} numa variável {t}")
                ambitos[-1][n] = t
            case ("atribui", n, e, linha):
                t, te = procura(n), tipo(e, linha)
                if t is None:
                    erros.append(f"linha {linha}: '{n}' não está declarada")
                elif te not in (t, "?"):
                    erros.append(f"linha {linha}: não se pode guardar {te} numa variável {t}")
            case ("se", c, corpo, linha):
                if tipo(c, linha) not in ("bool", "?"):
                    erros.append(f"linha {linha}: a condição do 'se' tem de ser bool")
                ambitos.append({}); verifica(corpo); ambitos.pop()
            case ("bloco", corpo, linha):
                ambitos.append({}); verifica(corpo); ambitos.pop()

verifica(programa)
print("\n".join(erros) or "sem erros")
```

Repara em três casos interessantes: na linha 8, `total` é declarada **outra vez** num bloco interior (é permitido: esconde a de fora); na linha 10, `adulto` já saiu de âmbito; na linha 11, `idade` repete-se no mesmo âmbito.

## Inferência de tipos

Em muitas linguagens modernas não é preciso escrever os tipos: `var x = 3;` (Java), `let x = 3;` (Rust), `auto` (C++). O compilador deduz o tipo da expressão. O Haskell e o OCaml vão mais longe, com o algoritmo de **Hindley-Milner** (na fase avançada, Linguagens de Programação), que deduz os tipos de funções inteiras.
