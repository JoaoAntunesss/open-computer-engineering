As duas camadas de baixo levam os bits de um aparelho ao vizinho: pelo cabo, pela fibra ou pelo ar. A **camada física** transforma bits em sinais; a **camada de ligação** organiza esses bits em **tramas**, endereça-as com endereços **MAC**, deteta erros e decide quem fala quando o meio é partilhado. Ethernet (cabo) e Wi-Fi (rádio) são as duas tecnologias que usas todos os dias.

## Camada física: alguns números

- **Largura de banda:** bits por segundo (1 Gb/s numa porta Ethernet, centenas de Mb/s num Wi-Fi bom).
- **Atraso de propagação:** a luz numa fibra percorre cerca de 200 000 km/s. Lisboa–Nova Iorque (≈ 5600 km): ≈ 28 ms só de ida, seja qual for a velocidade da ligação.
- **Atraso de transmissão:** tempo a pôr os bits no fio = tamanho / largura de banda. Uma trama de 1500 bytes a 1 Gb/s: 12 µs.

```python run
def atraso(tamanho_bytes, banda_bps, distancia_km, v_kms=200_000):
    transmissao = tamanho_bytes * 8 / banda_bps
    propagacao = distancia_km / v_kms
    return transmissao * 1000, propagacao * 1000

casos = [
    ("ficheiro de 10 MB, Porto-Lisboa, 100 Mb/s", 10e6, 100e6, 300, 200_000),
    ("ficheiro de 10 MB, Porto-Lisboa, 1 Gb/s", 10e6, 1e9, 300, 200_000),
    ("pacote de 1500 B, Lisboa-Nova Iorque, 1 Gb/s", 1500, 1e9, 5600, 200_000),
    ("pacote de 1500 B, satélite geoestacionário", 1500, 50e6, 2 * 35786, 300_000),  # rádio no vácuo
]
for nome, t, b, d, v in casos:
    tx, prop = atraso(t, b, d, v)
    print(f"{nome:46} transmissão {tx:9.3f} ms  propagação {prop:7.2f} ms")
```

Prevê qual dos dois atrasos domina em cada caso. Para ficheiros grandes, conta a largura de banda; para pacotes pequenos e longe, conta a distância (e nenhuma ligação mais rápida resolve isso).

## Tramas Ethernet

```
| preâmbulo | MAC destino | MAC origem | tipo | dados (46–1500 B) | CRC |
```

- **Endereço MAC:** 48 bits, escrito como `a4:5e:60:12:34:56`. Os primeiros 24 identificam o fabricante. Só tem significado na rede local.
- **CRC:** um código que deteta erros de transmissão. Uma trama com erro é descartada (a recuperação, se houver, é feita mais acima, pelo TCP).
- **MTU:** os dados de uma trama Ethernet têm no máximo 1500 bytes.

## Comutação: o switch

Um **switch** liga vários aparelhos e encaminha cada trama só para a porta certa:

1. **Aprende:** ao receber uma trama na porta 3 com MAC de origem X, anota "X está na porta 3".
2. **Encaminha:** se conhece a porta do MAC de destino, envia só para lá; se não conhece, envia para todas as outras (inundação).

É o que torna as redes rápidas: duas conversas em portas diferentes não se atrapalham.

## ARP: do IP ao MAC

Para enviar um pacote IP para 192.168.1.30 na mesma rede, é preciso saber o MAC. O **ARP** pergunta a toda a rede (*broadcast*): "Quem tem 192.168.1.30?" e o dono responde com o MAC. A resposta fica em cache (`arp -a` mostra-a). Se o destino estiver noutra rede, pergunta-se o MAC do **router** (o *gateway*).

## Wi-Fi

O ar é partilhado: se dois aparelhos transmitirem ao mesmo tempo no mesmo canal, colidem. O Wi-Fi usa **CSMA/CA**: ouvir antes de falar, esperar um tempo aleatório se o canal estiver ocupado, e confirmar cada trama (ACK). Por isso uma rede Wi-Fi com muitos aparelhos fica lenta, mesmo com uma ligação à Internet rápida.

- **2,4 GHz:** maior alcance, atravessa melhor as paredes, mas só 3 canais sem sobreposição e muita interferência (micro-ondas, Bluetooth, vizinhos).
- **5 GHz e 6 GHz** (Wi-Fi 6E/7): mais canais e mais largura de banda, menos alcance.
- Segurança: **WPA3** (ou, no mínimo, WPA2 com uma palavra-passe forte). Nunca WEP.

## VLAN

Um switch pode ser dividido em várias redes lógicas (**VLANs**), separadas: a rede dos funcionários, a dos clientes e a das câmaras, no mesmo equipamento. O tráfego entre VLANs tem de passar por um router ou firewall.
