Em redes, o código que vais ler é sobretudo código que fala com a rede: sockets, pedidos HTTP, parsing de endereços. Ler esse código obriga a saber o que acontece "por baixo" de cada linha: que pacotes saem, em que ordem e o que pode falhar.

## Ler e prever: endereços e sub-redes

```python run
import ipaddress

rede = ipaddress.ip_network("192.168.10.0/26")
print(rede.num_addresses, rede.netmask, rede.broadcast_address)
for ip in ["192.168.10.5", "192.168.10.63", "192.168.10.64"]:
    print(ip, ipaddress.ip_address(ip) in rede)
print(list(rede.subnets(new_prefix=28))[1])
```

Antes de correr, faz as contas à mão: quantos endereços tem um /26? Qual é a máscara? Qual é o endereço de broadcast? Que endereços pertencem à rede?

## Encontra o erro: um servidor TCP que só atende metade

```python
import socket

srv = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
srv.bind(("0.0.0.0", 5000))
srv.listen()
while True:
    con, endereco = srv.accept()
    dados = con.recv(1024)
    con.sendall(b"Recebido: " + dados)
```

Este servidor de eco funciona com o primeiro cliente, mas os clientes reclamam que a ligação nunca fecha e que mensagens grandes chegam cortadas. Encontra os dois problemas a ler o código.

Escreve uma função `mesma_rede(ip1, ip2, prefixo)` que diz se dois IPs estão na mesma sub-rede, sem usar `ipaddress` (com operações de bits sobre os 32 bits do endereço).

**Ler e prever:** um /26 tem 2⁶ = `64` endereços, máscara `255.255.255.192`, broadcast `192.168.10.63`. Pertencem `.5` e `.63`; o `.64` já é da rede seguinte. A segunda sub-rede /28 é `192.168.10.16/28`.

**Encontra o erro:** (1) nunca chama `con.close()`, por isso o cliente fica à espera do fim da ligação; (2) `recv(1024)` lê **no máximo** 1024 bytes de uma vez, e o TCP é um fluxo, não mensagens: é preciso ler em ciclo até receber tudo (ou até um delimitador combinado).

**Escreve tu:**
```python
def para_int(ip):
    a, b, c, d = map(int, ip.split("."))
    return (a << 24) | (b << 16) | (c << 8) | d

def mesma_rede(ip1, ip2, prefixo):
    mascara = (0xFFFFFFFF << (32 - prefixo)) & 0xFFFFFFFF
    return para_int(ip1) & mascara == para_int(ip2) & mascara
```
