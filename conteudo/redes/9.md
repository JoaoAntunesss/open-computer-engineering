Num router tradicional, a lógica que decide as rotas (o **plano de controlo**) e o hardware que reencaminha os pacotes (o **plano de dados**) estão na mesma caixa, fechada pelo fabricante. As **redes definidas por software** (SDN) separam os dois: os switches só reencaminham, segundo tabelas que um **controlador** central, programável, lhes envia. A rede passa a ser configurada por código, como qualquer outro software.

## Os dois planos

- **Plano de dados:** para cada pacote, consulta uma tabela e decide em nanossegundos (encaminhar, descartar, alterar cabeçalhos). Hardware especializado.
- **Plano de controlo:** decide **o que** vai nas tabelas: calcula caminhos, aplica políticas, reage a falhas.

Na rede tradicional, cada router corre o seu plano de controlo (OSPF, BGP) e as decisões emergem da troca de mensagens. Na SDN, o controlador tem a visão global e decide por todos.

## Tabelas de fluxos: correspondência e ação

Os switches SDN guardam regras do tipo **correspondência → ação**, com prioridade:

| Prioridade | Correspondência | Ação |
|---|---|---|
| 100 | IP destino 10.0.2.0/24, porta TCP 22 | descartar |
| 50 | IP destino 10.0.2.0/24 | enviar pela porta 2 |
| 50 | IP destino 10.0.1.0/24 | enviar pela porta 1 |
| 0 | qualquer | enviar ao controlador |

Uma única abstração faz de router (por IP), de switch (por MAC), de firewall (por porta) e de balanceador (reescrever o destino). O protocolo clássico entre controlador e switches é o **OpenFlow**; a linguagem **P4** permite até programar como o switch analisa os pacotes.

```python run
import ipaddress

class Switch:
    def __init__(self, nome):
        self.nome, self.regras = nome, []           # (prioridade, condição, ação)
    def instala(self, prioridade, condicao, acao):
        self.regras.append((prioridade, condicao, acao))
        self.regras.sort(key=lambda r: -r[0])
    def processa(self, pacote):
        for prioridade, condicao, acao in self.regras:
            if condicao(pacote):
                return acao
        return "enviar ao controlador"

def em(rede):
    r = ipaddress.ip_network(rede)
    return lambda p: ipaddress.ip_address(p["dst"]) in r

class Controlador:
    """Visão global: decide as regras de todos os switches a partir de políticas."""
    def __init__(self, switches):
        self.switches = switches
    def politica_bloquear_ssh(self, rede):
        for s in self.switches:
            s.instala(100, lambda p, c=em(rede): c(p) and p["porta"] == 22, "descartar")
    def rota(self, rede, saidas):
        for s in self.switches:
            s.instala(50, em(rede), f"porta {saidas[s.nome]}")

s1, s2 = Switch("s1"), Switch("s2")
ctl = Controlador([s1, s2])
ctl.rota("10.0.1.0/24", {"s1": 1, "s2": 3})
ctl.rota("10.0.2.0/24", {"s1": 2, "s2": 1})
ctl.politica_bloquear_ssh("10.0.2.0/24")

for p in [{"dst": "10.0.1.7", "porta": 443}, {"dst": "10.0.2.9", "porta": 22},
          {"dst": "10.0.2.9", "porta": 80}, {"dst": "8.8.8.8", "porta": 53}]:
    print(p, "| s1:", s1.processa(p), "| s2:", s2.processa(p))
```

Prevê a ação de cada switch para os quatro pacotes. Repara que a política de segurança foi escrita **uma vez** no controlador e aplicada a toda a rede.

## Porque é útil

- **Programabilidade:** mudar o comportamento da rede é escrever código, não entrar em cada router a configurar à mão.
- **Visão global:** encaminhamento por critérios que um protocolo distribuído não vê (balancear carga entre caminhos, evitar ligações caras).
- **Automatização:** a rede reage a eventos (um servidor novo, um ataque) sem intervenção humana.
- **Centros de dados e cloud:** a Google usa SDN (B4) para ligar os seus centros de dados, com ligações quase a 100% de utilização; as redes virtuais da AWS, Azure e GCP são SDN.

## Riscos e limites

- O controlador é um ponto central: tem de ser **replicado** (vários controladores, com o problema de consenso de Sistemas Distribuídos).
- Latência: a primeira vez que aparece um fluxo desconhecido, ir ao controlador demora. Instalam-se regras proativamente.
- Segurança: quem controla o controlador controla a rede inteira.
