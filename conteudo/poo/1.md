A programação orientada a objetos organiza um programa em **objetos**: cada um junta dados (o estado) e as operações que trabalham sobre esses dados (o comportamento). A linguagem desta cadeira é o Java, a mais usada no ensino de POO em Portugal (UAb, IST, FEUP). Instala o JDK 21 e usa o IntelliJ IDEA Community, ou corre no terminal com `java Ficheiro.java`.

## Classe e objeto

Uma **classe** é o molde; um **objeto** é uma coisa concreta feita com esse molde.

```java
// Conta.java
public class Conta {
    // atributos: o estado de cada objeto
    private final String titular;
    private double saldo;

    // construtor: cria um objeto num estado válido
    public Conta(String titular, double saldoInicial) {
        if (saldoInicial < 0) throw new IllegalArgumentException("saldo negativo");
        this.titular = titular;
        this.saldo = saldoInicial;
    }

    // métodos: o comportamento
    public void depositar(double valor) {
        if (valor <= 0) throw new IllegalArgumentException("valor inválido");
        saldo += valor;
    }

    public boolean levantar(double valor) {
        if (valor <= 0 || valor > saldo) return false;
        saldo -= valor;
        return true;
    }

    public double getSaldo() { return saldo; }
    public String getTitular() { return titular; }

    @Override
    public String toString() {
        return titular + ": " + String.format("%.2f", saldo) + " €";
    }

    public static void main(String[] args) {
        Conta a = new Conta("Ana", 100);
        Conta b = new Conta("Rui", 50);
        a.depositar(25);
        boolean ok = b.levantar(80);
        System.out.println(a + " | " + b + " | " + ok);
    }
}
```

`new Conta("Ana", 100)` cria um objeto. `a` e `b` são dois objetos diferentes da mesma classe, cada um com o seu saldo.

## Encapsulamento

Os atributos são `private`: só a própria classe lhes mexe. Quem usa a classe só tem acesso aos métodos `public`. Porquê:

- **Invariantes protegidas:** ninguém consegue pôr o saldo negativo, porque a única forma de o mudar é por `depositar` e `levantar`, que verificam.
- **Liberdade para mudar:** podes guardar o saldo em cêntimos (`long`) amanhã sem mudar quem usa a classe.

Regra prática: atributos sempre `private`; `final` quando não mudam depois de construídos; getters só para o que for preciso; setters só quando faz sentido mudar.

## this, static e referências

- `this` é o próprio objeto: `this.saldo = saldo` distingue o atributo do parâmetro.
- `static` pertence à classe, não a cada objeto: um contador de contas criadas, ou o `main`.
- Variáveis de objetos guardam **referências**. `Conta c = a;` não copia a conta: `c` e `a` passam a ser a mesma conta.

```java
Conta c = a;
c.depositar(10);       // a também passa a ter mais 10
```

## Igualdade

`==` compara referências (é o mesmo objeto?). Para comparar conteúdos, usa-se `equals`, que tens de redefinir (e, com ele, `hashCode`). Com `String`, compara sempre com `equals`.

## Ler e prever

```java
Conta x = new Conta("Zé", 10);
Conta y = new Conta("Zé", 10);
Conta z = x;
z.depositar(5);
System.out.println(x.getSaldo() + " " + y.getSaldo() + " " + (x == y) + " " + (x == z));
```
