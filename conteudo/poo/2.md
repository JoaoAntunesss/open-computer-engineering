A **herança** permite definir uma classe nova a partir de outra: a subclasse herda os atributos e métodos e pode acrescentar ou mudar comportamento. O **polimorfismo** permite tratar objetos de classes diferentes da mesma forma, e cada um responde à sua maneira. Juntos, permitem escrever código que funciona com tipos que ainda nem existem.

## Herança

```java
// Formas.java
import java.util.List;

public class Formas {
    public static void main(String[] args) {
        List<Forma> formas = List.of(new Circulo(1), new Retangulo(2, 3), new Quadrado(2));
        double total = 0;
        for (Forma f : formas) {
            System.out.println(f);          // chama o area() de cada uma
            total += f.area();
        }
        System.out.printf("total: %.2f%n", total);
    }
}

abstract class Forma {
    private final String nome;
    protected Forma(String nome) { this.nome = nome; }
    public String getNome() { return nome; }
    public abstract double area();          // cada subclasse diz como
    @Override
    public String toString() { return nome + " com área " + String.format("%.2f", area()); }
}

class Circulo extends Forma {
    private final double raio;
    Circulo(double raio) { super("círculo"); this.raio = raio; }
    @Override public double area() { return Math.PI * raio * raio; }
}

class Retangulo extends Forma {
    protected final double l, a;
    Retangulo(double l, double a) { this("retângulo", l, a); }
    protected Retangulo(String nome, double l, double a) { super(nome); this.l = l; this.a = a; }
    @Override public double area() { return l * a; }
}

class Quadrado extends Retangulo {
    Quadrado(double lado) { super("quadrado", lado, lado); }
}
```

- Com `java Formas.java`, a classe com o `main` tem de ser a primeira do ficheiro.
- `extends` declara a herança. Em Java, cada classe tem **uma** superclasse.
- `super(...)` chama o construtor da superclasse; tem de ser a primeira instrução.
- `@Override` pede ao compilador que confirme que estás mesmo a redefinir um método (apanha erros de escrita).
- `protected` é visível nas subclasses.

## Polimorfismo e ligação dinâmica

A variável `f` é do tipo `Forma`, mas o método chamado é o do **objeto real**: `Circulo.area()` para o círculo, `Retangulo.area()` para o retângulo. Esta escolha é feita em tempo de execução (**ligação dinâmica**).

Vantagem: o ciclo `for (Forma f : formas)` funciona com uma classe `Triangulo` escrita no próximo ano, sem mudar uma linha. É o princípio aberto/fechado: aberto a extensão, fechado a modificação.

## Tipo estático e tipo dinâmico

```java
Forma f = new Quadrado(2);     // tipo estático: Forma; dinâmico: Quadrado
f.area();                      // ok: Forma tem area()
// f.l;                        // erro de compilação: Forma não tem l
if (f instanceof Retangulo r) {
    System.out.println(r.l);   // ok, depois de confirmar
}
```

O compilador só deixa usar o que o tipo **estático** tem. O método executado é o do tipo **dinâmico**.

## Sobreposição (override) e sobrecarga (overload)

- **Override:** a subclasse redefine um método com a mesma assinatura. Escolhido em tempo de execução.
- **Overload:** vários métodos com o mesmo nome e parâmetros diferentes (`println(int)`, `println(String)`). Escolhido em tempo de compilação, pelos tipos estáticos dos argumentos.

## Quando não usar herança

A herança é a ligação mais forte entre duas classes: a subclasse depende dos detalhes da superclasse. Usa-a só quando a subclasse **é um** caso particular da superclasse, e pode ser usada em qualquer sítio onde a superclasse é esperada (**princípio de Liskov**).

O exemplo clássico de herança errada: se `Retangulo` tivesse `setLargura` e `setAltura`, um `Quadrado` não podia cumprir o contrato (mudar a largura mudaria a altura). Muitas vezes, **composição** (a classe tem um objeto de outra) é melhor do que herança.

## Ler e prever

```java
class A { String quem() { return "A"; } String ola() { return "olá de " + quem(); } }
class B extends A { @Override String quem() { return "B"; } }

A x = new B();
System.out.println(x.ola());
```

class Triangulo extends Forma {
    private final double a, b, c;
    Triangulo(double a, double b, double c) { super("triângulo"); this.a = a; this.b = b; this.c = c; }
