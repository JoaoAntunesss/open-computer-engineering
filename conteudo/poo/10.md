## Um programa para ler: a média dos números positivos de uma lista

```java
import java.util.List;

public class Media {

    public static double mediaPositivos(List<Integer> numeros) {
        int soma = 0;
        int quantos = 0;
        for (int n : numeros) {
            if (n > 0) {
                soma += n;
                quantos++;
            }
        }
        if (quantos == 0) {
            return 0;
        }
        return (double) soma / quantos;
    }

    public static void main(String[] args) {
        System.out.println(mediaPositivos(List.of(4, -2, 10, 0, 7)));
    }
}
```

Para correr: com o JDK instalado, `java Media.java` (nas versões recentes, compila e corre de uma vez).

## Como se lê

- **Tudo vive dentro de uma classe** (`public class Media`). Mesmo um programa pequeno.
- **Tipos explícitos**, como em C: `int`, `double`, `List<Integer>` (uma lista de inteiros).
- `public static`: a função (em Java chama-se **método**) pertence à classe e pode ser chamada sem criar um objeto.
- `for (int n : numeros)` é o `for n in numeros` do Python.
- `main(String[] args)` é o ponto de entrada.
- `System.out.println` é o `print`.

## Porque é tão comprido?

Java obriga a dizer muita coisa por extenso: tipos, visibilidade (`public`, `private`), a classe. Em troca, o compilador apanha muitos erros **antes** de o programa correr, e em projetos grandes com muitas pessoas isso vale muito. As versões recentes (`var`, `record`, `List.of`) já reduziram bastante o texto.

## Armadilhas

- Comparar textos com `==` em vez de `.equals()`: `==` compara se são o **mesmo objeto**, não se têm o mesmo texto.
- `NullPointerException`: usar um objeto que é `null`. É o `NoneType` do Java.
- Divisão inteira entre `int`, como em C.

## Exercício

Lê e diz o que aparece:

```java
String a = new String("ola");
String b = new String("ola");
System.out.println(a == b);
System.out.println(a.equals(b));
```

??? Solução
`false` e depois `true`. São dois objetos diferentes (por isso `==` dá falso) com o mesmo texto (por isso `.equals` dá verdadeiro). Para comparar textos em Java usa-se sempre `.equals`.
