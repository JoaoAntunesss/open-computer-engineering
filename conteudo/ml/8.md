As redes "densas" da lição anterior tratam cada entrada de forma independente: não sabem que dois píxeis estão ao lado um do outro, nem que uma palavra vem depois de outra. Duas arquiteturas resolvem isto incorporando a estrutura dos dados: as **redes convolucionais** (CNN), para imagens, e as **redes recorrentes** (RNN), para sequências.

## Convolução

Uma **convolução** desliza um pequeno filtro (por exemplo, 3×3) sobre a imagem e, em cada posição, calcula a soma dos produtos. O mesmo filtro (os mesmos pesos) é usado em toda a imagem:

- **Partilha de pesos:** um detetor de arestas serve em qualquer sítio da imagem. Muitíssimo menos parâmetros do que uma camada densa.
- **Localidade:** cada saída só depende de uma vizinhança.

```python run
import numpy as np

imagem = np.zeros((8, 8))
imagem[2:6, 3:7] = 1                       # um quadrado branco sobre fundo preto

def convolve(img, filtro):
    h, w = filtro.shape
    saida = np.zeros((img.shape[0] - h + 1, img.shape[1] - w + 1))
    for i in range(saida.shape[0]):
        for j in range(saida.shape[1]):
            saida[i, j] = np.sum(img[i:i + h, j:j + w] * filtro)
    return saida

aresta_vertical = np.array([[-1, 0, 1], [-1, 0, 1], [-1, 0, 1]])
aresta_horizontal = aresta_vertical.T

def mostra(m):
    for linha in m:
        print(" ".join(f"{int(v):2d}" for v in linha))

print("arestas verticais:"); mostra(convolve(imagem, aresta_vertical))
print("arestas horizontais:"); mostra(convolve(imagem, aresta_horizontal))
```

Prevê onde aparecem valores positivos, negativos e zeros. Numa CNN, os valores dos filtros não são escolhidos à mão: são **aprendidos**. As primeiras camadas acabam a detetar arestas e cores; as seguintes, texturas e formas; as últimas, partes de objetos (olhos, rodas).

## Uma CNN típica

```
imagem 224×224×3
 → [convolução 3×3, 64 filtros → ReLU → pooling 2×2]   112×112×64
 → [convolução 3×3, 128 filtros → ReLU → pooling 2×2]   56×56×128
 → …
 → camadas densas → softmax (1000 classes)
```

- **Pooling** (normalmente o máximo de cada bloco 2×2) reduz o tamanho e dá alguma tolerância a pequenos deslocamentos.
- Arquiteturas conhecidas: LeNet (dígitos, 1998), AlexNet (2012, o início da era moderna), VGG, **ResNet** (ligações residuais, que permitem redes com centenas de camadas).
- **Transferência de aprendizagem:** pegar numa rede treinada com milhões de imagens (ImageNet) e afinar só as últimas camadas com as tuas poucas centenas. É a forma prática de usar CNN com poucos dados.

## Redes recorrentes

Para sequências (texto, áudio, séries temporais), uma RNN processa um elemento de cada vez e mantém um **estado escondido** que resume o que viu até ali:

hₜ = tanh(Wₓ xₜ + Wₕ hₜ₋₁ + b)

Os mesmos pesos em todos os passos (partilha de pesos no tempo). Problema: em sequências longas, os gradientes da retropropagação no tempo **desaparecem** ou **explodem** (multiplicam-se muitas vezes pelo mesmo Wₕ). As **LSTM** e as **GRU** acrescentam "portas" que controlam o que se guarda e o que se esquece, e foram durante anos o estado da arte em tradução e reconhecimento de fala.

```python run
import numpy as np
# porque é que os gradientes desaparecem ou explodem: multiplicar muitas vezes pelo mesmo fator
for fator in (0.9, 1.0, 1.1):
    print(f"fator {fator}: depois de 10 passos {fator ** 10:.3f}, de 50 passos {fator ** 50:.2e}, de 100 passos {fator ** 100:.2e}")
```

Desde 2017, para texto, as RNN foram quase todas substituídas pelos **transformers** (lição seguinte), que olham para a sequência inteira de uma vez.
