A **regressão linear** prevê um número como uma soma pesada das características; a **regressão logística** usa a mesma ideia para prever uma **probabilidade** (e, com ela, uma classe). São os modelos mais simples, rápidos e interpretáveis, e deviam ser sempre a primeira coisa a experimentar: muitas vezes chegam, e quando não chegam, servem de linha de base.

## Regressão linear

ŷ = w₀ + w₁x₁ + w₂x₂ + … + wₙxₙ

Treinar é escolher os pesos w que minimizam o **erro quadrático médio** nos dados de treino. Há duas formas:

- **Fórmula fechada** (equações normais / mínimos quadrados, como em Métodos Numéricos): `np.linalg.lstsq`.
- **Descida do gradiente:** útil quando há muitos dados ou muitas características.

Cada peso diz quanto muda a previsão por unidade da característica, **mantendo as outras fixas**: é isso que torna o modelo interpretável (com cuidado se as características estiverem correlacionadas).

## Regressão logística

Para classificação binária: aplica-se a **função sigmoide** à combinação linear, para ficar entre 0 e 1:

p = σ(w₀ + w·x),   σ(z) = 1 / (1 + e⁻ᶻ)

Classifica-se como "sim" se p ≥ 0,5 (ou outro limiar, conforme o custo dos erros). Treina-se minimizando a **entropia cruzada** (*log-loss*), com descida do gradiente. A fronteira de decisão é uma reta (um hiperplano).

## Prever faltas a marcações

Duas características: dias de antecedência da marcação e número de faltas anteriores do cliente.

```python run
import numpy as np
rng = np.random.default_rng(42)

n = 600
antecedencia = rng.integers(0, 30, n)                 # dias
faltas_ant = rng.poisson(0.5, n)                      # faltas anteriores
# o "mundo real" que queremos descobrir:
logit = -3.0 + 0.08 * antecedencia + 1.2 * faltas_ant
faltou = rng.random(n) < 1 / (1 + np.exp(-logit))

X = np.column_stack([antecedencia, faltas_ant]).astype(float)
media, desvio = X[:400].mean(0), X[:400].std(0)       # normalizar só com o treino
Xn = (X - media) / desvio
Xn = np.column_stack([np.ones(n), Xn])                # coluna de 1 para o w0
treino, teste = slice(0, 400), slice(400, None)

w = np.zeros(3)
sig = lambda z: 1 / (1 + np.exp(-z))
for passo in range(2000):                             # descida do gradiente na log-loss
    p = sig(Xn[treino] @ w)
    grad = Xn[treino].T @ (p - faltou[treino]) / 400
    w -= 0.5 * grad

p_teste = sig(Xn[teste] @ w)
prev = p_teste >= 0.5
print("pesos (escala normalizada):", np.round(w, 2))
print("exatidão no teste:", f"{np.mean(prev == faltou[teste]):.1%}",
      "| linha de base (nunca falta):", f"{np.mean(~faltou[teste]):.1%}")
for ant, fa in [(1, 0), (25, 0), (25, 3)]:
    x = np.r_[1, (np.array([ant, fa]) - media) / desvio]
    print(f"marcou com {ant:2} dias e {fa} faltas anteriores → P(falta) = {sig(x @ w):.0%}")
```

Prevê, antes de correr: os dois pesos são positivos ou negativos? Qual dos três clientes do fim tem a probabilidade mais alta?

## Características não lineares

Os modelos são lineares **nos pesos**, não nas características: podes acrescentar x², log(x), produtos (x₁·x₂) ou indicadores ("é sábado") e continuar a usar a regressão linear. Com características bem escolhidas, modelos simples vão muito longe.

## Regularização

Com muitas características, os pesos podem ficar enormes e o modelo sobreajusta. A **regularização** penaliza pesos grandes:

- **Ridge** (L2): soma dos quadrados dos pesos. Encolhe todos.
- **Lasso** (L1): soma dos valores absolutos. Põe alguns exatamente a zero (seleciona características).
