Em machine learning, um erro no código raramente rebenta: o modelo treina, dá uma métrica, e a métrica até parece ótima. Os erros mais caros são de **leitura**: dados que passam de um lado para o outro sem deverem. Esta lição treina-te a encontrá-los.

## Ler e prever: uma regressão linear à mão

```python run
import numpy as np

rng = np.random.default_rng(0)
x = rng.uniform(0, 10, 200)
y = 3 * x + 5 + rng.normal(0, 1, 200)

w, b, lr = 0.0, 0.0, 0.01
for _ in range(2000):
    pred = w * x + b
    erro = pred - y
    w -= lr * 2 * np.mean(erro * x)
    b -= lr * 2 * np.mean(erro)

print(round(w, 2), round(b, 2))
```

Antes de correr: os dados foram gerados com y = 3x + 5 mais ruído. Que valores esperas para `w` e `b` no fim da descida do gradiente?

## Encontra o erro: uma exatidão boa demais

```python run
import numpy as np
rng = np.random.default_rng(1)

X = rng.normal(size=(1000, 5))
y = (X[:, 0] + rng.normal(scale=2, size=1000) > 0).astype(int)

# normalizar antes de separar treino e teste
X = (X - X.mean(axis=0)) / X.std(axis=0)

idx = rng.permutation(1000)
treino, teste = idx[:800], idx[800:]

def prever(Xtr, ytr, Xte):
    # 1 vizinho mais próximo
    d = ((Xte[:, None, :] - Xtr[None, :, :]) ** 2).sum(axis=2)
    return ytr[d.argmin(axis=1)]

print("teste:", (prever(X[treino], y[treino], X[teste]) == y[teste]).mean())
print("treino:", (prever(X[treino], y[treino], X[treino]) == y[treino]).mean())
```

Há aqui dois problemas de método, sem nenhuma mensagem de erro. Um é a exatidão no treino, que dá 1,0. O outro está numa linha com comentário. Encontra os dois.
