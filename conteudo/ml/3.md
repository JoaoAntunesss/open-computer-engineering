Uma **árvore de decisão** faz perguntas sim/não sobre as características ("faltas anteriores > 1?", "antecedência > 14 dias?") até chegar a uma previsão. É fácil de explicar a qualquer pessoa, lida bem com dados mistos e não precisa de normalização. Sozinha sobreajusta com facilidade; **muitas árvores juntas** (florestas aleatórias, gradient boosting) estão entre os modelos mais fortes para dados em tabela, frequentemente melhores do que as redes neuronais.

## Como se constrói uma árvore

De forma gananciosa, de cima para baixo:

1. Para cada característica e cada possível ponto de corte, mede quão "puros" ficam os dois grupos.
2. Escolhe a pergunta que mais aumenta a pureza.
3. Repete em cada grupo, até um critério de paragem (profundidade máxima, poucos exemplos, grupo puro).

Medidas de impureza: **Gini** (1 − Σ pᵢ²) ou **entropia** (−Σ pᵢ log pᵢ). Um grupo só com faltas tem Gini 0; meio-meio, 0,5.

```python run
import numpy as np
rng = np.random.default_rng(3)

n = 400
antecedencia = rng.integers(0, 30, n)
faltas_ant = rng.poisson(0.6, n)
sabado = rng.random(n) < 0.3
p = 0.05 + 0.4 * (faltas_ant >= 2) + 0.25 * (antecedencia > 20) + 0.1 * sabado
faltou = rng.random(n) < p
X = np.column_stack([antecedencia, faltas_ant, sabado])
nomes = ["antecedência", "faltas anteriores", "sábado"]

def gini(y):
    if len(y) == 0: return 0
    q = y.mean()
    return 1 - q ** 2 - (1 - q) ** 2

def melhor_corte(X, y):
    melhor = (None, None, gini(y))
    for j in range(X.shape[1]):
        for c in np.unique(X[:, j])[:-1]:
            esq = X[:, j] <= c
            g = (esq.sum() * gini(y[esq]) + (~esq).sum() * gini(y[~esq])) / len(y)
            if g < melhor[2]:
                melhor = (j, c, g)
    return melhor

def arvore(X, y, prof=0, maxprof=2, recuo=""):
    j, c, g = melhor_corte(X, y)
    if prof == maxprof or j is None or len(y) < 20:
        print(f"{recuo}→ P(falta) = {y.mean():.0%}  ({len(y)} marcações)")
        return
    print(f"{recuo}{nomes[j]} <= {c}?  (Gini {gini(y):.3f} → {g:.3f})")
    esq = X[:, j] <= c
    arvore(X[esq], y[esq], prof + 1, maxprof, recuo + "   sim: ")
    arvore(X[~esq], y[~esq], prof + 1, maxprof, recuo + "   não: ")

arvore(X, faltou)
```

Prevê a primeira pergunta da árvore. No "mundo" simulado, o fator mais forte são as faltas anteriores.

## O problema: sobreajustamento

Sem limites, a árvore cresce até cada folha ter um exemplo: acerta 100% no treino e generaliza mal (decorou o ruído). Controla-se com profundidade máxima, mínimo de exemplos por folha, ou podando depois.

## Florestas aleatórias

Treinam-se **centenas de árvores**, cada uma:

- com uma amostra **com reposição** dos dados (*bootstrap*);
- escolhendo, em cada nó, entre um **subconjunto aleatório** de características.

A previsão é a votação (classificação) ou a média (regressão). Cada árvore sobreajusta à sua maneira, e os erros, em média, cancelam-se. Resultado: muito mais estável e preciso, com pouca afinação. Bónus: a **importância de cada característica**.

## Gradient boosting

Árvores pequenas treinadas **em sequência**: cada nova árvore corrige os erros das anteriores. **XGBoost**, **LightGBM** e **CatBoost** ganham a maioria das competições com dados tabulares. Precisam de mais afinação do que as florestas (taxa de aprendizagem, número de árvores, profundidade) e de validação cuidada.
