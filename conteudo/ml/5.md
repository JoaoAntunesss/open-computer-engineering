Todos os modelos erram por duas razões diferentes. **Enviesamento** (*bias*): o modelo é simples demais para a realidade (uma reta para uma curva) e erra sistematicamente. **Variância**: o modelo é tão flexível que se adapta ao ruído dos dados de treino, e muda muito com outra amostra. Reduzir um costuma aumentar o outro. A **regularização** é a ferramenta para controlar este equilíbrio.

## Subajustamento e sobreajustamento

| | treino | validação | diagnóstico | o que fazer |
|---|---|---|---|---|
| **subajustamento** | erro alto | erro alto | enviesamento | modelo mais flexível, mais características |
| **sobreajustamento** | erro baixo | erro alto | variância | mais dados, regularização, modelo mais simples |
| **bom** | erro baixo | erro um pouco mais alto | | |

## Ver o compromisso

Ajustam-se polinómios de graus crescentes a 20 pontos com ruído, e mede-se o erro em dados novos:

```python run
import numpy as np
rng = np.random.default_rng(0)

verdade = lambda x: np.sin(2 * x)
x_tr = np.sort(rng.uniform(0, 3, 20)); y_tr = verdade(x_tr) + rng.normal(0, 0.25, 20)
x_va = np.sort(rng.uniform(0, 3, 200)); y_va = verdade(x_va) + rng.normal(0, 0.25, 200)

def caracteristicas(x, grau):
    return np.vander(x / 3, grau + 1, increasing=True)        # 1, x, x², …

def ajusta(x, y, grau, lam=0.0):
    A = caracteristicas(x, grau)
    I = np.eye(grau + 1); I[0, 0] = 0                         # não penalizar o termo constante
    return np.linalg.solve(A.T @ A + lam * I, A.T @ y)        # ridge: (AᵀA + λI) w = Aᵀy

erro = lambda w, x, y, g: np.mean((caracteristicas(x, g) @ w - y) ** 2)

print("sem regularização:")
for grau in (1, 3, 5, 9, 15):
    w = ajusta(x_tr, y_tr, grau)
    print(f"  grau {grau:2}: erro treino {erro(w, x_tr, y_tr, grau):.3f}  validação {erro(w, x_va, y_va, grau):8.3f}")

print("grau 15 com ridge:")
for lam in (1e-6, 1e-4, 1e-2, 1, 100):
    w = ajusta(x_tr, y_tr, 15, lam)
    print(f"  λ = {lam:6}: erro treino {erro(w, x_tr, y_tr, 15):.3f}  validação {erro(w, x_va, y_va, 15):.3f}"
          f"  |w| = {np.abs(w).max():.1f}")
```

Prevê a forma das curvas: o erro de treino desce sempre com o grau? E o de validação? Com o grau 15 fixo, que λ é melhor?

## Regularização

Acrescenta à função de erro uma penalização pela "complexidade" do modelo:

- **L2 (ridge, *weight decay*):** λ · Σ wⱼ². Encolhe todos os pesos.
- **L1 (lasso):** λ · Σ |wⱼ|. Põe muitos pesos **exatamente a zero**: seleciona características.
- **Elastic net:** as duas.

λ é um hiperparâmetro: escolhe-se com a validação (ou validação cruzada). λ = 0 é o modelo sem restrições; λ enorme reduz o modelo a uma constante.

Outras formas de regularizar:

- **Mais dados:** a melhor de todas, quando é possível.
- **Paragem antecipada** (*early stopping*): parar o treino quando o erro de validação começa a subir.
- **Dropout** (redes neuronais): desligar neurónios ao acaso durante o treino.
- **Aumento de dados:** rodar, cortar e mudar o brilho das imagens; parafrasear frases.
- Árvores: limitar a profundidade, o número mínimo de exemplos por folha.

## Curvas de aprendizagem

Desenha o erro de treino e de validação em função do **número de exemplos**:

- Se as duas curvas convergem para um erro alto: enviesamento. Mais dados não ajudam; é preciso um modelo melhor.
- Se há um fosso grande entre elas que diminui com mais dados: variância. Mais dados ajudam.
