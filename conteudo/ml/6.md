Na aprendizagem **não supervisionada** não há alvo: procura-se estrutura nos dados. As duas tarefas mais comuns são **agrupar** (que clientes se parecem uns com os outros?) e **reduzir a dimensão** (como resumir 50 características em 2 ou 3, para visualizar ou para acelerar outros modelos?). Os algoritmos clássicos são o **k-means** e a **PCA**.

## k-means

Divide os dados em k grupos, cada um representado pelo seu **centro** (a média dos pontos).

1. Escolhe k centros iniciais (ao acaso, ou com a heurística k-means++, que os espalha).
2. **Atribui** cada ponto ao centro mais próximo.
3. **Atualiza** cada centro para a média dos pontos que lhe calharam.
4. Repete 2 e 3 até nada mudar.

Converge sempre (a soma das distâncias ao quadrado nunca aumenta), mas para um mínimo **local**: corre-se várias vezes com inícios diferentes e fica-se com o melhor.

```python run
import numpy as np
rng = np.random.default_rng(5)

# clientes de um salão: (visitas por ano, gasto médio por visita em €)
grupos_reais = [((4, 20), 60), ((12, 25), 40), ((5, 90), 30)]
X = np.vstack([rng.normal(c, (1.5, 8), (n, 2)) for c, n in grupos_reais])
Xn = (X - X.mean(0)) / X.std(0)                  # normalizar: as escalas são diferentes

def kmeans(X, k, iteracoes=50, semente=0):
    r = np.random.default_rng(semente)
    centros = X[r.choice(len(X), k, replace=False)]
    for _ in range(iteracoes):
        d = ((X[:, None] - centros[None]) ** 2).sum(-1)
        grupo = d.argmin(1)
        novos = np.array([X[grupo == j].mean(0) if np.any(grupo == j) else centros[j] for j in range(k)])
        if np.allclose(novos, centros):
            break
        centros = novos
    inercia = ((X - centros[grupo]) ** 2).sum()
    return grupo, centros, inercia

for k in range(1, 7):
    _, _, inercia = min((kmeans(Xn, k, semente=s) for s in range(5)), key=lambda r: r[2])
    print(f"k = {k}: inércia {inercia:7.1f}")

grupo, centros, _ = min((kmeans(Xn, 3, semente=s) for s in range(5)), key=lambda r: r[2])
for j in range(3):
    membros = X[grupo == j]
    print(f"grupo {j}: {len(membros):3} clientes, {membros[:, 0].mean():4.1f} visitas/ano, {membros[:, 1].mean():5.1f} € por visita")
```

Prevê a partir de que k a inércia (soma das distâncias ao quadrado) deixa de baixar muito: é o "cotovelo", uma pista para escolher k. Depois lê os três grupos: os clientes ocasionais, os habituais e os que vêm pouco mas gastam muito (colorações).

Limitações: supõe grupos redondos e de tamanhos parecidos; sensível a escalas e a valores extremos. Alternativas: **DBSCAN** (grupos de qualquer forma, por densidade, e deteta ruído), **agrupamento hierárquico** (uma árvore de agrupamentos), **misturas gaussianas** (grupos elípticos, com probabilidades).

## PCA: análise em componentes principais

Encontra as direções em que os dados **variam mais**. A primeira componente é a direção de maior variância; a segunda, a de maior variância perpendicular à primeira; e assim por diante. Projetar nas primeiras componentes resume os dados perdendo o mínimo de informação.

Matematicamente, as componentes são os vetores próprios da matriz de covariância (ou os vetores singulares da SVD, que viste em Álgebra Linear).

```python run
import numpy as np
rng = np.random.default_rng(2)

# 5 medidas de 200 pessoas, quase todas explicadas por um fator ("tamanho") e um segundo ("forma")
tamanho = rng.normal(0, 1, 200)
forma = rng.normal(0, 1, 200)
X = np.column_stack([
    tamanho + 0.1 * rng.normal(size=200),
    tamanho * 0.9 + 0.3 * forma + 0.1 * rng.normal(size=200),
    tamanho * 0.8 - 0.4 * forma + 0.1 * rng.normal(size=200),
    forma + 0.1 * rng.normal(size=200),
    0.2 * rng.normal(size=200),                  # quase só ruído
])
Xc = (X - X.mean(0)) / X.std(0)
U, S, Vt = np.linalg.svd(Xc, full_matrices=False)
variancia = S ** 2 / np.sum(S ** 2)
print("variância explicada por componente:", np.round(variancia, 3))
print("acumulada:", np.round(np.cumsum(variancia), 3))
Z = Xc @ Vt[:2].T                                # os dados em 2 dimensões
print("forma dos dados reduzidos:", Z.shape)
```

Prevê quantas componentes explicam quase tudo, e em que posição aparece a coluna que é só ruído.

Usos: visualizar dados de muitas dimensões, comprimir, remover ruído, acelerar outros modelos. Para visualização com estruturas não lineares, usam-se também **t-SNE** e **UMAP**.

Os grupos: cerca de 60 clientes com ~4 visitas e ~20 € por visita; 40 com ~12 visitas e ~25 €; 30 com ~5 visitas e ~90 €. 3: k = 3. A inércia baixa sempre porque, com mais centros, cada ponto fica mais perto do seu centro (no limite, com k = n, a inércia é 0). Por isso não se escolhe k pela inércia mínima, mas pelo cotovelo, ou por uma métrica como a silhueta, e pelo que faz sentido para o negócio.
