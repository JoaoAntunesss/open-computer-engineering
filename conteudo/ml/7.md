Uma **rede neuronal** é uma composição de muitas funções simples: cada "neurónio" faz uma soma pesada das entradas e aplica uma função não linear. Empilhando camadas, a rede consegue aproximar praticamente qualquer função. Treina-se com descida do gradiente, e os gradientes calculam-se com a **retropropagação** (*backpropagation*): a regra da cadeia aplicada de trás para a frente.

## Um neurónio e uma camada

Um neurónio: z = w·x + b, saída a = g(z), com g uma **função de ativação**:

- **ReLU:** max(0, z). A mais usada nas camadas escondidas: simples e não satura para valores positivos.
- **Sigmoide:** 1/(1 + e⁻ᶻ), entre 0 e 1; na saída, para probabilidades binárias.
- **Softmax:** na saída, para várias classes (probabilidades que somam 1).

Uma **camada** são muitos neurónios em paralelo: a = g(W x + b), com W uma matriz. Uma rede é uma sequência de camadas.

Sem a função não linear, empilhar camadas não serviria de nada: a composição de funções lineares é linear.

## Retropropagação

Para treinar, é preciso ∂Erro/∂w para **todos** os pesos. A regra da cadeia diz como: o gradiente de uma camada obtém-se a partir do gradiente da camada seguinte. Faz-se uma passagem para a frente (calcular as saídas, guardando os valores intermédios) e uma para trás (propagar os gradientes). O custo é o de umas poucas passagens para a frente, seja qual for o número de pesos.

## Uma rede que aprende o XOR

O XOR não é separável por uma reta (uma regressão logística não o aprende), mas uma rede com uma camada escondida aprende:

```python run
import numpy as np
rng = np.random.default_rng(1)

X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)
y = np.array([[0], [1], [1], [0]], dtype=float)

# 2 entradas → 4 neurónios escondidos (tanh) → 1 saída (sigmoide)
W1, b1 = rng.normal(0, 1, (2, 4)), np.zeros(4)
W2, b2 = rng.normal(0, 1, (4, 1)), np.zeros(1)
sig = lambda z: 1 / (1 + np.exp(-z))
taxa = 0.5

for epoca in range(5001):
    # para a frente
    z1 = X @ W1 + b1;  a1 = np.tanh(z1)
    z2 = a1 @ W2 + b2; a2 = sig(z2)
    perda = -np.mean(y * np.log(a2) + (1 - y) * np.log(1 - a2))
    # para trás (regra da cadeia)
    dz2 = (a2 - y) / len(X)                 # derivada da entropia cruzada com sigmoide
    dW2 = a1.T @ dz2;  db2 = dz2.sum(0)
    da1 = dz2 @ W2.T
    dz1 = da1 * (1 - a1 ** 2)               # derivada da tanh
    dW1 = X.T @ dz1;   db1 = dz1.sum(0)
    # descida do gradiente
    W1 -= taxa * dW1; b1 -= taxa * db1; W2 -= taxa * dW2; b2 -= taxa * db2
    if epoca % 1000 == 0:
        print(f"época {epoca:4}: perda {perda:.4f}")

print("previsões:", np.round(a2.ravel(), 3), "→", (a2.ravel() > 0.5).astype(int))
```

Prevê como evolui a perda e se a rede acaba por acertar nos quatro casos.

## Verificar os gradientes

Um erro na retropropagação escrita à mão não dá erro nenhum: a rede só aprende pior. Verifica-se comparando com a derivada numérica (diferença central, Métodos Numéricos, lição 5). Na prática, as bibliotecas calculam os gradientes automaticamente (**diferenciação automática**).

## Na prática: PyTorch

```python
import torch
from torch import nn

modelo = nn.Sequential(nn.Linear(2, 16), nn.ReLU(), nn.Linear(16, 1))
otim = torch.optim.Adam(modelo.parameters(), lr=0.01)
perda_fn = nn.BCEWithLogitsLoss()

for epoca in range(1000):
    otim.zero_grad()
    perda = perda_fn(modelo(X), y)
    perda.backward()          # retropropagação automática
    otim.step()               # um passo do otimizador
```

## Ingredientes de um bom treino

- **Inicialização** dos pesos com a escala certa (Xavier, He); tudo a zero não funciona (todos os neurónios aprendiam o mesmo).
- **Otimizadores:** SGD com momento, **Adam** (o mais usado por omissão).
- **Mini-lotes:** calcular o gradiente com 32–512 exemplos de cada vez, não com todos.
- **Normalização** das entradas e de camadas (*batch norm*, *layer norm*).
- **Regularização:** *dropout*, *weight decay*, paragem antecipada (lição 5).
