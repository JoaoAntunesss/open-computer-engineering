Duas ideias geométricas para classificar. Os **k vizinhos mais próximos** (k-NN) não aprendem nada no treino: guardam os exemplos e, para um ponto novo, olham para os k mais parecidos. As **máquinas de vetores de suporte** (SVM) procuram a fronteira que separa as classes com a **maior margem** possível, e com o **truque do kernel** conseguem fronteiras curvas.

## k vizinhos mais próximos

1. Calcula a distância do ponto novo a todos os exemplos de treino.
2. Fica com os k mais próximos.
3. Classe = a mais votada entre eles (ou, em regressão, a média).

- **k pequeno:** fronteira irregular, sensível ao ruído (sobreajusta). **k grande:** fronteira suave demais.
- **Normalizar é obrigatório:** sem isso, uma característica em euros (0–100 000) domina outra em anos (0–80).
- Treino instantâneo, previsão lenta (compara com todos); estruturas como árvores k-d ou índices aproximados aceleram.
- **Maldição da dimensionalidade:** em muitas dimensões, todos os pontos ficam quase à mesma distância, e "vizinho" perde o sentido.

```python run
import numpy as np
rng = np.random.default_rng(7)

# duas classes em forma de anéis: dentro (0) e à volta (1) — não separáveis por uma reta
def aneis(n):
    r = np.r_[rng.uniform(0, 1, n // 2), rng.uniform(1.2, 2.2, n // 2)]
    a = rng.uniform(0, 2 * np.pi, n)
    X = np.c_[r * np.cos(a), r * np.sin(a)] + rng.normal(0, 0.3, (n, 2))
    return X, np.r_[np.zeros(n // 2), np.ones(n // 2)]

Xtr, ytr = aneis(300)
Xte, yte = aneis(200)

def knn(Xtr, ytr, X, k):
    d = ((X[:, None, :] - Xtr[None, :, :]) ** 2).sum(-1)       # distâncias ao quadrado
    vizinhos = np.argsort(d, axis=1)[:, :k]
    return (ytr[vizinhos].mean(1) >= 0.5).astype(float)

for k in (1, 5, 25, 151):
    print(f"k = {k:3}: exatidão treino {np.mean(knn(Xtr, ytr, Xtr, k) == ytr):.0%}, "
          f"teste {np.mean(knn(Xtr, ytr, Xte, k) == yte):.0%}")

# uma fronteira linear (regressão logística simples) não consegue separar anéis
w = np.linalg.lstsq(np.c_[np.ones(300), Xtr], ytr * 2 - 1, rcond=None)[0]
print("fronteira linear, teste:", f"{np.mean(((np.c_[np.ones(200), Xte] @ w) > 0) == yte):.0%}")
# mas acrescentando a característica r² = x² + y², fica separável por um corte
print("com x² + y² como característica:", f"{np.mean(((Xte ** 2).sum(1) > 1.2) == yte):.0%}")
```

## SVM: a margem máxima

Entre todas as retas (hiperplanos) que separam duas classes, a SVM escolhe a que fica **mais longe** dos pontos mais próximos de cada lado. Esses pontos, os **vetores de suporte**, são os únicos que definem a fronteira. Margem larga = mais robustez a dados novos.

Com dados que não se separam perfeitamente, a **margem suave** aceita alguns erros, com um parâmetro C: C grande penaliza muito os erros (margem estreita, risco de sobreajustar); C pequeno aceita mais erros (margem larga).

## O truque do kernel

A última linha da simulação mostra a ideia: os anéis não se separam com uma reta em (x, y), mas separam-se com um corte em x² + y². Passar os dados para um espaço com mais dimensões torna-os separáveis.

A SVM só precisa de **produtos internos** entre pontos. Um **kernel** calcula o produto interno nesse espaço maior sem nunca construir as coordenadas:

- **Polinomial:** (x·z + 1)ᵈ
- **RBF (gaussiano):** exp(−γ‖x − z‖²), o mais usado; equivale a um espaço de dimensão infinita.

Com o kernel RBF, a SVM aprende fronteiras curvas arbitrárias. O parâmetro γ controla a "largura" de influência de cada ponto (γ grande: fronteira muito irregular).

```python
from sklearn.svm import SVC
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

svm = make_pipeline(StandardScaler(), SVC(kernel="rbf", C=1.0, gamma="scale")).fit(X_treino, y_treino)
```

As SVM foram o estado da arte nos anos 2000 (reconhecimento de dígitos, classificação de texto). Hoje, para dados tabulares usam-se mais as árvores (lição 3), e para imagens e texto as redes neuronais, mas continuam boas com poucos dados e muitas características.
