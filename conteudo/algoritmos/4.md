Um **fluxo numa rede** modela qualquer coisa que passa por canais com capacidade limitada: água em canos, dados numa rede, carros em estradas, produtos numa cadeia de distribuição. O problema do **fluxo máximo** pergunta quanto se consegue enviar da origem ao destino. Surpreendentemente, o mesmo algoritmo resolve **emparelhamentos**: atribuir alunos a projetos, trabalhadores a turnos, pedidos a servidores.

## O problema

Um grafo orientado com uma **origem** s, um **destino** t e uma **capacidade** em cada aresta. Um fluxo atribui a cada aresta um valor que:

1. não ultrapassa a capacidade;
2. se conserva: em cada vértice (exceto s e t), entra tanto como sai.

Quer-se maximizar o que sai de s.

## Ford-Fulkerson

Ideia: enquanto houver um **caminho de aumento** de s a t com capacidade livre, envia fluxo por ele.

O truque está no **grafo residual**: para cada aresta u → v com capacidade c e fluxo f, há

- uma aresta u → v com capacidade residual c − f (o que ainda se pode enviar);
- uma aresta **inversa** v → u com capacidade f (para poder "desfazer" fluxo enviado antes).

Sem as arestas inversas, uma má escolha inicial bloqueava a solução ótima. Com elas, o algoritmo corrige-se a si próprio.

Se os caminhos forem encontrados por BFS (o mais curto em número de arestas), chama-se **Edmonds-Karp** e corre em O(V·E²).

```python run
from collections import deque

def fluxo_maximo(capacidade, s, t):
    # capacidade: dict de dicts, cap[u][v]
    res = {u: dict(vs) for u, vs in capacidade.items()}
    for u in list(res):
        for v in list(res[u]):
            res.setdefault(v, {}).setdefault(u, 0)       # arestas inversas
    total = 0
    while True:
        pai = {s: None}
        fila = deque([s])
        while fila and t not in pai:                     # BFS no residual
            u = fila.popleft()
            for v, c in res[u].items():
                if c > 0 and v not in pai:
                    pai[v] = u
                    fila.append(v)
        if t not in pai:
            return total
        gargalo, v = float("inf"), t                     # menor capacidade no caminho
        while pai[v] is not None:
            gargalo = min(gargalo, res[pai[v]][v]); v = pai[v]
        v = t
        while pai[v] is not None:                        # atualizar o residual
            u = pai[v]
            res[u][v] -= gargalo
            res[v][u] += gargalo
            v = u
        total += gargalo

rede = {
    "s": {"a": 10, "b": 5},
    "a": {"b": 15, "t": 5},
    "b": {"t": 10},
}
print("fluxo máximo:", fluxo_maximo(rede, "s", "t"))
```

Prevê o resultado: quanto pode sair de s, e quanto pode chegar a t?

## Fluxo máximo = corte mínimo

Um **corte** divide os vértices em dois grupos, um com s e outro com t. A sua capacidade é a soma das arestas que vão do lado de s para o lado de t. O **teorema do fluxo máximo e corte mínimo** diz que o fluxo máximo é igual à capacidade do corte mínimo: o "gargalo" da rede.

No exemplo, o corte {s, a, b} | {t} tem capacidade 5 + 10 = 15. É útil para encontrar os pontos fracos de uma rede: que ligações cortar para desligar duas partes, ou quais reforçar.

## Emparelhamento bipartido

Alunos de um lado, projetos do outro, e uma aresta quando o aluno aceita o projeto. Quantos alunos se conseguem colocar, cada um num projeto diferente?

Transforma-se num fluxo: s liga a cada aluno (capacidade 1), cada aluno liga aos projetos que aceita (capacidade 1), cada projeto liga a t (capacidade 1). O fluxo máximo é o número máximo de pares, e as arestas aluno → projeto com fluxo 1 dizem quem fica com o quê.
