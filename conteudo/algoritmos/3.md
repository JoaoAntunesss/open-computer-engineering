**Programação dinâmica** (PD) resolve problemas que se partem em subproblemas que **se repetem**. Em vez de os resolver vezes sem conta, guarda cada resposta numa tabela e reutiliza-a. Transforma algoritmos exponenciais em polinomiais. É usada em corretores ortográficos, no `diff` do Git, no alinhamento de ADN, no encaminhamento de redes e em muitas entrevistas técnicas.

## O exemplo de sempre: Fibonacci

```python run
import time
from functools import lru_cache

chamadas = 0
def fib_ingenuo(n):
    global chamadas
    chamadas += 1
    return n if n < 2 else fib_ingenuo(n - 1) + fib_ingenuo(n - 2)

@lru_cache(maxsize=None)            # memoização: guarda as respostas
def fib_memo(n):
    return n if n < 2 else fib_memo(n - 1) + fib_memo(n - 2)

def fib_tabela(n):                  # de baixo para cima
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

t = time.perf_counter(); r = fib_ingenuo(25); t = time.perf_counter() - t
print("ingénuo:", r, "chamadas:", chamadas, f"{t * 1000:.0f} ms")
print("memo:", fib_memo(25), "  tabela:", fib_tabela(25), "  fib(90):", fib_tabela(90))
```

A versão ingénua calcula fib(23) duas vezes, fib(22) três vezes, e assim por diante: O(φⁿ). Com memória, cada valor calcula-se uma vez: O(n).

## Duas formas

- **De cima para baixo (memoização):** escreve a recursão natural e guarda os resultados (`lru_cache` ou um dicionário). Só calcula os subproblemas necessários.
- **De baixo para cima (tabulação):** preenche a tabela por ordem, dos casos pequenos para os grandes. Sem recursão, e muitas vezes só é preciso guardar a última linha.

## Como desenhar uma solução

1. **Define o subproblema** numa frase: "dp[i] = o melhor que se consegue com os primeiros i elementos".
2. **Escreve a recorrência:** como dp[i] se calcula a partir de subproblemas menores.
3. **Casos base.**
4. **Ordem de cálculo** (para a tabela).
5. **Onde está a resposta** (dp[n], ou o máximo da tabela).

## Mochila 0/1

n objetos com peso e valor; capacidade C; cada objeto vai inteiro ou não vai. dp[i][c] = melhor valor usando os primeiros i objetos com capacidade c:

- não levar o objeto i: dp[i−1][c]
- levar (se couber): dp[i−1][c − pᵢ] + vᵢ

dp[i][c] = máximo das duas. Custo O(n·C).

## Distância de edição

Quantas inserções, remoções e substituições transformam uma palavra noutra? É o que os corretores usam para sugerir "casa" quando escreves "csaa". dp[i][j] = distância entre os primeiros i caracteres de a e os primeiros j de b.

```python run
def edicao(a, b):
    dp = [[0] * (len(b) + 1) for _ in range(len(a) + 1)]
    for i in range(len(a) + 1): dp[i][0] = i          # apagar tudo
    for j in range(len(b) + 1): dp[0][j] = j          # inserir tudo
    for i in range(1, len(a) + 1):
        for j in range(1, len(b) + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = 1 + min(dp[i - 1][j],      # remover
                                   dp[i][j - 1],      # inserir
                                   dp[i - 1][j - 1])  # substituir
    return dp[len(a)][len(b)]

def mochila(objetos, capacidade):
    dp = [0] * (capacidade + 1)
    for peso, valor in objetos:
        for c in range(capacidade, peso - 1, -1):      # de trás para a frente!
            dp[c] = max(dp[c], dp[c - peso] + valor)
    return dp[capacidade]

for a, b in (("gato", "pato"), ("casa", "csaa"), ("kitten", "sitting"), ("", "abc")):
    print(a, b, edicao(a, b))
print("mochila:", mochila([(1, 1), (3, 4), (4, 5), (5, 7)], 7))
```

Prevê as distâncias e o valor da mochila. Na mochila, porque é que o ciclo interior vai de trás para a frente?

## Outros problemas clássicos

- **Maior subsequência comum** (LCS): base do `diff`.
- **Maior subsequência crescente:** O(n²) por PD, O(n log n) com pesquisa binária.
- **Trocos com o mínimo de moedas**, para qualquer sistema de moedas.
- **Caminhos numa grelha**, multiplicação ótima de matrizes, Floyd-Warshall (lição 5).

## PD ou ganancioso?

Os dois exigem subestrutura ótima. O ganancioso faz **uma** escolha e confia nela; a PD **experimenta todas** as escolhas e guarda os melhores resultados. Se o ganancioso não tem prova, a PD é a aposta segura (mais lenta, mas correta).

Alguns testes usam entradas grandes: uma solução correta mas lenta demais excede o tempo limite (6 segundos). Escreve a solução no editor e carrega em **Testar**: o teu código é corrido contra vários casos e vês logo quais passam. Tenta primeiro sem ajuda; a dica e a solução estão lá para quando precisares.

```exercicio
id: alg3-escada
titulo: Subir uma escada
enunciado: Podes subir uma escada de 1 em 1 ou de 2 em 2 degraus. Escreve `formas(n)`, que devolve de quantas maneiras diferentes se sobe uma escada de n degraus (`formas(3)` é 3: 1+1+1, 1+2, 2+1). Com n = 90 a recursão simples nunca acaba: usa programação dinâmica.
dica: `formas(n) = formas(n - 1) + formas(n - 2)`, com `formas(0) = 1` e `formas(1) = 1`. Calcula de baixo para cima guardando só os dois últimos valores, ou usa `@lru_cache`.
inicio:
def formas(n):
    if n <= 1:
        return 1
    return formas(n - 1) + formas(n - 2)
testes:
formas(1) == 1
formas(2) == 2
formas(3) == 3
formas(5) == 8
formas(10) == 89
formas(90) == 4660046610375530309
solucao:
def formas(n):
    a, b = 1, 1
    for _ in range(n - 1):
        a, b = b, a + b
    return b if n >= 1 else 1
```

```exercicio
id: alg3-mochila
titulo: Mochila 0/1
enunciado: Escreve `mochila(pesos, valores, capacidade)`, que devolve o maior valor total que cabe na mochila, levando cada objeto inteiro ou não o levando. Usa programação dinâmica: com 60 objetos há 2⁶⁰ combinações, impossível de testar todas.
dica: Uma lista `melhor` de tamanho capacidade + 1, a zeros. Para cada objeto, percorre as capacidades de cima para baixo: `melhor[c] = max(melhor[c], melhor[c - peso] + valor)`.
inicio:
def mochila(pesos, valores, capacidade):
    return 0
testes:
mochila([1, 3, 4], [15, 20, 30], 4) == 35
mochila([5], [10], 4) == 0
mochila([], [], 10) == 0
mochila([2, 2, 2], [3, 3, 3], 6) == 9
mochila([1, 2, 3], [6, 10, 12], 5) == 22
mochila(list(range(1, 61)), [x * x % 97 + 1 for x in range(1, 61)], 500) == 1624
solucao:
def mochila(pesos, valores, capacidade):
    melhor = [0] * (capacidade + 1)
    for p, v in zip(pesos, valores):
        for c in range(capacidade, p - 1, -1):
            melhor[c] = max(melhor[c], melhor[c - p] + v)
    return melhor[capacidade]
```
