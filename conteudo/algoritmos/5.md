O Dijkstra encontra caminhos mais curtos depressa, mas falha com **pesos negativos**. O **Bellman-Ford** aceita pesos negativos e deteta **ciclos negativos**. O **Floyd-Warshall** calcula de uma vez as distâncias entre **todos** os pares de vértices. Pesos negativos aparecem em problemas reais: custos que podem ser ganhos, taxas de câmbio, restrições de tempo.

## Bellman-Ford

Ideia: um caminho mais curto sem ciclos tem no máximo V − 1 arestas. Relaxa **todas** as arestas V − 1 vezes; depois da volta k, ficam certas todas as distâncias de caminhos com até k arestas.

```python
def bellman_ford(vertices, arestas, origem):
    dist = {v: float("inf") for v in vertices}
    dist[origem] = 0
    for _ in range(len(vertices) - 1):
        for u, v, w in arestas:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
    for u, v, w in arestas:                 # mais uma volta
        if dist[u] + w < dist[v]:
            return None                     # ainda melhora: há ciclo negativo
    return dist
```

Custo: O(V·E). Mais lento do que o Dijkstra, mas mais geral.

**Ciclo negativo:** se um ciclo tem soma negativa, dá para dar voltas infinitas e baixar a distância sem limite: "o caminho mais curto" deixa de existir. O Bellman-Ford deteta isto com uma volta extra.

É a base do protocolo de encaminhamento **RIP** (vetor de distâncias): cada router só fala com os vizinhos e vai atualizando as distâncias.

## Arbitragem de câmbio

Se 1 € compra 1,08 $, 1 $ compra 0,79 £ e 1 £ compra 1,19 €, dar a volta transforma 1 € em 1,08 × 0,79 × 1,19 ≈ 1,015 €. Lucro sem risco! Para o detetar com caminhos mais curtos: peso de cada aresta = −log(taxa). Um produto maior do que 1 corresponde a uma soma de logaritmos negativa: um **ciclo negativo**.

## Floyd-Warshall

Distâncias entre todos os pares, com uma ideia de programação dinâmica: dist[i][j] usando apenas os vértices 0..k como intermédios. Ou o caminho passa por k, ou não passa:

dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])

```python run
INF = float("inf")

def floyd_warshall(n, arestas):
    d = [[0 if i == j else INF for j in range(n)] for i in range(n)]
    for u, v, w in arestas:
        d[u][v] = min(d[u][v], w)
    for k in range(n):                       # k tem de ser o ciclo de fora!
        for i in range(n):
            for j in range(n):
                if d[i][k] + d[k][j] < d[i][j]:
                    d[i][j] = d[i][k] + d[k][j]
    return d

arestas = [(0, 1, 4), (0, 2, 1), (2, 1, 2), (1, 3, 1), (2, 3, 5), (3, 0, -2)]
d = floyd_warshall(4, arestas)
for linha in d:
    print(linha)
print("ciclo negativo?", any(d[i][i] < 0 for i in range(4)))

import math
taxas = {("EUR", "USD"): 1.08, ("USD", "GBP"): 0.79, ("GBP", "EUR"): 1.19,
         ("EUR", "GBP"): 0.85, ("USD", "EUR"): 0.92}
moedas = ["EUR", "USD", "GBP"]
idx = {m: i for i, m in enumerate(moedas)}
d2 = floyd_warshall(3, [(idx[a], idx[b], -math.log(t)) for (a, b), t in taxas.items()])
print("arbitragem possível?", any(d2[i][i] < -1e-12 for i in range(3)))
```

## Qual usar

| Situação | Algoritmo | Custo |
|---|---|---|
| sem pesos | BFS | O(V + E) |
| pesos ≥ 0, uma origem | Dijkstra | O((V + E) log V) |
| pesos negativos, uma origem | Bellman-Ford | O(V·E) |
| todos os pares, grafo pequeno | Floyd-Warshall | O(V³) |
| grafo sem ciclos (DAG) | ordem topológica + relaxar | O(V + E) |
