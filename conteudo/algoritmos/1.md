**Dividir para conquistar** resolve um problema partindo-o em subproblemas mais pequenos do mesmo tipo, resolvendo-os recursivamente e juntando as respostas. O merge sort é o exemplo que já conheces. O **teorema mestre** dá a complexidade destes algoritmos sem ser preciso resolver a recorrência à mão.

## O esquema

1. **Dividir** o problema em a subproblemas de tamanho n/b.
2. **Conquistar** cada um recursivamente (casos pequenos resolvem-se diretamente).
3. **Combinar** as respostas, com custo f(n).

O tempo segue a recorrência T(n) = a·T(n/b) + f(n).

## Exemplos

| Algoritmo | Recorrência | Resultado |
|---|---|---|
| Pesquisa binária | T(n) = T(n/2) + O(1) | O(log n) |
| Merge sort | T(n) = 2T(n/2) + O(n) | O(n log n) |
| Karatsuba (multiplicar inteiros) | T(n) = 3T(n/2) + O(n) | O(n^1,585) |
| Strassen (multiplicar matrizes) | T(n) = 7T(n/2) + O(n²) | O(n^2,807) |
| Máximo de um vetor, dividindo ao meio | T(n) = 2T(n/2) + O(1) | O(n) |

## O teorema mestre

Para T(n) = a·T(n/b) + f(n), compara-se f(n) com n^(log_b a), o trabalho feito nas folhas da árvore de recursão:

1. Se f(n) cresce **mais devagar** (f(n) = O(n^(c)) com c < log_b a): domina o trabalho das folhas. **T(n) = Θ(n^(log_b a))**.
2. Se crescem **ao mesmo ritmo** (f(n) = Θ(n^(log_b a))): cada nível custa o mesmo, e há log n níveis. **T(n) = Θ(n^(log_b a) · log n)**.
3. Se f(n) cresce **mais depressa** (e uma condição de regularidade se verifica): domina o trabalho de combinar na raiz. **T(n) = Θ(f(n))**.

**Merge sort:** a = 2, b = 2, n^(log₂ 2) = n, f(n) = n → caso 2 → Θ(n log n).

**Karatsuba:** a = 3, b = 2, n^(log₂ 3) ≈ n^1,585, f(n) = n → caso 1 → Θ(n^1,585).

## A árvore de recursão

Uma forma visual de chegar ao mesmo: desenha a árvore de chamadas, soma o custo de cada nível e soma os níveis. No merge sort, há log₂ n níveis e cada um custa n no total: n log n.

## Exemplo: contar inversões

Uma **inversão** num vetor é um par i < j com v[i] > v[j]. Mede quão desordenado está o vetor (e quão diferentes são duas classificações, como em sistemas de recomendação). Força bruta: O(n²). Com dividir para conquistar, durante o merge sort: quando um elemento da metade direita passa à frente, está invertido com todos os que ainda restam na metade esquerda.

```python run
def conta_inversoes(v):
    if len(v) <= 1:
        return v, 0
    m = len(v) // 2
    a, ia = conta_inversoes(v[:m])
    b, ib = conta_inversoes(v[m:])
    r, i, j, inv = [], 0, 0, ia + ib
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            r.append(a[i]); i += 1
        else:
            r.append(b[j]); j += 1
            inv += len(a) - i          # b[j] é menor do que todos os que restam em a
    return r + a[i:] + b[j:], inv

def forca_bruta(v):
    return sum(1 for i in range(len(v)) for j in range(i + 1, len(v)) if v[i] > v[j])

for v in ([1, 2, 3, 4], [4, 3, 2, 1], [2, 4, 1, 3, 5], [3, 1, 2]):
    print(v, conta_inversoes(v)[1], forca_bruta(v))
```

## Exemplo: o par de pontos mais próximo

Dado um conjunto de pontos no plano, encontrar os dois mais próximos. Força bruta: O(n²). Dividindo pela coordenada x, resolvendo cada metade e verificando só uma faixa estreita junto à linha de divisão (onde basta comparar cada ponto com poucos vizinhos), consegue-se O(n log n).

```exercicio
id: alg1-potencia
titulo: Potência rápida
enunciado: Escreve `potencia_mod(b, e, m)`, que devolve bᵉ mod m, com dividir para conquistar: bᵉ = (b^(e/2))² quando e é par. Com e = 10¹⁸, multiplicar e vezes nunca acabaria. Não podes usar `pow`.
dica: Caso base: e = 0 dá 1 % m. Calcula `metade = potencia_mod(b, e // 2, m)`; o resultado é `metade * metade % m`, multiplicado mais uma vez por b se e for ímpar.
proibido: pow
inicio:
def potencia_mod(b, e, m):
    r = 1
    for _ in range(e):
        r = r * b % m
    return r
testes:
potencia_mod(2, 10, 1000) == 24
potencia_mod(3, 0, 7) == 1
potencia_mod(5, 3, 13) == 8
potencia_mod(7, 1, 100) == 7
potencia_mod(2, 10**18, 10**9 + 7) == 719476260
solucao:
def potencia_mod(b, e, m):
    if e == 0:
        return 1 % m
    metade = potencia_mod(b, e // 2, m)
    r = metade * metade % m
    if e % 2 == 1:
        r = r * b % m
    return r
```
