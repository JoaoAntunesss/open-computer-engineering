Como sabes que o código que escreveste (ou que a IA escreveu) está certo? "Corri e parecia bem" não chega. Um **teste** é um bocado de código que verifica outro bocado de código, sempre da mesma maneira, sempre que quiseres.

## assert

`assert condição` não faz nada se a condição for verdadeira. Se for falsa, o programa para com `AssertionError`.

```python run
def iva(valor, taxa=23):
    return round(valor * taxa / 100, 2)

assert iva(100) == 23
assert iva(10, 6) == 0.6
assert iva(0) == 0
print("Tudo certo")
```

Muda a função para estar errada (por exemplo `taxa / 10`) e corre outra vez: vês exatamente que teste partiu.

## Que casos testar

Para cada função, pensa em três tipos de caso:

1. **Normal**: um exemplo típico (`iva(100)`).
2. **Limite**: o valor exatamente na fronteira (0, 18, o último dia do mês, a lista com 1 elemento).
3. **Estranho**: vazio, negativo, texto onde se esperava número.

```python run
def desconto_idade(idade):
    """Crianças até 12 pagam metade, seniores a partir de 65 pagam 70%, os outros pagam tudo."""
    if idade <= 12:
        return 0.5
    if idade >= 65:
        return 0.7
    return 1.0

# normais
assert desconto_idade(8) == 0.5
assert desconto_idade(40) == 1.0
assert desconto_idade(80) == 0.7
# limites
assert desconto_idade(12) == 0.5
assert desconto_idade(13) == 1.0
assert desconto_idade(64) == 1.0
assert desconto_idade(65) == 0.7
print("8 testes passaram")
```

Repara que os limites (12, 13, 64, 65) são os mais importantes: é aí que um `<` em vez de `<=` aparece.

## Escrever o teste primeiro

Um truque poderoso: escreve os `assert` **antes** da função. Obriga-te a decidir o que a função deve fazer antes de pensares em como. Depois escreves a função até os testes passarem. Chama-se TDD (*test-driven development*) e funciona muito bem com IA: tu escreves os testes, e o código (teu ou gerado) só é aceite quando eles passam.

## Com pytest

Em projetos a sério, os testes ficam num ficheiro à parte e corres todos de uma vez com o `pytest`:

```python
# test_precos.py
from precos import iva, desconto_idade

def test_iva_normal():
    assert iva(100) == 23

def test_crianca_no_limite():
    assert desconto_idade(12) == 0.5
```

No terminal: `pip install pytest` e depois `pytest`. Ele encontra todas as funções que começam por `test_` e diz quais falharam e porquê.
