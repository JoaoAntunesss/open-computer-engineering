Quase todos os programas, do mais pequeno ao maior, têm a mesma forma: **recebem dados**, **fazem alguma coisa com eles** e **devolvem um resultado**. Se separares bem estas três partes, o código fica fácil de ler, de testar e de mudar.

## As três partes

```python run
# 1. Entrada: de onde vêm os dados
linhas = [
    "Ana;Porto;1250",
    "Rui;Lisboa;980",
    "Sofia;Porto;1430",
    "Tiago;Braga;1100",
]

# 2. Processamento: transformar os dados
por_cidade = {}
for linha in linhas:
    nome, cidade, salario = linha.split(";")
    por_cidade.setdefault(cidade, []).append(int(salario))

medias = {c: sum(v) / len(v) for c, v in por_cidade.items()}

# 3. Saída: mostrar o resultado
for cidade in sorted(medias):
    print(f"{cidade}: {medias[cidade]:.0f} €")
```

Num programa real, a entrada viria de um ficheiro, de um formulário ou de uma API, e a saída podia ser um ficheiro, uma página ou uma resposta JSON. O meio é o mesmo.

## Porque separar

Compara com esta versão, que mistura tudo:

```python
for linha in open("salarios.csv"):
    n, c, s = linha.strip().split(";")
    print(c, int(s) * 1.0)   # e a média? e a ordenação?
```

Quando a entrada, as contas e os prints estão misturados, não consegues testar as contas sem o ficheiro, nem mudar o formato da saída sem mexer nas contas. A IA costuma gerar código assim. Um dos teus trabalhos ao rever é separá-lo.

## Ler dados de verdade

No teu computador (não nesta página), ler um ficheiro faz-se assim:

```python
with open("despesas.csv", encoding="utf-8") as f:
    linhas = [l.strip() for l in f if l.strip()]
```

Pedir ao utilizador faz-se com `input()`, que devolve **sempre texto**:

```python
idade = int(input("Idade: "))
```

## Validar à entrada

Os dados de fora estão sempre sujos: linhas vazias, espaços, vírgulas em vez de pontos, campos em falta. Trata isso **logo na entrada**, para o resto do programa poder confiar nos dados:

```python run
brutos = ["Ana;Porto;1250", "", "Rui ; Lisboa ; 980", "linha estragada", "Sofia;Porto;1.430"]

limpas = []
for linha in brutos:
    partes = [p.strip() for p in linha.split(";")]
    if len(partes) != 3:
        print("Ignorada:", repr(linha))
        continue
    nome, cidade, salario = partes
    salario = int(salario.replace(".", ""))
    limpas.append((nome, cidade, salario))

print(limpas)
```
