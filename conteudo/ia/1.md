A Inteligência Artificial clássica organiza-se em torno de uma ideia: o **agente**. Um agente percebe o ambiente através de sensores e age sobre ele através de atuadores, procurando atingir objetivos. Um aspirador robô, um programa de xadrez, um sistema de recomendação e um assistente de conversa são agentes. Esta forma de pensar ajuda a escolher a técnica certa para cada problema.

## Agente, ambiente, desempenho

Para definir um agente, descreve-se o seu **PEAS**:

| | Aspirador robô | Táxi autónomo |
|---|---|---|
| **P**erformance (medida) | área limpa, energia gasta | segurança, tempo, conforto, legalidade |
| **E**nvironment (ambiente) | divisões, sujidade, móveis | estradas, peões, trânsito, tempo |
| **A**ctuators (atuadores) | rodas, escovas, aspiração | volante, acelerador, travão, buzina |
| **S**ensors (sensores) | sensor de sujidade, colisão, posição | câmaras, LIDAR, GPS, velocímetro |

Um agente **racional** escolhe a ação que maximiza o desempenho esperado, dado o que percebeu até agora. Racional não é omnisciente: pode errar por falta de informação.

## Tipos de ambiente

- **Totalmente / parcialmente observável:** o xadrez mostra tudo; o póquer esconde as cartas.
- **Determinista / estocástico:** a mesma ação dá sempre o mesmo resultado?
- **Episódico / sequencial:** cada decisão é independente (classificar uma imagem) ou afeta o futuro (conduzir)?
- **Estático / dinâmico:** o mundo muda enquanto o agente pensa?
- **Discreto / contínuo**, **um agente / vários agentes** (cooperativos ou competitivos).

Quanto mais difícil o ambiente (parcialmente observável, estocástico, sequencial, dinâmico, contínuo, com vários agentes), mais sofisticado tem de ser o agente. O mundo real é o caso mais difícil em todos os eixos.

## Tipos de agentes

1. **Reflexo simples:** regras condição → ação sobre a perceção atual ("se sujo, aspira"). Rápido, mas falha quando a perceção não chega.
2. **Reflexo com modelo:** guarda um estado interno do mundo ("já limpei a sala").
3. **Baseado em objetivos:** pensa no futuro: "que sequência de ações me leva ao objetivo?" (pesquisa e planeamento, próximas lições).
4. **Baseado em utilidade:** compara resultados com uma função de utilidade ("chegar depressa **e** com segurança").
5. **Que aprende:** melhora com a experiência (aprendizagem por reforço, aprendizagem automática).

## Dois aspiradores

Prevê qual limpa mais em 20 passos, num corredor de 6 posições com sujidade ao acaso:

```python run
import random

def simula(agente, passos=20, n=6, semente=1):
    random.seed(semente)
    sujo = [random.random() < 0.6 for _ in range(n)]
    total_sujo = sum(sujo)
    pos, limpo, movimentos, memoria = 0, 0, 0, set()
    for _ in range(passos):
        acao = agente(pos, sujo[pos], memoria, n)
        if acao == "aspirar":
            if sujo[pos]:
                sujo[pos] = False; limpo += 1
        elif acao == "direita" and pos < n - 1:
            pos += 1; movimentos += 1
        elif acao == "esquerda" and pos > 0:
            pos -= 1; movimentos += 1
        memoria.add(pos)
    return f"limpou {limpo}/{total_sujo}, {movimentos} movimentos"

def reflexo_simples(pos, sujo, memoria, n):
    if sujo:
        return "aspirar"
    return random.choice(["esquerda", "direita"])          # sem memória: anda ao acaso

def com_modelo(pos, sujo, memoria, n):
    if sujo:
        return "aspirar"
    if len(memoria) == n:
        return "parar"                                     # já viu tudo: poupa energia
    return "direita"                                       # varre o corredor por ordem

for semente in (1, 2, 3):
    print(f"semente {semente}: reflexo → {simula(reflexo_simples, semente=semente):26} | com modelo → {simula(com_modelo, semente=semente)}")
```

O agente com modelo (que se lembra de onde já esteve) limpa tudo com menos movimentos. O reflexo simples, sem memória, depende da sorte.
