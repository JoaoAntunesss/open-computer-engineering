O mundo é incerto: os sensores têm ruído, as regras têm exceções, a informação está incompleta. O raciocínio probabilístico substitui "verdadeiro ou falso" por **graus de crença**, e atualiza-os com o teorema de Bayes quando chegam dados. As **redes bayesianas** tornam isto possível com muitas variáveis, representando só as dependências que existem.

## O problema da tabela completa

Com n variáveis verdadeiro/falso, a distribuição conjunta tem 2ⁿ entradas. Com 30 variáveis, mil milhões de números. Impossível de guardar e, sobretudo, de estimar a partir de dados.

## Independência condicional

A maioria das variáveis só depende diretamente de poucas outras. "A relva está molhada" depende de "choveu" e de "a rega esteve ligada"; dado isso, já não depende das nuvens.

## Redes bayesianas

Um grafo orientado sem ciclos: cada nó é uma variável, cada seta uma influência direta. Cada nó guarda uma tabela P(nó | pais). A conjunta é o produto:

P(X₁, …, Xₙ) = Π P(Xᵢ | pais(Xᵢ))

**Exemplo** (o alarme de Judea Pearl, adaptado):

```
   Assalto      Sismo
        \       /
         Alarme
        /      \
  Ana liga   Rui liga
```

Com 5 variáveis, a tabela completa teria 31 números independentes; a rede precisa de 10.

## Inferência

"A Ana e o Rui ligaram. Qual é a probabilidade de ter havido um assalto?" Por **enumeração**: soma-se a conjunta sobre as variáveis desconhecidas (sismo, alarme) e normaliza-se.

```python run
from itertools import product

P_assalto, P_sismo = 0.001, 0.002
P_alarme = {(True, True): 0.95, (True, False): 0.94, (False, True): 0.29, (False, False): 0.001}
P_ana = {True: 0.90, False: 0.05}        # P(Ana liga | alarme)
P_rui = {True: 0.70, False: 0.01}

def p(valor, prob):
    return prob if valor else 1 - prob

def conjunta(a, s, al, ana, rui):
    return (p(a, P_assalto) * p(s, P_sismo) * p(al, P_alarme[(a, s)])
            * p(ana, P_ana[al]) * p(rui, P_rui[al]))

def consulta(alvo, evidencia):
    resultados = {}
    for v in (True, False):
        total = 0
        for a, s, al, ana, rui in product((True, False), repeat=5):
            mundo = {"assalto": a, "sismo": s, "alarme": al, "ana": ana, "rui": rui}
            if mundo[alvo] == v and all(mundo[k] == x for k, x in evidencia.items()):
                total += conjunta(a, s, al, ana, rui)
        resultados[v] = total
    return resultados[True] / (resultados[True] + resultados[False])

print("P(assalto) a priori:", P_assalto)
print("P(assalto | Ana liga):", round(consulta("assalto", {"ana": True}), 4))
print("P(assalto | Ana e Rui ligam):", round(consulta("assalto", {"ana": True, "rui": True}), 4))
print("P(assalto | ambos ligam, houve sismo):",
      round(consulta("assalto", {"ana": True, "rui": True, "sismo": True}), 4))
```

Prevê a ordem de grandeza de cada probabilidade antes de correr. A última mostra o efeito de **explicar** (*explaining away*): saber que houve um sismo explica o alarme, e a probabilidade de assalto cai.

A enumeração é exponencial; para redes grandes usa-se **eliminação de variáveis** (programação dinâmica) ou **amostragem** (Monte Carlo).

## Modelos temporais

Para variáveis que mudam com o tempo (a posição de um robô, o estado de uma máquina):

- **Cadeias de Markov ocultas** (HMM): estados escondidos que geram observações. Usadas no reconhecimento de fala clássico e em bioinformática.
- **Filtros de Kalman:** para estados contínuos com ruído gaussiano (GPS, aviões, robótica).
- **Filtros de partículas:** amostragem, para casos não lineares (localização de robôs).
