Na **aprendizagem por reforço** (RL), o agente não conhece as regras do ambiente: aprende por tentativa e erro, recebendo **recompensas**. É o que está por trás do AlphaGo, de robôs que aprendem a andar, de sistemas que otimizam o arrefecimento de centros de dados e do afinamento dos modelos de linguagem com feedback humano (RLHF).

## O ciclo

```
estado s → o agente escolhe a ação a → o ambiente devolve a recompensa r e o novo estado s'
```

Em relação aos MDP da lição anterior, a diferença é que o agente **não sabe** P(s' | s, a) nem R: tem de experimentar.

## Exploração e aproveitamento

O dilema central: **aproveitar** o que já sabe que funciona, ou **explorar** ações novas que talvez sejam melhores? Sem explorar, fica preso numa solução medíocre; explorando demais, nunca usa o que aprendeu.

A estratégia mais simples é **ε-greedy**: com probabilidade ε, uma ação ao acaso; senão, a melhor conhecida. Normalmente ε diminui com o tempo.

## Q-learning

Aprende Q(s, a): o valor de fazer a no estado s e depois agir bem. Depois de cada passo:

Q(s, a) ← Q(s, a) + α · [ r + γ · max_a' Q(s', a') − Q(s, a) ]

- α: taxa de aprendizagem (quanto se corrige de cada vez).
- O termo entre parênteses retos é a **surpresa**: o que se observou menos o que se esperava.

A política é escolher, em cada estado, a ação com maior Q. O Q-learning converge para a política ótima sem nunca conhecer o modelo, desde que explore o suficiente.

## Um agente que aprende a atravessar uma ponte

Um corredor de 6 casas. O agente começa na casa 0; o objetivo (+10) está na casa 5. Na casa 3 há um atalho escorregadio: com 30% de probabilidade cai à água (−10 e volta ao início). Cada passo custa −1.

```python run
import random
random.seed(0)

N, ALVO = 6, 5
acoes = ["andar", "saltar"]       # andar: +1 casa; saltar: +2 casas (arriscado a partir da casa 3)

def passo(s, a):
    if a == "andar":
        s2 = s + 1
    else:
        if s == 3 and random.random() < 0.3:
            return 0, -10, False               # caiu à água
        s2 = min(s + 2, ALVO)
    if s2 == ALVO:
        return s2, 10, True
    return s2, -1, False

Q = {(s, a): 0.0 for s in range(N) for a in acoes}
alfa, gama, eps = 0.1, 0.95, 0.2
recompensas = []
for episodio in range(3000):
    s, total, fim = 0, 0, False
    while not fim:
        if random.random() < eps:
            a = random.choice(acoes)
        else:
            a = max(acoes, key=lambda a: Q[(s, a)])
        s2, r, fim = passo(s, a)
        alvo = r if fim else r + gama * max(Q[(s2, b)] for b in acoes)
        Q[(s, a)] += alfa * (alvo - Q[(s, a)])
        s, total = s2, total + r
    recompensas.append(total)

for s in range(ALVO):
    melhor = max(acoes, key=lambda a: Q[(s, a)])
    print(f"casa {s}: andar {Q[(s, 'andar')]:6.2f}  saltar {Q[(s, 'saltar')]:6.2f}  → {melhor}")
print("recompensa média, primeiros 100 episódios:", sum(recompensas[:100]) / 100)
print("recompensa média, últimos 100 episódios:  ", sum(recompensas[-100:]) / 100)
```

Prevê: na casa 3, o agente aprende a saltar (2 casas, mas 30% de risco) ou a andar? Repara como a recompensa média melhora com a experiência.

## Para lá das tabelas

Uma tabela Q só funciona com poucos estados. Num jogo de vídeo, o estado é a imagem do ecrã: milhões de estados. A **aprendizagem por reforço profunda** usa uma rede neuronal para aproximar Q (DQN, que aprendeu a jogar jogos da Atari a partir dos píxeis) ou para representar diretamente a política (métodos de gradiente de política, como o PPO).

## Riscos

- **Recompensas mal desenhadas** são exploradas: um agente de um jogo de barcos, recompensado por apanhar objetos, aprendeu a andar em círculos a apanhar o mesmo objeto em vez de acabar a corrida. O agente otimiza o que medes, não o que querias.
- Treinar no mundo real é caro e perigoso: treina-se em simulação e transfere-se.
- Muitos episódios: o AlphaZero jogou milhões de partidas contra si próprio.
