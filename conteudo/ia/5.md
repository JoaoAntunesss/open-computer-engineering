Um agente que raciocina precisa de **representar o que sabe** de forma que possa tirar conclusões novas. A lógica é a forma clássica: factos e regras, e um mecanismo de inferência que deduz o que se segue. É a base do Prolog, dos sistemas periciais, das regras de negócio, da web semântica e de muitas ferramentas de verificação.

## Bases de conhecimento

Uma base de conhecimento tem **factos** ("a Ana é mãe do Rui") e **regras** ("se X é mãe de Y e Y é pai de Z, então X é avó de Z"). Em Prolog (que viste em Lógica):

```prolog
mae(ana, rui).
pai(rui, eva).
pai(rui, tiago).
progenitor(X, Y) :- mae(X, Y).
progenitor(X, Y) :- pai(X, Y).
avo(X, Z) :- progenitor(X, Y), progenitor(Y, Z).

?- avo(ana, Quem).
Quem = eva ;
Quem = tiago.
```

## Encadeamento para a frente e para trás

- **Para a frente** (*forward chaining*): parte dos factos e aplica regras para gerar factos novos, até não haver mais. Bom quando chegam dados e queres saber todas as consequências (alertas, sistemas de regras como o Drools).
- **Para trás** (*backward chaining*): parte da pergunta e procura regras que a provem, transformando-a em subperguntas. É o que o Prolog faz. Bom quando há uma pergunta concreta.

```python run
factos = {("mae", "ana", "rui"), ("pai", "rui", "eva"), ("pai", "rui", "tiago"),
          ("pai", "jose", "ana")}

def regras(f):
    novos = set()
    for (r, x, y) in f:
        if r in ("mae", "pai"):
            novos.add(("progenitor", x, y))
    prog = [(x, y) for (r, x, y) in f if r == "progenitor"]
    for x, y in prog:
        for y2, z in prog:
            if y == y2:
                novos.add(("avo", x, z))
    for x, y in prog:
        novos.add(("antepassado", x, y))
    ante = [(x, y) for (r, x, y) in f if r == "antepassado"]
    for x, y in ante:
        for y2, z in prog:
            if y == y2:
                novos.add(("antepassado", x, z))
    return novos

voltas = 0
while True:                                   # encadeamento para a frente até ao ponto fixo
    novos = regras(factos) - factos
    if not novos:
        break
    factos |= novos
    voltas += 1

print("voltas:", voltas)
print("avós:", sorted((x, z) for r, x, z in factos if r == "avo"))
print("antepassados da eva:", sorted(x for r, x, z in factos if r == "antepassado" and z == "eva"))
```

Prevê os avós e os antepassados da Eva. O ciclo para quando uma volta não gera nada novo (o **ponto fixo**).

## Lógica de primeira ordem

A lógica proposicional só tem afirmações inteiras (p, q). A de **primeira ordem** acrescenta objetos, relações e quantificadores:

- ∀x (Aluno(x) ∧ Aprovado(x, LC) → PodeInscrever(x, Compiladores))
- ∃x (Funcionária(x) ∧ FazColoração(x))

A inferência usa **unificação** (encontrar substituições que tornam duas expressões iguais: `avo(ana, Q)` unifica com `avo(X, Z)` com X = ana, Z = Q) e **resolução**. A lógica de primeira ordem é semi-decidível: se algo segue da base, encontra-se a prova; se não segue, a pesquisa pode não acabar.

## Outras representações

- **Redes semânticas e ontologias:** conceitos ligados por relações (é-um, parte-de). A web semântica (RDF, OWL) e os grafos de conhecimento (o painel lateral do Google) usam isto.
- **Regras de produção:** "se condição então ação", em sistemas periciais.
- **Lógicas de descrição:** a base do OWL, decidíveis.

## Limites

O conhecimento do mundo real é incerto, cheio de exceções ("as aves voam", mas os pinguins não) e difícil de escrever à mão. Daí o raciocínio probabilístico (lição seguinte) e a aprendizagem a partir de dados. Mas as regras continuam ótimas quando o conhecimento é **exato e auditável**: regras fiscais, permissões, validações, configuração de produtos.
