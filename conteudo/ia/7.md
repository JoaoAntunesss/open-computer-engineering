Quando um agente toma decisões em sequência num mundo incerto (um robô que pode escorregar, um jogo com dados, a gestão de stock com procura imprevisível), não chega planear um caminho: é preciso uma **política**, que diz o que fazer em **cada** estado. Os **processos de decisão de Markov** (MDP) formalizam este problema, e a **iteração de valores** resolve-o.

## Os ingredientes

- **Estados** S e **ações** A.
- **Transições** P(s' | s, a): a probabilidade de ir parar a s' fazendo a em s. (Propriedade de Markov: só depende do estado atual.)
- **Recompensa** R(s): o que se ganha (ou perde) em cada estado.
- **Desconto** γ (entre 0 e 1): o quanto se valorizam as recompensas futuras face às imediatas.

O objetivo é uma política π(s) → a que maximiza a recompensa total esperada (descontada).

## Equação de Bellman

O valor de um estado é a recompensa lá mais o melhor valor esperado do seguinte:

V(s) = R(s) + γ · max_a Σ_s' P(s' | s, a) · V(s')

**Iteração de valores:** começa com V = 0 em todo o lado e aplica a equação repetidamente; converge para os valores ótimos. A política ótima escolhe, em cada estado, a ação que dá o máximo.

## O mundo da grelha

Um robô numa grelha 4 × 3. Cada ação (N, S, E, O) leva para onde se quer com 80% de probabilidade; com 10% vai para cada um dos lados. Cada passo custa um pouco (recompensa −0,04). O diamante (+1) e o buraco (−1) terminam o jogo.

```python run
L, C = 3, 4
parede, fins = {(1, 1)}, {(0, 3): 1.0, (1, 3): -1.0}
custo, gama = -0.04, 0.99
acoes = {"N": (-1, 0), "S": (1, 0), "E": (0, 1), "O": (0, -1)}
lados = {"N": "EO", "S": "EO", "E": "NS", "O": "NS"}
estados = [(r, c) for r in range(L) for c in range(C) if (r, c) not in parede]

def move(s, a):
    r, c = s[0] + acoes[a][0], s[1] + acoes[a][1]
    return (r, c) if 0 <= r < L and 0 <= c < C and (r, c) not in parede else s

def resultado(s, a):           # lista de (probabilidade, estado seguinte)
    return [(0.8, move(s, a))] + [(0.1, move(s, l)) for l in lados[a]]

V = {s: 0.0 for s in estados}
for it in range(100):
    novo = {}
    for s in estados:
        if s in fins:
            novo[s] = fins[s]
        else:
            novo[s] = custo + gama * max(sum(p * V[s2] for p, s2 in resultado(s, a)) for a in acoes)
    delta = max(abs(novo[s] - V[s]) for s in estados)
    V = novo
    if delta < 1e-6:
        break

seta = {"N": "↑", "S": "↓", "E": "→", "O": "←"}
print("convergiu em", it + 1, "iterações")
for r in range(L):
    linha = []
    for c in range(C):
        s = (r, c)
        if s in parede: linha.append("  ███  ")
        elif s in fins: linha.append(f" {fins[s]:+.2f} ")
        else:
            a = max(acoes, key=lambda a: sum(p * V[s2] for p, s2 in resultado(s, a)))
            linha.append(f"{seta[a]} {V[s]:.2f} ")
    print(" ".join(linha))
```

Prevê a direção na casa (1, 2), mesmo ao lado do buraco: vai para cima, em direção ao diamante, ou foge do buraco? Depois muda `custo` para −0,5 (cada passo custa muito) e vê como a política muda: o robô passa a arriscar.

## Iteração de políticas

Alternativa: começa com uma política qualquer, calcula os seus valores, melhora-a escolhendo em cada estado a melhor ação, e repete até não mudar. Costuma convergir em menos iterações.

## Onde aparecem os MDP

- Robótica e navegação com incerteza.
- Gestão de stock e preços dinâmicos.
- Sistemas de recomendação que pensam no longo prazo.
- São a base da **aprendizagem por reforço** (lição seguinte), em que o agente não conhece as probabilidades de transição e tem de as descobrir.
- Quando o estado não é totalmente visível: **POMDP** (muito mais difíceis).
