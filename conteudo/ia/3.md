Em jogos de dois jogadores (xadrez, damas, jogo do galo, quatro em linha), o agente não está sozinho: o adversário escolhe as jogadas que **te** são piores. O **minimax** escolhe a melhor jogada assumindo que o adversário joga perfeitamente. Os **cortes alfa-beta** fazem o mesmo cálculo ignorando ramos que não podem mudar a decisão, e é isso que torna possível pesquisar a fundo.

## Minimax

A árvore do jogo tem níveis alternados: MAX (tu) e MIN (o adversário). Nas folhas (fim do jogo, ou profundidade máxima), uma **função de avaliação** dá um valor (+1 vitória, 0 empate, −1 derrota; ou uma estimativa da posição).

- Num nó MAX, o valor é o **máximo** dos filhos.
- Num nó MIN, o **mínimo**.

A jogada escolhida é a do filho com maior valor na raiz.

## Cortes alfa-beta

Mantêm dois limites durante a pesquisa:

- **α:** o melhor valor que MAX já tem garantido;
- **β:** o melhor valor que MIN já tem garantido.

Se, num nó, α ≥ β, os restantes filhos não interessam: o outro jogador nunca deixaria o jogo chegar ali. O resultado é **exatamente o mesmo** do minimax, e com uma boa ordem das jogadas (as melhores primeiro), avalia cerca de √ do número de nós: no mesmo tempo, pesquisa o dobro da profundidade.

## O jogo do galo, resolvido

```python run
from functools import lru_cache

LINHAS = [(0,1,2),(3,4,5),(6,7,8),(0,3,6),(1,4,7),(2,5,8),(0,4,8),(2,4,6)]

def vencedor(t):
    for a, b, c in LINHAS:
        if t[a] != "." and t[a] == t[b] == t[c]:
            return t[a]
    return None

contagem = {"minimax": 0, "alfabeta": 0}

def minimax(t, jogador):
    contagem["minimax"] += 1
    v = vencedor(t)
    if v: return 1 if v == "X" else -1
    if "." not in t: return 0
    valores = [minimax(t[:i] + jogador + t[i+1:], "O" if jogador == "X" else "X")
               for i in range(9) if t[i] == "."]
    return max(valores) if jogador == "X" else min(valores)

def alfabeta(t, jogador, alfa=-2, beta=2):
    contagem["alfabeta"] += 1
    v = vencedor(t)
    if v: return 1 if v == "X" else -1
    if "." not in t: return 0
    for i in range(9):
        if t[i] != ".": continue
        valor = alfabeta(t[:i] + jogador + t[i+1:], "O" if jogador == "X" else "X", alfa, beta)
        if jogador == "X": alfa = max(alfa, valor)
        else: beta = min(beta, valor)
        if alfa >= beta: break                       # corte
    return alfa if jogador == "X" else beta

def melhor_jogada(t, jogador):
    jogadas = [i for i in range(9) if t[i] == "."]
    seg = "O" if jogador == "X" else "X"
    valor = lambda i: alfabeta(t[:i] + jogador + t[i+1:], seg)
    return max(jogadas, key=valor) if jogador == "X" else min(jogadas, key=valor)

print("valor do jogo vazio (minimax):", minimax("." * 9, "X"))
print("valor do jogo vazio (alfa-beta):", alfabeta("." * 9, "X"))
print("nós visitados:", contagem)

t = "XO." \
    ".X." \
    "..O"
print("O joga em", melhor_jogada(t, "O"), "para não perder")
```

## Jogos a sério

O xadrez tem cerca de 35 jogadas possíveis por posição e partidas de 80 meias-jogadas: 35⁸⁰ nós. Impossível. Na prática:

- **Profundidade limitada** com uma **função de avaliação** (material, mobilidade, segurança do rei).
- **Aprofundamento iterativo** (pesquisar a profundidade 1, 2, 3… até acabar o tempo).
- **Tabelas de transposição** (memoizar posições já vistas por outro caminho) e boa ordenação das jogadas.
- Jogos com sorte (gamão) usam **expectiminimax**, com nós de acaso que calculam a média.
- **AlphaGo/AlphaZero**: pesquisa em árvore Monte Carlo guiada por redes neuronais que avaliam posições e sugerem jogadas.
