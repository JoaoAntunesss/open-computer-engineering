Todas as linguagens anteriores acabam aqui: em instruções muito simples que o processador executa uma a uma. **Assembly** é a forma legível dessas instruções. Ninguém escreve programas grandes em Assembly, mas lê-lo faz-te perceber o que é realmente uma variável, um ciclo ou uma chamada de função. Usamos **RISC-V**, um conjunto de instruções aberto, cada vez mais usado no ensino (Berkeley, IST).

## O que existe a este nível

- **Registos**: poucas "variáveis" muito rápidas dentro do processador (`a0`, `t0`, `s1`…).
- **Memória**: um vetor enorme de bytes, acedido por endereço.
- **Instruções simples**: somar, comparar, carregar da memória, guardar na memória, saltar.

Não há `for`, nem `if`, nem funções: há **saltos** condicionais.

## A soma dos positivos em RISC-V

Para ficar curto, só a soma (sem a divisão):

```asm
# a0 = endereço da lista, a1 = número de elementos
# devolve em a0 a soma dos positivos
soma_positivos:
    li   t0, 0            # t0 = soma = 0
    li   t1, 0            # t1 = i = 0
ciclo:
    bge  t1, a1, fim      # se i >= n, salta para fim
    slli t2, t1, 2        # t2 = i * 4 (cada inteiro tem 4 bytes)
    add  t2, a0, t2       # t2 = endereço de lista[i]
    lw   t3, 0(t2)        # t3 = lista[i] (carrega da memória)
    ble  t3, zero, salta  # se lista[i] <= 0, não soma
    add  t0, t0, t3       # soma = soma + lista[i]
salta:
    addi t1, t1, 1        # i = i + 1
    j    ciclo            # volta ao início do ciclo
fim:
    mv   a0, t0           # resultado em a0
    ret                   # volta a quem chamou
```

## Como se lê

Linha a linha, com os comentários à direita. Repara como as ideias de alto nível aparecem:

| Ideia | Em Assembly |
|---|---|
| `soma = 0` | `li t0, 0` |
| `for i in range(n)` | `bge t1, a1, fim` no início + `addi` e `j ciclo` no fim |
| `lista[i]` | calcular o endereço (`i * 4` + início) e `lw` |
| `if x > 0:` | `ble t3, zero, salta` (saltar **por cima** quando é falso) |
| `return soma` | pôr o valor em `a0` e `ret` |

Um `if` é um salto que evita um bocado de código; um ciclo é um salto para trás. É tudo o que um processador sabe fazer.
