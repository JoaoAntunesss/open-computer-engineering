JavaScript é a única linguagem que corre em todos os browsers, por isso está em todos os sites. Com o Node.js também corre em servidores. Se fazes sites (ou a IA os faz por ti), é a linguagem que mais vais ler.

## O mesmo programa em JavaScript

```js run
function mediaPositivos(numeros) {
  const positivos = numeros.filter(n => n > 0);
  if (positivos.length === 0) {
    return 0;
  }
  const soma = positivos.reduce((acc, n) => acc + n, 0);
  return soma / positivos.length;
}

console.log(mediaPositivos([4, -2, 10, 0, 7]));
console.log(mediaPositivos([-1, -5]));
```

## Como se lê

- `function nome(params) { ... }` define uma função. Blocos com `{ }`, como em C e Java.
- `const` e `let` criam variáveis (`const` não pode ser reatribuída). Vais ver `var` em código antigo.
- `n => n > 0` é uma função curta (*arrow function*), como o `lambda` do Python.
- `.filter` filtra, `.map` transforma, `.reduce` acumula: são o pão nosso de cada dia em código moderno.
- `===` compara valor **e tipo**. Usa sempre `===`, nunca `==`.
- `console.log` é o `print`, e no browser aparece em F12 → Console.

## O que JavaScript faz de estranho

```js run
console.log("5" + 1);
console.log("5" - 1);
console.log(0.1 + 0.2);
console.log([] + []);
console.log(0 == "");
console.log(0 === "");
```

O JavaScript tenta converter tipos sozinho, com resultados surpreendentes. É por isso que se usa `===` e que muitas equipas usam **TypeScript**, que acrescenta tipos.

## Assíncrono: a parte mais difícil de ler

Muitas operações (pedir dados a um servidor, ler da base de dados) não respondem logo. Em JavaScript escreve-se assim:

```js
async function carregarClientes() {
  const resposta = await fetch("/api/clientes");
  const clientes = await resposta.json();
  return clientes.filter(c => c.ativo);
}
```

`await` quer dizer "espera pelo resultado antes de continuar". Esquecer o `await` é um dos erros mais comuns (em código gerado também): ficas com uma *Promise* em vez dos dados.

## Exercício

```js run
const precos = [10, 25, 5, 40];
const caros = precos.filter(p => p > 15).map(p => p * 0.9);
console.log(caros, caros.length);
```

`filter` fica com `[25, 40]`; `map` aplica 10% de desconto: `[22.5, 36]`. Mostra `[22.5,36] 2`.
