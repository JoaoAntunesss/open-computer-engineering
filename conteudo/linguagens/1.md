O programa de referência: **a média dos números positivos de uma lista**, devolvendo 0 se não houver nenhum.

## Python

```python run
def media_positivos(numeros):
    positivos = [n for n in numeros if n > 0]
    if not positivos:
        return 0
    return sum(positivos) / len(positivos)

print(media_positivos([4, -2, 10, 0, 7]))
print(media_positivos([-1, -5]))
```

## Como se lê

- `def` define uma função; os blocos são marcados por **indentação** e `:`.
- Não se declaram tipos: `numeros` pode ser qualquer coisa, e só se descobre o tipo ao correr.
- Muitas operações vêm prontas (`sum`, `len`, `sorted`) e o código fica curto.
- `[n for n in numeros if n > 0]` filtra numa linha.

## Armadilhas

- Indentação errada muda o significado (e mistura de tabs e espaços dá erro).

- `/` dá sempre um número decimal; `//` é a divisão inteira.
