C é a linguagem por baixo de quase tudo: sistemas operativos, o próprio interpretador de Python, microcontroladores e bases de dados. É mais trabalhosa de escrever, mas mostra-te o que o computador faz de verdade com a memória.

## Um programa para ler: a média dos números positivos de uma lista

```c
#include <stdio.h>

double media_positivos(const int numeros[], int n) {
    int soma = 0, quantos = 0;
    for (int i = 0; i < n; i++) {
        if (numeros[i] > 0) {
            soma += numeros[i];
            quantos++;
        }
    }
    if (quantos == 0) {
        return 0;
    }
    return (double) soma / quantos;
}

int main(void) {
    int v[] = {4, -2, 10, 0, 7};
    printf("%.2f\n", media_positivos(v, 5));
    return 0;
}
```

Para correr no teu computador: `gcc media.c -o media` e depois `./media`. Também podes experimentar sem instalar nada em compiladores online como o Compiler Explorer.

## Como se lê

- **Tipos em todo o lado**: `int` (inteiro), `double` (decimal), e a função diz o tipo do que devolve (`double media_positivos`).
- **Chavetas `{ }`** marcam os blocos e **`;`** termina cada instrução. A indentação é só para pessoas.
- **O tamanho da lista vai à parte** (`int n`): em C, um array não sabe quantos elementos tem.
- `for (int i = 0; i < n; i++)`: começa em 0, continua enquanto `i < n`, soma 1 a cada volta. É o `range(n)` do Python, escrito por extenso.
- `(double) soma / quantos`: converte para decimal antes de dividir. Sem isso, `27 / 3` daria `9`, mas `20 / 3` daria `6` (divisão inteira).
- `main` é onde o programa começa. `printf("%.2f\n", ...)` mostra com 2 casas decimais.

## Armadilhas

- **Ler fora do array** não dá erro: lê lixo da memória, ou rebenta mais tarde ("segmentation fault").
- Esquecer o `;` ou fechar uma chaveta no sítio errado.
- **Divisão inteira** quando os dois lados são `int`.
- Gestão de memória manual (`malloc`/`free`): esquecer o `free` gasta memória; usar depois do `free` dá erros imprevisíveis. Ferramentas como o Valgrind ajudam a encontrar estes erros.

## Exercício

Sem correr: o que mostra este programa? Porquê?

```c
int a = 7, b = 2;
printf("%d %.1f\n", a / b, (double) a / b);
```

??? Solução
Mostra `3 3.5`. `a / b` com dois `int` é divisão inteira (3). Com a conversão para `double`, a divisão é decimal (3,5).
