Programas úteis leem e escrevem ficheiros e recebem opções na linha de comandos, como `grep -i erro registo.txt`. Nesta lição aprendes a usar `argc` e `argv`, a trabalhar com ficheiros de texto e binários, e a tratar os erros que inevitavelmente acontecem.

## Argumentos da linha de comandos

```c
// args.c
#include <stdio.h>

int main(int argc, char *argv[]) {
    printf("%d argumento(s)\n", argc);
    for (int i = 0; i < argc; i++) printf("argv[%d] = \"%s\"\n", i, argv[i]);
    return 0;
}
```

```bash
./args ola "duas palavras" 42
# 4 argumento(s); argv[0] = "./args", argv[1] = "ola", argv[2] = "duas palavras", argv[3] = "42"
```

- `argc` conta os argumentos, incluindo o nome do programa em `argv[0]`.
- `argv[argc]` é sempre `NULL`.
- Tudo chega como string: converte com `strtol` (que deteta erros) em vez de `atoi` (que não deteta).
- A shell trata das aspas e dos asteriscos antes de o programa arrancar: `./prog *.txt` recebe a lista de ficheiros já expandida.

## Abrir, ler e fechar ficheiros

```c
FILE *f = fopen("notas.txt", "r");
if (f == NULL) {
    perror("notas.txt");           // ex.: "notas.txt: No such file or directory"
    return 1;
}
char linha[256];
while (fgets(linha, sizeof linha, f)) {
    // processa a linha
}
fclose(f);
```

Modos de `fopen`:

- `"r"` ler (o ficheiro tem de existir);
- `"w"` escrever (cria ou **apaga** o conteúdo);
- `"a"` acrescentar ao fim;
- junta `"b"` para binário (relevante no Windows) e `"+"` para ler e escrever.

Para escrever: `fprintf(f, "%s;%d\n", nome, idade)` ou `fputs`. Para ler valores formatados: `fscanf` (verifica sempre o número de campos lidos).

`stdin`, `stdout` e `stderr` são ficheiros já abertos. Escreve as mensagens de erro em `stderr`, para não se misturarem com a saída que pode estar a ser redirecionada para outro programa.

## Um mini "wc"

```c
// miniwc.c
#include <stdio.h>
#include <ctype.h>

int conta(FILE *f, const char *nome) {
    long linhas = 0, palavras = 0, bytes = 0;
    int c, dentro = 0;
    while ((c = fgetc(f)) != EOF) {       // c é int para distinguir EOF de um byte 255
        bytes++;
        if (c == '\n') linhas++;
        if (isspace(c)) dentro = 0;
        else if (!dentro) { dentro = 1; palavras++; }
    }
    printf("%7ld %7ld %7ld %s\n", linhas, palavras, bytes, nome);
    return 0;
}

int main(int argc, char *argv[]) {
    if (argc == 1) return conta(stdin, "");
    int erro = 0;
    for (int i = 1; i < argc; i++) {
        FILE *f = fopen(argv[i], "r");
        if (!f) { perror(argv[i]); erro = 1; continue; }
        conta(f, argv[i]);
        fclose(f);
    }
    return erro;
}
```

```bash
gcc -Wall -o miniwc miniwc.c
./miniwc miniwc.c
echo "uma duas três" | ./miniwc
```

## Ficheiros binários

Para guardar structs tal como estão em memória, usa `fwrite` e `fread`:

```c
// binario.c
#include <stdio.h>

typedef struct { char nome[32]; int stock; double preco; } Artigo;

int main(void) {
    Artigo v[] = {{"Parafuso M6", 1200, 0.05}, {"Chave inglesa", 14, 12.90}};
    FILE *f = fopen("stock.bin", "wb");
    if (!f) { perror("stock.bin"); return 1; }
    fwrite(v, sizeof v[0], 2, f);
    fclose(f);

    Artigo a;
    f = fopen("stock.bin", "rb");
    if (!f) { perror("stock.bin"); return 1; }
    fseek(f, sizeof a, SEEK_SET);                 // salta diretamente para o 2.º registo
    if (fread(&a, sizeof a, 1, f) == 1) printf("%s: %d a %.2f €\n", a.nome, a.stock, a.preco);
    fclose(f);
    return 0;
}
```

O acesso direto (`fseek`) é rápido, mas o formato depende do compilador e da máquina (tamanhos, enchimento, ordem dos bytes). Para trocar dados entre sistemas, prefere texto (CSV, JSON) ou um formato binário definido byte a byte.

## Tratar erros

- Quase todas as funções de ficheiros indicam erro no valor devolvido (`NULL`, `EOF`, um número de elementos menor do que o pedido). Verifica sempre.
- `errno` (de `<errno.h>`) guarda o código do último erro; `perror` e `strerror(errno)` transformam-no em texto.
- Termina com um código de saída diferente de 0 quando algo falha: os scripts e o `make` dependem disso.
- O `fclose` também pode falhar (por exemplo, disco cheio ao escrever o que estava em memória).

## Erros comuns

- Não verificar se `fopen` devolveu `NULL`.
- Guardar o resultado de `fgetc` num `char` (não se distingue `EOF` de um byte válido).
- Usar `while (!feof(f))` como condição do ciclo: processa a última linha duas vezes. Testa o resultado da leitura.
- Abrir com `"w"` um ficheiro que querias manter.
- Esquecer o `fclose` (os dados podem não chegar ao disco).
