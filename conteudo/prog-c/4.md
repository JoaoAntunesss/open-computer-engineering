Um apontador é uma variável que guarda um **endereço de memória**. É a ideia que distingue C das linguagens de alto nível: dá-te acesso direto à memória, o que permite estruturas de dados eficientes, comunicação com hardware e funções que alteram os argumentos — e também a maior parte dos erros graves.

## Endereços e apontadores

A memória é uma sequência enorme de bytes numerados. Cada variável ocupa alguns desses bytes, e o número do primeiro é o seu **endereço**.

```c
// apontadores.c
#include <stdio.h>

int main(void) {
    int x = 10;
    int *p = &x;          // p guarda o endereço de x
    printf("x = %d, &x = %p\n", x, (void *)&x);
    printf("p = %p, *p = %d\n", (void *)p, *p);
    *p = 25;              // altera x através de p
    printf("x = %d\n", x);   // 25
    return 0;
}
```

- `&x` é "o endereço de x".
- `int *p` declara um apontador para `int`.
- `*p` (fora da declaração) é "o valor que está no endereço p" — **desreferenciar**.
- `NULL` é um apontador que não aponta para nada. Desreferenciá-lo faz o programa terminar com "Segmentation fault".

## Passagem por referência

Os argumentos em C são cópias. Para uma função alterar variáveis de quem a chama, passa-se o endereço:

```c
// troca.c
#include <stdio.h>

void troca(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}

void divide(int n, int d, int *q, int *r) {   // "devolve" dois valores
    *q = n / d;
    *r = n % d;
}

int main(void) {
    int x = 1, y = 2;
    troca(&x, &y);
    printf("%d %d\n", x, y);        // 2 1
    int q, r;
    divide(17, 5, &q, &r);
    printf("%d %d\n", q, r);        // 3 2
    return 0;
}
```

É por isso que o `scanf` recebe `&idade`: precisa de saber onde escrever.

## Aritmética de apontadores

Somar 1 a um apontador avança **um elemento**, não um byte: para um `int *` avança 4 bytes, para um `double *` avança 8.

```c
// aritmetica.c
#include <stdio.h>

int main(void) {
    int v[] = {10, 20, 30, 40};
    int *p = v;                   // o nome do vetor decai para &v[0]
    printf("%d %d\n", *p, *(p + 2));     // 10 30
    printf("%d\n", p[3]);                 // 40: p[i] é o mesmo que *(p + i)
    for (int *q = v; q < v + 4; q++) printf("%d ", *q);
    printf("\n%td elementos entre o início e o fim\n", (v + 4) - v);   // 4
    return 0;
}
```

A igualdade `v[i] == *(v + i)` é a definição de indexação em C. Explica porque é que os vetores começam em 0: o primeiro elemento está a 0 posições do início.

Só é válido apontar para dentro de um vetor ou para a posição **imediatamente a seguir** ao último elemento. Desreferenciar fora disso é comportamento indefinido.

## Apontadores e const

```c
const int *a;        // não podes alterar *a (o valor), podes mudar a
int *const b = &x;   // não podes mudar b (o endereço), podes alterar *b
const int *const c = &x;   // nenhum dos dois
```

Lê da direita para a esquerda: "b é um apontador constante para int". Em parâmetros, `const char *s` diz a quem chama que a função não vai alterar a string.

## Apontadores para apontadores e para funções

`int **pp` aponta para um `int *`. Aparece quando uma função tem de alterar um apontador (por exemplo, a cabeça de uma lista ligada, na lição 6) e em `char *argv[]` (lição 8).

Também podes guardar o endereço de uma **função** e chamá-la mais tarde. É assim que o `qsort` recebe a regra de comparação:

```c
// ordena.c
#include <stdio.h>
#include <stdlib.h>

int decrescente(const void *a, const void *b) {
    int x = *(const int *)a, y = *(const int *)b;
    return (y > x) - (y < x);
}

int main(void) {
    int v[] = {5, 1, 4, 2, 3};
    qsort(v, 5, sizeof v[0], decrescente);
    for (int i = 0; i < 5; i++) printf("%d ", v[i]);   // 5 4 3 2 1
    printf("\n");
    return 0;
}
```

`void *` é um apontador "genérico", para qualquer tipo; tem de ser convertido antes de desreferenciar.

## Erros comuns

- Desreferenciar um apontador não inicializado ou `NULL`.
- Devolver o endereço de uma variável local: `int *f(void) { int x = 3; return &x; }` — `x` deixa de existir quando a função termina.
- Confundir `*p++` (avança o apontador) com `(*p)++` (incrementa o valor).
- Declarar `int* a, b;` e achar que `b` também é um apontador (só `a` é).
- Usar `return x - y;` numa função de comparação: pode dar overflow.
