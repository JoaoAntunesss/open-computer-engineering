C parece-se com Python na lógica — variáveis, condições, ciclos, funções — mas é muito mais explícito. Cada variável tem um tipo fixo e um tamanho em memória, e o compilador confia que sabes o que estás a fazer. Esta lição mostra as diferenças que mais apanham quem vem de Python.

## Tipos e tamanhos

```c
// tipos.c
#include <stdio.h>
#include <stdint.h>
#include <limits.h>

int main(void) {
    printf("char   %zu byte(s)\n", sizeof(char));
    printf("int    %zu, de %d a %d\n", sizeof(int), INT_MIN, INT_MAX);
    printf("long   %zu\n", sizeof(long));
    printf("double %zu\n", sizeof(double));
    int32_t exato = 42;          // exatamente 32 bits, em qualquer máquina
    uint8_t byte = 255;          // 0 a 255
    printf("%d %u\n", exato, byte);
    return 0;
}
```

- `char` tem sempre 1 byte. `int` tem normalmente 4 bytes, mas a norma só garante pelo menos 2.
- `long` tem 8 bytes em Linux e macOS de 64 bits, mas 4 em Windows.
- Quando o tamanho importa (ficheiros, rede, hardware), usa os tipos de `<stdint.h>`: `int8_t`, `uint32_t`, `int64_t`…
- `sizeof` devolve um `size_t`, que se escreve com `%zu`.
- Não há tipo booleano nativo antigo: `0` é falso, qualquer outro valor é verdadeiro. Com `<stdbool.h>` tens `bool`, `true` e `false`.

## Overflow e conversões

Em Python, os inteiros crescem sem limite. Em C, não:

```c
// overflow.c
#include <stdio.h>
#include <limits.h>

int main(void) {
    unsigned char u = 250;
    u += 10;                      // sem sinal: dá a volta (módulo 256)
    printf("%u\n", u);            // 4
    int a = 7, b = 2;
    printf("%d\n", a / b);        // 3: divisão inteira
    printf("%.2f\n", a / 2.0);    // 3.50: um operando double basta
    printf("%.2f\n", (double)a / b);
    printf("%d\n", -7 / 2);       // -3: trunca para zero (em Python, -7 // 2 dá -4)
    printf("%d\n", -7 % 2);       // -1
    return 0;
}
```

- Nos tipos **sem sinal**, o overflow está definido: o valor dá a volta.
- Nos tipos **com sinal**, o overflow é **comportamento indefinido** (*undefined behavior*): o compilador pode assumir que nunca acontece e gerar código surpreendente. Verifica antes de somar perto dos limites.
- Misturar `int` com `unsigned` numa comparação converte o `int` para sem sinal: `-1 < 1u` é falso!

## Operadores

Quase iguais aos de outras linguagens, com algumas particularidades:

- `++i` e `i++` incrementam; a diferença está no valor da expressão (antes ou depois).
- `&&` e `||` fazem avaliação em curto-circuito, como `and` e `or` em Python.
- `&`, `^`, `~`, `<<` e `>>` trabalham bit a bit (e há o "ou" bit a bit, a barra vertical simples).
- `=` é atribuição e **devolve um valor**: `if (x = 0)` compila, atribui 0 e é sempre falso. O `-Wall` avisa.
- O operador ternário: `int maior = a > b ? a : b;`

## Controlo de fluxo

```c
// controlo.c
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 15; i++) {
        if (i % 15 == 0) printf("FizzBuzz\n");
        else if (i % 3 == 0) printf("Fizz\n");
        else if (i % 5 == 0) printf("Buzz\n");
        else printf("%d\n", i);
    }

    int n = 27, passos = 0;
    while (n != 1) {               // conjetura de Collatz
        n = (n % 2 == 0) ? n / 2 : 3 * n + 1;
        passos++;
    }
    printf("passos: %d\n", passos);   // 111

    char op = '+';
    switch (op) {
        case '+': printf("soma\n"); break;
        case '-': printf("subtração\n"); break;
        default:  printf("?\n");
    }
    return 0;
}
```

- As chavetas delimitam os blocos (a indentação é só para humanos).
- No `switch`, sem `break` a execução "cai" para o caso seguinte.
- Há também `do { ... } while (cond);`, que executa o corpo pelo menos uma vez.

## Funções

```c
// funcoes.c
#include <stdio.h>

long fatorial(int n);              // protótipo: declara antes de usar

int main(void) {
    for (int i = 0; i <= 10; i++) printf("%d! = %ld\n", i, fatorial(i));
    return 0;
}

long fatorial(int n) {
    return n <= 1 ? 1 : n * fatorial(n - 1);
}
```

Os argumentos são passados **por valor**: a função recebe uma cópia. Para alterar uma variável de quem chama, precisas de apontadores (lição 4).

## Ler dados

```c
int idade;
if (scanf("%d", &idade) != 1) {
    fprintf(stderr, "Entrada inválida\n");
    return 1;
}
```

O `&` passa o endereço da variável para o `scanf` a poder preencher. Verifica sempre o valor devolvido (quantos campos leu).

## Erros comuns

- Usar uma variável local sem a inicializar: o valor é lixo.
- Esquecer o `break` no `switch`.
- Usar o formato errado no `printf` (`%d` para um `long` ou um `double`).
- Escrever `if (x = 5)` em vez de `if (x == 5)`.
- Assumir que `int` tem sempre 4 bytes ou `long` tem 8.

```c
// primo.c
#include <stdio.h>
#include <stdbool.h>

bool primo(int n) {
    if (n < 2) return false;
    for (int d = 2; d * d <= n; d++)
        if (n % d == 0) return false;
    return true;
}

int main(void) {
    int n;
    if (scanf("%d", &n) != 1) return 1;
    printf("%d %s primo\n", n, primo(n) ? "é" : "não é");
    return 0;
}
```

2: `5 / 2` é 2 (divisão inteira); `2 * 2.0` é 4.0; `4.0 > 4` é falso, por isso imprime **0**.

3: `int soma_digitos(int n) { int s = 0; while (n > 0) { s += n % 10; n /= 10; } return s; }` — para 2026 dá **10**.

4: um `unsigned` é sempre ≥ 0, por isso a condição é sempre verdadeira; quando `i` é 0, `i--` dá a volta para 4294967295. O `-Wextra` avisa: "comparison of unsigned expression in '>= 0' is always true".
