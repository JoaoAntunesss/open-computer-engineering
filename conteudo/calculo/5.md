Como é que uma calculadora sabe quanto vale sin(0.3)? Não tem uma tabela infinita: soma uns poucos termos de um polinómio. Esta lição explica de onde vêm esses polinómios — as séries de Taylor — começando pelas sucessões e séries, que são a forma rigorosa de falar em "somar infinitas parcelas".

## Sucessões

Uma **sucessão** é uma lista infinita a₁, a₂, a₃, …, ou seja, uma função de ℕ em ℝ. Diz-se que **converge** para L quando lim(n→∞) aₙ = L.

- aₙ = 1/n → 0
- aₙ = (1 + 1/n)ⁿ → e ≈ 2.71828
- aₙ = (−1)ⁿ não converge (oscila entre −1 e 1)
- aₙ = rⁿ converge para 0 se |r| < 1 e diverge se |r| > 1

Para comparar velocidades de crescimento, que é exatamente o que fazes ao analisar algoritmos: para n → ∞, ln n ≪ nᵏ ≪ aⁿ ≪ n! (com k > 0 e a > 1).

## Séries

Uma **série** é a soma dos termos de uma sucessão: Σ aₙ = a₁ + a₂ + a₃ + … Define-se pelas **somas parciais** Sₙ = a₁ + … + aₙ: a série converge se Sₙ converge.

**Série geométrica**: Σ(n≥0) rⁿ = 1 + r + r² + … = **1/(1 − r)**, se |r| < 1.

Prova: Sₙ = (1 − rⁿ⁺¹)/(1 − r), e rⁿ⁺¹ → 0. Exemplo: 1/2 + 1/4 + 1/8 + … = 1.

**Série harmónica**: Σ 1/n = 1 + 1/2 + 1/3 + … **diverge**, embora os termos tendam para 0. Cresce como ln n. Por isso, ter aₙ → 0 é necessário mas não suficiente para convergir.

**Séries p**: Σ 1/nᵖ converge se e só se p > 1. Por exemplo Σ 1/n² = π²/6.

## Critérios de convergência

- **Termo geral**: se aₙ não tende para 0, a série diverge.
- **Comparação**: se 0 ≤ aₙ ≤ bₙ e Σ bₙ converge, Σ aₙ também converge.
- **Razão (d'Alembert)**: calcula L = lim |aₙ₊₁/aₙ|. Se L < 1 converge; se L > 1 diverge; se L = 1 nada se conclui.
- **Leibniz** (séries alternadas): se |aₙ| decresce para 0, Σ(−1)ⁿ aₙ converge, e o erro de parar no termo n é menor do que o primeiro termo desprezado.

Exemplo com a razão: Σ 1/n!: |aₙ₊₁/aₙ| = 1/(n + 1) → 0 < 1, converge (para e − 1, começando em n = 1).

## Polinómios de Taylor

A aproximação linear da lição 3 usa f(a) e f′(a). Se usarmos também f″(a), f‴(a), …, obtemos polinómios que acompanham a função cada vez melhor. O **polinómio de Taylor** de grau n em torno de a é:

**Pₙ(x) = f(a) + f′(a)(x − a) + f″(a)/2! · (x − a)² + … + f⁽ⁿ⁾(a)/n! · (x − a)ⁿ**

É o único polinómio de grau n com as mesmas derivadas que f em a, até à ordem n. Quando a = 0 chama-se também polinómio de Maclaurin.

## As séries que deves conhecer (em torno de 0)

| Função | Série | Converge para |
|---|---|---|
| eˣ | 1 + x + x²/2! + x³/3! + … | todo o x |
| sin x | x − x³/3! + x⁵/5! − … | todo o x |
| cos x | 1 − x²/2! + x⁴/4! − … | todo o x |
| 1/(1 − x) | 1 + x + x² + x³ + … | ∣x∣ < 1 |
| ln(1 + x) | x − x²/2 + x³/3 − … | −1 < x ≤ 1 |

Repara que sin só tem potências ímpares (é função ímpar) e cos só pares. E derivando termo a termo a série de sin obténs a de cos.

## Taylor em Python

```python
import math

def taylor_sin(x, n_termos):
    return sum((-1)**k * x**(2*k + 1) / math.factorial(2*k + 1) for k in range(n_termos))

for n in [1, 2, 3, 5]:
    aprox = taylor_sin(1.0, n)
    print(f"{n} termos: {aprox:.10f}   erro = {abs(aprox - math.sin(1.0)):.2e}")
```

Com 5 termos (até x⁹/9!), o erro em x = 1 já é da ordem de 10⁻⁸. Mas em x = 10 os mesmos 5 termos dão um disparate: o polinómio só é bom perto do ponto de expansão. As bibliotecas resolvem isto primeiro reduzindo o argumento (usando a periodicidade, sin(x + 2π) = sin x) para um intervalo pequeno, e só depois aplicando um polinómio.

## O erro (resto de Lagrange)

O erro de parar no grau n é

Rₙ(x) = f⁽ⁿ⁺¹⁾(ξ)/(n + 1)! · (x − a)ⁿ⁺¹, para algum ξ entre a e x.

Para sin e cos, todas as derivadas estão entre −1 e 1, por isso |Rₙ(x)| ≤ |x|ⁿ⁺¹/(n + 1)!. O fatorial no denominador cresce tão depressa que o erro cai muito rápido perto de 0.

## Erros comuns

- Achar que aₙ → 0 garante que Σ aₙ converge (a harmónica é o contraexemplo).
- Usar um polinómio de Taylor longe do ponto de expansão.
- Usar a série de ln(1 + x) ou de 1/(1 − x) fora do intervalo de convergência.
- Calcular xⁿ/n! com n grande somando inteiros enormes: é mais estável calcular cada termo a partir do anterior (`termo *= x / n`).

## Exercícios

1. Calcula a soma de 3 + 3/4 + 3/16 + 3/64 + …
2. Diz se convergem: a) Σ n/2ⁿ, b) Σ 1/√n, c) Σ (−1)ⁿ/n.
3. Escreve o polinómio de Taylor de grau 2 de √x em torno de a = 4 e usa-o para estimar √4.1.
4. Quantos termos da série de eˣ são precisos para calcular e com erro menor do que 10⁻¹⁰?

??? Soluções
1: série geométrica com primeiro termo 3 e razão 1/4: 3/(1 − 1/4) = **4**.

2: a) converge (razão: (n + 1)/(2n) → 1/2 < 1); b) diverge (série p com p = 1/2 ≤ 1); c) converge (Leibniz), embora a série dos módulos, a harmónica, divirja.

3: f(4) = 2, f′(4) = 1/4, f″(x) = −1/(4x^(3/2)) → f″(4) = −1/32. P₂(x) = 2 + (x − 4)/4 − (x − 4)²/64. P₂(4.1) = 2 + 0.025 − 0.00015625 = **2.02484375**; o valor real é 2.0248456…

4: com termos até 1/n!, o erro é cerca de 1/(n + 1)!. Como 14! ≈ 8.7·10¹⁰, bastam os termos até **1/13!** (14 termos, contando o 1 inicial).

```python
s, termo, n = 0.0, 1.0, 0
while abs(math.e - s) >= 1e-10:
    s += termo
    n += 1
    termo /= n
print(n, "termos")   # 14
```
