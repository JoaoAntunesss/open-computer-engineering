Se a derivada mede a taxa de mudança, o integral acumula: a distância percorrida a partir da velocidade, a área debaixo de uma curva, a probabilidade a partir de uma densidade. O Teorema Fundamental do Cálculo mostra que estas duas operações são inversas uma da outra.

## Área como limite de somas

Para calcular a área debaixo de f ≥ 0 entre a e b, divide [a, b] em n faixas de largura Δx = (b − a)/n e aproxima cada faixa por um retângulo:

Sₙ = Σ f(xᵢ) · Δx

Esta é uma **soma de Riemann**. Quando n → ∞, se o limite existe, chama-se **integral definido**:

**∫ₐᵇ f(x) dx = lim(n→∞) Σ f(xᵢ) Δx**

Se f toma valores negativos, as áreas abaixo do eixo contam com sinal negativo.

```python
def riemann(f, a, b, n):
    dx = (b - a) / n
    return sum(f(a + (i + 0.5) * dx) for i in range(n)) * dx   # ponto médio de cada faixa

for n in [4, 40, 400]:
    print(n, riemann(lambda x: x**2, 0, 1, n))   # aproxima-se de 1/3
```

## Primitivas

Uma **primitiva** (ou antiderivada) de f é uma função F com F′ = f. Se F é primitiva, F + C também é, para qualquer constante C. O **integral indefinido** representa todas:

∫ f(x) dx = F(x) + C

Basta ler a tabela de derivadas ao contrário:

| f(x) | ∫ f(x) dx |
|---|---|
| xⁿ (n ≠ −1) | xⁿ⁺¹/(n + 1) + C |
| 1/x | ln ∣x∣ + C |
| eˣ | eˣ + C |
| sin x | −cos x + C |
| cos x | sin x + C |
| 1/(1 + x²) | arctan x + C |

## O Teorema Fundamental do Cálculo

Se f é contínua em [a, b] e F é uma primitiva de f, então

**∫ₐᵇ f(x) dx = F(b) − F(a)**

A soma infinita de retângulos reduz-se a duas avaliações de uma primitiva. Exemplo:

∫₀¹ x² dx = [x³/3]₀¹ = 1/3 − 0 = **1/3**, o valor para onde convergia a soma de Riemann acima.

A outra metade do teorema diz que, se G(x) = ∫ₐˣ f(t) dt, então G′(x) = f(x): acumular e depois derivar devolve a função original.

## Técnica 1: substituição

É a regra da cadeia ao contrário. Se vês uma função composta multiplicada pela derivada da função interior, faz u = g(x), du = g′(x) dx.

∫ 2x · cos(x²) dx: com u = x², du = 2x dx, fica ∫ cos u du = sin u + C = **sin(x²) + C**.

Num integral definido, muda também os limites: ∫₀² x·e^(x²) dx, com u = x², vai de u = 0 a u = 4: ½∫₀⁴ eᵘ du = **(e⁴ − 1)/2**.

## Técnica 2: integração por partes

É a regra do produto ao contrário:

**∫ u dv = u·v − ∫ v du**

Escolhe para u a parte que fica mais simples ao derivar (polinómios, logaritmos) e para dv a parte fácil de integrar (exponenciais, senos).

∫ x·eˣ dx: u = x, dv = eˣ dx → du = dx, v = eˣ. Fica x·eˣ − ∫ eˣ dx = **(x − 1)eˣ + C**.

∫ ln x dx: u = ln x, dv = dx → x ln x − ∫ x · (1/x) dx = **x ln x − x + C**.

## Técnica 3: frações parciais

Para quocientes de polinómios, decompõe em frações simples:

1/(x² − 1) = 1/((x − 1)(x + 1)) = ½ · (1/(x − 1) − 1/(x + 1))

e portanto ∫ 1/(x² − 1) dx = ½ ln|(x − 1)/(x + 1)| + C.

## Integração numérica

Muitas funções não têm primitiva escrita com funções elementares (por exemplo e^(−x²), a base da distribuição normal). Aí integra-se numericamente. A **regra de Simpson** aproxima f por parábolas e é muito precisa:

```python
import math

def simpson(f, a, b, n=100):          # n tem de ser par
    h = (b - a) / n
    s = f(a) + f(b)
    s += 4 * sum(f(a + i * h) for i in range(1, n, 2))
    s += 2 * sum(f(a + i * h) for i in range(2, n, 2))
    return s * h / 3

print(simpson(math.sin, 0, math.pi))                     # 2.000000...
print(simpson(lambda x: math.exp(-x**2), -5, 5))         # 1.7724538... = √π
```

## Integrais impróprios

Quando um limite de integração é infinito, ou a função explode no intervalo, o integral define-se como limite:

∫₁^∞ 1/x² dx = lim(b→∞) [−1/x]₁ᵇ = lim (1 − 1/b) = **1** (converge)

∫₁^∞ 1/x dx = lim(b→∞) ln b = ∞ (diverge)

## Erros comuns

- Esquecer o + C no integral indefinido.
- Na substituição num integral definido, mudar a variável mas não os limites.
- Aplicar ∫ xⁿ dx = xⁿ⁺¹/(n + 1) com n = −1.
- Calcular ∫₋₁¹ 1/x² dx com o TFC: a função não é contínua em 0, e o integral diverge.
