Uma equação diferencial relaciona uma função com as suas derivadas. Em vez de dizer quanto vale uma quantidade, diz como ela muda: "a população cresce proporcionalmente ao seu tamanho", "a velocidade do café a arrefecer é proporcional à diferença de temperatura". Resolver a equação é descobrir a função. Nesta lição vês os tipos mais simples, como se resolvem à mão e como se resolvem no computador.

## O que é uma equação diferencial

Uma **equação diferencial ordinária** (EDO) envolve uma função desconhecida y(t) e as suas derivadas. A **ordem** é a da derivada mais alta:

- y′ = 3y — primeira ordem;
- y″ + 4y = 0 — segunda ordem.

Uma **solução** é uma função que satisfaz a equação. Normalmente há infinitas (uma família com constantes), e uma **condição inicial** como y(0) = 5 escolhe uma delas. Equação + condição inicial = **problema de valor inicial** (PVI).

Verificar uma solução é só derivar e substituir: y = e^(3t) satisfaz y′ = 3y porque (e^(3t))′ = 3e^(3t).

## Crescimento e decaimento exponencial

A EDO mais importante de todas:

**y′ = k·y**  ⇒  **y(t) = y₀ · e^(kt)**

Com k > 0 é crescimento (juros compostos contínuos, bactérias); com k < 0 é decaimento (radioatividade, descarga de um condensador). O tempo de meia-vida é ln 2 / |k|.

## Equações separáveis

Se a equação se escreve y′ = g(t)·h(y), separa as variáveis e integra cada lado:

dy/h(y) = g(t) dt  ⇒  ∫ dy/h(y) = ∫ g(t) dt

Exemplo: y′ = t·y², y(0) = 1.

- ∫ dy/y² = ∫ t dt → −1/y = t²/2 + C.
- y(0) = 1 → C = −1.
- y = 1/(1 − t²/2) = **2/(2 − t²)**.

Repara que a solução explode em t = √2: as EDOs não lineares podem ter soluções que só existem durante um intervalo finito.

**Lei de arrefecimento de Newton**: T′ = −k(T − Tₐ), com Tₐ a temperatura ambiente. Separando: T(t) = Tₐ + (T₀ − Tₐ)e^(−kt). O café aproxima-se exponencialmente da temperatura da sala.

## Equações lineares de primeira ordem

Têm a forma y′ + p(t)·y = q(t). Resolvem-se com um **fator integrante** μ(t) = e^(∫p dt): multiplicando tudo por μ, o lado esquerdo fica (μ·y)′, e basta integrar.

Exemplo: y′ + 2y = 4. μ = e^(2t). (e^(2t) y)′ = 4e^(2t) → e^(2t) y = 2e^(2t) + C → **y = 2 + C·e^(−2t)**. Qualquer que seja o início, y tende para o equilíbrio 2.

## Segunda ordem: o oscilador

Uma mola com massa m e constante k obedece a m·x″ = −k·x. Com ω = √(k/m):

**x″ + ω²x = 0**  ⇒  **x(t) = A cos(ωt) + B sin(ωt)**

A e B vêm de x(0) e x′(0). É um movimento periódico de período 2π/ω. Se houver atrito (x″ + c·x′ + ω²x = 0), a oscilação vai-se amortecendo. Este mesmo modelo descreve circuitos RLC, suspensões de carros e muitos sistemas de controlo.

## Resolver no computador: o método de Euler

A maior parte das EDOs não tem solução com fórmula. Resolve-se numericamente, aproximando a curva por pequenos segmentos de reta. Se y′ = f(t, y), então com um passo h:

**yₙ₊₁ = yₙ + h · f(tₙ, yₙ)**

É a aproximação linear da lição 3 aplicada repetidamente.

```python
import math

def euler(f, t0, y0, h, n):
    t, y = t0, y0
    for _ in range(n):
        y = y + h * f(t, y)
        t = t + h
    return y

f = lambda t, y: y          # y' = y, y(0) = 1, solução exata e^t
for h in [0.1, 0.01, 0.001]:
    aprox = euler(f, 0, 1.0, h, round(1 / h))
    print(f"h = {h}: y(1) ≈ {aprox:.6f}   erro = {abs(aprox - math.e):.2e}")
```

O erro é proporcional a h: dividir o passo por 10 divide o erro por 10. É um método de **primeira ordem**.

## Métodos melhores: Runge–Kutta

O método de **Runge–Kutta de ordem 4** (RK4) avalia o declive em quatro pontos dentro de cada passo e faz uma média ponderada. O erro passa a ser proporcional a h⁴:

```python
def rk4(f, t0, y0, h, n):
    t, y = t0, y0
    for _ in range(n):
        k1 = f(t, y)
        k2 = f(t + h/2, y + h/2 * k1)
        k3 = f(t + h/2, y + h/2 * k2)
        k4 = f(t + h, y + h * k3)
        y += h / 6 * (k1 + 2*k2 + 2*k3 + k4)
        t += h
    return y

print(abs(rk4(f, 0, 1.0, 0.1, 10) - math.e))   # ~2e-6, com apenas 10 passos
```

Na prática usa-se `scipy.integrate.solve_ivp`, que escolhe o passo automaticamente:

```python
from scipy.integrate import solve_ivp

# oscilador x'' = -4x, escrito como sistema: x' = v, v' = -4x
sol = solve_ivp(lambda t, s: [s[1], -4 * s[0]], (0, math.pi), [1.0, 0.0], rtol=1e-10, atol=1e-12)
print(sol.y[0][-1])    # x(π) = cos(2π) = 1
```

Repara no truque: uma equação de segunda ordem transforma-se num **sistema** de primeira ordem, introduzindo a velocidade como nova variável. É assim que qualquer simulador de física funciona.

## Erros comuns

- Esquecer a constante de integração e depois não conseguir aplicar a condição inicial.
- Dividir por h(y) sem reparar que h(y) = 0 dá soluções constantes (equilíbrios) que se perdem.
- Usar Euler com um passo grande numa simulação longa: o erro acumula-se e, num oscilador, a energia cresce sem parar.
- Achar que todas as soluções existem para todo o t.
