Quase nada no mundo real depende de uma única variável. A temperatura depende da posição (x, y, z) e do tempo; o custo de um modelo de machine learning depende de milhões de pesos. Nesta lição estendemos limites e derivadas a funções de várias variáveis.

## Funções de várias variáveis

Uma função f: ℝⁿ → ℝ recebe um vetor e devolve um número. Para duas variáveis, f(x, y), o gráfico é uma **superfície** z = f(x, y) no espaço.

Exemplos:

- f(x, y) = x² + y²: um paraboloide em forma de taça, com mínimo em (0, 0).
- f(x, y) = x² − y²: uma "sela" — sobe numa direção e desce na outra.
- f(x, y) = √(1 − x² − y²): o hemisfério superior de raio 1; domínio x² + y² ≤ 1.

## Curvas de nível

Desenhar superfícies é difícil; um mapa topográfico é mais prático. A **curva de nível** k é o conjunto dos pontos onde f(x, y) = k. Para x² + y², as curvas de nível são circunferências de raio √k. Curvas muito juntas indicam que a função varia depressa.

```python
import numpy as np
import matplotlib.pyplot as plt

x, y = np.meshgrid(np.linspace(-2, 2, 200), np.linspace(-2, 2, 200))
z = x**2 - y**2
plt.contour(x, y, z, levels=15, cmap="viridis")
plt.gca().set_aspect("equal")
plt.title("Curvas de nível de x² − y²")
plt.savefig("sela.png")
```

## Limites e continuidade

lim((x,y)→(a,b)) f(x, y) = L quer dizer que f(x, y) fica perto de L sempre que (x, y) está perto de (a, b) — **por qualquer caminho**. Em ℝ só havia dois lados; agora há infinitos caminhos.

Exemplo clássico: f(x, y) = xy/(x² + y²) junto de (0, 0).

- Ao longo do eixo x (y = 0): f = 0.
- Ao longo da reta y = x: f = x²/(2x²) = 1/2.

Dois caminhos dão valores diferentes, por isso **o limite não existe**. Para provar que um limite *não* existe basta encontrar dois caminhos diferentes; para provar que existe é preciso um argumento que funcione para todos (por exemplo, coordenadas polares ou majorações).

## Derivadas parciais

A **derivada parcial** em ordem a x, ∂f/∂x (ou fₓ), é a derivada de f quando se trata y como constante:

∂f/∂x (a, b) = lim(h→0) (f(a + h, b) − f(a, b))/h

Geometricamente, é o declive da superfície quando se caminha na direção do eixo x.

Para f(x, y) = x²y + sin(xy):

- ∂f/∂x = 2xy + y·cos(xy)
- ∂f/∂y = x² + x·cos(xy)

As regras são as mesmas da lição 2; só tens de te lembrar de que a "outra" variável é uma constante.

## Derivadas de segunda ordem

Há quatro: fₓₓ, fᵧᵧ, fₓᵧ e fᵧₓ. O **Teorema de Schwarz** diz que, se forem contínuas, as derivadas cruzadas são iguais: fₓᵧ = fᵧₓ. Juntam-se na **matriz Hessiana**:

H = [[fₓₓ, fₓᵧ], [fᵧₓ, fᵧᵧ]]

que faz o papel de f″ em várias variáveis e se usa para classificar pontos críticos.

```python
import sympy as sp

x, y = sp.symbols('x y')
f = x**2 * y + sp.sin(x * y)
print(sp.diff(f, x))                 # 2*x*y + y*cos(x*y)
print(sp.diff(f, y))                 # x**2 + x*cos(x*y)
print(sp.hessian(f, (x, y)))
print(sp.simplify(sp.diff(f, x, y) - sp.diff(f, y, x)))   # 0 (Schwarz)
```

## Plano tangente e aproximação linear

Se f é diferenciável em (a, b), perto desse ponto a superfície parece um plano:

**f(x, y) ≈ f(a, b) + fₓ(a, b)(x − a) + fᵧ(a, b)(y − b)**

Exemplo: f(x, y) = √(x² + y²) em (3, 4): f = 5, fₓ = x/f = 3/5, fᵧ = 4/5. Então f(3.1, 3.9) ≈ 5 + 0.6·0.1 + 0.8·(−0.1) = **4.98** (exato: 4.9819…).

## Regra da cadeia

Se z = f(x, y) e x, y dependem de t, então

**dz/dt = ∂f/∂x · dx/dt + ∂f/∂y · dy/dt**

Cada caminho pelo qual t influencia z contribui com um produto de derivadas, e somam-se as contribuições. É precisamente assim que o *backpropagation* soma gradientes quando um valor é usado em vários sítios de uma rede.

Exemplo: f(x, y) = x²y, com x = cos t, y = sin t. dz/dt = 2xy·(−sin t) + x²·cos t = −2 cos t sin² t + cos³ t.

## Pontos críticos e a Hessiana

Os candidatos a extremos são os pontos onde **todas** as derivadas parciais se anulam. Para os classificar em duas variáveis, calcula D = fₓₓ·fᵧᵧ − (fₓᵧ)² (o determinante da Hessiana):

- D > 0 e fₓₓ > 0 → mínimo local;
- D > 0 e fₓₓ < 0 → máximo local;
- D < 0 → ponto de sela;
- D = 0 → o teste não decide.

Para x² − y² em (0, 0): fₓₓ = 2, fᵧᵧ = −2, fₓᵧ = 0, D = −4 < 0: é uma sela, como no gráfico.

## Erros comuns

- Testar o limite só ao longo dos eixos e concluir que existe.
- Ao calcular ∂f/∂x, derivar também os termos que só têm y (são constantes, a derivada é 0).
- Esquecer um dos caminhos na regra da cadeia.
- Achar que todos os pontos críticos são máximos ou mínimos: em várias variáveis, as selas são muito comuns.
