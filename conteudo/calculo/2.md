A derivada mede a rapidez com que uma função muda. É a velocidade quando a função é uma posição, a taxa de crescimento de uma população, a sensibilidade do erro de uma rede neuronal a cada peso. Nesta lição definimos a derivada com um limite e aprendemos as regras que permitem calculá-la sem voltar à definição.

## Taxa de variação média e instantânea

Entre x = a e x = a + h, a função muda f(a + h) − f(a). A **taxa de variação média** é

(f(a + h) − f(a)) / h

que é o declive da reta secante que passa por (a, f(a)) e (a + h, f(a + h)). Fazendo h → 0, a secante torna-se a **reta tangente**, e o declive passa a ser a **derivada**:

**f′(a) = lim(h→0) (f(a + h) − f(a)) / h**

Se o limite existe, f é **diferenciável** em a. Outras notações: df/dx, dy/dx, Df.

## Calcular pela definição

Para f(x) = x²:

(f(x + h) − f(x))/h = ((x + h)² − x²)/h = (2xh + h²)/h = 2x + h → **2x**

Para f(x) = 1/x:

(1/(x + h) − 1/x)/h = (x − (x + h))/(h·x·(x + h)) = −1/(x(x + h)) → **−1/x²**

## Derivada numérica

O computador não calcula limites, mas pode usar um h pequeno. A **diferença central** é muito mais precisa do que a diferença para a frente:

```python
import math

def derivada_frente(f, x, h=1e-5):
    return (f(x + h) - f(x)) / h

def derivada_central(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)

x = 1.0
exato = math.cos(x)                       # (sin x)' = cos x
print(abs(derivada_frente(math.sin, x) - exato))    # erro ~ 4e-6
print(abs(derivada_central(math.sin, x) - exato))   # erro ~ 1e-11
```

O erro da diferença para a frente é proporcional a h; o da central, a h². Mas h não pode ser pequeno demais: com h = 10⁻¹⁵, a subtração f(x + h) − f(x) perde quase todos os algarismos significativos.

## Derivadas que deves saber de cor

| f(x) | f′(x) |
|---|---|
| c (constante) | 0 |
| xⁿ | n·xⁿ⁻¹ |
| eˣ | eˣ |
| aˣ | aˣ · ln a |
| ln x | 1/x |
| sin x | cos x |
| cos x | −sin x |
| tan x | 1/cos²x |
| arctan x | 1/(1 + x²) |

A regra xⁿ vale para qualquer expoente real: (√x)′ = (x^(1/2))′ = 1/(2√x).

## Regras de derivação

- **Linearidade**: (a·f + b·g)′ = a·f′ + b·g′
- **Produto**: (f·g)′ = f′·g + f·g′
- **Quociente**: (f/g)′ = (f′·g − f·g′)/g²
- **Cadeia**: (f(g(x)))′ = f′(g(x)) · g′(x)

A regra da cadeia é a mais importante para informática: é exatamente o que o *backpropagation* faz numa rede neuronal, multiplicando derivadas camada a camada.

Exemplos:

- (x² · sin x)′ = 2x · sin x + x² · cos x
- (e^(3x²))′ = e^(3x²) · 6x
- (ln(1 + x²))′ = 2x/(1 + x²)

## Derivação simbólica

O SymPy aplica estas regras por ti, o que é ótimo para confirmar resultados:

```python
import sympy as sp

x = sp.symbols('x')
print(sp.diff(x**2 * sp.sin(x), x))          # x**2*cos(x) + 2*x*sin(x)
print(sp.diff(sp.exp(3*x**2), x))            # 6*x*exp(3*x**2)
print(sp.simplify(sp.diff(sp.log(1 + x**2), x)))   # 2*x/(x**2 + 1)
```

## Derivadas de ordem superior

A derivada de f′ é a **segunda derivada** f″. Se f é a posição, f′ é a velocidade e f″ é a aceleração. f″ também diz para onde o gráfico "curva": f″ > 0 é côncavo para cima (forma de ∪), f″ < 0 é côncavo para baixo (∩).

## Diferenciável implica contínua (mas não o contrário)

Se f é diferenciável em a, então é contínua em a. O recíproco é falso: |x| é contínua em 0, mas o declive à esquerda é −1 e à direita é 1, por isso não há derivada em 0. Gráficos com "bicos" não são diferenciáveis nesses pontos. A função ReLU, max(0, x), usada em redes neuronais, tem exatamente este problema em 0; na prática escolhe-se 0 ou 1 como derivada nesse ponto.

## Erros comuns

- Derivar um produto como produto das derivadas: (f·g)′ ≠ f′·g′.
- Esquecer a derivada interior na regra da cadeia: (sin 2x)′ = 2 cos 2x, não cos 2x.
- Tratar eˣ como potência: (eˣ)′ não é x·eˣ⁻¹.
- Escolher h demasiado pequeno numa derivada numérica.
