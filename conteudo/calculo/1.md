O Cálculo estuda como as coisas mudam. Antes de medir a mudança, precisamos de duas ideias: **função**, que liga cada entrada a uma saída, e **limite**, que diz para onde vai a saída quando a entrada se aproxima de um valor. Tudo o resto — derivadas, integrais, séries — é construído com limites.

## Funções

Uma **função** f: A → B associa a cada elemento x do **domínio** A exatamente um valor f(x) no conjunto de chegada B. O conjunto dos valores que f realmente toma chama-se **contradomínio** (ou imagem).

| Função | Domínio | Contradomínio |
|---|---|---|
| f(x) = x² | ℝ | [0, +∞[ |
| f(x) = √x | [0, +∞[ | [0, +∞[ |
| f(x) = 1/x | ℝ \ {0} | ℝ \ {0} |
| f(x) = ln x | ]0, +∞[ | ℝ |

Num programa, uma função matemática é uma função pura: a mesma entrada dá sempre a mesma saída. Encontrar o domínio é perguntar "para que valores é que isto não rebenta?": não dividir por zero, não tirar raiz de negativos, não tirar logaritmo de zero ou negativos.

As funções que vais usar a toda a hora: polinómios, racionais (quociente de polinómios), exponencial eˣ, logaritmo ln x, e as trigonométricas sin, cos, tan. Também se combinam por **composição**: (f ∘ g)(x) = f(g(x)).

## A ideia de limite

Considera f(x) = (x² − 1)/(x − 1). Em x = 1 dá 0/0, não está definida. Mas o que acontece *perto* de 1?

```python
f = lambda x: (x**2 - 1) / (x - 1)
for h in [0.1, 0.01, 0.001, 0.0001]:
    print(f"{1 - h:.4f} -> {f(1 - h):.6f}    {1 + h:.4f} -> {f(1 + h):.6f}")
```

Os valores aproximam-se de 2, dos dois lados. Escrevemos **lim(x→1) f(x) = 2**. De facto, para x ≠ 1, (x² − 1)/(x − 1) = (x − 1)(x + 1)/(x − 1) = x + 1, que vale 2 em x = 1.

O limite não quer saber do valor *em* x = a, só dos valores *perto* de a.

## A definição rigorosa (ε–δ)

"Perto" precisa de ser preciso. Dizemos que lim(x→a) f(x) = L quando:

> para todo o ε > 0 existe δ > 0 tal que, se 0 < |x − a| < δ, então |f(x) − L| < ε.

Lê-se como um jogo: o adversário escolhe uma tolerância ε na saída; tu tens de responder com uma tolerância δ na entrada que garanta essa precisão. Se ganhas sempre, o limite é L.

Exemplo: lim(x→3) (2x + 1) = 7. Dado ε, queremos |2x + 1 − 7| = 2|x − 3| < ε. Basta escolher δ = ε/2.

## Regras de cálculo

Se lim f = L e lim g = M (com x → a), então:

- lim (f ± g) = L ± M
- lim (f · g) = L · M
- lim (f / g) = L / M, se M ≠ 0
- para polinómios e outras funções contínuas, basta substituir: lim(x→2) (x³ − x) = 6.

Quando a substituição dá **0/0** ou **∞/∞** (uma *indeterminação*), é preciso trabalhar: fatorizar, multiplicar pelo conjugado, ou usar limites notáveis.

Dois limites notáveis que vais encontrar em todo o lado:

- lim(x→0) sin(x)/x = 1
- lim(x→0) (eˣ − 1)/x = 1

## Limites laterais e no infinito

O limite à esquerda, lim(x→a⁻), só olha para x < a; o limite à direita, lim(x→a⁺), para x > a. O limite existe se e só se os dois existem e são iguais. Por exemplo, para f(x) = |x|/x, lim(x→0⁻) = −1 e lim(x→0⁺) = 1, por isso lim(x→0) não existe.

Limites no infinito descrevem o comportamento para x muito grande. lim(x→+∞) 1/x = 0. Para quocientes de polinómios, compara os termos de maior grau:

lim(x→+∞) (3x² + 5)/(x² − 4x) = 3, porque domina 3x²/x².

## Continuidade

f é **contínua em a** quando três coisas se verificam: f(a) existe, lim(x→a) f(x) existe, e são iguais. Intuitivamente, o gráfico desenha-se sem levantar o lápis.

São contínuas no seu domínio: polinómios, racionais, eˣ, ln, sin, cos, e somas, produtos, quocientes e composições destas.

O **Teorema do Valor Intermédio** (TVI): se f é contínua em [a, b] e f(a), f(b) têm sinais contrários, então existe c em ]a, b[ com f(c) = 0. É a base do método da bisseção, um dos algoritmos mais simples e robustos para encontrar raízes:

```python
def bissecao(f, a, b, tol=1e-10):
    assert f(a) * f(b) < 0, "f(a) e f(b) têm de ter sinais contrários"
    while b - a > tol:
        m = (a + b) / 2
        if f(a) * f(m) <= 0:
            b = m
        else:
            a = m
    return (a + b) / 2

print(bissecao(lambda x: x**2 - 2, 0, 2))   # 1.41421356...  (√2)
```

Cada iteração corta o intervalo a meio, por isso para precisão 10⁻¹⁰ a partir de um intervalo de comprimento 2 bastam cerca de 35 iterações.

## Erros comuns

- Achar que o limite é f(a). Só é assim se f for contínua em a.
- Concluir que um limite não existe porque a substituição dá 0/0. 0/0 quer dizer "ainda não sei".
- Esquecer os limites laterais em funções definidas por ramos ou com |x|.
- Confiar só numa tabela numérica: com h muito pequeno, os erros de vírgula flutuante podem estragar o resultado (experimenta h = 10⁻¹⁵ no exemplo acima).
