No trabalho, o cálculo aparece quase sempre dentro de código: aproximações, otimização, simulações. Esta lição treina-te a **ler** esse código, a **prever** o que dá e a **encontrar** os erros que fazem um resultado parecer certo sem o ser.

## Ler e prever: derivada numérica

```python run
def derivada(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)

def f(x):
    return x ** 3 - 2 * x

print(round(derivada(f, 2), 4))
print(round(derivada(f, 0), 4))
```

Antes de correr: qual é a derivada de x³ − 2x? Quanto vale em x = 2 e em x = 0? A função usa a **diferença central**, que aproxima f'(x) com um erro da ordem de h².

## Encontra o erro: método de Newton

Este programa devia encontrar a raiz quadrada de 2 resolvendo x² − 2 = 0, mas não converge para o valor certo.

```python run
def newton(f, df, x0, passos=20):
    x = x0
    for _ in range(passos):
        x = x - df(x) / f(x)
    return x

print(newton(lambda x: x**2 - 2, lambda x: 2*x, 1.0))
```

**Encontra o erro:** a fórmula está invertida. Newton é x ← x − f(x)/f'(x), e o código faz x − f'(x)/f(x). Corrige para `x = x - f(x) / df(x)` e dá `1.4142135623730951`.

```python
def integral(f, a, b, n):
    h = (b - a) / n
    soma = (f(a) + f(b)) / 2
    for i in range(1, n):
        soma += f(a + i * h)
    return soma * h
```
