Saber derivar serve para duas coisas muito práticas: encontrar o melhor valor possível de uma quantidade (otimização) e substituir uma função complicada por uma reta perto de um ponto (aproximação linear). Desta segunda ideia nasce o método de Newton, que as bibliotecas numéricas usam para resolver equações.

## Crescimento e decrescimento

O sinal da derivada diz o sentido da função:

- f′(x) > 0 num intervalo → f é **crescente** aí;
- f′(x) < 0 → f é **decrescente**;
- f′(x) = 0 → tangente horizontal: candidato a máximo ou mínimo.

Os pontos onde f′(x) = 0 ou onde f′ não existe chamam-se **pontos críticos**.

## Máximos e mínimos

Num ponto crítico c, há três testes possíveis:

1. **Teste da primeira derivada**: se f′ passa de + para −, c é máximo local; de − para +, mínimo local; se não muda de sinal, não é extremo (ex.: x³ em 0).
2. **Teste da segunda derivada**: se f″(c) > 0, mínimo local; se f″(c) < 0, máximo local; se f″(c) = 0, o teste não decide.
3. **Extremos absolutos num intervalo fechado [a, b]**: se f é contínua, o máximo e o mínimo absolutos existem (Teorema de Weierstrass) e estão nos pontos críticos ou nas extremidades. Calcula f em todos e compara.

Exemplo: f(x) = x³ − 3x em [−2, 3].

- f′(x) = 3x² − 3 = 0 → x = ±1.
- f(−2) = −2, f(−1) = 2, f(1) = −2, f(3) = 18.
- Máximo absoluto 18 em x = 3; mínimo absoluto −2, atingido em x = −2 e x = 1.

## Um problema de otimização

Queres fazer uma caixa sem tampa com uma folha quadrada de 30 cm de lado, cortando quadrados de lado x nos cantos e dobrando. Que x dá o maior volume?

1. **Modelo**: V(x) = x · (30 − 2x)², com 0 ≤ x ≤ 15.
2. **Derivada**: V′(x) = (30 − 2x)² − 4x(30 − 2x) = (30 − 2x)(30 − 6x).
3. **Pontos críticos**: x = 15 (volume 0) ou **x = 5**.
4. **Verificação**: V(0) = V(15) = 0 e V(5) = 5 · 20² = 2000 cm³. O máximo é em x = 5.

O passo mais difícil é quase sempre o primeiro: escrever a quantidade a otimizar como função de **uma** variável, usando as restrições do problema.

## Aproximação linear

Perto de a, o gráfico de uma função diferenciável é quase igual à sua tangente:

**f(x) ≈ f(a) + f′(a)·(x − a)**

Exemplo: √4.1 com f(x) = √x e a = 4: f(4) = 2, f′(4) = 1/(2·2) = 1/4, por isso √4.1 ≈ 2 + 0.1/4 = **2.025**. O valor exato é 2.02485…

Esta ideia aparece por todo o lado: na física (sin θ ≈ θ para ângulos pequenos), na propagação de erros de medida (Δf ≈ f′(x)·Δx) e é o primeiro termo da série de Taylor, que vês na lição 5.

## O método de Newton

Para resolver f(x) = 0, começa num palpite x₀. Substitui f pela sua tangente em x₀ e resolve a equação da reta, que é fácil:

0 = f(x₀) + f′(x₀)(x − x₀)  ⇒  **x₁ = x₀ − f(x₀)/f′(x₀)**

Repete. Quando converge, converge **quadraticamente**: o número de algarismos certos mais ou menos duplica a cada passo.

```python
def newton(f, df, x0, tol=1e-12, max_iter=50):
    x = x0
    for i in range(max_iter):
        passo = f(x) / df(x)
        x -= passo
        print(f"iteração {i + 1}: x = {x:.15f}")
        if abs(passo) < tol:
            return x
    raise RuntimeError("não convergiu")

import math
r = newton(lambda x: x**2 - 2, lambda x: 2 * x, x0=1.0)
print("erro:", abs(r - math.sqrt(2)))
```

Saída: 1.5, 1.41666…, 1.41421568…, 1.41421356237469…, 1.41421356237310 — em 5 iterações chega à precisão da máquina. A bisseção da lição 1 precisava de mais de 30.

Newton pode falhar: se f′(xₖ) ≈ 0 o passo explode; se o palpite inicial está longe, pode saltar para outra raiz ou oscilar. Por isso as bibliotecas (por exemplo `scipy.optimize.brentq`) combinam Newton com bisseção, que nunca falha.

## Erros comuns

- Esquecer de verificar as extremidades do intervalo nos extremos absolutos.
- Achar que f′(c) = 0 garante um extremo (x³ em 0 é um contraexemplo).
- Usar a aproximação linear longe do ponto a: o erro cresce com (x − a)².
- No método de Newton, não limitar o número de iterações.
