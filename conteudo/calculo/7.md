O gradiente junta todas as derivadas parciais num único vetor que aponta na direção em que a função sobe mais depressa. Andar no sentido contrário, passo a passo, é a **descida do gradiente**: o algoritmo que treina praticamente todas as redes neuronais.

## O vetor gradiente

Para f(x, y), o **gradiente** é o vetor das derivadas parciais:

**∇f(x, y) = (∂f/∂x, ∂f/∂y)**

e em n variáveis, ∇f = (∂f/∂x₁, …, ∂f/∂xₙ). Lê-se "nabla f" ou "grad f".

Para f(x, y) = x² + 3y²: ∇f = (2x, 6y). Em (1, 1), ∇f = (2, 6).

## Derivada direcional

A derivada parcial mede a variação ao longo dos eixos. Para uma direção qualquer, dada por um vetor **unitário** u, a **derivada direcional** é

**Dᵤf = ∇f · u**

(o produto interno do gradiente com a direção). Exemplo: f = x² + 3y² em (1, 1), na direção u = (3/5, 4/5): Dᵤf = 2·3/5 + 6·4/5 = 30/5 = **6**.

## Três propriedades que explicam tudo

Como ∇f · u = |∇f| · |u| · cos θ = |∇f| cos θ:

1. A derivada direcional é **máxima** quando u aponta no sentido de ∇f (θ = 0). O gradiente aponta para a subida mais íngreme, e |∇f| é esse declive máximo.
2. É **mínima** (a descida mais íngreme) no sentido de −∇f.
3. É **zero** perpendicularmente a ∇f. Por isso o gradiente é sempre perpendicular às curvas de nível.

Num mapa topográfico, o gradiente aponta "monte acima", cortando as curvas de nível em ângulo reto. Num ponto crítico, ∇f = 0: não há direção de subida.

## A descida do gradiente

Queremos minimizar f. Começamos num ponto x₀ e damos passos no sentido de −∇f:

**xₖ₊₁ = xₖ − η · ∇f(xₖ)**

O número η > 0 é a **taxa de aprendizagem** (*learning rate*). Paramos quando o gradiente é quase zero ou ao fim de um número fixo de passos.

```python
import numpy as np

def f(p):
    x, y = p
    return (x - 3)**2 + 10 * (y + 1)**2

def grad(p):
    x, y = p
    return np.array([2 * (x - 3), 20 * (y + 1)])

def descida(grad, p0, eta, passos):
    p = np.array(p0, dtype=float)
    for _ in range(passos):
        p = p - eta * grad(p)
    return p

p = descida(grad, [0.0, 0.0], eta=0.05, passos=200)
print(p, f(p))          # ≈ [3, -1], f ≈ 0
```

O mínimo exato é (3, −1). A descida não precisa de o saber: só precisa de conseguir calcular o gradiente.

## A escolha da taxa de aprendizagem

É o parâmetro mais delicado:

| η | O que acontece |
|---|---|
| muito pequeno | converge, mas demora uma eternidade |
| adequado | converge depressa |
| grande demais | os passos saltam por cima do mínimo e divergem |

No exemplo acima, na direção y a função é 10·(y + 1)², com segunda derivada 20. Cada passo multiplica o erro em y por (1 − 20η). Se η > 2/20 = 0.1, |1 − 20η| > 1 e o método **diverge**. Experimenta:

```python
for eta in [0.01, 0.05, 0.09, 0.11]:
    p = descida(grad, [0.0, 0.0], eta, 100)
    print(eta, p, f(p))
```

Com 0.11 os valores explodem. Funções "alongadas" (curvas de nível muito elípticas) obrigam a um η pequeno por causa da direção mais curva, o que torna a descida lenta na direção menos curva. É por isso que existem variantes como o **momento** e o **Adam**, e por isso se normalizam os dados antes de treinar um modelo.

## Descida do gradiente estocástica

Em machine learning, a função a minimizar é uma média do erro sobre milhões de exemplos: L(w) = (1/N) Σ ℓ(w; exemplo i). Calcular o gradiente exato a cada passo seria caríssimo. A **descida estocástica** (SGD) usa em cada passo o gradiente de um pequeno lote (*mini-batch*) aleatório de exemplos. Cada passo é ruidoso, mas muito barato, e em média aponta na direção certa.

Exemplo: ajustar uma reta y = w·x + b a dados minimizando o erro quadrático médio:

```python
rng = np.random.default_rng(0)
X = rng.uniform(0, 10, 500)
Y = 2.5 * X - 1 + rng.normal(0, 1, 500)    # dados com ruído à volta de y = 2.5x − 1

w, b, eta = 0.0, 0.0, 0.01
for epoca in range(200):
    for i in rng.permutation(500).reshape(-1, 50):   # lotes de 50
        erro = w * X[i] + b - Y[i]
        w -= eta * 2 * np.mean(erro * X[i])
        b -= eta * 2 * np.mean(erro)
print(w, b)    # perto de 2.5 e −1
```

## Mínimos locais e selas

A descida do gradiente encontra um ponto onde ∇f ≈ 0, mas não garante que seja o mínimo **global**: pode ficar presa num mínimo local, ou abrandar muito perto de uma sela. Se f for **convexa** (por exemplo, a Hessiana é sempre semidefinida positiva), todo o mínimo local é global, e o problema é "fácil". O erro quadrático da regressão linear é convexo; o erro de uma rede neuronal não é.

## Erros comuns

- Usar u não unitário na derivada direcional.
- Subir em vez de descer: o passo é −η∇f, não +η∇f.
- Escolher η grande demais e concluir que "o algoritmo não funciona".
- Esquecer que a descida só garante um ponto estacionário, não o mínimo global.
