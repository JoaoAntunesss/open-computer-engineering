Em física computacional, o programa é a experiência. Um erro de unidades ou de passo de tempo dá resultados com ótimo aspeto e completamente errados. Ler o código de uma simulação e prever o que deve sair (por estimativa física) é a melhor defesa.

## Ler e prever: queda livre passo a passo

```python run
g = 9.8
dt = 0.01
y, v, t = 100.0, 0.0, 0.0     # altura em m, velocidade em m/s
while y > 0:
    v = v - g * dt
    y = y + v * dt
    t = t + dt
print(round(t, 2), round(v, 1))
```

Antes de correr, calcula com as fórmulas: quanto tempo demora um corpo a cair 100 m sem atrito, e com que velocidade chega ao chão? O resultado da simulação deve estar perto.

## Encontra o erro: energia que aparece do nada

Este oscilador (mola sem atrito) devia conservar a energia, mas ela cresce a cada passo.

```python run
k, m, dt = 1.0, 1.0, 0.1
x, v = 1.0, 0.0
for passo in range(1, 301):
    a = -k / m * x
    x_novo = x + v * dt
    v = v + a * dt
    x = x_novo
    if passo % 100 == 0:
        print(passo, round(0.5 * m * v**2 + 0.5 * k * x**2, 3))
```

A energia inicial é 0,5. Olha para a ordem das atualizações: que valor de `v` usa a nova posição?
