Um computador só sabe guardar dois estados: ligado e desligado, 1 e 0. Tudo o resto (números, texto, imagens) é uma forma combinada de escrever com esses dois símbolos. Nesta lição aprendemos a ler e a escrever números em binário e a representar negativos.

## Bases de numeração

Em base 10, 345 = 3·10² + 4·10¹ + 5·10⁰. Em base 2 é igual, com potências de 2:

1011₂ = 1·8 + 0·4 + 1·2 + 1·1 = 11

Para converter de decimal para binário, divide sucessivamente por 2 e lê os restos de baixo para cima: 13 → 6 r1 → 3 r0 → 1 r1 → 0 r1, logo 13 = 1101₂.

**Hexadecimal** (base 16, algarismos 0–9 e A–F) agrupa 4 bits: 1101 0110₂ = D6₁₆. É por isso que as cores web se escrevem #FF8800.

```python
print(bin(13), hex(214), int('1101', 2), int('D6', 16))   # 0b1101 0xd6 13 214
```

## Tamanho fixo

O hardware trabalha com um número fixo de bits. Com n bits sem sinal representam-se os valores de 0 a 2ⁿ − 1: um byte (8 bits) vai de 0 a 255. Somar 1 a 255 num byte dá 0: é um **transbordo** (*overflow*).

## Números negativos: complemento para dois

A forma usada por quase todos os processadores é o **complemento para dois**. Com n bits, o bit mais à esquerda vale −2ⁿ⁻¹ em vez de +2ⁿ⁻¹. Em 8 bits:

- 0000 0101 = 5
- 1111 1011 = −128 + 64 + 32 + 16 + 8 + 2 + 1 = −5

Para negar um número: inverte todos os bits e soma 1. 5 = 0000 0101 → 1111 1010 → 1111 1011 = −5.

Com 8 bits vai-se de −128 a 127. A grande vantagem: a soma é a mesma para números com e sem sinal, por isso o mesmo circuito somador serve para os dois.

## Transbordo com sinal

Em complemento para dois há transbordo quando se somam dois números do mesmo sinal e o resultado tem o sinal contrário: 100 + 100 em 8 bits dá −56. Em C, o transbordo de inteiros com sinal é comportamento indefinido; em Java e Python (que usa inteiros sem limite) é diferente.

## Erros comuns

- Ler um número em complemento para dois como se fosse sem sinal.
- Esquecer de somar 1 depois de inverter os bits.
- Achar que 0x10 vale 10 (vale 16).
- Ignorar o tamanho: −1 em 8 bits é 1111 1111, em 16 bits é 1111 1111 1111 1111.
