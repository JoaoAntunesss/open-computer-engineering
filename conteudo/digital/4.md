Os circuitos **combinatórios** calculam a saída só a partir das entradas atuais, sem memória. São as peças com que se fazem as contas e as escolhas dentro de um processador.

## Meio somador e somador completo

O **meio somador** soma dois bits:

- soma S = A XOR B
- transporte C = A · B

O **somador completo** soma três bits (A, B e o transporte que vem de trás, Cᵢₙ):

- S = A XOR B XOR Cᵢₙ
- Cₒᵤₜ = A·B + Cᵢₙ·(A XOR B)

## Somador de n bits

Ligando n somadores completos em cadeia, cada um a passar o transporte ao seguinte, soma-se números de n bits. É o **somador de transporte em cascata** (*ripple carry*). O problema: o último bit tem de esperar pelos anteriores, por isso o tempo cresce com n. Os somadores de **antecipação de transporte** (*carry lookahead*) calculam os transportes em paralelo e são muito mais rápidos.

Com complemento para dois, para subtrair A − B basta somar A ao negativo de B: inverte os bits de B e põe Cᵢₙ = 1.

```python
def somador(a, b, n=8):
    carry, out = 0, 0
    for i in range(n):
        x, y = (a >> i) & 1, (b >> i) & 1
        s = x ^ y ^ carry
        carry = (x & y) | (carry & (x ^ y))
        out |= s << i
    return out, carry
print(somador(100, 27))   # (127, 0)
```

## Multiplexer

Um **multiplexer** (MUX) escolhe uma de várias entradas consoante um sinal de seleção. Um MUX 2:1: Y = S̄·A + S·B. Um MUX 4:1 usa 2 bits de seleção. É o "if" do hardware.

## Descodificador e codificador

- Um **descodificador** n:2ⁿ ativa exatamente uma de 2ⁿ saídas consoante o número de entrada. Usa-se para escolher qual chip de memória responde a um endereço.
- Um **codificador** faz o inverso: diz qual das entradas está ativa.

## Comparadores

Um comparador de igualdade de n bits faz XOR bit a bit e verifica que todos dão 0. Para A < B, usa-se a subtração e olha-se para o sinal.

## Erros comuns

- Esquecer o transporte de entrada no somador completo.
- Ignorar o tempo de propagação: num circuito real, as saídas demoram a estabilizar.
- Trocar a ordem das entradas de seleção de um MUX.
