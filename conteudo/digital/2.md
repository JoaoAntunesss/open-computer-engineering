A álgebra de Boole é a matemática dos valores verdadeiro e falso, e as portas lógicas são a sua versão física, feita de transístores. Com estas duas ideias desenha-se qualquer circuito digital.

## Operações básicas

| A | B | A·B (E) | A+B (OU) | Ā (NÃO A) |
|---|---|---|---|---|
| 0 | 0 | 0 | 0 | 1 |
| 0 | 1 | 0 | 1 | 1 |
| 1 | 0 | 0 | 1 | 0 |
| 1 | 1 | 1 | 1 | 0 |

Também se usam **NAND** (NÃO-E), **NOR** (NÃO-OU) e **XOR** (OU exclusivo: 1 quando as entradas são diferentes).

## Leis úteis

- Identidade: A·1 = A, A + 0 = A.
- Nulo: A·0 = 0, A + 1 = 1.
- Idempotência: A·A = A, A + A = A.
- Complemento: A·Ā = 0, A + Ā = 1.
- Distributiva: A·(B + C) = A·B + A·C, e também A + B·C = (A + B)·(A + C).
- Absorção: A + A·B = A.
- **De Morgan**: (A·B)‾ = Ā + B̄ e (A + B)‾ = Ā·B̄.

## Da tabela à expressão

Qualquer tabela de verdade se transforma numa expressão: para cada linha com saída 1, escreve o produto das entradas (negando as que valem 0) e soma tudo. É a **soma de produtos** (forma canónica disjuntiva).

Exemplo, a função "maioria de três" (1 se pelo menos duas entradas são 1):

M = Ā·B·C + A·B̄·C + A·B·C̄ + A·B·C, que simplifica para **A·B + A·C + B·C**.

## Portas universais

Só com portas NAND (ou só com NOR) constrói-se qualquer circuito:

- NÃO A = A NAND A
- A E B = (A NAND B) NAND (A NAND B)
- A OU B = (A NAND A) NAND (B NAND B)

É por isso que o curso Nand2Tetris começa com uma única porta e acaba num computador.

```python
nand = lambda a, b: 1 - (a & b)
nao  = lambda a: nand(a, a)
e    = lambda a, b: nao(nand(a, b))
ou   = lambda a, b: nand(nao(a), nao(b))
print([ou(a, b) for a in (0, 1) for b in (0, 1)])   # [0, 1, 1, 1]
```

## Erros comuns

- Aplicar De Morgan sem trocar E por OU.
- Esquecer que A + B·C = (A + B)(A + C), que não existe na álgebra dos números.
- Confundir XOR com OU.
