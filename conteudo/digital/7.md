A ALU (unidade aritmética e lógica) é a parte do processador que faz as contas. O **caminho de dados** (*datapath*) é o conjunto de registos, ALU, memória e ligações por onde os dados circulam ao executar uma instrução.

## A ALU

Uma ALU recebe dois operandos A e B e um código de operação (*opcode*) que escolhe o que fazer: somar, subtrair, E, OU, XOR, comparar. Por dentro, calcula vários resultados em paralelo e um multiplexer escolhe o pedido.

Além do resultado, gera **indicadores** (*flags*):

- **Z** (zero): o resultado é 0.
- **N** (negativo): o bit de sinal é 1.
- **C** (*carry*): houve transporte para fora.
- **V** (*overflow*): transbordo com sinal.

As instruções de salto condicional ("salta se igual") olham para estes indicadores.

```python
def alu(a, b, op, n=8):
    m = (1 << n) - 1
    r = {'ADD': a + b, 'SUB': a - b, 'AND': a & b, 'OR': a | b, 'XOR': a ^ b}[op]
    res = r & m
    return res, {'Z': res == 0, 'N': res >> (n - 1) == 1, 'C': r > m or r < 0}
print(alu(5, 5, 'SUB'))   # (0, {'Z': True, 'N': False, 'C': False})
```

## O banco de registos

O processador tem um pequeno conjunto de registos rápidos (16 ou 32, normalmente). O **banco de registos** permite ler dois registos e escrever um no mesmo ciclo, para instruções como ADD R1, R2, R3 (R1 = R2 + R3).

## O ciclo de uma instrução

1. **Buscar** (*fetch*): ler a instrução da memória no endereço do contador de programa (PC), e somar ao PC.
2. **Descodificar**: perceber que operação é e que registos usa.
3. **Executar**: a ALU calcula.
4. **Memória**: se for LOAD ou STORE, aceder à memória.
5. **Escrever**: guardar o resultado no registo de destino.

## Caminho de dados e unidade de controlo

O caminho de dados é o "músculo"; a **unidade de controlo** é o "cérebro": uma máquina de estados (ou uma tabela) que, a partir da instrução, liga os sinais certos (que operação a ALU faz, que registo escreve, se lê a memória).

Num processador de **ciclo único**, cada instrução faz tudo num ciclo longo. Num processador com ***pipeline***, as cinco fases de instruções diferentes sobrepõem-se, como numa linha de montagem.

## Erros comuns

- Confundir C (transbordo sem sinal) com V (transbordo com sinal).
- Esquecer que o PC avança antes de a instrução executar (os saltos são relativos ao PC já incrementado).
- Achar que a ALU guarda valores: é combinatória; quem guarda são os registos.
