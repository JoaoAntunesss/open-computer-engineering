Os circuitos digitais descrevem-se cada vez mais com código (Verilog, VHDL) e simulam-se com programas. Ler uma função lógica em código e prever a tabela de verdade é o mesmo raciocínio que fazes no papel, com a vantagem de poderes confirmar.

## Ler e prever: um somador completo

```python run
def somador_completo(a, b, cin):
    s = a ^ b ^ cin
    cout = (a & b) | (cin & (a ^ b))
    return s, cout

for a in (0, 1):
    for b in (0, 1):
        for c in (0, 1):
            print(a, b, c, "->", *somador_completo(a, b, c))
```

Antes de correr, escreve à mão a tabela de verdade das saídas `s` e `cout` para as 8 combinações.

## Encontra o erro: somador de 4 bits

Este código liga quatro somadores completos para somar números de 4 bits, mas o resultado está errado.

```python run
def somador_completo(a, b, cin):
    return a ^ b ^ cin, (a & b) | (cin & (a ^ b))

def soma4(x, y):
    resultado, transporte = 0, 0
    for i in range(4):
        a = (x >> i) & 1
        b = (y >> i) & 1
        s, transporte = somador_completo(a, b, 0)
        resultado |= s << i
    return resultado, transporte

print(soma4(5, 3))   # esperado: (8, 0)
```

## Em Verilog

O mesmo somador completo numa linguagem de descrição de hardware. Lê e compara com o Python:

```verilog
module somador_completo(input a, b, cin, output s, cout);
  assign s = a ^ b ^ cin;
  assign cout = (a & b) | (cin & (a ^ b));
endmodule
```

## Escreve tu

Escreve `multiplexer(s, a, b)` que devolve `a` se `s` for 0 e `b` se for 1, **só com** `&`, `|` e `^` (sem `if`). Testa as 8 combinações.

??? Soluções
**Ler e prever:** `s` é 1 quando há um número ímpar de uns; `cout` é 1 quando há pelo menos dois uns. Ex.: 1 1 0 → `0 1`; 1 1 1 → `1 1`.

**Encontra o erro:** o transporte de cada bit não é passado ao seguinte: a chamada usa sempre `0` como `cin`. Corrige para `somador_completo(a, b, transporte)`. Com o erro, 5 + 3 (101 + 011) dá `(6, 0)`: o 6 vem de perder o transporte do bit 0; corrigido dá `(8, 0)`.

**Escreve tu:**
```python
def multiplexer(s, a, b):
    nao_s = s ^ 1
    return (nao_s & a) | (s & b)
```
