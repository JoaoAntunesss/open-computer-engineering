Uma **máquina de estados finitos** (MEF) é um circuito sequencial com um número fixo de estados que muda de estado consoante as entradas. Semáforos, máquinas de vender, protocolos de rede e o controlo de um processador são MEF.

## Ingredientes

- Um conjunto de **estados** (por exemplo, Vermelho, Verde, Amarelo).
- As **entradas** (um botão, um sensor, um temporizador).
- Uma **função de transição**: estado atual + entradas → próximo estado.
- As **saídas** (que luzes acender).

## Moore e Mealy

- **Moore**: as saídas dependem só do estado atual. Mais simples e previsível.
- **Mealy**: as saídas dependem do estado e das entradas. Pode reagir um ciclo mais cedo e precisar de menos estados.

## Exemplo: detetar a sequência 101

Entrada: um bit por ciclo. Saída: 1 quando os últimos três bits foram 1, 0, 1.

| Estado | Significado | entrada 0 | entrada 1 |
|---|---|---|---|
| S0 | nada útil | S0 | S1 |
| S1 | vi "1" | S2 | S1 |
| S2 | vi "10" | S0 | S3 |
| S3 | vi "101" (saída 1) | S2 | S1 |

Repara que de S3 com entrada 0 volta-se a S2, porque o último "1" pode ser o início de um novo "101".

```python
T = {'S0': ('S0', 'S1'), 'S1': ('S2', 'S1'), 'S2': ('S0', 'S3'), 'S3': ('S2', 'S1')}
estado, saida = 'S0', []
for bit in [1, 0, 1, 0, 1, 1, 0, 1]:
    estado = T[estado][bit]
    saida.append(int(estado == 'S3'))
print(saida)   # [0, 0, 1, 0, 1, 0, 0, 1]
```

## MEF em software

Fora do hardware, as MEF descrevem ecrãs de uma app, estados de uma encomenda ou o analisador léxico de um compilador. Escrevê-las de forma explícita evita estados impossíveis.

## Erros comuns

- Esquecer transições: todo o estado precisa de uma saída para cada entrada possível.
- Recomeçar do zero depois de uma deteção, perdendo sobreposições.
- Confundir Moore com Mealy ao desenhar quando a saída muda.
