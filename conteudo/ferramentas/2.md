Na lição anterior usaste comandos um a um. A força da shell está em **juntá-los**: a saída de um passa a ser a entrada do seguinte, e uma sequência que funciona vira um script que podes reutilizar.

## Entrada, saída e redirecionamento

Cada programa tem três canais:

- **stdin** (entrada padrão): de onde lê, normalmente o teclado;
- **stdout** (saída padrão): onde escreve os resultados, normalmente o ecrã;
- **stderr** (erros): onde escreve as mensagens de erro, também o ecrã.

Podes desviar estes canais para ficheiros:

```bash
ls -l > lista.txt          # stdout para um ficheiro (apaga o que lá estava)
echo "mais uma" >> lista.txt   # acrescenta ao fim
sort < nomes.txt           # stdin vem de um ficheiro
gcc main.c 2> erros.txt    # só os erros (canal 2) para um ficheiro
comando > tudo.txt 2>&1    # stdout e stderr para o mesmo ficheiro
comando > /dev/null        # deita a saída fora
```

## Pipes

O `|` liga o stdout de um comando ao stdin do seguinte:

```bash
cat acessos.log | grep "404" | wc -l
```

Lê-se da esquerda para a direita: mostra o registo, fica só com as linhas que têm `404` e conta-as. Cada programa faz uma coisa pequena; juntos respondem a uma pergunta que nenhum deles responde sozinho.

Um exemplo mais completo: quais são os 5 endereços IP que mais aparecem num registo de servidor web?

```bash
cut -d' ' -f1 acessos.log | sort | uniq -c | sort -rn | head -5
```

- `cut -d' ' -f1` fica com o primeiro campo de cada linha (o IP);
- `sort` ordena, para os iguais ficarem juntos;
- `uniq -c` junta os repetidos e conta-os;
- `sort -rn` ordena pelo número, do maior para o menor;
- `head -5` mostra os 5 primeiros.

## Variáveis e substituição de comandos

```bash
nome="Ana"                  # sem espaços à volta do =
echo "Olá, $nome"           # Olá, Ana
hoje=$(date +%Y-%m-%d)      # guarda a saída de um comando
echo "Backup de $hoje"
```

Usa **aspas duplas** à volta de variáveis: `"$ficheiro"`. Sem elas, um nome com espaços parte-se em várias palavras. As aspas simples não expandem nada: `'$nome'` fica literalmente `$nome`.

## O primeiro script

Cria `backup.sh`:

```bash
#!/usr/bin/env bash
set -euo pipefail          # pára no primeiro erro e em variáveis por definir

origem="${1:?Uso: backup.sh PASTA}"
destino="backup-$(date +%Y%m%d-%H%M).tar.gz"

tar -czf "$destino" "$origem"
echo "Criado $destino ($(du -h "$destino" | cut -f1))"
```

- A primeira linha (*shebang*) diz que programa corre o script.
- `set -euo pipefail` faz o script parar quando algo corre mal, em vez de continuar com dados estragados.
- `$1` é o primeiro argumento; `${1:?mensagem}` aborta com a mensagem se não houver argumento.

```bash
chmod +x backup.sh
./backup.sh relatorios
```

## Condições e ciclos

```bash
if [[ -f "$ficheiro" ]]; then
  echo "existe"
elif [[ -d "$ficheiro" ]]; then
  echo "é uma pasta"
else
  echo "não existe"
fi

for f in *.jpg; do
  echo "A converter $f"
  convert "$f" "${f%.jpg}.png"     # ${f%.jpg} tira o .jpg do fim
done

while read -r linha; do
  echo "linha: $linha"
done < dados.txt
```

Testes úteis: `-f` (é ficheiro), `-d` (é pasta), `-z "$x"` (string vazia), `"$a" == "$b"`, `$n -lt 10` (menor que).

Cada comando devolve um **código de saída**: `0` significa sucesso, outro número significa erro. O `if` testa precisamente isso, e `$?` guarda o código do último comando. Por isso podes escrever:

```bash
if grep -q "ERRO" registo.log; then
  echo "Há erros no registo"
fi
```

## Erros comuns

- `nome = "Ana"` com espaços: a shell tenta correr um comando chamado `nome`.
- `for f in $(ls)`: parte nomes com espaços. Usa `for f in *`.
- Esquecer as aspas em `"$var"` e o script falhar só com certos ficheiros.
- Scripts que continuam depois de um erro. Começa sempre com `set -euo pipefail`.
