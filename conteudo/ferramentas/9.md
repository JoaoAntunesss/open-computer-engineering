Há meia dúzia de erros que vais ver 90% das vezes. Se os reconheceres pelo nome, já sabes metade da solução antes de olhares para o código.

## O catálogo

| Erro | O que quer dizer | Causa típica |
|---|---|---|
| `SyntaxError` | O Python nem conseguiu ler o ficheiro | Falta `:`, parêntese ou aspas por fechar |
| `IndentationError` | Espaços à esquerda errados | Misturar tabs e espaços, bloco vazio |
| `NameError` | Nome desconhecido | Erro de escrita, variável usada antes de criada |
| `TypeError` | Operação com o tipo errado | Somar texto com número, chamar algo que não é função |
| `ValueError` | Tipo certo, valor impossível | `int("doze")` |
| `IndexError` | Posição fora da lista | Falhar por um, lista vazia |
| `KeyError` | Chave que não existe no dicionário | Maiúsculas, chave que não veio da API |
| `AttributeError` | O objeto não tem esse método/campo | `None.algo`, método com outro nome |
| `ZeroDivisionError` | Divisão por zero | Média de lista vazia |

## SyntaxError e IndentationError

```python run
if 5 > 3
    print("sim")
```

Estes aparecem **antes** de qualquer linha correr. A seta `^` aponta para onde o Python se baralhou, mas o erro verdadeiro está muitas vezes na linha **anterior** (um parêntese que ficou aberto lá atrás, por exemplo).

## AttributeError com None: o mais traiçoeiro

```python run
def procura(clientes, nome):
    for c in clientes:
        if c["nome"] == nome:
            return c

clientes = [{"nome": "Ana", "cidade": "Porto"}]
encontrado = procura(clientes, "Rui")
print(encontrado.get("cidade"))
```

`AttributeError: 'NoneType' object has no attribute 'get'`. A função não encontrou o Rui, chegou ao fim sem `return` e devolveu `None`. O erro rebenta **noutro sítio** (na última linha), longe da causa. Sempre que vires `NoneType` num erro, pergunta: "qual foi a função que me devolveu `None` sem eu estar à espera?"

## TypeError: dados que vêm de fora

```python run
linha = "Ana;17;Porto"
nome, idade, cidade = linha.split(";")
if idade >= 18:
    print(nome, "é maior de idade")
```

Tudo o que vem de ficheiros, formulários ou da internet chega como **texto**. `"17" >= 18` compara texto com número e rebenta. Converte à entrada: `idade = int(idade)`.

## Erros frequentes em código copiado ou gerado

- Usa uma função ou um método que **não existe** na versão que tens instalada (`AttributeError`, `ImportError`).
- Esquece-se do caso vazio (`IndexError`, `ZeroDivisionError`).
- Assume que um campo vem sempre preenchido (`KeyError`, `NoneType`).

## Exercícios

Diz o nome do erro e a causa sem correr. Depois corrige cada programa na caixa até funcionar.

```python run
nomes = ["Ana", "Rui"]
print(nomes.lenght)
```

```python run
total = 0
for p in ["2", "3", "5"]:
    total = total + p
print(total)
```

```python run
def primeiro_par(nums):
    for n in nums:
        if n % 2 == 0:
            return n

print(primeiro_par([1, 3, 5]) * 10)
```

??? Soluções
1: `AttributeError: 'list' object has no attribute 'lenght'`. Erro de escrita, e mesmo `length` não existe em Python: o tamanho é `len(nomes)`.

2: `TypeError: unsupported operand type(s) for +: 'int' and 'str'`. Os elementos são texto. Corrige com `total = total + int(p)`.

3: `TypeError: unsupported operand type(s) for *: 'NoneType' and 'int'`. Não há nenhum par, a função devolve `None` e `None * 10` rebenta. Corrige decidindo o que fazer quando não há par (devolver `None` e verificar antes de multiplicar, ou devolver um valor por defeito).
