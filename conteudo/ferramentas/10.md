A forma mais simples e mais usada de depurar, mesmo por programadores séniores, é pôr `print` no código para ver o que está a acontecer. Parece básico, mas feito com método resolve a maioria dos problemas.

## O bug

Este programa devia dar o desconto certo a cada cliente, mas o resultado está errado. Não há mensagem de erro.

```python run
def desconto(total, cliente_vip):
    if total > 100:
        taxa = 0.10
    if cliente_vip:
        taxa = 0.05
    else:
        taxa = 0
    return round(total * (1 - taxa), 2)

print(desconto(150, False))  # esperado: 135.0
print(desconto(150, True))   # esperado: 127.5 (10% + 5%)
print(desconto(50, True))    # esperado: 47.5
```

## Ver o que está lá dentro

Põe prints que mostrem **nome e valor** das variáveis em pontos-chave:

```python run
def desconto(total, cliente_vip):
    print(f"[entrada] total={total} vip={cliente_vip}")
    if total > 100:
        taxa = 0.10
        print(f"[>100] taxa={taxa}")
    if cliente_vip:
        taxa = 0.05
    else:
        taxa = 0
    print(f"[depois do vip] taxa={taxa}")
    return round(total * (1 - taxa), 2)

print(desconto(150, False))
```

O print mostra: entrou nos 10%, mas depois do bloco do VIP a taxa ficou 0. O segundo `if/else` **substitui** a taxa em vez de a **somar**. Agora que vês, a correção é óbvia:

```python run
def desconto(total, cliente_vip):
    taxa = 0
    if total > 100:
        taxa = taxa + 0.10
    if cliente_vip:
        taxa = taxa + 0.05
    return round(total * (1 - taxa), 2)

print(desconto(150, False), desconto(150, True), desconto(50, True))
```

## Regras para prints úteis

- **Mostra o nome**, não só o valor: `print(f"{taxa=}")` mostra `taxa=0.1`. Muito melhor do que um `0.1` solto no meio de 40 linhas.
- **Marca o sítio**: `[entrada]`, `[dentro do ciclo]`. Assim sabes de onde veio cada linha.
- **Mostra o tipo** quando desconfiares: `print(type(idade), repr(idade))`. O `repr` mostra as aspas, por isso vês logo se é `"30"` ou `30`, ou se há um espaço escondido em `"Porto "`.
- **Dentro de ciclos**, mostra a volta: `print(f"volta {i}: {total=}")`.
- **Tira-os no fim.** Prints esquecidos são um clássico em código de produção. Em projetos maiores usa-se `logging` em vez de `print`.

## O print também serve para confirmar o que achas

Depurar é testar hipóteses. Antes de pores um print, diz em voz alta o que esperas ver: "aqui a taxa devia ser 0.15". Se o print mostrar outra coisa, encontraste o sítio onde a realidade se afasta do que pensavas. É lá que está o bug.

## No JavaScript

Nos sites, o equivalente é `console.log`, que aparece na consola do browser (F12 → Console):

```js run
const carrinho = [{ nome: "caneta", preco: 1.5, qtd: 2 }, { nome: "caderno", preco: 3, qtd: 1 }];
let total = 0;
for (const item of carrinho) {
  total += item.preco * item.qtd;
  console.log("item:", item.nome, "total parcial:", total);
}
console.log("total:", total);
```

## Exercício

Este programa devia calcular a média das temperaturas positivas, mas dá um valor errado. Usa prints para descobrir onde a realidade se afasta do que esperas e corrige-o.

```python run
temperaturas = [12, -3, 8, -1, 10]
soma = 0
quantas = 0
for t in temperaturas:
    if t > 0:
        soma = soma + t
    quantas = quantas + 1
print(soma / quantas)   # esperado: 10.0 (12 + 8 + 10 a dividir por 3)
```

??? Solução
Com `print(f"{t=} {soma=} {quantas=}")` dentro do ciclo vês que `quantas` aumenta em todas as voltas, incluindo as negativas: chega a 5 em vez de 3. A linha `quantas = quantas + 1` está fora do `if` (indentação a menos). Corrige indentando-a para dentro do `if`. O resultado passa a `10.0`.
