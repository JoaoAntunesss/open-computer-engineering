Duas famílias de relações aparecem em todo o lado: as que dizem "isto é equivalente àquilo" e as que dizem "isto vem antes daquilo". As primeiras agrupam, as segundas ordenam.

## Relações de equivalência

Uma relação é de **equivalência** se é reflexiva, simétrica e transitiva. Exemplos:

- "tem o mesmo resto na divisão por 3" nos inteiros;
- "tem o mesmo tamanho" nas strings;
- "estão ligados por um caminho" nos nós de um grafo.

## Classes e partições

A **classe** de a, [a], é o conjunto de todos os elementos equivalentes a a. As classes de uma equivalência formam uma **partição**: não se sobrepõem e cobrem tudo. Com o resto por 3, os inteiros ficam em três classes: [0], [1] e [2].

O inverso também vale: qualquer partição define uma equivalência ("estar no mesmo bloco"). É a ideia por trás da estrutura **union-find**, usada para agrupar componentes:

```python
pai = list(range(10))
def raiz(x):
    while pai[x] != x:
        x = pai[x]
    return x
def junta(a, b):
    pai[raiz(a)] = raiz(b)
junta(1, 2); junta(2, 5)
print(raiz(1) == raiz(5))   # True: estão na mesma classe
```

## Ordens parciais

Uma relação é uma **ordem parcial** se é reflexiva, antissimétrica e transitiva. Exemplos: ≤ nos números, ⊆ nos conjuntos, "divide" nos inteiros positivos. É **parcial** porque pode haver elementos incomparáveis: {1} e {2} não estão contidos um no outro.

Se todos os pares são comparáveis, é uma **ordem total** (como ≤ nos inteiros).

## Diagramas de Hasse e ordenação topológica

Uma ordem parcial desenha-se num **diagrama de Hasse**: um traço de a para b se b está imediatamente acima de a. Uma **ordenação topológica** é uma ordem total compatível com a parcial: é o que um gestor de pacotes faz para instalar dependências antes de quem precisa delas, e o que este site faz com os pré-requisitos das cadeiras.

## Elementos especiais

- **Mínimo**: abaixo de todos. **Minimal**: nada está abaixo dele.
- **Majorante** de um subconjunto: acima de todos os seus elementos.
- **Supremo**: o menor majorante.

## Erros comuns

- Confundir antissimétrica com "não simétrica".
- Achar que uma ordem parcial tem sempre mínimo.
- Esquecer a reflexividade: < não é uma ordem parcial neste sentido, ≤ é.
