Matemática discreta é a matemática dos programas: conjuntos, contagens, recursão e grafos. Quase todos os conceitos desta cadeira cabem em poucas linhas de Python. Ler esse código e prever o resultado é uma boa forma de testar se percebeste a matemática.

## Ler e prever: contagens

```python run
from itertools import combinations, permutations, product

letras = "ABC"
print(len(list(permutations(letras, 2))))
print(len(list(combinations(letras, 2))))
print(len(list(product("01", repeat=3))))
print(len({x % 4 for x in range(20)}))
```

Antes de correr, responde com fórmulas: arranjos de 3 elementos 2 a 2, combinações de 3 elementos 2 a 2, palavras binárias de comprimento 3, e quantos restos diferentes há na divisão por 4.

## Encontra o erro: indução feita em código

Esta função recursiva devia calcular o número de subconjuntos de um conjunto com n elementos (2ⁿ), mas falha.

```python run
def subconjuntos(n):
    if n == 1:
        return 2
    return 2 * subconjuntos(n - 1)

print([subconjuntos(n) for n in range(4)])
```

Pensa no caso base como na indução: qual é o primeiro caso que a função tem de saber responder?
