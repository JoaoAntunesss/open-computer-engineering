Um grafo é um conjunto de pontos (vértices) ligados por linhas (arestas). Redes sociais, mapas, a internet, dependências de pacotes e circuitos são grafos, e muitos problemas de informática resolvem-se ao vê-los assim.

## Vocabulário

- **Grafo** G = (V, E): vértices V e arestas E.
- **Orientado** se as arestas têm sentido (seguir no Instagram), não orientado se não (amizade no Facebook).
- **Grau** de um vértice: número de arestas que lhe tocam.
- **Caminho**: sequência de vértices ligados. **Ciclo**: caminho que volta ao início.
- **Conexo**: há caminho entre quaisquer dois vértices.

**Lema dos apertos de mão**: a soma dos graus é 2|E|, porque cada aresta conta duas vezes. Logo, o número de vértices com grau ímpar é sempre par.

## Representação

```python
# lista de adjacências
g = {
    'A': ['B', 'C'],
    'B': ['A', 'D'],
    'C': ['A', 'D'],
    'D': ['B', 'C'],
}
```

A matriz de adjacências gasta |V|² posições; a lista gasta |V| + |E| e é melhor para grafos esparsos.

## Percorrer: largura e profundidade

```python
from collections import deque
def largura(g, inicio):
    vistos, fila = {inicio}, deque([inicio])
    while fila:
        v = fila.popleft()
        print(v)
        for w in g[v]:
            if w not in vistos:
                vistos.add(w); fila.append(w)
largura(g, 'A')   # A B C D
```

A pesquisa em **largura** (BFS) encontra os caminhos mais curtos em número de arestas. A pesquisa em **profundidade** (DFS) usa uma pilha ou recursão e serve para detetar ciclos e fazer ordenações topológicas.

## Árvores

Uma **árvore** é um grafo conexo sem ciclos. Propriedades equivalentes, para n vértices:

- tem exatamente n − 1 arestas;
- entre quaisquer dois vértices há um único caminho;
- tirar qualquer aresta desliga-a.

Árvores com raiz são as estruturas de diretórios, o DOM de uma página e as árvores de pesquisa. Uma **árvore abrangente** de um grafo liga todos os vértices com o mínimo de arestas.

## Euler e Hamilton

- Caminho de **Euler**: passa uma vez por cada **aresta**. Existe (num grafo conexo) se há 0 ou 2 vértices de grau ímpar.
- Caminho de **Hamilton**: passa uma vez por cada **vértice**. Decidir se existe é NP-completo.

## Erros comuns

- Esquecer de marcar os vértices visitados e ficar num ciclo infinito.
- Usar BFS para caminhos mais curtos com pesos diferentes (aí é preciso Dijkstra).
- Confundir caminho de Euler com caminho de Hamilton.
