Uma demonstração é um argumento que não deixa margem para dúvidas: parte de factos aceites e chega à conclusão por passos que qualquer pessoa pode verificar. Em informática, demonstrar é o que separa "o meu programa parece funcionar" de "o meu algoritmo está correto para todas as entradas".

## Implicação, hipótese e tese

Quase todos os teoremas têm a forma **se P, então Q** (P → Q). P é a **hipótese**, Q é a **tese**. Para demonstrar P → Q basta mostrar que, sempre que P é verdadeira, Q também é. Se P for falsa, a implicação é verdadeira por vacuidade.

## Demonstração direta

Assume-se P e chega-se a Q.

**Teorema.** Se n é ímpar, então n² é ímpar.
**Demonstração.** n ímpar quer dizer n = 2k + 1 para algum inteiro k. Então n² = 4k² + 4k + 1 = 2(2k² + 2k) + 1, que é ímpar. ∎

## Contrarrecíproco

P → Q é equivalente a ¬Q → ¬P. Às vezes o contrarrecíproco é muito mais fácil.

**Teorema.** Se n² é par, então n é par.
**Demonstração.** Contrarrecíproco: se n é ímpar, n² é ímpar, que já demonstrámos. ∎

## Redução ao absurdo

Assume-se que a tese é falsa e chega-se a uma contradição.

**Teorema.** √2 é irracional.
**Demonstração.** Suponhamos √2 = a/b com a e b inteiros sem fatores comuns. Então a² = 2b², logo a² é par e, pelo teorema anterior, a é par: a = 2c. Daí 4c² = 2b², ou seja b² = 2c², e b também é par. Mas a e b não tinham fatores comuns. Contradição. ∎

## Casos e contraexemplos

- **Por casos**: divide-se em situações que cobrem tudo (n par, n ímpar) e demonstra-se cada uma.
- **Contraexemplo**: para mostrar que "para todo o x, P(x)" é **falso**, basta um x que falhe. "Todo o número da forma n² + n + 41 é primo" falha em n = 40.

## Existência

Para demonstrar "existe x tal que P(x)" pode-se **construir** o x (demonstração construtiva) ou mostrar que a inexistência leva a um absurdo. Em informática preferem-se as construtivas, porque dão um algoritmo.

## Erros comuns

- Demonstrar o recíproco (Q → P) em vez da implicação pedida.
- Usar um exemplo como prova de uma afirmação universal.
- Na redução ao absurdo, assumir a tese em vez da sua negação.
- Saltar passos "óbvios" que afinal escondem o erro.
