Conjuntos, relações e funções são a linguagem de toda a matemática discreta e de boa parte da informática: tipos de dados, bases de dados relacionais e o próprio conceito de programa assentam neles.

## Conjuntos

Um conjunto é uma coleção de elementos sem ordem e sem repetições: {1, 2, 3} = {3, 1, 2}.

- **Pertença**: 2 ∈ {1, 2, 3}.
- **Subconjunto**: A ⊆ B se todo o elemento de A está em B.
- **Operações**: união A ∪ B, interseção A ∩ B, diferença A \ B, complementar.
- **Conjunto das partes** 𝒫(A): todos os subconjuntos de A. Se |A| = n, |𝒫(A)| = 2ⁿ.
- **Produto cartesiano** A × B: todos os pares (a, b).

Em Python:

```python
A, B = {1, 2, 3}, {3, 4}
print(A | B, A & B, A - B)       # {1, 2, 3, 4} {3} {1, 2}
from itertools import product
print(list(product(A, B)))       # pares de A × B
```

## Relações

Uma **relação** R entre A e B é um subconjunto de A × B. Escreve-se a R b quando (a, b) ∈ R. Uma tabela de uma base de dados é exatamente uma relação: cada linha é um tuplo.

Uma relação num só conjunto pode ser:

- **reflexiva**: a R a para todo o a;
- **simétrica**: a R b implica b R a;
- **antissimétrica**: a R b e b R a implicam a = b;
- **transitiva**: a R b e b R c implicam a R c.

## Funções

Uma **função** f: A → B associa a cada elemento de A **exatamente um** elemento de B. A é o domínio, B o conjunto de chegada.

- **Injetiva**: elementos diferentes vão para imagens diferentes.
- **Sobrejetiva**: todo o elemento de B é imagem de algum.
- **Bijetiva**: injetiva e sobrejetiva; tem inversa.

A **composição** (g ∘ f)(x) = g(f(x)) é o encadeamento de funções que fazes ao programar.

## Erros comuns

- Confundir ∈ (pertence) com ⊆ (está contido): 1 ∈ {1} mas {1} ⊆ {1}.
- Achar que {∅} é vazio: tem um elemento, o conjunto vazio.
- Chamar função a uma relação que dá dois resultados para a mesma entrada.
- Esquecer que a composição se lê da direita para a esquerda.
