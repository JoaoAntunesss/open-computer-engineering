Uma recorrência define uma sequência à custa dos seus termos anteriores. Aparecem sempre que analisas um algoritmo recursivo: o tempo para n depende do tempo para problemas mais pequenos.

## Exemplos

- Fibonacci: F(n) = F(n − 1) + F(n − 2), com F(0) = 0, F(1) = 1.
- Torres de Hanói: T(n) = 2T(n − 1) + 1, com T(1) = 1.
- Pesquisa binária: T(n) = T(n/2) + 1.
- Merge sort: T(n) = 2T(n/2) + n.

## Resolver por substituição e indução

Calcula os primeiros termos, adivinha a fórmula e demonstra-a por indução. Hanói: 1, 3, 7, 15, 31… parece T(n) = 2ⁿ − 1. Passo: 2(2ⁿ − 1) + 1 = 2ⁿ⁺¹ − 1. ✓

## Recorrências lineares homogéneas

Para a(n) = c₁a(n − 1) + c₂a(n − 2), experimenta a(n) = rⁿ. Obténs a **equação característica** r² = c₁r + c₂. Se tem raízes distintas r₁ e r₂:

a(n) = A·r₁ⁿ + B·r₂ⁿ

com A e B dados pelas condições iniciais. Para Fibonacci, r² = r + 1 dá r = (1 ± √5)/2, e

F(n) = (φⁿ − ψⁿ)/√5, com φ ≈ 1,618 (a razão de ouro).

Por isso Fibonacci cresce exponencialmente, e o Fibonacci recursivo ingénuo também.

## Do recursivo ao eficiente

```python
from functools import cache

@cache
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)

print(fib(90))   # instantâneo; sem @cache demorava anos
```

## Dividir para conquistar: o teorema mestre

Para T(n) = a·T(n/b) + f(n), compara f(n) com n^(log_b a):

- se f cresce mais devagar: T(n) = Θ(n^(log_b a));
- se crescem igual: T(n) = Θ(n^(log_b a) · log n);
- se f cresce mais depressa (com uma condição de regularidade): T(n) = Θ(f(n)).

Merge sort: a = 2, b = 2, n^(log₂2) = n = f(n), logo Θ(n log n). Pesquisa binária: Θ(log n).

## Erros comuns

- Esquecer as condições iniciais, que fixam as constantes.
- Aplicar o teorema mestre a recorrências que não têm a forma a·T(n/b) + f(n).
- Confundir o número de chamadas com o trabalho feito em cada uma.
