A aritmética modular é a aritmética do relógio: depois das 23 h vêm as 0 h. É a base das funções de dispersão, dos códigos de verificação e da criptografia que protege a internet, como o RSA.

## Congruências

a ≡ b (mod n) quer dizer que a e b têm o mesmo resto na divisão por n, ou que n divide a − b. 17 ≡ 2 (mod 5).

Somas, diferenças e produtos podem ser reduzidos a meio do caminho:

(a + b) mod n = ((a mod n) + (b mod n)) mod n, e o mesmo para ·.

O último algarismo de 7¹⁰⁰ é 7¹⁰⁰ mod 10, que se calcula sem nunca escrever o número inteiro.

## Exponenciação rápida

```python
print(pow(7, 100, 10))   # 1: Python calcula 7¹⁰⁰ mod 10 com quadrados sucessivos
```

Elevar ao quadrado repetidamente faz a^e mod n em cerca de log₂ e multiplicações.

## Máximo divisor comum e Euclides

mdc(a, b) = mdc(b, a mod b), e mdc(a, 0) = a.

```python
def mdc(a, b):
    while b:
        a, b = b, a % b
    return a
```

A versão **estendida** encontra x e y com a·x + b·y = mdc(a, b). Se mdc(a, n) = 1, esse x é o **inverso** de a módulo n: a·x ≡ 1 (mod n).

## Fermat e Euler

- **Pequeno teorema de Fermat**: se p é primo e p não divide a, a^(p−1) ≡ 1 (mod p).
- **Euler**: se mdc(a, n) = 1, a^φ(n) ≡ 1 (mod n), onde φ(n) conta os números até n primos com n. Para n = p·q com p e q primos, φ(n) = (p − 1)(q − 1).

## RSA

1. Escolhe dois primos grandes p e q; n = p·q; φ = (p − 1)(q − 1).
2. Escolhe e com mdc(e, φ) = 1 (costuma ser 65537).
3. Calcula d, o inverso de e módulo φ.
4. **Chave pública**: (n, e). **Chave privada**: d.
5. Cifrar: c = mᵉ mod n. Decifrar: m = c^d mod n.

```python
p, q = 61, 53
n, phi = p * q, (p - 1) * (q - 1)
e = 17
d = pow(e, -1, phi)          # inverso modular (Python 3.8+)
m = 65
c = pow(m, e, n)
print(c, pow(c, d, n))       # 2790 65
```

Funciona por causa de Euler: m^(e·d) ≡ m (mod n). É seguro porque, conhecendo só n, ninguém sabe fatorizar números de 600 algarismos depressa.

## Erros comuns

- Usar RSA "de brincar" a sério: números pequenos e sem *padding* são inseguros.
- Calcular a potência completa e só depois o resto (estoura a memória).
- Tentar inverter a módulo n quando mdc(a, n) ≠ 1.
