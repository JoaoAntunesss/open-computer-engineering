Há infinitos maiores do que outros. Esta ideia, de Georg Cantor, parece filosofia, mas tem uma consequência muito prática: há problemas que nenhum programa consegue resolver.

## Mesma cardinalidade

Dois conjuntos têm o mesmo tamanho (a mesma **cardinalidade**) se existe uma **bijeção** entre eles. Para conjuntos finitos é contar; para infinitos, é a única definição que funciona.

## Contáveis

Um conjunto é **contável** (numerável) se tem uma bijeção com ℕ = {0, 1, 2, …}, ou seja, se os seus elementos se podem pôr numa lista infinita.

- Os pares são contáveis: n ↦ 2n.
- Os inteiros são contáveis: 0, 1, −1, 2, −2, …
- Os racionais são contáveis: percorre a tabela p/q em diagonais.
- As strings finitas sobre um alfabeto, e por isso todos os **programas**, são contáveis: lista-as por tamanho e depois por ordem alfabética.

## O argumento da diagonal

**Teorema (Cantor).** Os números reais entre 0 e 1 não são contáveis.

**Demonstração.** Supõe uma lista r₁, r₂, r₃, … de todos. Constrói um número x cujo n-ésimo algarismo é diferente do n-ésimo algarismo de rₙ (por exemplo, 5 se esse for 4, e 4 caso contrário). x difere de cada rₙ pelo menos num algarismo, por isso não está na lista. Contradição. ∎

O mesmo argumento mostra que 𝒫(ℕ) não é contável e, em geral, que |𝒫(A)| > |A| para qualquer A.

## A consequência para a informática

Há tantos programas como números naturais, mas há mais funções de ℕ em {0, 1} do que números naturais (é 𝒫(ℕ)). Logo, **há funções que nenhum programa calcula**.

Um exemplo concreto é o **problema da paragem**: não existe um programa para(P, x) que diga sempre se P termina com a entrada x. A demonstração é uma diagonal:

```python
def contradicao(P):
    if para(P, P):     # se P pararia consigo próprio...
        while True:    # ...então fica em ciclo infinito
            pass
    return             # senão, para
# contradicao(contradicao) para se e só se não para.
```

Por isso nenhum compilador consegue detetar todos os ciclos infinitos, e nenhum antivírus perfeito pode existir.

## Erros comuns

- Pensar que "infinito" é um só tamanho.
- Achar que os racionais são mais do que os naturais por serem "densos".
- No argumento da diagonal, esquecer que 0,4999… = 0,5 (evita os algarismos 9 e 0 ao construir x).
