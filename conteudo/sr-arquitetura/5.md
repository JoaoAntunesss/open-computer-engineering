Uma API pública (usada por outras equipas, apps instaladas nos telemóveis dos clientes ou parceiros) é um **contrato**. Mudar o código é fácil; mudar um contrato que outros usam é muito difícil. Desenhar bem à primeira poupa anos de compatibilidade.

## Princípios

- **Consistência**: nomes, formatos de data, paginação e erros iguais em todos os endpoints. Quem aprende um, sabe usar todos.
- **Recursos claros**: `/saloes/12/marcacoes`, não `/getMarcacoesDoSalao`.
- **Datas em ISO 8601 com fuso** (`2027-01-10T15:00:00+00:00`). Datas ambíguas são a origem de bugs eternos.
- **Dinheiro em cêntimos inteiros** e com a moeda: `{"valor": 1250, "moeda": "EUR"}`.
- **Identificadores opacos**: o cliente não deve depender do formato.

## Erros úteis

Um formato único para todos os erros, legível por máquinas e por pessoas:

```json
{
  "erro": "hora_ocupada",
  "mensagem": "Já existe uma marcação às 15:00 com este funcionário.",
  "campo": "inicio"
}
```

O `erro` é um código estável (o frontend decide o que fazer a partir dele); a `mensagem` pode mudar.

## Paginação

Nunca devolvas listas sem limite. Com milhares de registos, a resposta fica enorme e lenta.

```text
GET /marcacoes?limite=50&depois=eyJpZCI6NDF9
```

A paginação por **cursor** (`depois=...`) é mais estável do que `pagina=3` quando os dados mudam entre pedidos.

## Evoluir sem partir

- **Acrescentar** campos e endpoints não parte ninguém, desde que os clientes ignorem campos que não conhecem.
- **Remover ou mudar** o significado de um campo parte. Faz-se em passos: marcar como obsoleto (*deprecated*), avisar, medir quem ainda usa, e só depois remover.
- Quando é inevitável partir, uma **versão nova** (`/v2/...`) a correr ao lado da antiga durante a transição.
- Apps móveis são o caso mais difícil: há sempre utilizadores com versões antigas que nunca atualizam.

## Documentar

A especificação **OpenAPI** descreve a API num ficheiro que gera documentação interativa, clientes e testes. O FastAPI gera-a sozinho a partir do código (em `/docs`). Mantém exemplos reais para cada endpoint.
