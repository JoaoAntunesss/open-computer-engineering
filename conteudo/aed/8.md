Um **grafo** é um conjunto de vértices ligados por arestas. Serve para representar mapas de estradas, redes sociais, dependências entre tarefas, páginas web e ligações de rede. Muitos problemas que parecem diferentes, como encontrar o caminho num labirinto, detetar ciclos de dependências ou ver quem está ligado a quem, resolvem-se com duas travessias: a **pesquisa em largura** (BFS) e a **pesquisa em profundidade** (DFS).

## Tipos de grafos

- **Não orientado:** a aresta A–B serve nos dois sentidos (amizade no Facebook).
- **Orientado:** A → B não implica B → A (seguir no Instagram, pré-requisitos de cadeiras).
- **Pesado:** cada aresta tem um custo (distância, tempo).

## Representação

**Lista de adjacências:** para cada vértice, a lista dos vizinhos. Memória O(V + E). É a escolha habitual.

```python
grafo = {
    "A": ["B", "C"],
    "B": ["A", "D"],
    "C": ["A", "D"],
    "D": ["B", "C", "E"],
    "E": ["D"],
}
```

**Matriz de adjacências:** `m[i][j] = 1` se há aresta. Memória O(V²); responde a "há aresta entre i e j?" em O(1). Boa para grafos densos e pequenos.

## BFS: pesquisa em largura

Visita primeiro os vizinhos, depois os vizinhos dos vizinhos, por camadas. Usa uma **fila**. Num grafo sem pesos, encontra o **caminho mais curto** (em número de arestas).

```python
from collections import deque

def bfs(grafo, origem):
    dist = {origem: 0}
    fila = deque([origem])
    while fila:
        v = fila.popleft()
        for w in grafo[v]:
            if w not in dist:          # marcar ao pôr na fila, não ao tirar
                dist[w] = dist[v] + 1
                fila.append(w)
    return dist
```

## DFS: pesquisa em profundidade

Vai o mais longe possível por um caminho e só depois volta para trás. Usa recursão (ou uma **pilha**).

```python
def dfs(grafo, v, visto=None, ordem=None):
    visto = set() if visto is None else visto
    ordem = [] if ordem is None else ordem
    visto.add(v)
    ordem.append(v)
    for w in grafo[v]:
        if w not in visto:
            dfs(grafo, w, visto, ordem)
    return ordem
```

Ambas visitam cada vértice e cada aresta uma vez: **O(V + E)**.

## Ler e prever

```python run
from collections import deque
grafo = {"A": ["B", "C"], "B": ["A", "D"], "C": ["A", "D"],
         "D": ["B", "C", "E"], "E": ["D"], "F": []}

def bfs(g, o):
    dist, fila = {o: 0}, deque([o])
    while fila:
        v = fila.popleft()
        for w in g[v]:
            if w not in dist:
                dist[w] = dist[v] + 1
                fila.append(w)
    return dist

def dfs(g, v, visto=None):
    visto = [] if visto is None else visto
    visto.append(v)
    for w in g[v]:
        if w not in visto:
            dfs(g, w, visto)
    return visto

print(bfs(grafo, "A"))
print(dfs(grafo, "A"))
print("F alcançável?", "F" in bfs(grafo, "A"))
```

## O que se resolve com estas travessias

- **Componentes ligadas:** corre BFS ou DFS a partir de cada vértice ainda não visitado; cada execução encontra uma componente.
- **Caminho mais curto sem pesos:** BFS, guardando o "pai" de cada vértice para reconstruir o caminho.
- **Ordenação topológica** (por que ordem fazer tarefas com dependências): DFS, juntando cada vértice à lista **quando termina**, e invertendo no fim. Só existe se o grafo orientado não tiver ciclos.
- **Detetar ciclos** num grafo orientado: na DFS, encontrar uma aresta para um vértice que ainda está "em curso".
- **Labirintos** e grelhas: cada casa é um vértice ligado às vizinhas livres.
