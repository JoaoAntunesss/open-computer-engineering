Listas, pilhas, filas e deques são as estruturas de dados lineares. Diferem nas operações que fazem depressa. Escolher a certa muda um programa de O(n²) para O(n), e muitos problemas resolvem-se naturalmente com uma delas: desfazer (pilha), atender por ordem (fila), janelas deslizantes (deque).

## Vetor dinâmico (a `list` do Python, o `ArrayList` do Java)

Os elementos estão seguidos em memória.

- Aceder a `v[i]`: O(1).
- Acrescentar no fim (`append`): O(1) **amortizado**. Quando enche, o vetor duplica a capacidade e copia tudo, mas isso acontece tão raramente que, em média, cada `append` custa O(1).
- Inserir ou remover no início ou no meio: O(n), porque é preciso deslocar os elementos seguintes.

## Lista ligada

Cada nó guarda um valor e um apontador para o seguinte.

```python
class No:
    def __init__(self, valor, seguinte=None):
        self.valor, self.seguinte = valor, seguinte

lista = No(1, No(2, No(3)))      # 1 -> 2 -> 3
```

- Inserir ou remover à frente, ou depois de um nó que já tens: O(1).
- Aceder ao i-ésimo: O(n), é preciso seguir os apontadores.
- Na prática, é mais lenta do que um vetor para percorrer, porque os nós estão espalhados na memória (pior uso da cache).

## Pilha (LIFO: o último a entrar é o primeiro a sair)

Operações: `push` (pôr no topo), `pop` (tirar do topo), `top` (ver o topo). Todas O(1). Em Python, uma `list` com `append` e `pop()`.

Usos: o "desfazer" de um editor, a pilha de chamadas de funções, verificar parênteses, avaliar expressões.

```python run
def equilibrado(s):
    pares = {")": "(", "]": "[", "}": "{"}
    pilha = []
    for c in s:
        if c in "([{":
            pilha.append(c)
        elif c in pares:
            if not pilha or pilha.pop() != pares[c]:
                return False
    return not pilha

for s in ("(a[b]{c})", "(]", "((", "f(x[0]) + {}"):
    print(s, equilibrado(s))
```

Prevê os quatro resultados antes de correr.

## Fila (FIFO: o primeiro a entrar é o primeiro a sair)

Operações: `enqueue` (pôr no fim), `dequeue` (tirar do início). Usos: atender pedidos por ordem, impressoras, a pesquisa em largura (BFS) em grafos.

**Cuidado em Python:** `lista.pop(0)` é O(n). Usa `collections.deque`:

```python run
from collections import deque
import time

n = 50000
lista = list(range(n))
t = time.perf_counter()
while lista:
    lista.pop(0)
print("list.pop(0):", round((time.perf_counter() - t) * 1000), "ms")

fila = deque(range(n))
t = time.perf_counter()
while fila:
    fila.popleft()
print("deque.popleft():", round((time.perf_counter() - t) * 1000), "ms")
```

## Deque (fila com duas pontas)

Pôr e tirar dos dois lados em O(1). Serve de pilha e de fila. Uso clássico: **máximo numa janela deslizante** em O(n), em vez de O(n·k).

## Resumo

| Operação | vetor | lista ligada | deque |
|---|---|---|---|
| aceder a [i] | O(1) | O(n) | O(1)* |
| pôr/tirar no fim | O(1) amort. | O(1)** | O(1) |
| pôr/tirar no início | O(n) | O(1) | O(1) |
| inserir no meio | O(n) | O(1) com o nó | O(n) |

\* no `deque` do Python, O(1) nas pontas e O(n) no meio. \*\* se guardares um apontador para o último nó.
