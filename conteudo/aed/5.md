Uma **tabela de dispersão** (*hash table*) guarda pares chave-valor e encontra qualquer chave em O(1) em média, seja a tabela de dez ou de dez milhões de elementos. É a estrutura mais usada na prática: os `dict` e `set` de Python, os `HashMap` de Java, os objetos de JavaScript e os índices de muitas bases de dados.

## A ideia

1. Uma **função de dispersão** transforma a chave num número: `h("ana") = 8231…`.
2. Esse número, módulo o tamanho da tabela, dá a posição: `8231… % 8 = 3`.
3. Guarda-se o par na posição 3. Para procurar, calcula-se a mesma posição e vai-se lá diretamente.

Uma boa função de dispersão é rápida e espalha as chaves de forma uniforme.

## Colisões

Duas chaves diferentes podem cair na mesma posição. Há duas formas de resolver:

- **Encadeamento:** cada posição guarda uma lista de pares (é o que faz o `HashMap` de Java).
- **Endereçamento aberto:** se a posição está ocupada, tenta a seguinte (sondagem linear) ou outra calculada (é o que faz o `dict` de Python).

```python run
class TabelaDispersao:
    def __init__(self, tamanho=8):
        self.baldes = [[] for _ in range(tamanho)]
        self.n = 0

    def _balde(self, chave):
        return self.baldes[hash(chave) % len(self.baldes)]

    def poe(self, chave, valor):
        b = self._balde(chave)
        for i, (k, _) in enumerate(b):
            if k == chave:
                b[i] = (chave, valor)
                return
        b.append((chave, valor))
        self.n += 1
        if self.n > 2 * len(self.baldes):       # fator de carga > 2: crescer
            self._cresce()

    def tira(self, chave):
        for k, v in self._balde(chave):
            if k == chave:
                return v
        raise KeyError(chave)

    def _cresce(self):
        pares = [p for b in self.baldes for p in b]
        self.baldes = [[] for _ in range(2 * len(self.baldes))]
        self.n = 0
        for k, v in pares:
            self.poe(k, v)

t = TabelaDispersao()
for i in range(100):
    t.poe(f"aluno{i}", i * 10)
print(t.tira("aluno42"), len(t.baldes), max(len(b) for b in t.baldes))
```

## Fator de carga e redimensionar

O **fator de carga** é n / número de posições. Se cresce muito, as listas ficam longas e as operações deixam de ser O(1). Por isso a tabela **duplica** quando passa um limite (0,66 no `dict` de Python, 0,75 no `HashMap`) e reinsere tudo. Como no vetor dinâmico, o custo amortizado continua O(1).

## Pior caso

Se todas as chaves colidirem, tudo fica numa lista e as operações passam a O(n). Isto pode ser usado num **ataque**: um atacante envia milhares de chaves escolhidas para colidirem e bloqueia o servidor. Por isso Python e outras linguagens usam uma função de dispersão com uma semente aleatória para strings (`PYTHONHASHSEED`), e o `HashMap` de Java transforma listas longas em árvores equilibradas.

## Regras para chaves

- A chave tem de ser **imutável**, ou pelo menos o seu hash não pode mudar enquanto está na tabela. Por isso, em Python, uma `list` não pode ser chave de um `dict` e um `tuple` pode.
- Se `a == b`, então tem de ser `hash(a) == hash(b)`. Em Java, quem redefine `equals` tem de redefinir `hashCode`. Esquecer isto é um erro clássico: o objeto entra na tabela e nunca mais é encontrado.

## Usos típicos

- Contar ocorrências (`collections.Counter`).
- Eliminar repetidos (`set`).
- Memoização: guardar resultados de funções já calculados.
- Juntar dados de duas tabelas por uma chave (o *hash join* das bases de dados).

```exercicio
def par_soma(numeros, alvo):

solucao:
def par_soma(numeros, alvo):
    vistos = set()
    for x in numeros:
        if alvo - x in vistos:
            return True
        vistos.add(x)
    return False
```

```exercicio
dica: Conta as letras de `a` num dicionário (somando 1) e as de `b` no mesmo dicionário (subtraindo 1). São anagramas se no fim todas as contagens forem 0.
proibido: sorted, sort, Counter
inicio:
def anagramas(a, b):
    return len(a) == len(b)
testes:
anagramas("roma", "amor") == True
anagramas("Roma", "mora") == True
anagramas("abc", "abd") == False
anagramas("aab", "abb") == False
anagramas("", "") == True
anagramas("ab", "abc") == False
solucao:
def anagramas(a, b):
    conta = {}
    for ch in a.lower():
        conta[ch] = conta.get(ch, 0) + 1
    for ch in b.lower():
        conta[ch] = conta.get(ch, 0) - 1
    return all(v == 0 for v in conta.values())
```
