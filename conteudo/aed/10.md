Algoritmos e estruturas de dados são a parte do curso onde mais compensa ler código com uma tabela de rastreio: um índice trocado ou uma condição de paragem errada estragam tudo, e só se veem a seguir passo a passo.

## Ler e prever: pesquisa binária

```python run
def pesquisa(v, alvo):
    lo, hi = 0, len(v) - 1
    passos = 0
    while lo <= hi:
        passos += 1
        meio = (lo + hi) // 2
        if v[meio] == alvo:
            return meio, passos
        if v[meio] < alvo:
            lo = meio + 1
        else:
            hi = meio - 1
    return -1, passos

v = [2, 5, 8, 12, 16, 23, 38, 56, 72, 91]
print(pesquisa(v, 23))
print(pesquisa(v, 4))
```

Faz a tabela (lo, hi, meio) para os dois casos antes de correr. Quantos passos, no máximo, para uma lista de 1000 elementos?

## Encontra o erro: uma pilha que perde elementos

```python run
class Pilha:
    def __init__(self):
        self.itens = []
    def push(self, x):
        self.itens.insert(0, x)
    def pop(self):
        return self.itens.pop()
    def vazia(self):
        return not self.itens

p = Pilha()
for x in [1, 2, 3]:
    p.push(x)
print(p.pop(), p.pop(), p.pop())   # esperado: 3 2 1
```

Uma pilha é LIFO: sai primeiro o último que entrou. O que está a sair, e porquê?

def equilibrada(expr):
    pares = {")": "(", "]": "[", "}": "{"}
    p = []
    for c in expr:
        if c in "([{":
            p.append(c)
        elif c in pares:
            if not p or p.pop() != pares[c]:
