Procurar numa lista desordenada obriga a ver todos os elementos: O(n). Se a lista estiver **ordenada**, a pesquisa binária encontra qualquer elemento em O(log n): num milhão de elementos, 20 comparações. A ideia é simples, mas a implementação tem armadilhas famosas: durante anos, a versão da biblioteca do Java teve um bug.

## A ideia

Olha para o elemento do meio. Se for o alvo, acabou. Se o alvo for menor, só pode estar na metade esquerda; se for maior, na direita. Cada passo corta o intervalo ao meio.

```python
def pesquisa_binaria(v, alvo):
    lo, hi = 0, len(v) - 1           # o alvo, se existir, está em v[lo..hi]
    while lo <= hi:
        meio = (lo + hi) // 2
        if v[meio] == alvo:
            return meio
        elif v[meio] < alvo:
            lo = meio + 1
        else:
            hi = meio - 1
    return -1
```

A **invariante** (comentário na 2.ª linha) é o que garante que está certa: se o alvo existe, está sempre entre `lo` e `hi`. Quando `lo > hi`, o intervalo está vazio e o alvo não existe.

## Rastrear

Procura 23 em `[2, 5, 8, 12, 16, 23, 38, 56, 72, 91]`:

| lo | hi | meio | v[meio] | decisão |
|---|---|---|---|---|
| 0 | 9 | 4 | 16 | 16 < 23: lo = 5 |
| 5 | 9 | 7 | 56 | 56 > 23: hi = 6 |
| 5 | 6 | 5 | 23 | encontrado |

## As armadilhas

- `while lo < hi` em vez de `<=`: falha quando o alvo é o último candidato.
- `lo = meio` em vez de `meio + 1`: ciclo infinito quando `hi = lo + 1`.
- `(lo + hi) / 2` em C ou Java com índices grandes: `lo + hi` pode ultrapassar o maior `int`. Usa `lo + (hi - lo) / 2`. Foi este o bug do Java, descoberto em 2006.

## Variante: primeira posição onde caberia

Muitas vezes queres "o primeiro elemento ≥ x" (para inserir mantendo a ordem, ou contar quantos são menores). O módulo `bisect` do Python faz isto:

```python run
import bisect
notas = [8, 10, 10, 10, 13, 15, 18]
print(bisect.bisect_left(notas, 10))    # primeira posição de 10
print(bisect.bisect_right(notas, 10))   # depois do último 10
print(bisect.bisect_right(notas, 10) - bisect.bisect_left(notas, 10))
print(bisect.bisect_left(notas, 14))    # onde inserir 14
```

Prevê os quatro números antes de correr.

## Pesquisa binária na resposta

A ideia funciona sempre que há uma condição que é falsa até certo ponto e depois sempre verdadeira. Exemplo: qual é a raiz quadrada inteira de um número enorme?

```python run
def raiz_inteira(n):
    lo, hi = 0, n
    while lo < hi:                # procura o primeiro x com x*x > n
        meio = (lo + hi) // 2
        if meio * meio > n:
            hi = meio
        else:
            lo = meio + 1
    return lo - 1

print(raiz_inteira(10), raiz_inteira(16), raiz_inteira(10 ** 30))
```

O mesmo raciocínio serve para "qual é a menor capacidade de camião que transporta tudo em 5 viagens?" ou para o `git bisect`, que encontra o commit que introduziu um erro.
