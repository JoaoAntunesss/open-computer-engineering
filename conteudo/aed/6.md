Uma **árvore binária de pesquisa** (ABP) guarda elementos de forma que procurar, inserir e remover custa O(altura). Se a árvore estiver **equilibrada**, a altura é O(log n). Se não estiver, pode degenerar numa lista e custar O(n). As árvores AVL e rubro-negras garantem o equilíbrio. São usadas no `TreeMap` de Java, no `std::map` de C++ e nos índices das bases de dados (na variante B-tree).

## A propriedade

Em cada nó, tudo o que está na subárvore esquerda é **menor** e tudo na direita é **maior**.

```
        8
      /   \
     3     10
    / \      \
   1   6      14
      / \    /
     4   7  13
```

Por isso, uma travessia **em ordem** (esquerda, nó, direita) dá os elementos ordenados: 1 3 4 6 7 8 10 13 14.

## Procurar e inserir

```python
class No:
    def __init__(self, chave):
        self.chave, self.esq, self.dir = chave, None, None

def insere(raiz, chave):
    if raiz is None:
        return No(chave)
    if chave < raiz.chave:
        raiz.esq = insere(raiz.esq, chave)
    elif chave > raiz.chave:
        raiz.dir = insere(raiz.dir, chave)
    return raiz

def procura(raiz, chave):
    while raiz and raiz.chave != chave:
        raiz = raiz.esq if chave < raiz.chave else raiz.dir
    return raiz is not None
```

## Remover

- Nó sem filhos: retira-se.
- Nó com um filho: o filho toma o lugar dele.
- Nó com dois filhos: troca-se a chave pela do **sucessor** (o menor da subárvore direita) e remove-se o sucessor, que tem no máximo um filho.

## O problema: a ordem de inserção

Prevê a altura da árvore em cada caso, antes de correr:

```python run
import random

class No:
    def __init__(self, c): self.chave, self.esq, self.dir = c, None, None

def insere(r, c):
    if r is None: return No(c)
    if c < r.chave: r.esq = insere(r.esq, c)
    else: r.dir = insere(r.dir, c)
    return r

def altura(r):
    return 0 if r is None else 1 + max(altura(r.esq), altura(r.dir))

import sys; sys.setrecursionlimit(5000)
n = 1000
r = None
for c in random.sample(range(n), n): r = insere(r, c)
print("aleatória:", altura(r))
r = None
for c in range(n): r = insere(r, c)
print("ordenada:", altura(r))
```

Com inserções por ordem, cada nó só tem filho direito: a árvore é uma lista com 1000 de altura.

## Árvores AVL

Em cada nó, a diferença de altura entre as duas subárvores (o **fator de equilíbrio**) é no máximo 1. Depois de inserir ou remover, se algum nó ficar desequilibrado, corrige-se com **rotações**:

```
rotação à esquerda em x:

    x                 y
     \               / \
      y      →      x   c
     / \             \
    b   c             b
```

Uma rotação muda poucos apontadores (O(1)) e mantém a propriedade da ABP. Há quatro casos (esquerda-esquerda, direita-direita, esquerda-direita, direita-esquerda), resolvidos com uma ou duas rotações. A altura de uma AVL é no máximo ≈ 1,44·log₂ n.

## Árvores rubro-negras

Cada nó é vermelho ou preto, com regras (a raiz é preta, um vermelho não tem filhos vermelhos, todos os caminhos até às folhas têm o mesmo número de pretos). Garantem altura ≤ 2·log₂(n + 1). São menos rigorosas do que as AVL, por isso fazem menos rotações nas inserções e remoções. São as mais usadas nas bibliotecas.

## Quando usar uma árvore e não uma tabela de dispersão

- Precisas dos elementos **ordenados** (listar por ordem, mínimo e máximo).
- Consultas por **intervalo**: "todas as marcações entre as 10h e as 12h".
- "O maior elemento menor do que x" (antecessor), "o seguinte".

Uma tabela de dispersão é mais rápida para procurar uma chave exata, mas não sabe nada de ordem.
