Uma **fila de prioridade** é uma fila em que sai sempre o elemento com maior prioridade (ou o menor valor), e não o primeiro a entrar. A implementação habitual é a **heap binária**: inserir e retirar o mínimo em O(log n), ver o mínimo em O(1). Aparece no escalonamento de processos, no algoritmo de Dijkstra, em simulações por eventos e para obter os k maiores de uma lista enorme.

## A heap binária

É uma árvore binária **completa** (todos os níveis cheios, exceto o último, preenchido da esquerda para a direita) com a **propriedade de heap**: cada nó é menor ou igual aos filhos (*min-heap*). O mínimo está sempre na raiz.

Como é completa, guarda-se num **vetor**, sem apontadores:

- filhos do nó `i`: `2i + 1` e `2i + 2`
- pai do nó `i`: `(i - 1) // 2`

```
            1
         /     \
        3       2          vetor: [1, 3, 2, 7, 4, 5]
       / \     /
      7   4   5
```

## Inserir: subir

Põe o novo elemento no fim do vetor e troca-o com o pai enquanto for menor.

## Retirar o mínimo: descer

Tira a raiz, põe o último elemento no lugar dela e troca-o com o **menor** dos filhos enquanto for maior.

Cada operação percorre no máximo a altura da árvore: O(log n).

```python run
class MinHeap:
    def __init__(self):
        self.v = []

    def poe(self, x):
        v = self.v
        v.append(x)
        i = len(v) - 1
        while i > 0 and v[(i - 1) // 2] > v[i]:
            p = (i - 1) // 2
            v[i], v[p] = v[p], v[i]
            i = p

    def tira(self):
        v = self.v
        topo = v[0]
        ultimo = v.pop()
        if v:
            v[0] = ultimo
            i = 0
            while True:
                menor = i
                for f in (2 * i + 1, 2 * i + 2):
                    if f < len(v) and v[f] < v[menor]:
                        menor = f
                if menor == i:
                    break
                v[i], v[menor] = v[menor], v[i]
                i = menor
        return topo

h = MinHeap()
for x in [7, 3, 9, 1, 4, 8]:
    h.poe(x)
print(h.v)
print([h.tira() for _ in range(6)])
```

## Em Python: heapq

```python
import heapq
tarefas = []
heapq.heappush(tarefas, (2, "rever código"))
heapq.heappush(tarefas, (1, "corrigir produção"))
heapq.heappush(tarefas, (3, "atualizar documentação"))
heapq.heappop(tarefas)            # (1, 'corrigir produção')
heapq.nlargest(3, numeros)        # os 3 maiores, O(n log 3)
```

Para uma max-heap com `heapq`, guarda os valores com o sinal trocado.

## Construir uma heap em O(n)

Inserir n elementos um a um custa O(n log n). Mas `heapify` (descer a partir do meio do vetor até à raiz) constrói a heap em **O(n)**, porque a maioria dos nós está perto das folhas e desce pouco.

## Heapsort

Constrói uma max-heap e retira o máximo n vezes, pondo-o no fim do vetor: ordenação O(n log n), no próprio sítio.

## Os k maiores de um fluxo enorme

Para guardar os 10 maiores de mil milhões de valores sem os ter todos em memória: mantém uma **min-heap com 10**. Para cada valor novo, se for maior do que o mínimo da heap, substitui-o. Custo O(n log k) e memória O(k).
