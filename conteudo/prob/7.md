Quase nunca se conhece a verdade sobre uma população inteira (todos os utilizadores, todos os pedidos, todos os eleitores). Tem-se uma **amostra**, e a partir dela **estima-se** um valor. Um número sozinho não chega: é preciso dizer quanto se confia nele. É isso que faz um **intervalo de confiança**.

## População, amostra, estimador

- **Parâmetro:** o valor verdadeiro, desconhecido (a média μ do tempo de resposta de todos os pedidos).
- **Amostra:** n observações (os tempos de 200 pedidos registados).
- **Estimador:** uma fórmula aplicada à amostra (a média amostral x̄). O valor obtido é uma **estimativa**.

Propriedades desejáveis de um estimador:

- **Centrado** (sem enviesamento): em média, acerta no parâmetro.
- **Consistente:** aproxima-se do parâmetro quando n cresce.
- **Eficiente:** variância pequena.

A média amostral x̄ é centrada para μ. Para a variância, usa-se s² = Σ(xᵢ − x̄)²/(**n − 1**): dividir por n daria um valor sistematicamente pequeno, porque os dados estão mais perto de x̄ do que de μ.

## Intervalo de confiança para a média

Pelo teorema do limite central, x̄ ≈ N(μ, σ/√n). Por isso, em 95% das amostras, μ está a menos de 1,96 erros padrão de x̄:

IC 95% = x̄ ± 1,96 · s/√n

Com amostras pequenas (n < 30) e σ desconhecido, troca-se 1,96 pelo valor da distribuição **t de Student** com n − 1 graus de liberdade (maior, para compensar a incerteza extra em s).

**Exemplo:** 100 pedidos, média 120 ms, s = 40 ms. Erro padrão = 4 ms. IC 95% = 120 ± 7,8 ms = [112,2; 127,8].

## Intervalo para uma proporção

p̂ ± 1,96 · √(p̂(1 − p̂)/n)

**Exemplo:** num teste A/B, 120 de 1000 visitantes clicaram. p̂ = 0,12; erro padrão ≈ 0,0103; IC 95% ≈ [0,10; 0,14].

## O que "95% de confiança" quer dizer

**Não** quer dizer "há 95% de probabilidade de μ estar neste intervalo": μ é fixo e está ou não está. Quer dizer: **o método** produz intervalos que contêm μ em 95% das amostras. Se repetires a experiência 100 vezes, cerca de 95 intervalos apanham o valor verdadeiro.

A simulação mostra isto. Prevê quantos dos 100 intervalos falham:

```python run
import random, statistics, math

mu_verdadeiro = 120
falham = 0
for exp in range(100):
    amostra = [random.gauss(mu_verdadeiro, 40) for _ in range(50)]
    m, s = statistics.mean(amostra), statistics.stdev(amostra)
    e = 1.96 * s / math.sqrt(len(amostra))
    if not (m - e <= mu_verdadeiro <= m + e):
        falham += 1
        if falham <= 3:
            print(f"falhou: [{m - e:.1f}, {m + e:.1f}]")
print("intervalos que não contêm μ:", falham, "em 100")
```

## Bootstrap: intervalos para quase tudo

E se quiseres um intervalo para a **mediana**, ou para o percentil 99 dos tempos de resposta, que não têm fórmula simples? O **bootstrap** reamostra os próprios dados (com reposição) muitas vezes e vê como a estatística varia:

```python run
import random, statistics
random.seed(1)
tempos = [random.expovariate(1 / 100) for _ in range(200)]      # tempos de resposta (ms)

def p99(v):
    return sorted(v)[int(0.99 * len(v)) - 1]

reamostras = sorted(p99(random.choices(tempos, k=len(tempos))) for _ in range(2000))
print("p99 da amostra:", round(p99(tempos)))
print("IC 95% (bootstrap):", round(reamostras[50]), "a", round(reamostras[1949]))
print("mediana:", round(statistics.median(tempos)))
```

O intervalo do p99 é largo: com 200 pedidos, só 2 estão acima do percentil 99. Para estimar caudas com precisão, precisas de muitos dados.

## Tamanho da amostra

Para uma margem de erro E (com 95%), n ≈ (1,96 · σ / E)². Para uma proporção, no pior caso (p = 0,5), n ≈ 0,96/E²: 2% de margem precisa de cerca de 2400 respostas.
