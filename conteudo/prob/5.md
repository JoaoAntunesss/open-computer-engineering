Algumas distribuições aparecem tantas vezes que têm nome, fórmula e funções prontas em todas as bibliotecas. Reconhecer qual se aplica a um problema é metade do trabalho: depois, as probabilidades, a média e a variância vêm das fórmulas.

## Binomial: número de sucessos em n tentativas

n tentativas independentes, cada uma com probabilidade p de sucesso. X = número de sucessos.

- P(X = k) = C(n, k) · pᵏ · (1 − p)ⁿ⁻ᵏ
- E[X] = n·p, Var(X) = n·p·(1 − p)

**Exemplo:** 5% das peças são defeituosas. Numa caixa de 20, P(nenhuma defeituosa) = 0,95²⁰ ≈ 0,36. Média: 1 peça.

## Poisson: contagens de acontecimentos raros

Número de acontecimentos num intervalo, quando acontecem ao acaso a uma taxa média λ: pedidos por segundo a um servidor, erros por página, chamadas por hora.

- P(X = k) = e^(−λ) · λᵏ / k!
- E[X] = Var(X) = λ

**Exemplo:** um site recebe em média 3 pedidos por segundo. P(0 pedidos num segundo) = e⁻³ ≈ 0,05. P(mais de 6) ≈ 0,034.

É a aproximação da binomial com n grande e p pequeno (λ = n·p).

## Normal (gaussiana): a curva em sino

Definida pela média μ e pelo desvio padrão σ. Simétrica, com a forma de sino.

- Regra 68–95–99,7: cerca de 68% dos valores estão a menos de 1σ da média, 95% a menos de 2σ, 99,7% a menos de 3σ.
- **Padronizar:** Z = (X − μ)/σ tem distribuição normal com média 0 e desvio 1. As tabelas e funções usam Z.

**Exemplo:** as notas de um exame seguem N(μ = 12, σ = 3). Que fração tem mais de 18? Z = (18 − 12)/3 = 2; P(Z > 2) ≈ 0,023: 2,3%.

Aparece sempre que um valor é a **soma de muitos efeitos pequenos** (erros de medição, alturas, ruído), graças ao teorema do limite central (próxima lição).

## Exponencial: tempo até ao próximo acontecimento

Se os acontecimentos seguem uma Poisson de taxa λ, o tempo entre eles é exponencial:

- f(x) = λ·e^(−λx), para x ≥ 0
- P(X > t) = e^(−λt)
- E[X] = 1/λ

**Sem memória:** P(X > s + t | X > s) = P(X > t). Se um componente com tempo de vida exponencial ainda funciona, é como se fosse novo. Por isso é o modelo base em teoria de filas e fiabilidade.

**Exemplo:** com 3 pedidos por segundo, o tempo médio entre pedidos é 1/3 s, e P(esperar mais de 1 s) = e⁻³ ≈ 0,05 (o mesmo que "0 pedidos num segundo").

## Qual escolher

| Pergunta | Distribuição |
|---|---|
| Quantos sucessos em n tentativas? | Binomial |
| Quantos acontecimentos num intervalo? | Poisson |
| Quanto tempo até ao próximo? | Exponencial |
| Quantas tentativas até ao 1.º sucesso? | Geométrica (média 1/p) |
| Soma ou média de muitas coisas | Normal |
| Qualquer valor num intervalo, igualmente provável | Uniforme |

## Com scipy (ou à mão)

Prevê os valores antes de correr. Este código só usa a biblioteca padrão:

```python run
import math
from statistics import NormalDist

def binomial(n, k, p):
    return math.comb(n, k) * p ** k * (1 - p) ** (n - k)

def poisson(k, lam):
    return math.exp(-lam) * lam ** k / math.factorial(k)

print("binomial, 0 defeitos em 20:", round(binomial(20, 0, 0.05), 3))
print("Poisson, 0 pedidos (λ=3):", round(poisson(0, 3), 3))
print("Poisson, mais de 6:", round(1 - sum(poisson(k, 3) for k in range(7)), 3))
print("normal, nota > 18:", round(1 - NormalDist(12, 3).cdf(18), 3))
print("exponencial, esperar > 1 s:", round(math.exp(-3 * 1), 3))
print("binomial(1000, 0.003) vs Poisson(3) em k=2:",
      round(binomial(1000, 2, 0.003), 4), round(poisson(2, 3), 4))
```

Em projetos reais, `scipy.stats` tem todas (`binom.pmf`, `poisson.cdf`, `norm.sf`, `expon`).
