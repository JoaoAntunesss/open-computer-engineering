Dois teoremas explicam porque é que a estatística funciona. A **lei dos grandes números** diz que a média de muitas observações se aproxima do valor esperado. O **teorema do limite central** diz que essa média, seja qual for a distribuição original, segue aproximadamente uma normal. Juntos, justificam as sondagens, os testes A/B, as simulações de Monte Carlo e os intervalos de confiança.

## Lei dos grandes números

Sejam X₁, X₂, …, Xₙ observações independentes da mesma distribuição, com média μ. A média amostral

X̄ₙ = (X₁ + … + Xₙ)/n

aproxima-se de μ quando n cresce.

É o que garante que:

- a proporção de caras em muitos lançamentos tende para 50%;
- um casino ganha dinheiro a longo prazo, mesmo perdendo jogos individuais;
- uma simulação de Monte Carlo dá a resposta certa com amostras suficientes.

**Não diz** que os resultados se "compensam": depois de 10 caras seguidas, a próxima continua a ter 50% (a falácia do jogador). Os desvios não desaparecem; ficam é pequenos **em proporção** ao número de lançamentos.

## Quão depressa? O erro diminui com √n

A variância da média é Var(X̄ₙ) = σ²/n, por isso o desvio padrão da média (o **erro padrão**) é σ/√n.

Para reduzir o erro para metade, precisas de **quatro vezes** mais dados. Para 10 vezes menos erro, 100 vezes mais dados. É por isso que as sondagens usam cerca de 1000 pessoas: com 4000, o erro só cai para metade.

## Teorema do limite central

Para n grande (na prática, n ≥ 30 costuma chegar), a média amostral segue **aproximadamente uma normal**:

X̄ₙ ≈ N(μ, σ/√n)

**seja qual for a distribuição original** (desde que tenha variância finita). A soma também: X₁ + … + Xₙ ≈ N(n·μ, σ·√n).

Isto explica porque é que a normal aparece em todo o lado: muitos fenómenos são somas de muitos efeitos pequenos e independentes.

**Exemplo:** um dado tem μ = 3,5 e σ ≈ 1,71. A soma de 100 dados é aproximadamente N(350, 17,1). P(soma > 380) ≈ P(Z > 1,75) ≈ 0,04.

## Ver acontecer

Prevê: a distribuição de **um** valor exponencial é muito assimétrica (muitos valores pequenos, alguns enormes). Como fica a distribuição da **média** de 30?

```python run
import random, statistics

def histograma(valores, titulo, lo, hi, caixas=16, largura=40):
    c = [0] * caixas
    for v in valores:
        if lo <= v < hi:
            c[int((v - lo) / (hi - lo) * caixas)] += 1
    m = max(c)
    print(titulo)
    for i, k in enumerate(c):
        print(f"{lo + i * (hi - lo) / caixas:5.2f} {'#' * round(k / m * largura)}")

um = [random.expovariate(1) for _ in range(20_000)]
medias = [statistics.mean(random.expovariate(1) for _ in range(30)) for _ in range(20_000)]
histograma(um, "um valor exponencial (média 1)", 0, 4)
histograma(medias, "média de 30 valores", 0.4, 1.6)
print("desvio das médias:", round(statistics.stdev(medias), 3), " teórico σ/√n:", round(1 / 30 ** 0.5, 3))
```
