A nova versão do site aumentou as vendas, ou foi sorte? O algoritmo novo é mesmo mais rápido, ou as medições variaram? Um **teste de hipóteses** dá um método para responder: assume-se que **não há** efeito e vê-se se os dados seriam muito improváveis nesse caso. É a ferramenta dos testes A/B e da comparação de desempenho.

## A lógica

1. **Hipótese nula** H₀: não há efeito ("as duas versões convertem igual").
2. **Hipótese alternativa** H₁: há efeito.
3. Escolhe-se um **nível de significância** α, normalmente 0,05.
4. Calcula-se uma **estatística de teste** a partir dos dados.
5. O **valor-p** é a probabilidade de obter um resultado **tão ou mais extremo** se H₀ for verdadeira.
6. Se valor-p < α, **rejeita-se H₀**: o resultado é "estatisticamente significativo".

É uma espécie de prova por absurdo com probabilidades: "se não houvesse efeito, isto seria muito raro; logo, provavelmente há efeito".

## Exemplo: uma moeda viciada?

Lanças uma moeda 100 vezes e saem 62 caras. É justa? H₀: p = 0,5. Sob H₀, o número de caras é aproximadamente N(50, 5). Z = (62 − 50)/5 = 2,4. Valor-p (bilateral) = P(|Z| ≥ 2,4) ≈ 0,016 < 0,05: rejeita-se H₀.

## Erros possíveis

| | H₀ verdadeira | H₀ falsa |
|---|---|---|
| Rejeitar H₀ | **erro tipo I** (falso positivo), probabilidade α | correto |
| Não rejeitar | correto | **erro tipo II** (falso negativo), probabilidade β |

**Potência** = 1 − β: a probabilidade de detetar um efeito que existe. Aumenta com mais dados e com efeitos maiores.

## Testes comuns

- **Teste t para duas médias:** comparar tempos de execução de dois algoritmos.
- **Teste para duas proporções / qui-quadrado:** comparar taxas de conversão (A/B).
- **Testes não paramétricos** (Mann-Whitney): quando os dados estão longe de normais (tempos de resposta com caudas longas).
- **Teste de permutação:** o mais intuitivo, e funciona com qualquer estatística (ver abaixo).

## Teste de permutação: um teste A/B à mão

Se H₀ for verdadeira, as etiquetas "A" e "B" não importam: baralhá-las não deve mudar nada. Baralha-se muitas vezes e vê-se com que frequência a diferença aleatória é tão grande como a observada. Prevê se o resultado é significativo:

```python run
import random
random.seed(7)
# 1 = clicou, 0 = não clicou
A = [1] * 48 + [0] * 952          # versão antiga: 4,8%
B = [1] * 66 + [0] * 934          # versão nova:   6,6%
observada = sum(B) / len(B) - sum(A) / len(A)

todos = A + B
extremas = 0
N = 5000
for _ in range(N):
    random.shuffle(todos)
    a, b = todos[:len(A)], todos[len(A):]
    if abs(sum(b) / len(b) - sum(a) / len(a)) >= abs(observada):
        extremas += 1
print(f"diferença observada: {observada:.3f}")
print(f"valor-p ≈ {extremas / N:.3f}")
```

## Armadilhas (muito comuns)

- **Significativo não é importante.** Com milhões de utilizadores, uma diferença de 0,01% dá valor-p minúsculo e não interessa a ninguém. Olha sempre para o **tamanho do efeito** e para o intervalo de confiança.
- **Não rejeitar H₀ não prova H₀.** Pode ser só falta de dados (pouca potência).
- **Espreitar os resultados** e parar o teste A/B mal fica significativo aumenta muito os falsos positivos. Decide o tamanho da amostra antes.
- **Comparações múltiplas:** testando 20 métricas com α = 0,05, espera-se 1 "significativa" por acaso. Corrige (Bonferroni: α/20) ou define a métrica principal antes.
- O valor-p **não** é a probabilidade de H₀ ser verdadeira.
