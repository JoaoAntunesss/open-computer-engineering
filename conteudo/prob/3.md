Uma **variável aleatória** é um número que depende do resultado de uma experiência aleatória: o número de caras em 10 lançamentos, o tempo até um servidor falhar, a nota de um aluno escolhido ao acaso. É o que permite fazer contas com a incerteza. Há dois tipos: **discretas** (valores que se podem contar) e **contínuas** (valores num intervalo).

## Variáveis discretas

Descrevem-se pela **função de probabilidade**: p(x) = P(X = x), com Σ p(x) = 1.

Exemplo: X = número de caras em 3 lançamentos de uma moeda.

| x | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| p(x) | 1/8 | 3/8 | 3/8 | 1/8 |

(Há 8 sequências igualmente prováveis; 3 delas têm exatamente uma cara: CKK, KCK, KKC.)

## Função de distribuição

F(x) = P(X ≤ x). Serve para os dois tipos de variáveis. Para o exemplo: F(1) = 1/8 + 3/8 = 1/2. É sempre crescente, vai de 0 a 1, e P(a < X ≤ b) = F(b) − F(a).

## Variáveis contínuas

Numa variável contínua (o tempo de resposta de um servidor, a altura de uma pessoa), a probabilidade de um valor **exato** é zero. Descreve-se pela **função densidade** f(x):

- P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx (a área debaixo da curva)
- f(x) ≥ 0 e a área total é 1
- f(x) não é uma probabilidade: pode ser maior do que 1.

Exemplo: X uniforme entre 0 e 10 minutos (o tempo de espera por um autocarro que passa de 10 em 10). f(x) = 1/10 entre 0 e 10. P(esperar mais de 7 min) = 3/10.

## Funções de variáveis aleatórias

Se X é aleatória, Y = g(X) também é. Se X é a nota (0 a 20) e Y = "aprovado" (1 se X ≥ 9,5), Y é uma variável discreta com dois valores.

## Várias variáveis

- **Distribuição conjunta:** P(X = x, Y = y).
- X e Y são **independentes** se P(X = x, Y = y) = P(X = x) · P(Y = y) para todos os valores.
- A soma de variáveis aleatórias é uma variável aleatória: a soma de dois dados vai de 2 a 12, com 7 a mais provável.

## Ver uma distribuição

A forma mais rápida de perceber uma variável aleatória é simulá-la muitas vezes e desenhar o histograma. Prevê a forma de cada um antes de correr:

```python run
import random
from collections import Counter

def histograma(valores, titulo, largura=40):
    c = Counter(valores)
    m = max(c.values())
    print(titulo)
    for x in sorted(c):
        print(f"{x:>4} {'#' * round(c[x] / m * largura)}")

n = 50_000
histograma([sum(random.random() < 0.5 for _ in range(3)) for _ in range(n)], "caras em 3 lançamentos")
histograma([random.randint(1, 6) + random.randint(1, 6) for _ in range(n)], "soma de dois dados")
tempos = [int(random.expovariate(1 / 3)) for _ in range(n)]
histograma([t for t in tempos if t < 15], "minutos até ao próximo pedido (inteiros)")
```

A terceira é contínua (a exponencial, que se estuda na lição 5); arredondar aos minutos torna-a discreta para a poder desenhar.
