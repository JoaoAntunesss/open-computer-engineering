A **regressão linear** procura a reta que melhor descreve a relação entre duas variáveis: quanto aumenta o tempo de execução por cada 1000 elementos, quanto sobe o preço de uma casa por metro quadrado. É o modelo de previsão mais simples, a base de muitos outros e, muitas vezes, o primeiro a experimentar em aprendizagem automática.

## O modelo

y = a + b·x + erro

- **b** (declive): quanto muda y, em média, quando x aumenta 1.
- **a** (ordenada na origem): o valor previsto de y quando x = 0.
- O erro é a parte que a reta não explica.

## Mínimos quadrados

Escolhem-se a e b que minimizam a soma dos quadrados dos **resíduos** (diferença entre o valor real e o previsto):

Σ (yᵢ − (a + b·xᵢ))²

A solução tem fórmula fechada:

- b = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)²
- a = ȳ − b·x̄

## Correlação e R²

- **Correlação** r (de −1 a 1): força e sentido da relação **linear**. r = 0,9 é forte e positiva; r ≈ 0 é ausência de relação linear (pode haver uma relação curva).
- **R²** = r² (na regressão simples): fração da variação de y explicada pela reta. R² = 0,81 quer dizer que 81% da variação é explicada.

## Exemplo completo

Mediu-se o tempo de um programa para vários tamanhos de entrada. Prevê, olhando para os dados, o declive aproximado e o tempo para n = 10 000:

```python run
n = [1000, 2000, 3000, 4000, 5000, 6000, 7000, 8000]
t = [12.1, 21.8, 33.0, 41.5, 52.9, 61.2, 72.4, 80.3]     # ms

def regressao(x, y):
    mx, my = sum(x) / len(x), sum(y) / len(y)
    sxy = sum((a - mx) * (b - my) for a, b in zip(x, y))
    sxx = sum((a - mx) ** 2 for a in x)
    syy = sum((b - my) ** 2 for b in y)
    b = sxy / sxx
    a = my - b * mx
    r = sxy / (sxx * syy) ** 0.5
    return a, b, r

a, b, r = regressao(n, t)
print(f"t ≈ {a:.2f} + {b * 1000:.3f} ms por cada 1000 elementos")
print(f"R² = {r * r:.4f}")
print(f"previsão para n = 10000: {a + b * 10000:.1f} ms")
for xi, yi in zip(n, t):
    print(xi, yi, "resíduo:", round(yi - (a + b * xi), 2))
```

## Analisar os resíduos

Os resíduos devem parecer **ruído aleatório** à volta de zero. Se tiverem um padrão (primeiro positivos, depois negativos, depois positivos), a relação não é linear: talvez o programa seja O(n log n) ou O(n²). Neste caso, pode-se regredir y contra n·log n ou n², ou fazer a regressão em escala logarítmica (log t contra log n: o declive é o expoente).

## Armadilhas

- **Correlação não é causalidade.** As vendas de gelados e os afogamentos estão correlacionados (ambos sobem no verão). Uma terceira variável explica os dois.
- **Extrapolar** muito para fora dos dados é perigoso: a reta foi ajustada entre 1000 e 8000; prever para 1 milhão assume que nada muda (caches, memória).
- **Valores extremos** puxam muito a reta (porque os erros são elevados ao quadrado).
- Um R² alto não garante que o modelo está certo; um R² baixo não quer dizer que x não importa.

## Mais variáveis

Com várias variáveis (preço de uma casa ~ área + quartos + distância ao centro), é **regressão linear múltipla**: y = a + b₁x₁ + b₂x₂ + … A solução usa álgebra linear (mínimos quadrados com matrizes, que viste em Álgebra). Em Python: `numpy.linalg.lstsq`, `statsmodels` ou `scikit-learn`.
