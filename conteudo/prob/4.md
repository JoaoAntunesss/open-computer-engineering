Uma distribuição inteira é muita informação. Dois números resumem quase sempre o essencial: o **valor esperado** (onde está o centro) e a **variância** (quanto os valores se afastam dele). São estes que usas para dizer que um algoritmo faz "em média n log n comparações", que um jogo de azar dá prejuízo a longo prazo ou que um servidor responde em "120 ms ± 30".

## Valor esperado

A média dos valores, pesada pelas probabilidades:

- Discreta: E[X] = Σ x · p(x)
- Contínua: E[X] = ∫ x · f(x) dx

**Exemplo:** um dado. E[X] = (1 + 2 + 3 + 4 + 5 + 6)/6 = 3,5. Nunca sai 3,5: o valor esperado é a média a longo prazo, não o valor "mais provável".

**Exemplo: vale a pena jogar?** Pagas 2 € para lançar um dado; se sair 6, recebes 10 €. Ganho: +8 com probabilidade 1/6, −2 com probabilidade 5/6. E[ganho] = 8/6 − 10/6 = −1/3 €: em média perdes 33 cêntimos por jogo.

## Propriedades (as mais úteis de todas)

- **Linearidade:** E[aX + b] = a·E[X] + b e **E[X + Y] = E[X] + E[Y]**, mesmo que X e Y **não** sejam independentes.
- E[X·Y] = E[X]·E[Y] só se forem independentes.

A linearidade resolve problemas que parecem difíceis. **Quantos pontos fixos tem uma permutação aleatória de n elementos?** (Quantas pessoas recebem o próprio presente num amigo secreto?) Seja Xᵢ = 1 se a pessoa i recebe o seu. E[Xᵢ] = 1/n. Somando: E[total] = n × 1/n = **1**, seja n 5 ou 5 milhões.

## Variância e desvio padrão

Var(X) = E[(X − μ)²] = E[X²] − (E[X])², com μ = E[X].

O **desvio padrão** σ = √Var(X) tem as mesmas unidades de X.

**Dado:** E[X²] = (1 + 4 + 9 + 16 + 25 + 36)/6 = 91/6. Var = 91/6 − 3,5² ≈ 2,92; σ ≈ 1,71.

Propriedades:

- Var(aX + b) = a² · Var(X) (somar uma constante não muda a dispersão).
- Var(X + Y) = Var(X) + Var(Y) **se forem independentes**.

## Desigualdades: limites sem conhecer a distribuição

- **Markov:** se X ≥ 0, P(X ≥ a) ≤ E[X]/a. Se o tempo médio de resposta é 100 ms, no máximo 10% dos pedidos demoram 1 s ou mais.
- **Chebyshev:** P(|X − μ| ≥ k·σ) ≤ 1/k². Seja qual for a distribuição, pelo menos 75% dos valores estão a menos de 2σ da média.

## Exemplo em algoritmos: o quicksort aleatório

O número esperado de comparações do quicksort com pivô aleatório é exatamente 2(n + 1)Hₙ − 4n, onde Hₙ = 1 + 1/2 + … + 1/n ≈ ln n. Para n grande, isto é cerca de 2n ln n ≈ 1,39 n log₂ n. A prova usa linearidade: soma-se, para cada par de elementos, a probabilidade de serem comparados.

## Simular e prever

Prevê os três valores antes de correr:

```python run
import random, statistics

def pontos_fixos(n):
    p = list(range(n))
    random.shuffle(p)
    return sum(1 for i, x in enumerate(p) if i == x)

def comparacoes_quicksort(v):
    if len(v) <= 1:
        return 0
    pivo = random.choice(v)
    menores = [x for x in v if x < pivo]
    maiores = [x for x in v if x > pivo]
    return len(v) - 1 + comparacoes_quicksort(menores) + comparacoes_quicksort(maiores)

dado = [random.randint(1, 6) for _ in range(100_000)]
print("dado: média", round(statistics.mean(dado), 2), "desvio", round(statistics.pstdev(dado), 2))
print("pontos fixos (n = 50):", round(statistics.mean(pontos_fixos(50) for _ in range(20_000)), 2))
import math
n = 1000
H = sum(1 / k for k in range(1, n + 1))
print("quicksort:", round(statistics.mean(comparacoes_quicksort(list(range(n))) for _ in range(50))),
      "  fórmula exata:", round(2 * (n + 1) * H - 4 * n), "  2 n ln n:", round(2 * n * math.log(n)))
```
