Em probabilidades e estatística, a simulação é a melhor forma de confirmar uma resposta (e de apanhar uma resposta errada, tua ou de um programa). Ler código de simulação exige perceber o que é aleatório, o que é fixo e quantas repetições fazem falta.

## Ler e prever: o problema do aniversário

```python run
import random
random.seed(1)

def ha_repetido(pessoas):
    dias = [random.randint(1, 365) for _ in range(pessoas)]
    return len(set(dias)) < pessoas

for n in (10, 23, 50):
    ensaios = 20000
    p = sum(ha_repetido(n) for _ in range(ensaios)) / ensaios
    print(n, round(p, 3))
```

Antes de correr: com 23 pessoas, achas que a probabilidade de duas fazerem anos no mesmo dia está mais perto de 5%, 25% ou 50%? E com 50?

## Encontra o erro: média e desvio padrão

```python run
def media(xs):
    return sum(xs) / len(xs)

def desvio_padrao(xs):
    m = media(xs)
    return (sum(x - m for x in xs) / (len(xs) - 1)) ** 0.5

dados = [2, 4, 4, 4, 5, 5, 7, 9]
print(media(dados), desvio_padrao(dados))
```

O desvio padrão dá 0. Isso só aconteceria se todos os valores fossem iguais. Onde está o erro?
