A probabilidade dá uma linguagem precisa para a incerteza. Em informática aparece em todo o lado: na análise de algoritmos aleatórios, em tabelas de dispersão, em testes A/B, em aprendizagem automática, em criptografia e em sistemas que falham. Começa-se por definir o que é uma probabilidade e por aprender a **contar**.

## Espaço de probabilidade

- **Espaço amostral** Ω: todos os resultados possíveis. Lançar um dado: Ω = {1, 2, 3, 4, 5, 6}.
- **Acontecimento**: um subconjunto de Ω. "Sair par" = {2, 4, 6}.
- **Probabilidade** P: atribui a cada acontecimento um número entre 0 e 1, com P(Ω) = 1 e P(A ∪ B) = P(A) + P(B) quando A e B não têm resultados em comum (axiomas de Kolmogorov).

Consequências úteis:

- P(não A) = 1 − P(A)
- P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

Quando todos os resultados são **igualmente prováveis**: P(A) = (casos favoráveis) / (casos possíveis). Calcular probabilidades passa a ser **contar**.

## Técnicas de contagem

- **Regra do produto:** k escolhas independentes com n₁, n₂, … opções dão n₁ × n₂ × … resultados. Uma password de 8 letras minúsculas: 26⁸ ≈ 2 × 10¹¹.
- **Permutações:** ordenar n objetos distintos: n!. Ordenar 5 livros: 120.
- **Arranjos:** escolher k de n **com ordem**: n! / (n − k)!. Pódio de 10 atletas: 10 × 9 × 8 = 720.
- **Combinações:** escolher k de n **sem ordem**: C(n, k) = n! / (k! (n − k)!). Euromilhões, 5 números de 50: C(50, 5) = 2 118 760.
- **Com repetição:** n^k sequências.

Pergunta-chave: **a ordem importa? Há repetição?**

## Exemplo: o problema do aniversário

Numa turma de 23 pessoas, qual é a probabilidade de duas fazerem anos no mesmo dia? Conta-se o complementar, "todos diferentes":

P(todos diferentes) = (365 × 364 × … × 343) / 365²³ ≈ 0,493

Logo P(pelo menos dois iguais) ≈ 0,507. Mais de 50%, com apenas 23 pessoas! É o mesmo raciocínio que mostra que, numa tabela de dispersão com m posições, as colisões começam por volta de √m elementos, e que torna possíveis os "ataques de aniversário" a funções de hash.

## Calcular e simular

Duas formas de obter uma probabilidade: **contar** (exato) e **simular** (aproximado, mas funciona quando contar é difícil). Prevê os valores antes de correr:

```python run
import math, random, itertools

# 1. Exato: probabilidade de a soma de dois dados ser 7
resultados = list(itertools.product(range(1, 7), repeat=2))
favoraveis = [r for r in resultados if sum(r) == 7]
print("soma 7 (exato):", len(favoraveis), "/", len(resultados), "=", round(len(favoraveis) / len(resultados), 4))

# 2. Simulado
n = 100_000
conta = sum(1 for _ in range(n) if random.randint(1, 6) + random.randint(1, 6) == 7)
print("soma 7 (simulado):", round(conta / n, 4))

# 3. Combinações
print("Euromilhões (5 de 50 e 2 de 12):", math.comb(50, 5) * math.comb(12, 2))

# 4. Aniversário com 23 pessoas
p = 1
for i in range(23):
    p *= (365 - i) / 365
print("aniversário:", round(1 - p, 3))
```
