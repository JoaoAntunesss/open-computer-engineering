Saber uma coisa muda a probabilidade de outra. A **probabilidade condicionada** formaliza isto, e o **teorema de Bayes** diz como atualizar uma crença quando chega informação nova. É a base dos filtros de spam, dos diagnósticos médicos, dos sistemas de recomendação e de muitos modelos de aprendizagem automática. Também é onde a intuição falha mais vezes.

## Probabilidade condicionada

P(A | B) é a probabilidade de A **sabendo que** B aconteceu:

P(A | B) = P(A ∩ B) / P(B)

Saber B reduz o espaço amostral a B. Exemplo: lança-se um dado e sabe-se que saiu par. Qual é a probabilidade de ter saído 6? P(6 | par) = (1/6) / (3/6) = 1/3.

**Regra do produto:** P(A ∩ B) = P(A | B) · P(B).

**Independência:** A e B são independentes se P(A | B) = P(A), ou seja, P(A ∩ B) = P(A) · P(B). Saber um não diz nada sobre o outro. Dois lançamentos de moeda são independentes; "chover" e "haver trânsito" não são.

## Lei da probabilidade total

Se B₁, …, Bₙ dividem o espaço em casos que não se sobrepõem:

P(A) = Σ P(A | Bᵢ) · P(Bᵢ)

Exemplo: 60% das peças vêm da fábrica X (2% defeituosas) e 40% da Y (5% defeituosas). P(defeito) = 0,02 × 0,6 + 0,05 × 0,4 = 0,032.

## Teorema de Bayes

P(B | A) = P(A | B) · P(B) / P(A)

Permite **inverter** a condicionada: de "probabilidade do sintoma dada a doença" para "probabilidade da doença dado o sintoma".

- P(B) é o *a priori*: o que se acreditava antes.
- P(A | B) é a verosimilhança: quão compatível é a observação com B.
- P(B | A) é o *a posteriori*: a crença atualizada.

## O exemplo que engana quase toda a gente

Uma doença afeta 1 em cada 1000 pessoas. Um teste deteta 99% dos doentes e dá falso positivo em 5% dos saudáveis. Deste positivo. Qual é a probabilidade de teres a doença?

A intuição diz "99%". As contas:

- P(positivo) = 0,99 × 0,001 + 0,05 × 0,999 ≈ 0,051
- P(doente | positivo) = 0,99 × 0,001 / 0,051 ≈ **0,019**, menos de 2%.

Em 1000 pessoas: 1 doente (dá positivo) e cerca de 50 saudáveis com falso positivo. Dos 51 positivos, só 1 está doente. Quando a condição é rara, até um bom teste dá sobretudo falsos positivos. O mesmo acontece em sistemas de deteção de fraude e de intrusões.

## Simular para confirmar

Prevê o resultado da simulação antes de correr:

```python run
import random
n = 1_000_000
positivos = doentes_positivos = 0
for _ in range(n):
    doente = random.random() < 0.001
    if doente:
        positivo = random.random() < 0.99
    else:
        positivo = random.random() < 0.05
    if positivo:
        positivos += 1
        doentes_positivos += doente
print("P(doente | positivo) ≈", round(doentes_positivos / positivos, 4))
```

## Um filtro de spam (Bayes ingénuo)

Para cada palavra, estima-se P(palavra | spam) e P(palavra | normal) a partir de emails já classificados. Para um email novo, combinam-se as palavras assumindo (ingenuamente) que são independentes:

```python run
import math
treino = [
    ("ganhe dinheiro rápido grátis", "spam"),
    ("oferta grátis clique já", "spam"),
    ("dinheiro fácil clique aqui", "spam"),
    ("reunião amanhã às dez", "normal"),
    ("envio o relatório da reunião", "normal"),
    ("almoço amanhã", "normal"),
]
conta = {"spam": {}, "normal": {}}
total = {"spam": 0, "normal": 0}
for texto, c in treino:
    for p in texto.split():
        conta[c][p] = conta[c].get(p, 0) + 1
        total[c] += 1
vocab = {p for c in conta for p in conta[c]}

def classifica(texto):
    pont = {}
    for c in conta:
        log_p = math.log(0.5)                       # a priori: metade é spam
        for p in texto.split():                     # suavização de Laplace (+1)
            log_p += math.log((conta[c].get(p, 0) + 1) / (total[c] + len(vocab)))
        pont[c] = log_p
    return max(pont, key=pont.get)

for t in ("dinheiro grátis", "reunião amanhã", "clique no relatório"):
    print(t, "->", classifica(t))
```

Usa-se o logaritmo para não multiplicar muitos números pequenos (que dariam zero em vírgula flutuante), e soma-se 1 às contagens para que uma palavra nunca vista não ponha a probabilidade a zero.
