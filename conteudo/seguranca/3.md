A cifra protege a **confidencialidade**. Para a **integridade** (ninguém alterou) e a **autenticidade** (veio de quem diz), há três ferramentas: as **funções de hash** (uma impressão digital dos dados), os **MAC** (hash com uma chave secreta partilhada) e as **assinaturas digitais** (com chave pública). Estão em todo o lado: no Git, nos downloads, nos tokens de sessão, nas atualizações de software, nas blockchains.

## Funções de hash criptográficas

Transformam dados de qualquer tamanho num resumo de tamanho fixo (SHA-256: 256 bits). Propriedades:

- **Determinista** e rápida.
- **Resistente a pré-imagem:** dado o hash, é impraticável encontrar uma mensagem que o produza.
- **Resistente a colisões:** é impraticável encontrar duas mensagens com o mesmo hash.
- **Efeito avalanche:** mudar um bit da entrada muda cerca de metade dos bits da saída.

Atuais: **SHA-256**, **SHA-3**, **BLAKE2/3**. Quebradas (já se encontraram colisões): **MD5** e **SHA-1**. Não se usam para segurança.

```python run
import hashlib

a = hashlib.sha256(b"Marcacao: Ana, 10h, corte, 15 EUR").hexdigest()
b = hashlib.sha256(b"Marcacao: Ana, 10h, corte, 16 EUR").hexdigest()
print(a)
print(b)
bits_diferentes = bin(int(a, 16) ^ int(b, 16)).count("1")
print(f"um carácter diferente → {bits_diferentes} de 256 bits mudaram")

# integridade de um ficheiro descarregado: compara-se com o hash publicado
ficheiro = b"conteudo do instalador..." * 1000
print("SHA-256 do ficheiro:", hashlib.sha256(ficheiro).hexdigest()[:16], "...")
```

Prevê, aproximadamente, quantos bits mudam. Um hash publicado ao lado de um download só protege se o próprio hash vier de uma fonte de confiança (outro sítio, ou assinado).

## MAC: hash com chave

Um hash sozinho não prova quem o fez: um atacante que altera a mensagem também recalcula o hash. Um **MAC** (*message authentication code*) usa uma chave secreta: só quem tem a chave o calcula. O mais usado é o **HMAC**.

```python run
import hmac, hashlib, json, base64

CHAVE = b"segredo-do-servidor-guardado-numa-variavel-de-ambiente"

def emite_token(dados):
    corpo = base64.urlsafe_b64encode(json.dumps(dados).encode()).decode()
    assinatura = hmac.new(CHAVE, corpo.encode(), hashlib.sha256).hexdigest()
    return f"{corpo}.{assinatura}"

def verifica_token(token):
    corpo, assinatura = token.rsplit(".", 1)
    esperada = hmac.new(CHAVE, corpo.encode(), hashlib.sha256).hexdigest()
    if not hmac.compare_digest(assinatura, esperada):        # comparação em tempo constante
        return "INVÁLIDO: o token foi alterado"
    return json.loads(base64.urlsafe_b64decode(corpo))

t = emite_token({"utilizador": 42, "papel": "cliente"})
print("token válido:", verifica_token(t))

# um atacante decodifica o corpo, muda o papel e volta a codificar
corpo, assinatura = t.rsplit(".", 1)
falso = json.loads(base64.urlsafe_b64decode(corpo)); falso["papel"] = "dona"
adulterado = base64.urlsafe_b64encode(json.dumps(falso).encode()).decode() + "." + assinatura
print("token adulterado:", verifica_token(adulterado))
```

Prevê o resultado das duas verificações. É exatamente assim que funcionam os JWT assinados com HS256 e os cookies de sessão assinados.

## Assinaturas digitais

Com a chave **privada** assina-se (na prática, o hash da mensagem); com a **pública**, qualquer pessoa verifica. Diferenças para o MAC:

- Quem verifica não precisa de nenhum segredo, e não consegue forjar assinaturas.
- Dão **não repúdio**: só o dono da chave privada as podia ter feito.

Algoritmos: **Ed25519** (recomendado), ECDSA, RSA-PSS. Usos: atualizações de software e aplicações de telemóvel assinadas, commits do Git assinados, certificados TLS (lição 5), o Cartão de Cidadão e a Chave Móvel Digital (assinatura qualificada, com valor legal na UE).

```python
# com a biblioteca cryptography (pip install cryptography)
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PrivateKey
privada = Ed25519PrivateKey.generate()
assinatura = privada.sign(b"contrato: 12 sessoes por 300 EUR")
privada.public_key().verify(assinatura, b"contrato: 12 sessoes por 300 EUR")   # OK, ou lança exceção
```

## Hashes de palavras-passe são outra coisa

Para guardar palavras-passe **não** se usa SHA-256 sozinho (é rápido demais): usa-se Argon2id, bcrypt ou scrypt, com sal (lição 6 de Tecnologias Web e lição seguinte).
