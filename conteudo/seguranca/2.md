A **criptografia** protege a informação mesmo quando ela passa por canais inseguros ou cai nas mãos erradas. Há duas famílias: a **simétrica**, em que a mesma chave cifra e decifra (rápida, mas é preciso partilhar a chave em segredo), e a **assimétrica** (de chave pública), em que há uma chave pública para cifrar e uma privada para decifrar. Na prática usam-se as duas juntas.

## A regra de ouro

**Nunca inventes a tua própria criptografia**, nem implementes os algoritmos à mão em produção. Usa bibliotecas estabelecidas (libsodium, a `cryptography` do Python, a Web Crypto API dos browsers) com as configurações recomendadas. Os exemplos desta lição são para perceber, não para usar.

## Cifras clássicas (e porque falham)

```python run
from collections import Counter

def cesar(texto, k):
    return "".join(chr((ord(c) - 97 + k) % 26 + 97) if c.isalpha() else c for c in texto)

segredo = cesar("a marcacao da ana e amanha as dez horas na rua das flores", 7)
print("cifrado:", segredo)

# ataque 1: força bruta (só há 26 chaves)
for k in range(26):
    tentativa = cesar(segredo, -k)
    if " amanha " in tentativa:
        print(f"chave {k}:", tentativa)

# ataque 2: análise de frequências (em português, 'a' e 'e' são as letras mais comuns)
mais_comum = Counter(c for c in segredo if c.isalpha()).most_common(1)[0][0]
print("letra mais frequente no cifrado:", mais_comum, "→ deslocamento provável", (ord(mais_comum) - ord("a")) % 26)
```

Prevê como é que cada ataque encontra a chave. As cifras modernas são desenhadas para que nenhum ataque seja muito melhor do que experimentar todas as chaves, e as chaves têm 128 ou 256 bits: 2¹²⁸ possibilidades, impossível de percorrer.

## Criptografia simétrica

- **AES** (*Advanced Encryption Standard*): o padrão mundial, cifra blocos de 128 bits com chaves de 128 ou 256 bits. Com instruções próprias nos processadores, cifra gigabytes por segundo.
- **ChaCha20:** uma alternativa rápida em telemóveis sem aceleração para AES.
- **Modos de operação:** como cifrar mensagens maiores do que um bloco. Usa sempre um modo **autenticado** (AEAD), que cifra e protege a integridade ao mesmo tempo: **AES-GCM** ou **ChaCha20-Poly1305**. Nunca ECB (blocos iguais dão cifrados iguais, e os padrões continuam visíveis).
- Cada mensagem precisa de um **nonce** (número usado uma vez) diferente. Repetir o nonce com a mesma chave quebra a segurança do GCM.

## Criptografia assimétrica

Cada pessoa tem um par de chaves: a **pública** (que se publica) e a **privada** (que nunca sai do seu computador).

- **Cifrar:** quem quer enviar-te um segredo usa a tua chave pública; só a tua privada decifra.
- **Assinar:** assinas com a tua privada; qualquer pessoa verifica com a tua pública (lição 3).

Algoritmos: **RSA** (baseado na dificuldade de fatorizar números enormes), **curvas elípticas** (ECDH, Ed25519: chaves muito mais pequenas para a mesma segurança). Um RSA de brincar mostra a ideia:

```python run
# RSA com números minúsculos — só para perceber; inseguro na prática
p, q = 61, 53
n = p * q                    # 3233, público
phi = (p - 1) * (q - 1)      # 3120, secreto
e = 17                       # expoente público
d = pow(e, -1, phi)          # expoente privado: inverso de e módulo phi
print("chave pública (n, e):", (n, e), " chave privada d:", d)

mensagem = 1234
cifrado = pow(mensagem, e, n)
print("cifrado:", cifrado, " decifrado:", pow(cifrado, d, n))

# quem conseguir fatorizar n descobre a chave privada:
fator = next(k for k in range(2, n) if n % k == 0)
print("n fatorizado:", fator, n // fator, "→ d =", pow(e, -1, (fator - 1) * (n // fator - 1)))
```

Com n de 2048 bits (617 algarismos), fatorizar é impraticável com os computadores atuais. Os **computadores quânticos** poderiam fazê-lo (algoritmo de Shor); por isso já existem algoritmos **pós-quânticos** (ML-KEM, ML-DSA), normalizados pelo NIST em 2024, que os browsers começam a usar.

## Juntar as duas: cifra híbrida

A assimétrica é lenta (milhares de vezes mais do que a simétrica). Por isso, usa-se a assimétrica só para **combinar uma chave simétrica** (troca de chaves Diffie-Hellman), e depois tudo é cifrado com AES ou ChaCha20. É exatamente o que faz o TLS (lição 5), o Signal, o WhatsApp e o SSH.
