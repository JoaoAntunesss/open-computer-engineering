Um **autómato finito** é a máquina mais simples que reconhece uma linguagem: lê a palavra símbolo a símbolo, muda de estado conforme uma tabela, e no fim diz "aceito" ou "rejeito". Tem memória finita (só o estado atual). É o que está por trás das expressões regulares, dos analisadores léxicos dos compiladores, dos protocolos de rede e de muitos controladores.

## Autómato finito determinista (AFD)

É definido por:

- um conjunto finito de **estados** Q;
- um **alfabeto** Σ;
- uma **função de transição** δ(estado, símbolo) = próximo estado (exatamente um);
- um **estado inicial**;
- um conjunto de **estados de aceitação**.

**Exemplo:** palavras binárias com número **par de 1**. Dois estados: `par` (inicial e de aceitação) e `impar`. Cada 1 troca de estado; cada 0 mantém.

```
        0                 0
      ┌──┐              ┌──┐
      ▼  │      1       ▼  │
   →((par))───────────►(impar)
         ◄─────────────
                 1
```

## Simular

```python run
def aceita(afd, palavra):
    estado = afd["inicial"]
    for s in palavra:
        estado = afd["delta"][(estado, s)]
    return estado in afd["aceitacao"]

par_de_uns = {
    "inicial": "par", "aceitacao": {"par"},
    "delta": {("par", "0"): "par", ("par", "1"): "impar",
              ("impar", "0"): "impar", ("impar", "1"): "par"},
}

# múltiplos de 3 em binário: o estado é o resto da divisão por 3
mult3 = {
    "inicial": 0, "aceitacao": {0},
    "delta": {(r, b): (2 * r + int(b)) % 3 for r in range(3) for b in "01"},
}

for p in ["", "1", "11", "1011", "0110"]:
    print(repr(p), aceita(par_de_uns, p), end="   ")
print()
for n in range(10):
    print(n, aceita(mult3, bin(n)[2:]), end="   ")
```

Prevê as respostas antes de correr. O segundo autómato tem uma ideia bonita: ler um bit b depois de já ter lido o número x dá o número 2x + b, por isso basta guardar o **resto** módulo 3.

## Autómato finito não determinista (AFND)

Pode ter **zero, um ou vários** próximos estados para o mesmo símbolo, e transições ε (sem ler nada). Aceita se **algum** caminho chegar a um estado de aceitação.

**Exemplo:** palavras que acabam em `01`. O AFND "adivinha" quando começa o fim: no estado inicial fica a ler qualquer coisa, ou, ao ler 0, salta para um estado que espera um 1 final. Muito mais fácil de desenhar do que o AFD equivalente.

## AFND e AFD têm o mesmo poder

**Construção dos subconjuntos:** cada estado do AFD é um **conjunto** de estados do AFND (todos aqueles onde o AFND podia estar). Com n estados no AFND, o AFD pode ter até 2ⁿ, mas na prática costuma ter poucos.

```python run
def aceita(afd, palavra):
    estado = afd["inicial"]
    for s in palavra:
        estado = afd["delta"][(estado, s)]
    return estado in afd["aceitacao"]

def afnd_para_afd(afnd, alfabeto):
    inicio = frozenset([afnd["inicial"]])
    estados, por_ver, delta = {inicio}, [inicio], {}
    while por_ver:
        S = por_ver.pop()
        for a in alfabeto:
            T = frozenset(q2 for q in S for q2 in afnd["delta"].get((q, a), ()))
            delta[(S, a)] = T
            if T not in estados:
                estados.add(T); por_ver.append(T)
    aceit = {S for S in estados if S & afnd["aceitacao"]}
    return {"inicial": inicio, "aceitacao": aceit, "delta": delta}, estados

acaba_em_01 = {"inicial": "q0", "aceitacao": {"q2"},
               "delta": {("q0", "0"): {"q0", "q1"}, ("q0", "1"): {"q0"}, ("q1", "1"): {"q2"}}}
afd, estados = afnd_para_afd(acaba_em_01, "01")
print(len(estados), "estados:", [sorted(s) for s in estados])
print([(p, aceita(afd, p)) for p in ["01", "1101", "010", "1"]])
```

## Minimização

Dois estados são **equivalentes** se, para qualquer resto de palavra, ambos aceitam ou ambos rejeitam. O algoritmo de minimização junta os equivalentes: começa por separar aceitação de não aceitação e vai partindo grupos enquanto houver estados no mesmo grupo que levam, com o mesmo símbolo, a grupos diferentes. O AFD mínimo é **único** (a menos dos nomes dos estados): é uma forma de verificar se duas expressões regulares descrevem a mesma linguagem.

## Teorema de Kleene

Expressões regulares, AFND e AFD descrevem **exatamente** as mesmas linguagens: as **linguagens regulares**. Os motores de expressões regulares convertem a expressão num autómato (Thompson) para a executar.
