As **gramáticas independentes do contexto** (GIC) descrevem linguagens com estrutura encaixada: expressões com parênteses, blocos de código dentro de blocos, HTML, JSON. Toda a sintaxe das linguagens de programação se escreve assim. A máquina que as reconhece é o **autómato de pilha**: um autómato finito com uma pilha de memória ilimitada.

## Gramáticas

Uma gramática tem:

- **Símbolos terminais:** os que aparecem nas palavras (`a`, `+`, `(`, números).
- **Variáveis** (não terminais): categorias sintáticas (`Expr`, `Termo`).
- **Regras de produção:** `Variável → sequência de terminais e variáveis`.
- Uma **variável inicial**.

Uma palavra pertence à linguagem se se consegue **derivar** a partir da variável inicial, substituindo variáveis pelas regras até só haver terminais.

**Exemplo:** aⁿbⁿ (que não é regular):

```
S → a S b | ε
```

Derivação de aaabbb: S ⇒ aSb ⇒ aaSbb ⇒ aaaSbbb ⇒ aaabbb.

**Parênteses equilibrados:**

```
S → ( S ) S | ε
```

## Expressões aritméticas e precedência

```
Expr  → Expr + Termo | Termo
Termo → Termo * Fator | Fator
Fator → ( Expr ) | num
```

A gramática codifica a **precedência** (`*` está "mais abaixo", por isso liga com mais força) e a **associatividade** (`Expr → Expr + Termo` torna `+` associativo à esquerda).

## Árvores de derivação e ambiguidade

Cada derivação dá uma **árvore**. Uma gramática é **ambígua** se uma palavra tem duas árvores diferentes:

```
E → E + E | E * E | num
```

`2 + 3 * 4` pode ser (2 + 3) * 4 = 20 ou 2 + (3 * 4) = 14. Por isso se usa a versão com `Expr`, `Termo` e `Fator`, que só dá uma árvore. Outro exemplo famoso: o `else` pendente em `if a then if b then s1 else s2`.

## Analisar: descida recursiva

Para cada variável, uma função; para cada alternativa, um ramo. Com a gramática das expressões (reescrita sem recursão à esquerda, que poria a função a chamar-se a si própria para sempre):

```python run
import re

def analisa(texto):
    tokens = re.findall(r"\d+|[-+*/()]", texto)
    pos = 0

    def ver():
        return tokens[pos] if pos < len(tokens) else None

    def comer(t):
        nonlocal pos
        if ver() != t:
            raise SyntaxError(f"esperava {t!r} na posição {pos}, encontrei {ver()!r}")
        pos += 1

    def expr():                      # Expr → Termo (('+' | '-') Termo)*
        v = termo()
        while ver() in ("+", "-"):
            op = ver(); comer(op)
            v = v + termo() if op == "+" else v - termo()
        return v

    def termo():                     # Termo → Fator (('*' | '/') Fator)*
        v = fator()
        while ver() in ("*", "/"):
            op = ver(); comer(op)
            v = v * fator() if op == "*" else v / fator()
        return v

    def fator():                     # Fator → '(' Expr ')' | num
        nonlocal pos
        if ver() == "(":
            comer("("); v = expr(); comer(")")
            return v
        t = ver()
        if t is None or not t.isdigit():
            raise SyntaxError(f"esperava um número na posição {pos}, encontrei {t!r}")
        pos += 1
        return int(t)

    v = expr()
    if pos != len(tokens):
        raise SyntaxError(f"sobra {tokens[pos:]}")
    return v

for e in ["2 + 3 * 4", "(2 + 3) * 4", "10 - 4 - 3", "2 * (3 + 4", "2 + * 3"]:
    try:
        print(e, "=", analisa(e))
    except SyntaxError as erro:
        print(e, "→ erro:", erro)
```

Prevê os cinco resultados. É assim que funcionam muitos compiladores e interpretadores reais (o GCC e o Clang usam descida recursiva escrita à mão).

## Autómatos de pilha

Um autómato de pilha (AP) pode, em cada passo, ler um símbolo, consultar o topo da pilha, e empilhar ou desempilhar. Para aⁿbⁿ: empilha um marcador por cada a; desempilha um por cada b; aceita se a pilha ficar vazia exatamente no fim.

**Teorema:** as linguagens das GIC são exatamente as linguagens dos AP **não deterministas**. Os AP deterministas reconhecem menos (por exemplo, não reconhecem os palíndromos de comprimento par), mas chegam para as linguagens de programação, que são desenhadas para isso (analisadores LL e LR).

## Limites

Também há linguagens que não são independentes do contexto: { aⁿbⁿcⁿ } é o exemplo clássico (prova-se com uma versão do lema da bombagem para GIC). Na prática: "a variável foi declarada antes de ser usada" e "o número de argumentos coincide com a declaração" não se verificam com a gramática. Isso fica para a **análise semântica** do compilador.
