A **máquina de Turing** (Alan Turing, 1936) é o modelo matemático de "um computador". É simplíssima: uma fita infinita, uma cabeça que lê e escreve, e uma tabela de regras. E, no entanto, consegue calcular **tudo** o que qualquer computador real consegue. Foi com ela que Turing mostrou que há problemas que **nenhum** programa resolve, antes de existirem computadores.

## A máquina

- Uma **fita** infinita dividida em células, cada uma com um símbolo (ou branco, `_`).
- Uma **cabeça** que está sobre uma célula.
- Um **estado** atual, de um conjunto finito.
- Uma **tabela de transições**: (estado, símbolo lido) → (símbolo a escrever, mover para Esquerda ou Direita, novo estado).
- Estados especiais de **aceitação** e **rejeição**, onde a máquina para.

A diferença para os autómatos: pode **escrever** e **voltar atrás**, por isso a fita funciona como memória ilimitada.

## Um simulador

```python run
def corre(regras, fita, estado="q0", max_passos=10_000):
    fita = dict(enumerate(fita))
    pos = passos = 0
    while estado not in ("aceita", "rejeita") and passos < max_passos:
        simbolo = fita.get(pos, "_")
        escreve, move, estado = regras[(estado, simbolo)]
        fita[pos] = escreve
        pos += 1 if move == "D" else -1
        passos += 1
    texto = "".join(fita.get(i, "_") for i in range(min(fita), max(fita) + 1)).strip("_")
    return estado, texto, passos

# Somar 1 a um número binário: vai até ao fim e propaga o "vai um" da direita para a esquerda
incremento = {
    ("q0", "0"): ("0", "D", "q0"), ("q0", "1"): ("1", "D", "q0"), ("q0", "_"): ("_", "E", "q1"),
    ("q1", "1"): ("0", "E", "q1"),             # 1 + 1 = 0, vai um
    ("q1", "0"): ("1", "E", "aceita"),         # 0 + 1 = 1, acabou
    ("q1", "_"): ("1", "E", "aceita"),         # passou o início: novo dígito
}

# aⁿbⁿ: risca um a (X) e o b correspondente (Y), repete
anbn = {
    ("q0", "a"): ("X", "D", "q1"), ("q0", "Y"): ("Y", "D", "q3"), ("q0", "_"): ("_", "D", "aceita"),
    ("q1", "a"): ("a", "D", "q1"), ("q1", "Y"): ("Y", "D", "q1"), ("q1", "b"): ("Y", "E", "q2"),
    ("q2", "a"): ("a", "E", "q2"), ("q2", "Y"): ("Y", "E", "q2"), ("q2", "X"): ("X", "D", "q0"),
    ("q3", "Y"): ("Y", "D", "q3"), ("q3", "_"): ("_", "D", "aceita"),
}
anbn_completa = dict(anbn)          # o que não está na tabela: rejeita
for e in ("q0", "q1", "q2", "q3"):
    for s in "abXY_":
        anbn_completa.setdefault((e, s), (s, "D", "rejeita"))

for n in ["1011", "111", "0"]:
    print(n, "+ 1 →", corre(incremento, n))
for w in ["aabb", "aaabbb", "aab", "abab", ""]:
    print(repr(w), corre(anbn_completa, w)[0])
```

Prevê os resultados. A segunda máquina reconhece aⁿbⁿ, que nenhum autómato finito reconhece.

## A tese de Church-Turing

Tudo o que é "calculável por um procedimento mecânico" é calculável por uma máquina de Turing. Não é um teorema (não se pode provar, porque "procedimento mecânico" não é uma definição formal), mas todos os modelos alguma vez propostos se revelaram equivalentes: o cálculo lambda de Church, as funções recursivas, as máquinas de registos, e qualquer linguagem de programação com memória ilimitada.

Uma linguagem é **Turing-completa** se consegue simular uma máquina de Turing. Python, C, Java, JavaScript, Haskell são todas. Também o são, sem querer, o Excel (com LAMBDA), o Minecraft (com redstone), o jogo da vida de Conway e os modelos CSS + HTML com interação.

## Variantes que não aumentam o poder

- Várias fitas.
- Fita infinita para os dois lados.
- Máquina não determinista.
- Alfabeto de só dois símbolos.

Todas se simulam com a máquina simples (às vezes com uma perda de eficiência, mas sem perder poder). Isto mostra como o conceito é robusto.

## A máquina universal

Turing mostrou que existe uma máquina **U** que recebe na fita a **descrição** de outra máquina M e uma entrada w, e simula M sobre w. É a ideia do **computador de programa armazenado**: o programa é dados. Um interpretador de Python é uma máquina universal.
