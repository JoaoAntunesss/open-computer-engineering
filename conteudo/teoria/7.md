Na lição anterior viste problemas **impossíveis**. Agora, problemas **possíveis mas, talvez, impraticáveis**. A teoria da complexidade classifica os problemas pelo tempo de que precisam. As duas classes centrais são **P** (o que se resolve depressa) e **NP** (o que se verifica depressa). A pergunta "P = NP?" é o maior problema em aberto da informática.

## Medir o tempo em máquinas de Turing

O tempo de uma máquina é o número de passos, em função do tamanho n da entrada. Os modelos razoáveis (máquina de Turing com uma fita, com várias, um computador real) diferem entre si por fatores **polinomiais**. Por isso, a fronteira que interessa é "polinomial ou não": a classe P é a mesma em qualquer modelo razoável.

## A classe P

Problemas de decisão resolvidos por um algoritmo determinista em tempo O(nᵏ), para algum k.

- Ordenar, pesquisar, caminhos mais curtos, árvores mínimas, fluxo máximo, emparelhamentos.
- Programação linear (com pontos interiores).
- **Primalidade:** o algoritmo AKS (2002) mostrou que está em P, com uma prova surpreendente.

"Polinomial" é considerado "tratável": O(n¹⁰⁰) não é prático, mas na realidade os algoritmos polinomiais conhecidos costumam ter expoentes baixos.

## A classe NP

Problemas de decisão em que, quando a resposta é "sim", existe um **certificado** curto (de tamanho polinomial) que se **verifica** em tempo polinomial.

Equivalente: problemas resolvidos em tempo polinomial por uma máquina de Turing **não determinista** (que "adivinha" o certificado). NP quer dizer *Nondeterministic Polynomial*, não "não polinomial".

| Problema | Certificado | Verificação |
|---|---|---|
| SAT: a fórmula é satisfazível? | valores das variáveis | avaliar a fórmula |
| Sudoku n×n tem solução? | a grelha preenchida | ver linhas, colunas e blocos |
| O grafo tem um ciclo hamiltoniano? | a ordem dos vértices | ver que é um ciclo e passa por todos |
| N é composto? | um divisor | fazer a divisão |

## Verificar contra encontrar

```python run
import itertools, time

# uma fórmula em forma normal conjuntiva: lista de cláusulas; 3 = x3, -3 = não x3
formula = [[1, -2, 3], [-1, 2], [2, -3, 4], [-4, -1], [3, 4], [-2, -3, -4], [1, 2, 4]]
n = 4

def verifica(formula, valores):           # O(tamanho da fórmula)
    return all(any(valores[abs(l)] == (l > 0) for l in c) for c in formula)

def procura(formula, n):                  # O(2^n · tamanho)
    for bits in itertools.product([False, True], repeat=n):
        valores = dict(enumerate(bits, start=1))
        if verifica(formula, valores):
            return valores
    return None

t = time.perf_counter()
sol = procura(formula, n)
print("solução:", sol, f"({(time.perf_counter() - t) * 1e6:.0f} µs)")
print("verificação:", verifica(formula, sol))
for variaveis in (20, 40, 60, 100):
    print(f"{variaveis} variáveis: 2^{variaveis} = {2 ** variaveis:.2e} atribuições")
```

Com 100 variáveis, a força bruta nunca acaba. Mas os **solvers SAT** modernos (com aprendizagem de cláusulas) resolvem muitas instâncias industriais com milhões de variáveis: o pior caso é exponencial, mas os casos reais têm estrutura.

## P = NP?

Sabe-se que P ⊆ NP (se se resolve depressa, verifica-se resolvendo). A pergunta é se são iguais: **encontrar é tão fácil como verificar?**

- Quase toda a gente acredita que **P ≠ NP**: a intuição é que verificar uma prova é mais fácil do que descobri-la.
- Se P = NP (com um algoritmo prático), a criptografia de chave pública cairia (encontrar a chave privada está em NP), mas muitos problemas de otimização, de planeamento e de demonstração automática ficariam fáceis.
- O Clay Mathematics Institute oferece 1 milhão de dólares por uma prova, num sentido ou no outro.

## Outras classes

- **co-NP:** problemas em que a resposta "não" tem certificado curto. "Esta fórmula é uma tautologia?"
- **PSPACE:** resolvidos com memória polinomial (tempo qualquer). Contém NP. Decidir quem ganha em jogos generalizados (xadrez n×n) costuma estar aqui ou acima.
- **EXPTIME:** tempo exponencial. Sabe-se que P ≠ EXPTIME (há problemas que comprovadamente precisam de tempo exponencial).

P ⊆ NP ⊆ PSPACE ⊆ EXPTIME, e pelo menos uma das inclusões é estrita, mas não se sabe qual.
