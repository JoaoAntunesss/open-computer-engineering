Autómatos e expressões regulares não ficam no papel: estão em todos os validadores de formulários, analisadores de texto e compiladores. Simular um autómato em código e prever o que aceita é a melhor ponte entre a teoria e a prática.

## Ler e prever: um DFA em Python

```python run
dfa = {
    ("q0", "0"): "q0", ("q0", "1"): "q1",
    ("q1", "0"): "q2", ("q1", "1"): "q0",
    ("q2", "0"): "q1", ("q2", "1"): "q2",
}

def aceita(palavra, inicial="q0", finais={"q0"}):
    estado = inicial
    for simbolo in palavra:
        estado = dfa[(estado, simbolo)]
    return estado in finais

for w in ["", "11", "110", "1001", "111", "10010"]:
    print(repr(w), aceita(w))
```

Os estados guardam o resto da divisão por 3 do número binário lido até agora. Antes de correr: que palavras são aceites? Que linguagem é esta?

## Encontra o erro: expressão regular para números pares sem zeros à esquerda

```python run
import re
padrao = re.compile(r"1[01]*0")

for w in ["0", "10", "100", "110", "0110", "1010", "1"]:
    print(w, bool(padrao.fullmatch(w)))
```

Devia aceitar todos os números binários pares sem zeros à esquerda. Que número par fica de fora?
