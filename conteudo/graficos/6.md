Uma **textura** é uma imagem colada à superfície de um objeto: a madeira de uma mesa, o tecido de uma camisola, os tijolos de uma parede. Em vez de modelar cada pormenor com triângulos, pinta-se. Cada vértice recebe **coordenadas de textura** (u, v), que a rasterização interpola, e o fragment shader lê a cor da imagem nesse ponto.

## Coordenadas UV

- u e v vão de 0 a 1 ao longo da imagem (0,0 num canto, 1,1 no oposto).
- O artista (no Blender, por exemplo) **desembrulha** o modelo 3D num plano (*UV unwrapping*), como abrir uma caixa de cartão, e pinta por cima.
- Valores fora de 0–1: **repetir** (azulejos, padrões), **espelhar** ou **prender** à borda.

No fragment shader: `vec4 c = texture(imagem, vUV);`.

## Amostragem e filtragem

As coordenadas (u, v) caem quase sempre **entre** píxeis da textura (os *texels*). Duas opções:

- **Vizinho mais próximo:** usa o texel mais perto. Rápido, aspeto "pixelizado" quando a textura é ampliada (a escolha certa para pixel art).
- **Bilinear:** média pesada dos 4 texels à volta. Suave.

```python run
textura = [                          # uma textura 4×4 de níveis de cinzento (0 a 9)
    [0, 0, 9, 9],
    [0, 0, 9, 9],
    [9, 9, 0, 0],
    [9, 9, 0, 0],
]
N = 4

def vizinho(u, v):
    x, y = min(int(u * N), N - 1), min(int(v * N), N - 1)
    return textura[y][x]

def bilinear(u, v):
    x, y = u * N - 0.5, v * N - 0.5
    x0, y0 = int(x // 1), int(y // 1)
    fx, fy = x - x0, y - y0
    t = lambda i, j: textura[min(max(j, 0), N - 1)][min(max(i, 0), N - 1)]
    cima = t(x0, y0) * (1 - fx) + t(x0 + 1, y0) * fx
    baixo = t(x0, y0 + 1) * (1 - fx) + t(x0 + 1, y0 + 1) * fx
    return cima * (1 - fy) + baixo * fy

def mostra(f, tamanho=16):
    for j in range(tamanho):
        print("".join(" .:-=+*#%@"[round(f((i + 0.5) / tamanho, (j + 0.5) / tamanho))] for i in range(tamanho)))

print("vizinho mais próximo (ampliado 4×):"); mostra(vizinho)
print("bilinear (ampliado 4×):"); mostra(bilinear)
```

Prevê a diferença: com o vizinho mais próximo, as fronteiras entre quadrados são duras; com a bilinear, há uma transição gradual.

## Mipmaps

Quando a textura é **reduzida** (um chão ao longe), muitos texels caem no mesmo píxel e aparecem padrões estranhos que tremem com o movimento (*aliasing*). Solução: guardar versões pré-reduzidas da textura (metade, um quarto…), os **mipmaps**, e usar a que corresponde à distância. Ocupam só mais um terço da memória. A **filtragem anisotrópica** melhora as superfícies vistas de lado.

## Texturas que não são cor

As texturas guardam qualquer valor por ponto da superfície:

- **Normal maps:** a normal em cada ponto, para simular relevo (tijolos, rugas) sem mais triângulos. A iluminação de Phong usa essa normal.
- **Mapas de rugosidade e de metalicidade** (PBR).
- **Mapas de oclusão ambiente:** cantos e frinchas mais escuros.
- **Mapas de deslocamento:** movem mesmo os vértices.
- **Mapas de ambiente** (*cubemaps*): o reflexo do céu e do cenário em superfícies brilhantes.

## Na prática

- Tamanhos em potências de 2 (512, 1024, 2048) funcionam melhor com mipmaps.
- Formatos comprimidos para a GPU (KTX2/Basis) poupam memória e tempo de carregamento na web.
- Em Three.js: `new THREE.TextureLoader().load("madeira.jpg")`, e `texture.wrapS = THREE.RepeatWrapping` para repetir.
