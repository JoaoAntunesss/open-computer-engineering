Em computação gráfica, mover, rodar e escalar objetos são **transformações**, representadas por **matrizes**. Compor transformações é multiplicar matrizes, e o hardware gráfico faz milhares de milhões destas multiplicações por segundo. O truque das **coordenadas homogéneas** permite que até as translações sejam matrizes, e é a base de tudo o que se segue: câmaras, projeções e animação.

## Transformações 2D

Um ponto (x, y) é transformado multiplicando-o por uma matriz:

- **Escala:** `[[sx, 0], [0, sy]]`
- **Rotação** de θ à volta da origem: `[[cos θ, −sin θ], [sin θ, cos θ]]`
- **Cisalhamento:** `[[1, k], [0, 1]]`

Mas a **translação** (somar (tx, ty)) não é uma multiplicação de matriz 2×2: é uma soma.

## Coordenadas homogéneas

Acrescenta-se uma coordenada: o ponto (x, y) passa a (x, y, 1). Agora, a translação é uma matriz 3×3:

```
| 1  0  tx |   | x |   | x + tx |
| 0  1  ty | · | y | = | y + ty |
| 0  0  1  |   | 1 |   |   1    |
```

Todas as transformações são matrizes 3×3 (em 3D, 4×4), e compor é multiplicar. Para vetores (direções, que não devem ser deslocados), usa-se w = 0.

## A ordem importa

Multiplicar matrizes não é comutativo: rodar e depois deslocar não é o mesmo que deslocar e depois rodar. Com vetores-coluna, a transformação aplicada **primeiro** fica à **direita**: M = T · R aplica R e depois T.

Para rodar um objeto à volta do **seu centro** c (e não da origem): deslocar c para a origem, rodar, voltar a deslocar: M = T(c) · R(θ) · T(−c).

```python run
import numpy as np, math
np.set_printoptions(precision=2, suppress=True)

def T(tx, ty): return np.array([[1, 0, tx], [0, 1, ty], [0, 0, 1]], float)
def R(graus):
    a = math.radians(graus)
    return np.array([[math.cos(a), -math.sin(a), 0], [math.sin(a), math.cos(a), 0], [0, 0, 1]])
def S(sx, sy): return np.array([[sx, 0, 0], [0, sy, 0], [0, 0, 1]], float)

# um quadrado de lado 2 com o canto inferior esquerdo em (4, 4)
quadrado = np.array([[4, 4, 1], [6, 4, 1], [6, 6, 1], [4, 6, 1]], float).T      # colunas = pontos
centro = (5, 5)

def mostra(nome, M):
    print(f"{nome:28}", [tuple(p) for p in np.round((M @ quadrado)[:2].T, 2).tolist()])

mostra("rodar 90° (origem)", R(90))
mostra("rodar 90° à volta do centro", T(*centro) @ R(90) @ T(-centro[0], -centro[1]))
mostra("escalar 2× e depois deslocar", T(1, 0) @ S(2, 2))
mostra("deslocar e depois escalar 2×", S(2, 2) @ T(1, 0))
```

## 3D

Em 3D, matrizes 4×4 e pontos (x, y, z, 1). Há três rotações básicas (à volta de x, y e z); qualquer rotação é uma composição delas. Para animações e câmaras, usam-se muitas vezes **quaterniões**: interpolam rotações suavemente (sem os bloqueios dos ângulos de Euler, o *gimbal lock*).

## Hierarquias

Num braço de robô (ou num personagem), a mão está presa ao antebraço, que está preso ao braço. Cada parte tem uma transformação **relativa** à parte de cima; a posição no mundo é o produto das matrizes ao longo da hierarquia: M_mão = M_braço · M_antebraço · M_mão_local. Rodar o ombro move tudo o que está abaixo. É o **grafo de cena** do Three.js, Unity e Blender.
