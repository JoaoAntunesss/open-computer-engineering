Em computação gráfica, um erro de leitura vê-se no ecrã: a imagem fica de pernas para o ar, esticada ou do avesso. Ler o código com papel e lápis (e um sistema de coordenadas desenhado) evita horas de tentativa e erro.

## Ler e prever: transformações em ordem

```python run
import math

def roda(p, graus):
    t = math.radians(graus)
    x, y = p
    return (round(x * math.cos(t) - y * math.sin(t), 3), round(x * math.sin(t) + y * math.cos(t), 3))

def translada(p, dx, dy):
    return (p[0] + dx, p[1] + dy)

p = (1, 0)
print(roda(translada(p, 2, 0), 90))
print(translada(roda(p, 90), 2, 0))
```

Antes de correr, desenha num papel quadriculado: primeiro desloca e depois roda, e depois ao contrário. Dá o mesmo ponto?

## Encontra o erro: coordenadas do ecrã

Este código desenha pontos num ecrã de 800 × 600, a partir de coordenadas matemáticas de −1 a 1 nos dois eixos, mas a imagem aparece de pernas para o ar.

```python run
def para_ecra(x, y, largura=800, altura=600):
    px = (x + 1) / 2 * largura
    py = (y + 1) / 2 * altura
    return round(px), round(py)

print(para_ecra(0, 0), para_ecra(1, 1), para_ecra(-1, -1))
```

Pista: em quase todos os sistemas de janelas, o ponto (0, 0) do ecrã fica no canto **superior** esquerdo.

def lado(p, a, b):
    return (b[0] - a[0]) * (p[1] - a[1]) - (b[1] - a[1]) * (p[0] - a[0])

def dentro_triangulo(p, a, b, c):
    d1, d2, d3 = lado(p, a, b), lado(p, b, c), lado(p, c, a)
    negativo = d1 < 0 or d2 < 0 or d3 < 0
    positivo = d1 > 0 or d2 > 0 or d3 > 0
    return not (negativo and positivo)
