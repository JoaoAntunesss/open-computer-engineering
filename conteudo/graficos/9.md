Animar é mudar algo ao longo do tempo: a posição de um botão, a cor de um fundo, o esqueleto de uma personagem. O cérebro vê movimento contínuo a partir de imagens paradas mostradas depressa (24 por segundo no cinema, 60 ou mais nos ecrãs). As técnicas vão de interpolar entre **posições-chave** a **simular física**.

## O ciclo de animação

Em vez de "mover 5 píxeis por imagem", calcula-se a posição em função do **tempo decorrido**, para a animação ter a mesma velocidade num ecrã a 60 Hz e noutro a 144 Hz:

```js
let anterior = performance.now();
function imagem(agora) {
  const dt = (agora - anterior) / 1000;      // segundos desde a última imagem
  anterior = agora;
  atualiza(dt);                              // física, lógica
  desenha();
  requestAnimationFrame(imagem);             // o browser chama-nos antes da próxima imagem
}
requestAnimationFrame(imagem);
```

## Posições-chave e interpolação

Define-se o valor em alguns instantes (as *keyframes*) e calcula-se o meio. Interpolar linearmente dá movimentos mecânicos: na realidade, as coisas **aceleram** e **travam**. Usam-se **funções de suavização** (*easing*): uma função que transforma o progresso linear t ∈ [0, 1] noutro.

```js run
// funções de suavização: recebem o progresso linear t (0 a 1) e devolvem o progresso "visual"
const easing = {
  linear: t => t,
  entrada: t => t * t * t,                                  // começa devagar
  saida: t => 1 - (1 - t) ** 3,                             // trava no fim
  entradaSaida: t => (t < 0.5 ? 4 * t ** 3 : 1 - (-2 * t + 2) ** 3 / 2),
  ressalto: t => {                                          // como uma bola a cair
    const n = 7.5625, d = 2.75;
    if (t < 1 / d) return n * t * t;
    if (t < 2 / d) return n * (t -= 1.5 / d) * t + 0.75;
    if (t < 2.5 / d) return n * (t -= 2.25 / d) * t + 0.9375;
    return n * (t -= 2.625 / d) * t + 0.984375;
  },
};
// um botão vai de x = 0 a x = 30 em 10 imagens: onde está em cada imagem?
for (const [nome, f] of Object.entries(easing)) {
  const posicoes = Array.from({ length: 11 }, (_, i) => Math.round(30 * f(i / 10)));
  console.log(nome.padEnd(13), posicoes.join(" "));
}
```

Prevê, para cada função, se os primeiros passos são grandes ou pequenos. No CSS, `transition: transform 300ms ease-out` usa uma destas curvas (definidas como Bézier cúbicas, lição 8).

## Princípios da animação

Os 12 princípios dos animadores da Disney continuam a guiar o movimento em interfaces: **acelerar e travar**, **antecipação** (um pequeno recuo antes de saltar), **continuidade** (as partes não param todas ao mesmo tempo), **exagero**, **arcos** (os movimentos naturais seguem curvas). Em interfaces: animações curtas (150–300 ms), que explicam o que mudou, e respeitando `prefers-reduced-motion` (há quem fique enjoado com o movimento).

## Animação de personagens

- **Esqueleto (*rigging*):** uma hierarquia de ossos (lição 1) com a malha presa a eles; cada vértice segue vários ossos com pesos (*skinning*). Anima-se rodando os ossos.
- **Cinemática inversa:** dás a posição da mão e o sistema calcula os ângulos do ombro e do cotovelo.
- **Captura de movimento:** gravar atores reais.
- **Interpolação de rotações:** com quaterniões e *slerp*, para não haver saltos nem bloqueios.

## Simulação física

Em vez de definir o movimento, define-se a física e deixa-se correr (Física e Métodos Numéricos): forças, integração com passo fixo (Euler semi-implícito ou Verlet), deteção e resposta a colisões. Molas amortecidas dão animações de interface muito naturais (as do iOS e do Framer Motion):

```python run
def mola(alvo=100.0, rigidez=170.0, amortecimento=26.0, dt=1 / 60, segundos=1.0):
    x, v, trajetoria = 0.0, 0.0, []
    for _ in range(int(segundos / dt)):
        forca = -rigidez * (x - alvo) - amortecimento * v       # Hooke + atrito
        v += forca * dt                                          # Euler semi-implícito
        x += v * dt
        trajetoria.append(x)
    return trajetoria

for nome, amort in (("criticamente amortecida", 26.0), ("com ressalto", 10.0), ("muito amortecida", 60.0)):
    t = mola(amortecimento=amort)
    print(f"{nome:24} máx {max(t):6.1f}  aos 0,25 s: {t[14]:6.1f}  aos 0,5 s: {t[29]:6.1f}  no fim: {t[-1]:6.1f}")
```

Prevê qual passa do alvo (100) e qual demora mais a lá chegar.
