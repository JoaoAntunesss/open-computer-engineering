A iluminação é o que faz um objeto 3D parecer sólido. O modelo de **Phong** (1975) continua a ser a forma mais simples de o fazer: a luz que vemos num ponto é a soma de três parcelas, a **ambiente**, a **difusa** e a **especular**. Os motores modernos usam modelos fisicamente baseados (PBR), mas as ideias são as mesmas.

## Os vetores num ponto da superfície

- **N:** a normal (perpendicular à superfície).
- **L:** a direção do ponto para a luz.
- **V:** a direção do ponto para a câmara.
- **R:** a reflexão de L em relação a N: R = 2(N·L)N − L.

Todos normalizados (comprimento 1), para que os produtos internos sejam cossenos.

## As três parcelas

1. **Ambiente:** uma luz constante, que imita a luz que vem de todo o lado (ressaltos indiretos). Sem ela, o que não é iluminado fica completamente preto.
2. **Difusa (Lambert):** kd · max(0, N·L). Uma superfície mate recebe mais luz quando está virada para a luz. Não depende da posição da câmara.
3. **Especular:** ks · max(0, R·V)ⁿ. O brilho de superfícies polidas, que depende de onde está a câmara. O expoente n controla o tamanho do brilho: alto (100+) para metais polidos, baixo (5–10) para plástico.

Cor = ambiente + difusa + especular (cada uma multiplicada pela cor da luz e do material).

**Blinn-Phong** (a variante mais usada): troca R·V por N·H, com H = normalize(L + V), o "vetor a meio". Mais barato e mais realista em ângulos rasantes.

## Uma esfera iluminada

```python run
import math

def normaliza(v):
    n = math.sqrt(sum(c * c for c in v)); return [c / n for c in v]
def ponto(a, b): return sum(x * y for x, y in zip(a, b))

def desenha(luz, brilho, largura=40, altura=20):
    L = normaliza(luz)
    V = [0, 0, 1]                                         # a câmara olha de frente
    rampa = " .:-=+*#%@"
    for y in range(altura):
        linha = ""
        for x in range(largura):
            u = (x + 0.5) / largura * 2 - 1
            v = 1 - (y + 0.5) / altura * 2
            if u * u + v * v > 1:
                linha += " "; continue
            N = [u, v, math.sqrt(1 - u * u - v * v)]       # normal de uma esfera de raio 1
            ambiente = 0.1
            difusa = 0.6 * max(0, ponto(N, L))
            H = normaliza([L[i] + V[i] for i in range(3)])
            especular = 0.5 * max(0, ponto(N, H)) ** brilho
            i = min(1, ambiente + difusa + especular)
            linha += rampa[min(9, int(i * 9.99))]
        print(linha)

desenha(luz=[-1, 1, 1], brilho=40)                       # luz em cima à esquerda, à frente
```

Prevê onde fica a zona mais clara e onde fica a sombra. Depois muda a luz para `[1, 0, 0.2]` (da direita, quase de lado) e `brilho` para 5.

## Sombreamento por face, por vértice, por píxel

- **Flat:** uma cor por triângulo. Barato, aspeto facetado.
- **Gouraud:** calcula a luz nos vértices e interpola a cor. Os brilhos especulares ficam mal (desaparecem se caírem no meio de um triângulo).
- **Phong (sombreamento):** interpola a **normal** e calcula a luz em cada píxel, no fragment shader. É o habitual hoje.

## Tipos de luz

- **Direcional** (o Sol): a mesma direção em toda a cena.
- **Pontual** (uma lâmpada): direção diferente em cada ponto e atenuação com a distância (≈ 1/d²).
- **Holofote** (*spot*): pontual, só dentro de um cone.

## Para lá de Phong

- **Sombras:** Phong não sabe se há objetos entre o ponto e a luz. Usam-se *shadow maps* (desenhar a cena do ponto de vista da luz e guardar a profundidade).
- **PBR** (*physically based rendering*): parâmetros com significado físico (metalicidade, rugosidade), conservação de energia. É o `MeshStandardMaterial` do Three.js e o padrão do Unreal, Unity e Blender.
- **Iluminação global:** a luz que ressalta de umas superfícies para outras (*ray tracing*, lição 7).
