A rasterização (lição 3) pergunta "que píxeis cobre este triângulo?". O **ray tracing** pergunta o contrário: "para cada píxel, o que vê um raio de luz que parte do olho e passa por ele?". É mais lento, mas sombras, reflexos e refrações saem naturalmente, porque se segue o caminho da luz. É usado em cinema e, desde 2018, em tempo real nos jogos, com hardware dedicado.

## O algoritmo

Para cada píxel:

1. Lança um **raio** do olho, através do píxel: P(t) = O + t·D (origem O, direção D).
2. Encontra a **primeira interseção** com os objetos da cena (o menor t positivo).
3. No ponto atingido, calcula a cor:
   - para cada luz, lança um **raio de sombra** até ela; se bater em algo antes, o ponto está na sombra;
   - se o material é espelhado, lança um **raio refletido** e soma a cor que ele encontrar (recursivamente);
   - se é transparente, um **raio refratado** (lei de Snell).

## Interseção raio-esfera

Uma esfera de centro C e raio r: |P − C|² = r². Substituindo P(t) = O + tD, dá uma equação do 2.º grau em t:

(D·D)t² + 2D·(O − C)t + (O − C)·(O − C) − r² = 0

Se o discriminante for negativo, o raio falha a esfera; senão, a menor raiz positiva é o ponto atingido.

## Um ray tracer em texto

```python run
import math

def sub(a, b): return [a[i] - b[i] for i in range(3)]
def soma(a, b): return [a[i] + b[i] for i in range(3)]
def esc(a, k): return [x * k for x in a]
def dot(a, b): return sum(a[i] * b[i] for i in range(3))
def norm(a): n = math.sqrt(dot(a, a)); return esc(a, 1 / n)

esferas = [  # centro, raio, refletividade
    ([0, -1, 5], 1.0, 0.0),
    ([2, 0, 6], 1.0, 0.5),
    ([-2, 0, 6], 1.0, 0.0),
    ([0, -5001, 0], 5000, 0.2),       # o chão: uma esfera enorme
]
luz = [-3, 5, 1]

def intersecao(O, D):
    melhor = (math.inf, None)
    for c, r, refl in esferas:
        oc = sub(O, c)
        b = 2 * dot(D, oc); cc = dot(oc, oc) - r * r
        disc = b * b - 4 * cc
        if disc >= 0:
            t = (-b - math.sqrt(disc)) / 2
            if 1e-4 < t < melhor[0]:
                melhor = (t, (c, r, refl))
    return melhor

def cor(O, D, profundidade=2):
    t, esfera = intersecao(O, D)
    if esfera is None:
        return 0.05                                  # céu
    c, r, refl = esfera
    P = soma(O, esc(D, t)); N = norm(sub(P, c)); L = norm(sub(luz, P))
    na_sombra = intersecao(P, L)[1] is not None
    i = 0.1 + (0 if na_sombra else 0.9 * max(0, dot(N, L)))
    if refl > 0 and profundidade > 0:
        R = sub(D, esc(N, 2 * dot(D, N)))
        i = (1 - refl) * i + refl * cor(P, R, profundidade - 1)
    return i

rampa = " .:-=+*#%@"
for y in range(18):
    linha = ""
    for x in range(48):
        D = norm([(x - 24) / 24, (9 - y) / 18 * 1.1, 1])
        linha += rampa[min(9, int(cor([0, 0, 0], D) * 9.99))]
    print(linha)
```

## Porque é caro

Uma imagem Full HD tem 2 milhões de píxeis; com reflexos, sombras e várias amostras por píxel, são centenas de milhões de raios, cada um testado contra milhões de triângulos. O que o torna possível:

- **Estruturas de aceleração** (BVH: hierarquias de caixas envolventes): em vez de testar todos os triângulos, testa-se uma árvore de caixas e só se desce onde o raio acerta. Passa de O(n) para O(log n) por raio.
- Hardware dedicado (os núcleos RT das placas recentes).
- **Redução de ruído** com redes neuronais: menos raios por píxel e uma imagem limpa no fim.

## Path tracing

O ray tracing clássico (Whitted, 1980) só segue reflexos perfeitos. O **path tracing** segue raios em direções aleatórias a cada ressalto e faz a média de muitas amostras (Monte Carlo): obtém iluminação global realista (a luz que ressalta de uma parede vermelha e tinge o chão). É o que usam o Blender Cycles e o cinema de animação.
