A lógica proposicional não consegue dizer "**todos** os números pares maiores que 2 são a soma de dois primos" nem "**existe** um caminho entre A e B". Para falar de objetos, das suas propriedades e relações, precisamos da **lógica de primeira ordem** (ou lógica de predicados). É a linguagem das especificações, das bases de dados (o SQL é lógica de primeira ordem disfarçada) e da inteligência artificial simbólica.

## Os ingredientes

- **Domínio**: o conjunto de objetos de que se fala (números, pessoas, ficheiros).
- **Constantes**: nomes de objetos concretos: `ana`, `0`.
- **Variáveis**: `x`, `y`, que percorrem o domínio.
- **Funções**: produzem objetos a partir de objetos: `pai(x)`, `x + 1`.
- **Predicados**: propriedades e relações, verdadeiras ou falsas: `Par(x)`, `Ama(x, y)`, `x < y`.
- **Quantificadores**:
  - ∀x A: "para todo o x, A";
  - ∃x A: "existe pelo menos um x tal que A".

## Traduzir frases

| Frase | Fórmula |
|---|---|
| Todos os alunos estudam | ∀x (Aluno(x) → Estuda(x)) |
| Algum aluno estuda | ∃x (Aluno(x) ∧ Estuda(x)) |
| Nenhum aluno copia | ∀x (Aluno(x) → ¬Copia(x)) |
| Toda a gente ama alguém | ∀x ∃y Ama(x, y) |
| Há alguém que todos amam | ∃y ∀x Ama(x, y) |
| Não há maior número natural | ¬∃x ∀y (y ≤ x) |

Duas regras práticas:

- com **∀**, o conectivo natural é **→** ("para todo o x, *se* é aluno *então*...");
- com **∃**, o conectivo natural é **∧** ("existe x que é aluno *e*...").

Trocar estes conectivos é o erro mais frequente: `∃x (Aluno(x) → Estuda(x))` é verdadeira só porque existe algo que não é aluno.

A **ordem dos quantificadores** importa: `∀x ∃y Ama(x, y)` (cada um ama alguém, possivelmente diferente) não é o mesmo que `∃y ∀x Ama(x, y)` (há uma pessoa amada por todos).

## Negar quantificadores

As leis de De Morgan para quantificadores:

- ¬∀x A ≡ ∃x ¬A ("nem todos estudam" = "algum não estuda")
- ¬∃x A ≡ ∀x ¬A ("ninguém copia" = "todos não copiam")

Negar `∀x (Aluno(x) → Estuda(x))`:

1. `∃x ¬(Aluno(x) → Estuda(x))`
2. `∃x ¬(¬Aluno(x) ∨ Estuda(x))`
3. `∃x (Aluno(x) ∧ ¬Estuda(x))`: há um aluno que não estuda.

## Variáveis livres e ligadas

Em `∀x (P(x) → Q(x, y))`, o `x` está **ligado** pelo quantificador e o `y` está **livre**. O valor de uma fórmula com variáveis livres depende do valor que lhes damos, tal como o resultado de uma função depende dos argumentos. Uma fórmula sem variáveis livres chama-se **frase** (ou fórmula fechada).

## Modelos

Uma **interpretação** (ou estrutura) fixa o domínio e o significado de cada constante, função e predicado. Uma frase é verdadeira ou falsa **numa interpretação**. Um **modelo** de uma frase é uma interpretação onde ela é verdadeira.

`∀x ∃y (x < y)`:

- é verdadeira nos naturais com o `<` habitual (há sempre um maior);
- é falsa no domínio {1, 2, 3} com o mesmo `<` (não há nada maior que 3).

Uma frase é **válida** quando é verdadeira em **todas** as interpretações, por exemplo `∀x P(x) → ∃x P(x)` (com domínio não vazio).

## Verificar em domínios finitos

Num domínio finito, ∀ é um `all` e ∃ é um `any`:

```python
alunos = {"ana", "rui", "bea"}
estuda = {"ana", "bea"}
ama = {("ana", "rui"), ("rui", "bea"), ("bea", "ana")}

todos_estudam = all(x in estuda for x in alunos)                     # False
algum_estuda = any(x in estuda for x in alunos)                      # True
todos_amam_alguem = all(any((x, y) in ama for y in alunos) for x in alunos)   # True
alguem_amado_por_todos = any(all((x, y) in ama for x in alunos) for y in alunos)  # False
```

É exatamente isto que uma base de dados faz ao responder a uma consulta. A consulta "alunos que tiveram positiva em todas as cadeiras" é um ∀ dentro de um ∃ e, em SQL, escreve-se com `NOT EXISTS ... NOT EXISTS`, aplicando as leis de negação acima.

## Para lá do decidível

Na lógica proposicional, basta testar as `2ⁿ` valorações para saber se uma fórmula é tautologia. Na de primeira ordem, os domínios podem ser infinitos, e **não existe nenhum algoritmo** que decida sempre se uma frase é válida (teorema de Church e Turing, 1936). Há procedimentos que confirmam as válidas, mas que podem correr para sempre com as que não o são. Vais ver o porquê em Teoria da Computação.

## Erros comuns

- Usar ∧ com ∀ ou → com ∃.
- Trocar a ordem dos quantificadores.
- Negar `∀x A` como `∀x ¬A` (o correto é `∃x ¬A`).
- Esquecer que a verdade de uma frase depende da interpretação.
