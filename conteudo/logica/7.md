Em quase todas as linguagens dizes ao computador **como** fazer. Em **Prolog** dizes **o que é verdade** e fazes perguntas; o motor de inferência descobre as respostas sozinho, usando unificação e procura com retrocesso. É a linguagem usada em Lógica para Programação no IST e é uma ótima forma de ver a lógica a funcionar.

## Preparar

Instala o **SWI-Prolog** (swi-prolog.org) ou usa o SWISH no browser. Escreves factos e regras num ficheiro `familia.pl`, carregas com `swipl familia.pl` e fazes perguntas no interpretador, que mostra `?-`.

## Factos

```prolog
progenitor(maria, joao).
progenitor(maria, ana).
progenitor(joao, rita).
progenitor(ana, tiago).
homem(joao).
homem(tiago).
mulher(maria).
mulher(ana).
mulher(rita).
```

Constantes começam por minúscula, variáveis por maiúscula. Cada facto termina em ponto.

## Perguntas

```prolog
?- progenitor(maria, joao).
true.

?- progenitor(maria, X).
X = joao ;
X = ana.

?- progenitor(X, rita).
X = joao.
```

O `;` pede a resposta seguinte. A mesma relação responde a perguntas "nos dois sentidos": quem são os filhos da Maria, e quem é progenitor da Rita. Numa função de Python terias de escrever duas funções.

## Regras

Uma regra `Cabeça :- Corpo.` lê-se "a cabeça é verdade **se** o corpo for verdade". A vírgula é o "e"; várias regras para a mesma cabeça funcionam como "ou".

```prolog
pai(X, Y) :- progenitor(X, Y), homem(X).
mae(X, Y) :- progenitor(X, Y), mulher(X).
avo(X, Z) :- progenitor(X, Y), progenitor(Y, Z).
irmaos(X, Y) :- progenitor(P, X), progenitor(P, Y), X \= Y.
```

Logicamente, a regra do avô é `∀X ∀Y ∀Z (progenitor(X, Y) ∧ progenitor(Y, Z) → avo(X, Z))`. Uma regra é uma cláusula com, no máximo, um literal positivo (uma **cláusula de Horn**), e é por isso que o Prolog consegue usar resolução de forma eficiente.

## Recursão

Antepassados a qualquer distância:

```prolog
antepassado(X, Y) :- progenitor(X, Y).
antepassado(X, Y) :- progenitor(X, Z), antepassado(Z, Y).
```

```prolog
?- antepassado(maria, tiago).
true.
```

Repara na ordem: o caso base vem primeiro e a chamada recursiva vem depois de `progenitor(X, Z)`. Se escrevesses `antepassado(X, Y) :- antepassado(Z, Y), progenitor(X, Z).`, o Prolog entraria em recursão infinita antes de testar qualquer facto.

## Como o Prolog responde

Para responder a `avo(maria, Q)`:

1. Procura uma cláusula cuja cabeça **unifique** com a pergunta: `avo(X, Z)` com `X = maria`, `Z = Q`.
2. O objetivo passa a ser o corpo: `progenitor(maria, Y), progenitor(Y, Q)`.
3. Resolve o primeiro objetivo: `Y = joao`. Depois o segundo: `progenitor(joao, Q)`, `Q = rita`. Encontrou uma resposta.
4. Se pedires mais (`;`), **retrocede** (*backtracking*) à última escolha: `Y = ana`, e encontra `Q = tiago`.

É uma procura em profundidade, da esquerda para a direita, de cima para baixo.

## Listas

```prolog
% [Cabeça | Cauda]
comprimento([], 0).
comprimento([_ | T], N) :- comprimento(T, N1), N is N1 + 1.

membro(X, [X | _]).
membro(X, [_ | T]) :- membro(X, T).

junta([], L, L).
junta([H | T], L, [H | R]) :- junta(T, L, R).
```

O `is` avalia aritmética: `N = N1 + 1` só unificaria com o termo `N1 + 1`, sem calcular nada.

E `junta` funciona em vários sentidos:

```prolog
?- junta([1, 2], [3], L).
L = [1, 2, 3].

?- junta(X, Y, [1, 2]).
X = [], Y = [1, 2] ;
X = [1], Y = [2] ;
X = [1, 2], Y = [].
```

## Resolver problemas por restrições

Com a biblioteca de restrições sobre inteiros, problemas de procura escrevem-se quase como no enunciado. O clássico SEND + MORE = MONEY:

```prolog
:- use_module(library(clpfd)).

puzzle([S,E,N,D] + [M,O,R,E] = [M,O,N,E,Y]) :-
    Vars = [S,E,N,D,M,O,R,Y], Vars ins 0..9, all_different(Vars),
    S #\= 0, M #\= 0,
    1000*S + 100*E + 10*N + D + 1000*M + 100*O + 10*R + E #=
    10000*M + 1000*O + 100*N + 10*E + Y,
    label(Vars).
```

```prolog
?- puzzle(P).
P = ([9,5,6,7]+[1,0,8,5]=[1,0,6,5,2]).
```

## Erros comuns

- Começar constantes por maiúscula: `progenitor(Maria, joao)` faz de `Maria` uma variável.
- Esquecer o ponto final.
- Usar `=` em vez de `is` para fazer contas.
- Recursão à esquerda (a chamada recursiva como primeiro objetivo), que dá ciclos infinitos.
