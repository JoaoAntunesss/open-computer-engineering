Para aplicar regras da lógica de primeira ordem automaticamente, um programa tem de responder a perguntas como: "a fórmula `Pai(x, ana)` e a fórmula `Pai(joao, y)` podem ser a mesma coisa?". Sim, se `x = joao` e `y = ana`. Encontrar estas substituições chama-se **unificação**, e é a operação central do Prolog, da inferência de tipos em Haskell e OCaml, e da resolução em primeira ordem.

## Termos e substituições

Um **termo** é uma constante (`ana`), uma variável (`X`) ou uma função aplicada a termos (`pai(X)`, `soma(1, Y)`). Nesta lição, como no Prolog, as variáveis começam por maiúscula.

Uma **substituição** troca variáveis por termos. Escreve-se `{X ↦ ana, Y ↦ pai(Z)}`. Aplicada a `ama(X, Y)`, dá `ama(ana, pai(Z))`.

Dois termos **unificam** se existe uma substituição que os torna iguais. Essa substituição chama-se **unificador**.

## Exemplos

| Termos | Unificam? | Unificador |
|---|---|---|
| `ama(X, rui)` e `ama(ana, Y)` | sim | {X ↦ ana, Y ↦ rui} |
| `f(X, X)` e `f(a, b)` | não | X não pode ser a e b ao mesmo tempo |
| `f(X, g(Y))` e `f(g(Z), X)` | sim | {X ↦ g(Y), Z ↦ Y} |
| `ama(X)` e `odeia(X)` | não | funções diferentes |
| `X` e `f(X)` | não | X teria de conter-se a si próprio |

O terceiro exemplo tem muitos unificadores (`{X ↦ g(a), Y ↦ a, Z ↦ a}` também serve), mas o mais útil é o **mais geral** (MGU, *most general unifier*): o que fixa o mínimo possível. Todos os outros obtêm-se dele por mais substituições.

## O algoritmo

Mantém uma lista de equações por resolver e aplica estas regras até a lista ficar vazia (sucesso) ou falhar:

1. `t = t`: apaga (já são iguais).
2. `f(s1..sn) = f(t1..tn)`: troca por `s1 = t1, ..., sn = tn`.
3. `f(...) = g(...)` com f ≠ g, ou aridades diferentes: **falha**.
4. `X = t` (ou `t = X`), com X variável:
   - se X aparece dentro de t (e t não é X): **falha** (*occurs check*);
   - senão, junta `X ↦ t` à solução e substitui X por t em todas as outras equações.

Em Python, representando variáveis como strings com maiúscula e termos compostos como tuplos `("f", arg1, arg2)`:

```python
def e_var(t):
    return isinstance(t, str) and t[:1].isupper()

def aplica(s, t):
    if e_var(t):
        return aplica(s, s[t]) if t in s else t
    if isinstance(t, tuple):
        return (t[0],) + tuple(aplica(s, a) for a in t[1:])
    return t

def ocorre(x, t, s):
    t = aplica(s, t)
    return t == x or (isinstance(t, tuple) and any(ocorre(x, a, s) for a in t[1:]))

def unifica(a, b, s=None):
    s = {} if s is None else s
    a, b = aplica(s, a), aplica(s, b)
    if a == b:
        return s
    if e_var(a):
        return None if ocorre(a, b, s) else {**s, a: b}
    if e_var(b):
        return unifica(b, a, s)
    if isinstance(a, tuple) and isinstance(b, tuple) and a[0] == b[0] and len(a) == len(b):
        for x, y in zip(a[1:], b[1:]):
            s = unifica(x, y, s)
            if s is None:
                return None
        return s
    return None

print(unifica(("ama", "X", "rui"), ("ama", "ana", "Y")))      # {'X': 'ana', 'Y': 'rui'}
print(unifica(("f", "X", "X"), ("f", "a", "b")))              # None
print(unifica("X", ("f", "X")))                               # None (occurs check)
```

## Onde vais encontrar isto

- **Prolog**: cada pergunta é respondida unificando-a com factos e cabeças de regras (próxima lição).
- **Inferência de tipos**: quando escreves `map (+1) xs` em Haskell, o compilador unifica `(a -> b) -> [a] -> [b]` com o tipo de `(+1)` para descobrir que `a = b = Int`. É o algoritmo de Hindley-Milner.
- **Resolução em primeira ordem**: duas cláusulas resolvem-se quando um literal de uma unifica com a negação de um literal da outra.
- **Pattern matching** em linguagens funcionais é um caso particular, em que só um dos lados tem variáveis.

## Erros comuns

- Esquecer o *occurs check*: `X = f(X)` não tem solução finita. Por razões de eficiência, o Prolog por omissão não o faz, e pode criar termos infinitos.
- Não aplicar a substituição acumulada antes de comparar os termos seguintes.
- Confundir unificação (os dois lados podem ter variáveis) com correspondência de padrões (só um lado tem).
